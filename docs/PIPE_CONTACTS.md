# v103 · 배관과 손의 접점

2026-10-31 (한국 시간)

v102는 오르기 스프라이트의 머리 잘림을 고쳤지만 손이 실제 배관을 잡는 위치를 맞추지 못했다. 배관은 짧은 관 끝으로 표시하고, 캐릭터는 어느 벽에서든 위를 향해 이동하던 문제가 남아 있었다.

배관의 세로 축·붙잡는 아래/위 지점·옥상 착지점을 분리했다. 관 그림과 이동 동작이 같은 축을 사용한다. 캐릭터는 배관이 붙은 벽을 향하고, 구운 이미지의 방향·프레임·복장별 두 손 좌표를 기준으로 그린다. 두 손은 관 축 가까이 모으고 위아래로 번갈아 뻗도록 조정했다. 접근→오르기→옥상 넘기, 역방향 내려오기를 구분했다. 기존 아래/옥상 착지 좌표와 층은 유지한다. 배관 이동 중 근처 상호작용 안내는 숨긴다.

기본 체형과 주인공 네 복장의 오르기 동작만 다시 구웠다. 그 외 동작의 이미지 픽셀은 v102와 동일함을 비교했다. 다른 벽 오르기·사다리 등의 이동 경로는 변경하지 않는다.

[전후 화면과 동작 단계](pipe-v103/index.html): 모바일 390×844·PC 1280×800에서 같은 정면 가스관과 옆벽 배관을 실제로 오르내려 촬영했다. 동작 길이가 달라 같은 진행 비율로 비교한다. 휴대전화 실기기 성능 검사는 아니다.

검증:

- `t_pipe_contacts.py`: 6개 의뢰 배관 32곳의 실제 왕복, 기존 착지점과 옥상 높이, 복장별 손 접점 검사. 모바일·PC 각각 19,400개 접점과 실제 그리기 호출 1,660개를 확인한다. 실제 그리기에서 구운 손의 중심이 관 축에 놓이는지 검사한다.

- `t_roof_routes.py`: 연결 통로와 옥탑문 실제 키보드·터치 접근.
