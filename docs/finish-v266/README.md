# v266 · 내려놓기, 공간의 역할, 수색 분담

제압을 마친 상대가 무릎 꿇은 자세에서 팔을 벌린 시체로 바뀌던 전환을 수정했다. 기존 CC0 캐릭터 리그·팔레트·64px 규격으로 31개 체형/복장의 8방향 끝동작 시트를 추가했다. 총 5,640프레임이며, 새 파일은 `build/pr/body_*EndMotion.webp`, 원본 생성기는 `tools/prerender/bake_takedown_end.py`다. 모델 출처와 라이선스는 기존 `tools/prerender/characters/sources.json`을 따른다. 런타임은 2D 이미지와 캔버스만 사용한다.

- 무릎이 꺾인 뒤 몸을 받쳐 내려놓고 손을 뗀다. 두 사람 동작과 독립된 몸 그림이 같은 최종 자세·그리기 좌표를 사용한다. 몸 선택 영역도 새 자세의 실제 외곽을 따른다. 벽 때문에 몸 위치를 조정하면 끝동작에도 같은 보정을 적용한다.
- 같은 공격 입력을 1초 누른 경우에만 살해된다. 살해 판정 뒤 별도 0.16초 마무리 동작을 재생하며, 이 구간의 중복 몸 표시와 이동에 의한 동작 잘림을 막는다. 짧은 제압의 0.84초 이동 재개는 유지한다.
- 벽부등은 실제 벽 법선에 따라 측면 폭과 깊이, 반대편의 높이를 투영한다. 기존 회로·광원 위치·손이 닿는 상호작용 지점은 유지한다. 별도 스위치를 추가하지 않는다.
- 정산실의 회의 탁자, 접수 카운터, 접견실에 구매 에셋의 소품·게시판·바닥 구역을 배치했다. 정산실 구석 화분과 배차실 구석 정수기만 기존 가구 충돌을 추가한다. 계단·하단 창문·단말기 오른쪽 접근로를 유지한다. 탁자 위 소품은 기존 가구 그림·조명 수신에 포함되고 별도 충돌/목표를 만들지 않는다.
- 전달된 신고를 받은 경비는 현장, 여러 출입구, 계단 확인을 분담한다. 실제로 배정받은 역할을 대사와 기존 수색 표시로 설명한다. 숨은 플레이어 좌표를 수색 지점에 사용하지 않는다. 경비 수·감지 거리·보고 범위를 늘리지 않는다.
- 기술 트리의 원형 노드·3개 분야·27개 기술·습득 규칙을 유지한다. 화면 높이에 맞춰 행 간격과 여백을 계산하며 버튼은 최소 44px를 유지한다. 짧은 화면에는 스크롤을 남긴다. 세로 모바일 브리핑 지도는 원본 비율에 맞춰 여백을 줄이고 표적 글씨를 키운다.

## 검증과 범위

`tests/rev/t_finish_review.py`는 새 5,640프레임의 빈 그림/잘림, 제압 전후 동일한 몸 좌표, 탭/길게 누르기 구분, 별도 마무리, 수색 분담/숨은 좌표 독립성, PC·세로 모바일 기술 노드 영역을 검사한다. 기존 제압 리듬, 접근/운반/변장 입력, 전투 정책, 암살 기술, 이벤트 피드백, 9개 의뢰 수색·출구, 16개 업무 접근점과 5개 통로, 내부 아트, 회로/물리적 조명 복구, 5개 화면 크기 UI 검사를 통과했다. 조명 회로 검사는 없어진 별도 스위치 대신 실제 벽부등 접근과 전체 행동 시간을 사용하도록 갱신했다. Node 물리 검사도 실제 공유 전투 시간표를 읽는다.

정상 RAF와 실제 AI를 사용한 별도 플레이:

- PC/터치: 첫 에피소드 시작부터 기절·변장·몸 숨기기·2층 서류 회수·탈출·다음 의뢰 진입까지 완료. 체력 3, 발각 0.
- PC/터치: 연습 스테이지의 접근→제압→예약 운반→풀숲 숨기기. 입력에 의한 실제 이동이며 몸/아이템/체력/AI 덮어쓰기 없음.
- PC: 첫 의뢰에서 실제 발각 후 문·두 모서리를 지나 풀숲으로 도주하고 10초 수색 관찰. 체력 3. 현재 서쪽 문과 벽을 돌아가는 실제 경로를 네이티브 재현 스크립트에도 반영했다. 첫 의뢰의 이 경로 검증이며 전체 추격 난이도 평가가 아님.
- PC/터치: 금고 따기와 배차 단말기·기습 기회. 이 검사는 플레이어 위치·복장과 이미 회수한 송장 상태를 배치한 구간 재현이다. NPC·카메라·체력·시계는 변경하지 않으며 전체 미션 완주를 뜻하지 않는다.

Node 물리 20개 그룹, 빌드 8개 검사, 패키지 13개 브라우저 해시와 PC/터치 시작 검사도 통과했다. 스크린샷의 방과 모션 비교는 고정 배치/시간을 쓰는 렌더 검수이며 네이티브 플레이 기록과 구분한다. 이미지에는 새 끝동작을 알아보기 쉽게 확대한 실제 2D 렌더러의 두 방향이 포함된다.
