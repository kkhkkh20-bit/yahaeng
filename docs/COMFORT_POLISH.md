# v100 보조창·입력·정보 표시 개선

2026-10-31. [PC·가로/세로 모바일 전후 화면](comfort-v100/index.html).

## 발견한 문제와 수정

| 문제 | 수정 |
| --- | --- |
| 가로 모바일의 비밀번호 창이 약 410px 높이여서 320/390px 화면에서 아래가 잘림 | 높이가 낮은 화면은 안내/숫자판을 좌우로 배치해 비교 장면에서 약 229px에 담는다. 닫기·확인·숫자는 최소 44px 터치 높이를 확보한다. |
| 비밀번호 오류 알림이 창 밖에 뜨고, 키보드 포커스가 뒤의 HUD로 빠질 수 있음 | 오류·경고음 증가·잠금 해제를 창 안에 표시한다. Tab/Shift+Tab은 숫자판 안에서 순환한다. 숫자 입력·버튼·키보드 확인을 지원하고, 마지막 자리 자동 확인과 실제 문 잠금 해제를 유지한다. |
| 대화 중 F로 조준, M으로 전술 지도가 열릴 수 있음 | 대화 진행 키와 음소거 외의 게임 입력을 차단한다. 조준 함수 자체도 메뉴·대화·키패드를 확인한다. |
| 일시정지·지도·대화·키패드 전환 때 키/조이스틱/투척 조준/길게 누르기가 남음 | 입력 전환에서 누름 상태를 비운다. 탄약을 쓰지 않고 조준을 취소한다. 이미 시작된 제압 애니메이션은 이어가며, 이전 누름이 기절 대상을 처치로 바꾸지 않게 한다. 실패·재시작·체크포인트 복귀 때 키패드와 선택창도 정리한다. |
| 미니맵이 벽 뒤에서 ALERT 상태인 적, 같은 층 번호의 다른 높이 적까지 표시함 | 일반 적은 같은 실내 층·옥상 높이에서 거리와 실제 시선이 닿을 때만 표시한다. 표적은 기존의 활동 구역·마지막 목격·관찰 정보 규칙으로 표시한다. 실제 NPC의 수색·추격 동작은 이 표시 수정의 대상이 아니다. |
| 대상 목록의 버튼이 테두리 밖으로 넘치고, 같은 이름의 조명을 구분하기 어려움 | 상자 크기 계산을 맞추고 같은 동사에는 방향·거리만 보탠다. 선택과 실행은 별개다. 중앙 상태·미니맵·캐릭터·행동 버튼을 피하며, 자리가 좁으면 목록 폭을 줄인다. 지도·키패드·대화 중에는 선택창을 닫는다. |
| 종이색 테마의 설정 설명은 어두운 박스 위에 어두운 글자였고, 일부 버튼 호버 대비도 낮음 | 설명 박스·제목·선택/호버 버튼을 같은 종이·먹 팔레트로 맞춘다. 소리·밝기에 현재 %와 접근성 값을 표시하고 저장 후 복원한다. |
| 의뢰 기록에 ‘최고 최고 S’처럼 중복 표시됨 | ‘최고 S’로 정리한다. |

비밀번호 창·대상 목록은 잉크 시안의 공통 패널 재질에 맞췄다. 실제 플레이는 실시간으로 계속된다. 기본 실행에도 입력·정보·반응형 동작 수정을 함께 반영했다.

## 검증

- `t_comfort_polish.py`: 320×480, 390×480, 320×568, 390×844, 568×320, 844×390, 1280×800에서 기본/잉크 모드 총 14개 화면 조합. 실제 키보드·포인터 입력, 코드 문 오입력/해제, 버튼 경계·크기, 포커스 순환, 입력 취소와 탄약 유지, 미니맵의 실제 벽/층/높이, 중복 대상의 방향 안내, 목록 겹침·가로 넘침, 설정 대비·저장, 등급 문구를 확인한다. PC에서는 실제 제압 시작→일시정지→이어 하기 후 애니메이션이 기절로 마무리되는지도 확인한다.
- `t_combat_policy`: 키보드·터치의 짧게 기절/길게 처치, 붙잡기와 끌어들여 제압, 처치 입력의 연속성.
- `t_interaction_flow`: 실제 물건 조작·환복·선택 고정·이동·15개 환풍구 왕복과 동작 완료.
- `t_play_clarity`: 실제 시야·상호작용 선택·도움말 기록·접촉 시점·체크포인트 복원.
- `t_dialogue_proportions`: 12개 화면/테마 조합의 대화 크기·스크롤·실제 터치/키보드 진행.
- `t_controls_readability`, `t_product_plan`: 상단 메뉴·삭제된 입력·행동 안내·연습, 변장·표적 정보·준비 저장·VIP 행동과 선택창 회귀 검사.

전후 이미지는 브라우저에서 같은 상태를 배치해 촬영했다. 대상 목록은 구별 가능한지 확인하기 위해 두 조명을 배치한 통제 장면이다. 실제 휴대전화의 성능 측정이나 모든 의뢰의 사람 플레이를 의미하지 않는다.
