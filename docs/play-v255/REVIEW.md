# v255 플레이 흐름 검토와 개선

가장 큰 문제는 효과의 양보다 목표를 달성하는 방법과 동선이었다. 중반의 카드키·서류 왕복은 선택이 적었고, 배차를 멈춰도 표적의 행동에는 영향이 없었다. 숙소 금고 앞은 가구가 실제 통로를 막고 있었다. 기존 도구와 행동으로 다른 공략을 만들 수 있는 부분부터 수정했다.

## 즉시 고친 문제

| 발견 | 수정 | 기대 효과 | 비용 / 우선순위 |
|---|---|---|---|
| 돈줄 숙소 2층의 금고와 침대가 출입문 안쪽 길을 막음 | 금고를 남쪽 벽으로 이동. 가구 패치와 고정 배치를 함께 수정하고 기존 저장의 미회수 물품 위치 갱신 | 정상적인 계단 → 문 → 금고 접근 | 낮음 / 최우선 |
| 중개인이 한 자리에 고정돼 창문·조명·카메라 공략 뒤의 관찰이 의미가 약함 | 보고 자리와 장부 책상을 오가는 일정. 통화·장부 동작도 해당 일정에 맞춤 | 등을 보일 때 움직이는 짧은 매복 기회 | 낮음 / 높음 |
| 계약서 확보가 항상 같은 카드키 왕복 | 카드키는 2.2초·조용한 방법, 락픽 2개는 5.5초·소리가 나는 방법. 중단하면 도구를 소비하지 않음 | 시간을 쓸지 도구와 위험을 감수할지 선택 | 낮음 / 높음 |
| 배차 중단은 목표 수치만 바뀌고 보스의 행동과 연결되지 않음 | 관리자가 실제 단말로 이동해 확인 → 무전 → 보스가 계단으로 올라와 단말을 확인 → 원래 동선 복귀 | 서류를 먼저 챙긴 뒤 표적을 원하는 장소로 부르는 공략 | 중간 / 높음 |

## 사건의 원인과 결과

- **금고:** 행동 입력 → 도구·방법 확인 → 작업 게이지와 작업음 → 완료 때만 락픽 2개 소비 → 계약서 회수와 사용량을 한 알림으로 표시 → 이동 재개. 기존 게이지·획득 효과를 재사용한다.
- **배차:** 단말 작업 → 단말 중단 → 관리자의 현장 확인 → 1.6초 무전 전달 → 보스가 지상에서 2층으로 실제 이동 → 단말을 바라보는 14초의 기회 → 기존 일정 복귀. 관리자를 전달 전에 제압하면 호출도 중단된다. 전달 후 제압은 이미 전달한 정보를 지우지 않는다.
- **표적 관찰:** 멈춰 통화·장부 확인 → 이동과 회전 → 다음 자리에서 다른 방향을 봄. 일반 이동에 추가 화면 흔들림이나 확대를 넣지 않았다.

업무 때문에 단말을 확인하는 보스를 ‘수색 중’으로 표시하지 않고 ‘배차 확인’으로 표시한다. 실제 플레이어 발견은 기존 노랑 물음표·빨강 경계 판정을 따른다. 이 호출은 플레이어의 위치나 복장을 다른 적에게 알리지 않는다. 순간이동이나 적 추가로 긴장감을 만들지 않는다.

## 전체 9개 에피소드 점검

| 맵 | 현재 역할 | 이번 판단 |
|---|---|---|
| 닫힌 배차실 tB | 제압·변장·숨기기·2층 서류·탈출 | 초반 루프 유지. 새 저장 PC 완주로 기본 흐름 확인 |
| 닫힌 철문 p0 | 첫 표적과 층 이동 | 기존 첫 암살 유지 |
| e2 | 창문·옥상 연결·카메라·중개인 | 이동하는 표적과 조명 사용으로 마지막 접근 개선 |
| m2 | VIP의 여러 접근 경로와 문서 | 흡연 동선 공략을 직접 완주. 새 목표 추가 대신 유지 |
| 돈줄 m4 | 두 표적과 숙소·사무실 문서 | 막힌 통로 수정, 금고에 도구를 쓰는 우회 추가 |
| m6 | 감금 공간에서 장비·서류 회수 | 구조와 목표 접근성 유지·검사 |
| m7 | 배차 중단과 운송 보스 | 단말 → 사람 → 무전 → 보스 방문으로 연결 |
| m5 | 본거지 침투와 간부 | 기존 접근 선택 유지·검사 |
| n1 | 저택과 최종 표적 일정 | 기존 클라이맥스 유지·검사 |

전 맵을 같은 구조로 다시 만들거나 기존 에피소드를 삭제하지 않았다. 구조 검사는 9개 공개 맵의 실제 상호작용 가능한 위치까지의 길을 확인한다. 문을 연 상태로 하는 검사이므로 열쇠 획득 순서나 전투 난이도까지 증명하지는 않는다.

## 유지 / 통합 / 제외

- **유지:** 기존 작업 게이지·작업음·획득 효과·암살 입력·NPC 계단 이동·표적 동작·단말 조사 AI. 구매 배경 에셋과 캐릭터를 바꾸지 않는다.
- **통합:** 금고의 카드키와 락픽 접근을 기존 물품 작업 하나로 처리. 배차 호출도 기존 조사·계단 이동 AI를 사용. 획득과 도구 사용량은 알림 하나로 표시한다.
- **제외:** 단말 조작 직후 자동 보스 소환, 원격 플레이어 위치 공유, 업무 방문을 위협 수색으로 보이게 하는 표시, 일반 행동의 추가 줌·화면 흔들림·중복 알림.

## 검증과 한계

- **PC·브라우저 터치 전체 e2 완주:** 일반 프레임, 원래 경비 4명과 카메라 활성. 창문 → 옥상 건너기 → 계단 → 조명 끄기 → 카메라 처리 → 이동 표적 암살 → 서류 → 탈출. 각각 약 118초 / 133초, 체력 3, 발견 0. 위치·시간·목표·도구·스킬 덮어쓰기 없이 진행했다. 지도와 좌표를 아는 개발자 경로이므로 초보자 테스트는 아니다.
- **금고 접근 PC·터치:** 실제 지상 계단에서 올라가 문을 지나 금고 작업 완료, 카드 없이 락픽 2개 소비. 위치·변장은 시작 조건이며 원래 적 31명은 활성 상태다.
- **배차 호출 PC·터치:** 실제 관리자 확인과 무전, 보스의 층간 이동, 후방 암살, 출구 개방 확인. 시작 위치·복장·선행 명세서 회수 상태를 지정한 개별 상황 검사이며 전체 임무 완주가 아니다. 원래 적 9명은 활성 상태다.
- **통제 검사:** 두 중개인 정차 위치, 통화·장부 동작, 옛 저장 갱신, 금고 작업 중단·비용·키 우선 사용, 무전 전 제압, 무전 후 정보 유지, 실제 보스 계단 이동 통과.
- **구조 검사:** 공개 9개 맵의 목표 접근성 통과. 별도로 NPC를 정지한 기존 7개 맵 × 배치 3개 × PC·모바일의 42개 임무 경로 완주 통과. 후자는 순찰 회피나 재미를 증명하는 검사가 아니다.
- 변장 보고, 벽 기습·맨홀, 수색·탈출, 계약 안내·밀도, 임무 진행, 통로 가구, 표적 개성, 현장 HUD, 보안 표시, 층간 카메라 표현과 빌드 회귀 검사를 통과했다.

`native-episode3.json`, `native-encounters.json`, `native-safe-access.json`, `objective-access.json`, `opportunities.json`에 결과를 남겼다. `review-baseline.json`은 수정 전 v254에서 확인한 첫 에피소드와 VIP 완주 기록이다. 모든 에피소드를 이번에 실제 적과 함께 연속 완주했다고 주장하지 않는다. 브라우저 터치 검사는 실기기 iOS 검사가 아니다.

## 다음에 다듬을 부분

1. **즉시 효과가 큰 것:** 막힌 금고 통로 수정과 업무 방문 표시 수정 — 적용 완료.
2. **적은 비용으로 공략이 달라지는 것:** 이동 중개인, 도구와 카드키의 교환 관계, 단말로 표적 유인 — 적용 완료.
3. **이후 검토:** 지도를 모르는 사람의 연속 플레이에서 길 찾기 시간·라디오 이해·실패 후 재시도 시간을 측정하고, 후반 전체 임무의 실제 순찰 난이도를 조정한다. 추가 효과나 콘텐츠보다 이 검증을 먼저 한다.
