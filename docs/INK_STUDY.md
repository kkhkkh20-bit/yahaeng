# 메인 포스터와 연결하는 잉크 누아르 시안

2026-10-31. [실제 플레이·PC/모바일 비교](ink-study/index.html).

v97에서 시작해 v99의 대화창 비율과 v98의 조작 정리를 반영한 선택형 미술 시안이다. 메인 포스터를 기준으로 메뉴·의뢰·대화·플레이·결과를 연결했다. `?tone=ink` 또는 시안 전용 HTML에서만 켠다. 기본 실행과 별도로 검토하며, 다른 공간의 전면적인 미술 개편은 이 범위에 포함하지 않았다.

## 방향

| 역할 | 기준 |
| --- | --- |
| 종이 | `#eee4cf` · 메인·메뉴·브리핑·대화의 바탕 |
| 먹 | `#171817` · 큰 제목·선·플레이 중 패널 |
| 주홍 | `#b73528` · 시작·선택·완료의 강조 |
| 경고 | 기존 노랑·빨강 역할 유지, 글자·게이지와 함께 표시 |
| 정보 | 본문·보조 글자 대비 4.5:1 이상으로 검사한 주요 브리핑 항목 |

색 외에 패널 외곽선·모서리·제목 굵기·바닥 재질·공간 명판을 바꿨다. 메뉴는 상단 오른쪽으로 옮기고 살피기는 제거했다. 공격·행동·붙잡기 버튼과 미니맵·중앙 은신 표시의 배치는 기존 기준을 사용한다. 터치 버튼은 원형 입력 영역을 유지한다.

## 바뀐 화면

- 메인: 기존 포스터와 로고를 그대로 기준으로 사용한다.
- 의뢰 선택·브리핑·결과: 종이색 바탕, 먹색 제목·구분선과 주홍 선택 버튼. 밝은 바탕에서 사라지던 제목·탭·보조 문구·결과 버튼의 대비를 보정했다. 기존 정보·도전·기록·이어 하기 동작은 유지한다.
- 제목: 기존 메인 로고 글꼴은 ‘야행’ 두 글자만 가진 전용 서브셋이다. 동일한 Black Han Sans의 제목용 서브셋을 별도로 묶어 의뢰·결과의 글자 굵기가 다른 기본 글꼴로 바뀌지 않게 했다.
- 플레이: 청회색 반투명 판 대신 먹색 면과 따뜻한 종이색 글자를 사용한다. 미니맵의 바탕·벽·도로도 같은 중립색 계열로 맞추며 표적·경고·플레이어 색 역할은 유지한다. 은신·위험·발각 단계는 그대로 구별한다.
- 대화: 생성한 잉크 초상은 제외하고 이전 인게임 모델의 초상을 다시 사용한다. 얼굴은 대화 패널 안에 작게 붙인다. 행동 중 비필수 무전은 기다렸다가 보여주고, 주변 말풍선은 행동 안내와 인물·조작 버튼을 피한다.
- VIP 클럽: 파스텔 체크 바닥을 줄눈·마모·금속 테두리가 있는 어두운 타일로 교체했다. 크기·통행·가구 위치는 그대로다. 색 조명의 RGB 표현과 어둠의 색조만 조정하며 밝기 판정·광원 위치·반경·켜짐 상태는 유지한다. 의뢰 선택의 VIP 지도도 새 재질로 다시 만들었다.
- 공간 표시: VIP 문과 바 카운터에 작은 실제 명판을 붙였다. 이 클럽의 큰 바닥 방 이름을 생략하고, 중복 구역 이름은 전술 지도에서 보게 했다. 가까운 경계의 출입 안내·실제 경계선·상단 층 안내는 유지한다. 음악의 큰 분홍 파동은 전술 지도에서 확인하며, 실제 음악 은폐 판정은 동일하다.
- 인물: 기존 주인공 모델과 논리적 외형 키는 유지하고 기본 옷의 푸른 기운만 따뜻한 먹색 계열로 조정한다. 변장 복장의 색·출입 권한은 바꾸지 않는다.

## 자산

새 자산은 VIP 지도 약 31KiB, 제목 글꼴 약 30KiB다. v97 시안의 생성 초상 아틀라스와 로더는 v98에서 제거했다. 포스터·인게임 모델 자체를 다시 제작하지 않았다.

글꼴 원본: [Google Fonts Black Han Sans](https://github.com/google/fonts/tree/main/ofl/blackhansans), SIL OFL 1.1. 기존 [OFL 파일](../src/fonts/OFL-BlackHanSans.txt)을 함께 둔다. 제목 서브셋은 ASCII·현재 의뢰 이름·대표 화면 제목을 포함한다. 새로운 제목을 추가할 때 필요한 글자도 확인해야 한다.

## 검증

- `t_ink_study.py`: 기본/시안 두 모드를 같은 난수 조건으로 시작한다. PC·터치 각각 6개 의뢰의 지도·문·계단·가구·조명 값과 밝기 표본·플레이어/표적 위치·목표가 같은지 비교한다. 기본/시안 두 모드의 주요 조작 버튼 사각형이 같음을 확인한다. 세 인물의 초상이 서로 다르고, 제목 글꼴이 실제 제목을 포함하며, 브리핑 주요 문구 대비와 대화창 내부 초상 배치가 유지됨을 검사한다.
- 시안 모드의 기존 검사 9종 통과: `t_presentation`, `t_play_clarity`, `t_combat_policy`, `t_product_plan`, `t_building_search`, `t_scene_layers`, `t_stair_geometry`, `t_interaction_flow`, `t_mob`.
- PC 1280×800·터치 390×844에서 메인→선택→브리핑→플레이→대화→결과를 촬영했다. 플레이 비교는 동일한 인물·플레이어·카메라 배치다. 결과 화면은 레이아웃 검사용 상태이며 실제 완주 결과가 아니다. 실제 휴대전화 성능 검사는 아니다.

## 파일

`src/ink-study.css`: 선택형 UI 규칙. `01_ink_study.js`: 시안 활성화·타일·명판·조명 표현. `build.py`: 선택형 자산과 스타일을 단일 HTML에 포함한다. 기본 실행에는 시안 클래스를 붙이지 않는다. v98의 조작·가독성 변경은 기본 실행과 시안·itch ZIP에 함께 반영했다.
