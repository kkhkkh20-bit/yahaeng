# 주인공 모션과 상호작용 v191

기존 주인공의 얼굴·체형·복장과 2D 게임을 유지한다. 같은 CC0 Quaternius 리그의 자세를 오프라인에서 다시 촬영해 중간 프레임을 만들었다. 게임에서는 기존 Canvas 스프라이트만 재생하며 3D 런타임을 추가하지 않는다.

| 동작 | v190 | v191 |
|---|---:|---:|
| 걷기 / 달리기 / 웅크려 걷기 | 각각 8 | 각각 16 |
| 평상시 서기 / 웅크려 서기 | 2 / 1 | 12 / 8 |
| 운반 걸음 / 포로 끌기 / 상자 운반 | 8 / 6 / 8 | 16 / 12 / 16 |
| 일반 타격 | 4 | 12 |
| 암살 / 당하는 상대 | 각각 10 | 각각 25 |
| 일반 쓰러짐 반응 | 6 | 16 |

| 벽타기 / 매달림 / 벽 옆걸음 | 각각 4 | 각각 16 |

| 보행 정지 | 즉시 대기 자세 | 보행 위상별 7프레임 정리 |

네 가지 주인공 복장과 성별·체형에 맞는 상대 반응을 포함한다. 반복 동작의 정지 구간에는 의도적으로 같은 픽셀이 이어질 수 있으며, 걷기·달리기·웅크려 걷기와 암살 양측은 실제로 서로 다른 중간 실루엣을 사용한다.

걷기·달리기·웅크리기 사이에 보행 위상을 유지한다. 발을 움직인 거리로 시계를 진행하며 일시정지와 제자리 재그리기로 발이 더 움직이지 않는다. 걷기 1초, 달리기 0.64초, 웅크리기 1.24초 주기는 기존 발소리 간격과 맞춘다. 이동 속도, 발소리의 범위·위장 규칙, 암살의 접촉·판정 시점과 기술 비용은 바꾸지 않는다. 모션 때문에 배우의 실제 좌표를 옮기거나 반투명 인물을 겹쳐 그리지 않는다.

옷 갈아입기는 낮게 집기→일어서기→양쪽 어깨·옷매무새→손 거두기를 연결한다. 손 작업은 뻗기→작업 반복→놓기로 구분하며 기존 손잡이·접근·접촉 판정을 유지한다. 기절자 착지의 PixelFX 먼지는 착지 시점에만 한 번 재생하고, 제압 접촉의 먼지는 손을 가리지 않도록 작게 한다. 기존 PixelFX MIT 아틀라스를 재사용한다.

새 아틀라스는 역할별로 나누고 필요할 때 읽는다. 메뉴에서는 기존 hero·heroMotion만 읽으며, 임무 전환 시 필요 없는 NPC 모션은 해제한다. 새 모션이 아직 읽히지 않았으면 기존 자세를 그린다. 변장 복장이 읽히는 동안에도 주인공 체형과 복장 팔레트를 유지한다. 넓은 시트를 조각별로 채색하는 기존 캐시도 유지한다.

촬영 칸에 머리·팔이 닿는 자세는 촬영 여백을 다시 계산하고 배율·손 접점 정보를 함께 기록한다. 게임 속 체격을 줄여 잘림을 숨기지 않는다. 새 8방향 18,944프레임의 비어 있음·잘림을 검사했다.

- GIF는 움직임이 보이도록 화면을 잘라 확대했다. 실제 입력 기록과 시간은 같은 폴더의 JSON에 있다. 초보자 사용성 연구나 실물 iPhone 검증은 아니다.

- PC VIP: 표적·장부·남동쪽 숙소 암호표·탈출 완료, 체력 3·플레이어 발각 0·CCTV 촬영 0. 시신 발견 경보 1회가 있어 무경보 공략은 아니다. 기술 UI에서 의뢰 전 2P와 완료 후 4P를 정상 사용했다.

## 검증과 재생성

핵심 회귀 86개와 빌드 파이프라인 8개, 스프라이트 소유권 검사, 물리 상호작용 상태 전이 20개 그룹을 통과했다. 새 검사 `t_hero_fluid_motion.py`는 실제 실루엣·25프레임 양측 진행·반복 이음새·냉각 캐시 대체 자세·자세 전환·보행 위상·정지 중 재그리기·17개 배관 손 접점을 확인한다. 기존 제압·연속 입력·모바일·사물 조작 검사도 통과했다.

추가로 실행한 구형 `t_storage_motion.py`는 의식 있는 포로를 곧바로 수거함에 넣는 제거된 행동을 요구해 v190에서도 같은 위치에서 실패한다. 해당 행동을 되살리지 않았다. 현재의 기절→운반→숨기기는 `t_physical_interactions.py`, `t_mobile_flow.py` 및 실제 입력 재생으로 검증했다.

```sh
python tools/prerender/bake_fluid_motion.py
python build.py
python tools/package_cloudflare_2d.py build/yahaeng_city.html
# YH_TEST_HTTP=1에는 절대경로 PYTHONPATH를 사용한다.
PYTHONPATH="$PWD/tests/support:$PWD/tests/tutorial" YH_TEST_HTTP=1 python tools/run_tests.py --fast --quick --no-build
python tools/capture_hero_motion.py --out build/hero-motion-v191/round-2 --round 2
```

`tools/prerender`의 고정된 Three 빌드 도구와 기존 모델을 사용한다. PixelFX는 `.agents/skills/pixelfx/SKILL.md`의 렌더→검토→수정 절차와 기존 베이크 결과를 사용한다. 라이선스와 원본 출처는 기존 `tools/prerender/characters/sources.json`, `src/art/fx/LICENSE.txt`에 유지한다.
