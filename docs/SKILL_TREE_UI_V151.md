# v151 원형 기술 트리

사용자가 제공한 Assassin's Creed 기술 화면의 원형 배지·금색 해금 상태·실제 선행 연결과, 관리 게임의 분리된 목록/상세 구조를 현재 야행의 기술 화면에 적용했다. 기존 신체 8개·암살 9개·도구 10개와 포인트·선행 조건·저장·장비 지급·튜토리얼 임시 기술 규칙은 유지한다.

[실제 PC·모바일 화면](skills-v151/index.html) · [선택·구매·연결 검사](skills-v151/diagram-checks.json).

## 화면과 조작

- PC에서는 세 계열의 연결도를 함께 보고 오른쪽에서 선택한 기술의 효과·사용 방법·선행 조건·비용을 확인한다. 작은 화면에서는 계열 탭으로 바꾼다.
- 배운 기술은 금색 바탕, 배울 수 있는 기술은 금색 선, 선행 기술이 없는 기술은 자물쇠로 표시한다. 선택은 별도의 바깥 테두리다. 배운 적 없는 기술을 ‘장착 중’으로 강조하지 않는다.
- 원형 노드를 누르는 행동은 설명만 바꾼다. 실제 구매는 상세 영역의 배우기 버튼으로 구분한다. 포인트 부족·미충족 선행 조건을 확인한 뒤 원래 구매 함수를 호출한다.
- 선행 기술 이름을 누르면 해당 노드로 이동한다. 노드에서 방향키로 이동할 수 있고 Tab·Enter·Escape를 사용한다. 포인트 재배분과 현재 사용 가능한 암살 기술 장착도 유지한다.
- 27개의 원형 아이콘과 게임 데이터의 실제 24개 선행 연결을 그린다. 여러 행을 건너뛰는 선은 다른 원형 노드를 관통하지 않도록 옆으로 우회한다. 이미지 참고 화면의 3/3 강화 표시는 현재 단일 해금 규칙에 맞지 않아 추가하지 않는다.

## 모바일·표현 비용

세로 휴대폰에서는 위쪽 기술 연결도와 아래쪽 설명을 각각 스크롤한다. 가로 화면은 연결도/설명을 나란히 둔다. 낮은 화면(높이 700px 이하)에서는 설명과 구매 영역을 확보하려고 상황 안내 그림을 숨긴다. 돌아가기와 구매 영역은 화면 안에 남는다. 원형 버튼과 주요 조작은 44px 이상이다.

상세 그림은 기존 캐시된 게임 스프라이트로 그린 **정지 상황 안내**다. 실제 전투 영상이나 작동하는 별도 시뮬레이션이라고 표시하지 않는다. 선택할 때만 그리며 연속 프레임 루프나 신규 이미지 다운로드를 추가하지 않는다. 아이콘은 일관된 선 굵기의 직접 작성한 SVG다. 별도 UI 라이브러리나 아이콘 패키지는 설치하지 않는다.

`83_skill_visuals.js`가 기호와 정지 안내를, `84_skill_menu.js`가 선택·설명·연결·키보드·장착 표시를 담당한다. 새 모듈을 소유권 manifest에 등록했다. `template.html`과 `hud.css`의 기술 화면 부분을 교체하며 게임 화면과 3D 실험판은 수정하지 않는다.

## 검증

빠른 회귀 46개와 빌드 소유권 6개, 전 의뢰 도달 검사를 통과했다. 최종 분할 패키지도 HTML·버전·4개 스크립트 해시와 PC·터치 입력을 확인했다.

1440×900, 390×844, 844×390, 320×568에서 렌더링과 가로 넘침, 44px 조작 영역, 스크롤과 돌아가기를 확인했다. 노드 선택이 포인트를 소비하지 않는지, 실제 구매와 부족한 포인트, 선행 기술 이동, 방향키, 재배분과 기존 암살 기술 장착을 검사한다. 장비·전기·암살 기술 연습도 PC와 터치로 확인한다.

독립 검수는 스크린샷 5개와 코드에서 **ship / 중요한 발견 없음**을 반환했다. 기능 검증은 별도 브라우저 검사 결과에 근거하며, 독립 검수자가 직접 기기 조작까지 확인한 것으로 쓰지 않는다. [검수 범위](skills-v151/design-review.json).

기존 Impeccable 스킬을 사용했다. 기계 검출기의 6개 발견은 변경하지 않은 설정 화면의 기존 작은 글자/간격 항목이며 기술 화면 항목은 없었다. 요청 범위 밖의 설정 화면은 변경하지 않았다. 실물 휴대폰 FPS 측정은 아니다.
