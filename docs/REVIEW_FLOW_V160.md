# v160 · 학습 순서와 본편 첫 행동 재검토

초보자가 연습을 끝낸 뒤 본편의 첫 행동을 정할 수 있는지, 순서와 잘못된 입력에 초점을 맞춘 후속 검토다.

- 계단 연습이 계단을 필수로 쓰는 의뢰02보다 뒤에 있었다. 조명→실내·계단→의뢰02 순서로 옮긴다. 의뢰03의 감방은 기존 머리핀→문 안내로 시작하고, 이미 배운 층 이동을 재사용한다.
- 먼저 웅크린 채 이동하면 달리기 단계의 안내·강조가 현재 자세와 맞지 않았다. 일어서기부터 안내하고, 걷기 고정이 켜져 있다면 그 해제도 먼저 안내한다. 자동으로 자세를 바꾸지 않는다.
- 의뢰02 자동 목표가 가까운 잠긴 VIP룸을 먼저 가리킬 수 있었다. 브리핑에 공개된 카드키 경로를 실제 완료·문 잠금·회수 상태에 맞춰 한 단계씩 안내한다. 수동 목표·선택 단서·몸 운반 안내는 유지하고, 감지하지 못한 적의 실제 위치를 공개하지 않는다.

## Direction contract

모바일의 그늘·풀숲 접근→가까운 제압→몸 정리 액션을 유지한다. 기존 야간 마을, Plex Sans KR Regular400, 현재 HUD와 조작 위치를 상속하는 좁은 개선이다. 새 패널 대신 기존 목표 한 줄과 조작 강조를 사용한다. 기존 원본과 같은 진입/입력 조건을 비교하고, 잘못된 자세에서 복구와 실제 계단·회수·본편 연결을 PC/터치로 확인한다. 별도 승인 이미지 시안이나 새 시각 체계·래스터 자산은 없다. unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance. 상속 확장이므로 새 PRODUCT.md/DESIGN.md 작성은 해당하지 않는다.

## 확인 결과

핵심 회귀55개·빌드 검사7개·도달 검사가 통과했다. 최종 문구를 다듬은 뒤 배포 패키지에서 PC·터치 기초 연습18행동, 준비 임무14행동을 각각 다시 완료했다. 조명→계단→의뢰02는 실제 결과 버튼으로 이어지고, 의뢰03 시작은 장부에서 직접 선택해 머리핀을 실제로 줍는 검사다. 본편 전체 완주는 주장하지 않는다.

별도의 진행 상태 통제 검사에서 수금원의 미관측 이동이 안내 좌표에 새지 않는지, 수동 목표·선택 단서가 유지되는지, 카드키/문/회수 상태별 다음 행동, 다른 진입로로 이미 문을 열거나 열쇠를 얻었을 때의 생략, 몸 운반·탈출 우선순위를 확인했다. 이는 실제 본편 전체 플레이가 아니다.

전후 비교는 v159와 v160의 같은 시드·화면·입력 원본32장이다. 다음 버튼의 목적지 비교만 강제 완료한 결과 상태이며, 실제 연습 완주와 구분한다. 신규 사용자 이해도 조사·실물 휴대폰 성능 측정은 하지 않았다. 기존 포인트·기술·감지·적 난이도·맵 구조는 유지한다.

독립 검수는 네 크기 비교16장과 실제 조작6장을 확인해 ship으로 판정했다. 같은 자세의 버튼 이름, 계단 학습 순서, 본편 자동 안내와 수동 선택을 확인했다. [검수 기록](review-v160/finish-review.json).
