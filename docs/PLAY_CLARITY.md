# v97 · 진행 화면의 정보와 행동 정리

2026-10-31. [PC·모바일 전후 화면](play-clarity/index.html).

VIP 의뢰로 먼저 장면을 확인하고, 공통 UI와 주요 의뢰 세 곳의 공간 표시에 적용했다. 조작 버튼·우측 미니맵·중앙 은신 표시의 위치는 유지한다. 새 이미지 에셋은 추가하지 않았다.

## 목표와 알림

- 진행 중 HUD는 현재 목표 한 줄을 기본으로 표시한다. 목표 영역을 누르거나 키보드로 초점을 맞춰 Enter/Space를 누르면 기존 전체 목록을 볼 수 있다. 일시정지의 목표 고정·정보·기회도 유지한다.
- 지도 위에는 화살표·표식과 거리·층·입구·목격 정보만 남긴다. 긴 목표 문장은 상단에서 읽는다. 추격 중 은신처로 바뀌는 화살표에는 `은신처`를 남겨 의뢰 목표와 구분한다. 층을 옮기는 경로는 실제 다음 연결의 목적 층을 사용하고, 잠긴 문은 따로 표시한다. 중앙 은신 패널 아래로 화살표 여백을 확보했다.
- 시작 4.5초/10초 뒤 자동으로 뜨던 의뢰 도움말을 제거했다. 처음 만난 행동의 도움말은 한 번에 한 장, 의뢰당 최대 3개다. 2초 이상 실제 표시된 항목은 프로필에 기억한다. 전투·행동·대화·메뉴·급한 알림이 시작되면 도움말을 숨기며 나중에 오래된 설명을 재생하지 않는다. 차단되거나 2초 미만으로 끊긴 도움말은 읽었다고 저장하지 않는다.
- 공격·붙잡기·심문처럼 행동 패널에 직접 설명하는 항목은 별도의 도움말을 띄우지 않는다. 수동 조작 안내는 그대로 이용할 수 있다.
- 일반 알림은 기록을 유지하면서 화면에는 긴급도와 최근 발생 순서로 한 건만 표시한다. 급한 경고가 있는 동안 덜 중요한 완료 안내가 화면을 차지하지 않는다.

## 사람과의 선택

- 공격·붙잡기·열쇠 훔치기를 한 패널에 모았다. 붙잡은 뒤에는 심문 / 기절 / 은신처 찾기 또는 끌고 가기를 함께 보여 준다.
- 화면과 HUD·말풍선·발견 표시를 피해 패널을 배치한다. 키는 방향키 모드 Z/C/X, WASD 모드 Space/Q/E, 터치는 기존 버튼 이름에 대응한다. 패널 자체는 입력을 가로채지 않는다.
- 사용할 수 없는 선택은 어둡게 표시하고 거리·방향·정예·경계/교전 조건을 설명한다. 심문할 수 없는 사람과 이미 심문한 사람을 구분한다.
- 은신처로 끌고 가는 행동은 기존대로 짧게 기절·길게 처치한다. 이동만 하는 행동으로 오해하지 않게 `끌고 가 기절`과 `길게 처치`를 함께 표시한다. 공격의 짧게 기절·길게 처치 규칙도 유지한다.
- 일반 기절 대상의 선택 고리는 중립색이다. 사람 머리 위에 공격·붙잡기·금지 이유를 따로 겹쳐 띄우지 않는다. 전술 지도와 대화 중에는 실행할 수 없는 행동 안내를 생략한다.

## 주시·의심·발각

주시/얼굴 확인은 흰색, 의심·수색은 노란색, 현재 플레이어를 확인한 추격은 빨간색으로 구분한다. 놓친 적이 아직 내부적으로 ALERT여도 현재 시야가 없으면 수색 색을 사용한다. 마지막 목격 지점도 수색 표시로 남긴다.

얼굴을 알아보는 경비와 민간인 직원은 일반 침입 시야와 다른 판정을 쓴다. 그 실제 얼굴 확인 여부를 UI에 연결했다. 확인 중 눈 고리와 발견 삼각형을 중복 표시하지 않고, 확인이 끝나기 전에는 고리를 빨갛게 만들지 않는다. 실제 시야가 없는 다른 층·높이의 잔상, 죽은 적, 놓친 적의 수치는 현재 탐지 경고음과 중앙 위험 게이지를 채우지 않는다. 창가나 옥상에서 실제로 플레이어를 본 경우에는 관측한 플레이어 층·높이를 확인해 경고를 유지한다. 얼굴 확인 여부의 임시 필드는 체크포인트 복구 시 초기화한다. 기존 탐지 거리·시간·변장 허용 판정은 바꾸지 않는다.

## 공간과 접촉

기존 문 좌표·방향으로 문턱 선을 표시했다. 주요 의뢰의 가까운 실내 계단에는 실제 `stairFloor()`의 오르기/내려가기 표식 위치에 방향과 도착 층 명판을 그린다. 옥탑의 열린 문·발판과 층 단면은 기존 자산을 재사용한다. 충돌이나 입구 위치를 새 그림에 맞춰 옮기지 않았다.

문·조명·물건의 실제 접촉/상태 변경 시점과 적을 붙잡는 접촉 순간에만 짧은 확인 고리를 그린다. 입력 직후나 취소된 동작, 이미 다른 인물이 변경한 스위치에는 성공 표시가 나오지 않는다. 기존 접촉 효과음의 시점은 유지한다. 임시 확인 고리는 저장에서 복구하지 않는다.

## VIP 경로에서 발견한 보정

실제 NPC 검사 중 경호원이 화장실 밖 대기로 전환한 뒤에도 이전 경로를 잠깐 더 따라가는 경우를 찾았다. 지정 대기 위치 쪽 입구 한 칸 전부터 대기로 전환하고, 대기/추종 전환 시 이전 경로를 취소한다. 순간 이동 없이 원래 이동·충돌로 밖에서 대기한다.

## 검증

- 신규 `t_play_clarity.py`: 실제 클릭·키보드로 전체 목표 펼치기/접기, 주시·의심·발각·놓침과 층/높이/민간인 얼굴 확인, 실제 붙잡기 이후 선택과 심문 완료, 끌고 가기의 기절/처치 문구, 도움말 재시작/페이지 재로딩 간 기억과 알림 중단, 실제 스위치 접촉·취소·저장 복구, VIP 대기 전환의 옛 경로 취소를 PC/터치에서 확인한다.
- 기존 회귀 11종: `t_presentation`, `t_combat_policy`, `t_copy_scenarios`, `t_interaction_flow`, `t_product_plan`, `t_hanging_controls`, `t_mob`, `t_building_search`, `t_disguise_ai`, `t_scene_layers`, `t_stair_geometry`. 기존 문장 하나였던 은신처 안내 검사는 같은 정보를 나누어 표시하는 새 패널에 맞췄으며 키 입력·짧게 기절·매달리기 검증은 유지했다.
- `t_vip_routes`: NPC를 실제로 움직이는 약·간판·뒷문 경로의 PC/터치 장면 12개 통과. 재현을 위한 시작 위치·장비 배치를 사용한다.
- `t_mission_flow`: PC/모바일, 배치 3종의 6개 의뢰 전체 이동·목표·탈출 경로 36개 통과. 이 검사는 NPC를 정지시킨다.
- 비교는 1280×800과 터치 390×844의 브라우저 화면이다. 실제 휴대전화 성능 검사는 아니다.
