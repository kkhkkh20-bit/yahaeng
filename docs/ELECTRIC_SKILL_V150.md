# v150 전기 조작 기술

조명을 끄는 행동을 기본 능력에서 빼고, 도구 계열 **현장 장비 → 전기 조작 1P**로 해금한다. 전기 조작은 조명 스위치 켜기·끄기, 건물 분전반 차단, 구역 조명 전원 차단에 적용된다. 신체 8개·암살 9개·도구 10개로 총 27개이며 전체 비용은 43P다.

## 실제 동작

배우기 전에도 근처 스위치와 전원함은 대상 목록에 남는다. 행동 버튼은 **전기 조작 필요**를 표시하며 실행 가능 강조를 하지 않는다. 누르면 기술 트리에서 배우도록 안내한다. 여러 대상 중 다른 시설을 선택하는 기존 조작은 유지한다.

직접 실행·물체 작업 시작·실제 접촉·전원 차단 함수에서 소유권을 재검사한다. 예전 체크포인트의 미완료 스위치 작업도 기술이 없으면 접촉 시 취소한다. 이미 꺼져 있던 조명이나 완료된 정전은 저장 결과를 유지한다. 새로운 기술을 기존 플레이어에게 자동 지급하지 않으며, 기존 기술·포인트·선행 조건은 보존한다.

기술은 전기 시설을 조작할 자격을 연다. 거리·층·벽·물체 접촉 시간은 기존 규칙을 사용한다. 조명을 끄는 모습을 목격한 경비의 항의와 실제 이동 후 복구도 유지한다. 경비의 복구는 플레이어의 기술 소유권에 의존하지 않는다. 아궁이는 전기가 아닌 불이므로 기존 기본 행동으로 남긴다.

## 튜토리얼

**연습 1 · 시야와 소리**에서 전기 조작만 기본으로 임시 지급한다. 직접 스위치를 눌러 불을 끄고, 빛과 실제 적 시야가 줄어든 길을 통과한다. 안내에 ‘연습용이며 의뢰에서는 전기 조작을 배워야 한다’를 적었다. 다트와 은신 기습은 자동 지급하지 않는다. 다음 기초 연습과 본편으로 이 기술이 영구 해금되지 않는다. 연습 중 기술 트리에서 고른 추가 기술 역시 연습 안에서만 적용한다.

## 검증

빠른 회귀 45개를 검증했다. 기존 대상 선택·정전 경로의 두 검사는 무료 전기 조작을 가정하던 조건을 배운 기술 조건으로 고친 뒤 재실행해 통과했다. 빌드 소유권 6개와 전 의뢰 도달 검사도 통과했다. [검사별 결과](skills-v150/validation.json).

새 판정 검사는 미해금 상태의 스위치·건물·구역 차단, 실제 구매 후 접촉에 따른 켜기·끄기, 미완료 체크포인트 취소, 경비의 실제 스위치 작업과 건물 복구, 연습용 기술의 유출 방지를 확인한다.

PC와 터치의 UI 검사는 실제 의뢰의 스위치 앞에 플레이어를 배치하고 경비를 제거한 통제 조건에서 잠긴 행동 → K 기술 트리 → 현장 장비·전기 조작 구매 → 실제 행동 입력으로 끄기·켜기를 확인한다. 위치를 바꾸지 않는 완주 검사는 별도로 시야·소리 기초 연습 전체를 실제 이동과 입력으로 진행한다. 실제 입력 검증은 실물 휴대폰 FPS 측정이 아니다.
