야행 · HUD와 현장 장비

공격과 행동에 집중하도록 모바일 기본 버튼을 8개에서 6개로 줄였습니다. 상황별 붙잡기·갈아입기는 필요한 때만 나타납니다. 장비는 하나의 패널에서 고르고, 선택 중에는 시간이 멈춥니다.

동일한 시드·좌표·화면 크기로 촬영한 실제 게임 원본입니다. 이미지 보정·합성은 없습니다. 비교 장면은 본편 완주 증거가 아닙니다.
