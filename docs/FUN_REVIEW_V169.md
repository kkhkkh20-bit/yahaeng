# v169 반복 플레이와 재도전 개선

첫 의뢰는 준비 행동 사이의 안내가 끊겼고, 실패한 실험을 다시 시도하는 데 오래 걸렸다. 두 번째 의뢰는 첫 교전까지 우회 이동이 길었다. 이번 변경은 기존 Graphite HUD와 모바일 전용 조작 구성을 유지하면서, 발견한 경로를 선택하고 실패 뒤 다시 시도하기 쉽게 만든다.

## 반영 내용

- PC F9와 일시정지 메뉴의 체크포인트 재시도. 저장되지 않은 상태에서는 나타나지 않으며, 어려움 난이도의 저장 제한을 유지한다. 감옥 탈출과 안전한 상층 진입도 준비 진행으로 저장한다. 기술 포인트나 장비를 지급하지 않는다.
- 기본 단서 표시에서도 새로 발견한 기회를 알린다. 전투 중에는 알림을 미루고 수동 목표를 바꾸지 않는다. 펼친 목표창에서 발견한 경로를 직접 선택할 수 있다. 선택 뒤 숨겨진 버튼에 포커스가 남아 이동을 막던 현상도 수정했다.
- 클럽 공중화장실에 직원 옷을 두어 민간인을 해치지 않고 구토제 경로를 시작할 수 있게 했다. 약을 넣은 뒤 바 옆에서 발각되며 기다리는 대신 화장실로 이동하도록 안내한다. 실장의 대기 위치와 방향을 조정하고, 문을 닫는 단계를 안내한다.
- 대청소 시작점을 동쪽 큰길로 옮겼다. 창고에도 사무동 출입번호 쪽지를 추가해 현금 회수 뒤 북서쪽까지 되돌아갈 필요를 줄였다. 자동 안내는 가까운 미확인 쪽지를 고른다.
- 감옥 출구에 실제 시야를 가리는 적재물을 추가했다. 간수와 서쪽 사무실 경비에게 동시에 노출되던 구간을 분리한다. 적의 계단 추격과 수색 능력은 유지한다.
- 다른 층의 물체 때문에 현재 층의 상호작용 실패 설명이 잘못 나오는 경우를 수정했다.

## 플레이 방법과 확인 범위

Playwright 키보드 및 CDP 터치 입력으로 실행했다. 재현 가능한 진행을 위해 시뮬레이션 시간을 나누어 진행했으며, 사람의 실시간 플레이 평가는 아니다. 캠페인 플레이에서는 위치·체력·인벤토리·기술·목표 달성 상태를 덮어쓰지 않았다. 회귀 검사의 제어된 상태 설정은 별도 테스트다.

- 클럽: 경비 제압, 옷 갈아입기, 몸 숨기기, 비밀번호, 카메라 전선 분리, 장부 회수, 내선 호출, 실장 처치와 탈출을 PC·모바일에서 검증한다. 기술 구입과 다트를 사용하지 않는다. 재현 스크립트는 `tests/tutorial/contract_intro_walk.py`다.
- 구토제 대체 경로: 약 획득, 목표창에서 경로 선택, 놓인 옷 갈아입기, 술병에 약 넣기, 화장실 도착과 실장 처치까지 실행했다. 발각과 창문 탈출 입력 문제가 남았으므로 이 대체 경로의 무발각 완주를 검증했다고 보지 않는다.
- 대청소: 변경한 시작점에서 수금원과 경호원을 만나는 시간을 줄였는지 확인했다. 의뢰 전체 완주 검증은 하지 않았다.
- 감옥: 감방 잠금 해제, 복도 통과, 간수 복장, 압수품 회수, 경비실 보안 해제까지 실행했다. 상층 전투와 전체 탈출은 검증을 마치지 않았다. 실제 F9 입력으로 손상된 상태에서 저장 시점으로 복귀하는 것도 확인했다.

## 검사

작업 중 핵심 회귀 묶음 66개, 빌드 파이프라인, 스프라이트 소유권, 도달 검사가 통과했다. 최종 빌드에서 `t_replay_loop.py`, `t_contract_guidance.py`, 배포 패키지의 PC·터치 입력 및 파일 해시를 다시 확인했다. PC·모바일 첫 의뢰 완주는 별도 네이티브 입력 시나리오로 확인한다.

회귀 검사 `t_replay_loop.py`는 재시도 복원, 포인트 보존, 알림 중복·전투 지연·표시 끄기, 수동 목표 보존, 안전 구간 저장, 단서 선택 후 이동 복귀를 검사한다.

확장 진단 중 기존 `t_rendezvous.py`와 `t_restaurant_route.py`의 목표 우선순위 기대값은 통과하지 않았고, 3D 전용 `t_club_study.py`는 해당 전용 빌드를 실행하지 않은 상태에서 실패했다. 이 결과를 이번 핵심 검사 통과에 포함하지 않는다.

## 남은 개선점

이동하는 적에 대한 다트 조준과 주변 민간인 선택, 대체 암살 뒤 안전한 탈출, 상층 경계선의 가독성은 추가 플레이가 필요하다. 이번 변경으로 재미가 입증되었다고 주장하지 않는다. 플레이어가 경로를 이해하고 실패한 실험을 빠르게 다시 시도할 수 있도록 한 단계 개선한 것이다.
