# v238 — 버튼 위치와 한글 간판

플레이: https://yahaeng.kkhkkh-20.workers.dev/?study=agent-city&v=238

- 주 행동 84px(작은 화면 80px)을 오른쪽 아래에 두고, 행동·웅크림·도구·붙잡기/옷 입기를 가까운 호 안에 배치했다. 상황 버튼이 나타나도 다른 버튼의 위치는 바뀌지 않는다.
- 보조 버튼은 48–60px, 선택 전환은 44px 이상을 유지한다. 320px 화면에서 빠른 아이템과 웅크림의 사각 터치 영역이 겹치지 않도록 분리했다. 원형 마감과 기존 Press/Release/Disabled 반응을 유지한다.
- 탄약/수량이 없는 선택 도구는 모바일 화면에서 숨긴다. 장비 메뉴에서 다른 도구를 선택할 수 있다. 휘파람·심문·조준 중인 도구는 유지하고, 수량이 있는 도구는 기존 위치에서 나타난다. 하단 소모품은 즉시 사용 방식을 유지한다.
- Dotonbori의 일본어·일본 상표 광고판 5종을 현재 게임 아틀라스와 스테이지 참조에서 제거했다. 글자가 없는 원본 철제 광고판 프레임에 백송상사·밤샘식당·청솔약국·음악실·선일전기·동진인쇄·종로서점·백야다방을 표시한다. 원본 외벽과 창문 위치, 문, 충돌 및 미션 진행은 유지한다.

[모바일 전후 비교](mobile-before-after.webp)는 390×844의 정상 시간 화면이다. [한글 간판](korean-signs.webp)은 렌더러 위치 고정 장면이다.

## 검증

- 320×480, 320×568, 390×640, 390×844, 568×320, 844×390에서 소모품 전체·빈 도구·탄약 있는 도구·시체/옷·휘파람과 상황 버튼의 30개 조합을 검사했다. 표시되는 사각 터치 영역이 겹치지 않고 화면 안에 있으며 최소 44px이다. PC에서 터치 조작부가 숨겨지는 것도 확인했다. [결과](layout-checks.json).
- PC·모바일·작은 모바일·가로 화면에서 실제 메뉴 입력으로 장비 열기/선택/닫기, 정지/재개, 휘파람과 상황별 의상 조작을 확인했다.
- 모바일 CDP 터치로 정상 시간과 AI를 유지한 채 기절 → 변장 → 운반/숨기기 → 문 열기 → 2층 표적 처치 → 기록 회수 → 탈출을 완료했다. 체력 3, 발각 0, 경보 0. 이미 경로를 아는 실행이다. [기록](native-mobile.json).
- 제거한 광고판 5종이 아틀라스에 없는지 검사했다. 창문 181개와 실제 판정, 계단 42개, 옥상 연결, 시안/본편 저장 분리 검사를 통과했다. [결과](study-checks.json).
- 빌드 검사 8개와 배포용 파일의 PC/모바일 기본 실행 및 조작 검사를 통과했다.

버튼 변경은 본편과 시안 공통이다. 간판 교체는 해당 광고판을 사용하던 도시 시안에 적용된다. 기존 본편 외관과 메인 화면 간판은 한글이며, 본편 진행을 바꾸지 않는다. 과거 비교 문서와 캡처는 이력으로 유지한다.

간판 프레임은 프로젝트 소유자가 구매한 GuttyKreum Dotonbori City v3의 빈 원본 프레임이다. 선별 좌표와 원본 SHA는 `src/art/city-study/details.json`, 재현 절차는 `tools/import_city_study.py`에 있다. 전체 구매 원본/ZIP/데모맵은 포함하지 않는다.
