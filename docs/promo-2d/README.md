# 기존 2D 게임 소개 자료

Cloudflare에서 공개 중인 기존 2D v128의 실제 브라우저 실행 화면을 촬영했다. 알려진 정상 경로를 입력 드라이버로 재생했으며, NPC·카메라 AI를 켠 상태로 목표 획득·변장·처치를 정상 행동 판정으로 진행했다. 스크린샷은 원래 게임 화면이며 생성 이미지나 가상 UI가 아니다.

외부 게시판에는 업로드하지 않았다. 게시물 제목·본문은 dc-post.txt에 제공한다. 게임 URL은 https://yahaeng.kkhkkh-20.workers.dev/ 이다.

영상은 조작과 상호작용 장면을 짧게 편집하고 이동·대기 구간을 덜어낸다. 원래 장면의 재생 속도를 유지한다. 출시 완료나 전체 미술 개편이 끝난 것으로 소개하지 않는다.
