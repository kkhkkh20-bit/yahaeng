# v200 · 처음부터 시작

제목 화면에 저장 진행이 있는 경우 `처음부터 시작`을 표시한다. 기존 이어서 시작 동작은 유지한다. 완료한 이야기뿐 아니라 배운 기술만 있거나 체크포인트만 남은 경우에도 다시 시작할 수 있다.

확인창은 에피소드·기술·체크포인트 초기화와 설정 유지를 설명한다. 취소에 기본 초점을 놓고 Tab/Shift+Tab은 창 안에서 이동한다. 취소나 Escape는 저장을 변경하지 않는다. 확인하면 캠페인 관련 키만 초기화하고 첫 연습 `tB`로 진입한다. 전역 저장소 초기화는 하지 않으며 음량·밝기·걷기 설정 등은 유지한다. 저장소가 삭제를 거부하면 읽어 둔 기존 값을 복구하고 오류를 표시한다.

`PYTHONPATH=tests/support:tests/tutorial YH_TEST_HTTP=1 python tests/rev/t_new_campaign.py`

1440×900, 390×844, 844×390, 320×568에서 실제 버튼·키보드·터치로 확인창, 취소, Escape, 초점 이동, 저장 삭제 실패 복구, 설정 유지, 첫 연습 재시작, 실제 이동, 새로고침 후 지속 및 전체 이야기 완료 상태를 검증한다. 저장 기록을 주입하는 것은 회귀 테스트용이며 실제 신규 사용자 조사는 아니다.
