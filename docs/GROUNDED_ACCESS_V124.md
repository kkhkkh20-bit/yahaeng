# v124 — 발을 고정한 여닫기와 연결 동작

쓰레기통 뚜껑에 손을 맞추는 보정이 몸 전체를 위로 당겨, 여닫는 중에도 뛰는 것처럼 보였다. 통에 들어가는 동작도 장애물 넘기 자세와 높은 포물선을 재사용하고 있었다.

[같은 장소의 전후 영상](access-v124/index.html)

## 변경

- 여닫는 동안 발 위치를 고정한다. 손을 맞추기 위해 몸 전체를 옮기는 보정과 닫을 때 등 돌리는 회전을 제거했다.
- 여성 주인공의 기본·정장·작업복·조직 복장에 쓰레기통 전용 여닫기 자세를 추가했다. 한 손으로 뚜껑을 들어 올리고, 역순으로 내려놓은 뒤 손을 거둔다. 기존 모델과 색을 사용했다.
- 들어갈 때는 뚜껑 열기와 몸 넣기를 나눈다. 재사용하던 점프 자세·포물선을 제거하고 지지하는 다리와 몸 숙이기를 연결했다.
- 나올 때는 몸 빼기 → 입구 앞에서 닫기 → 안전한 출구까지 걷기로 이어진다. 멀리 떨어진 출구에서 뚜껑에 손을 뻗지 않는다. 닫는 위치는 실제 이동 경로 길이와 통행 가능 여부로 고른다.
- 사물함·옷장·맨홀의 여닫기에도 발 고정과 연결을 적용했다. 시체를 넣거나 붙잡은 적과 들어갈 때에도 먼저 연다. 밖에 남는 수납·회수 동작에는 닫기 단계를 둔다.
- 일반 문은 서서 손을 뻗고 문짝이 경첩을 중심으로 움직인다. 손을 뻗은 뒤 통행 상태를 바꾸며, 기존 건물 외벽에 구워진 닫힌 문 그림도 실제 상태와 맞춘다. 일반 닫기 문구는 ‘문 닫기’로 정리했다.
- 맨홀·환풍구 출입에서 몸을 위로 튕기는 궤적을 제거했다. 별도의 배관 오르기·높은 곳 점프·낙하 동작은 그대로 사용한다.

추가 자세는 작은 2D 시트 네 장이다. 게임 실행 중 3D 계산을 추가하지 않는다. 처치의 길게 누르기 규칙과 기존 버튼 배치는 유지한다.

## 검증

[전체 검사 기록](access-v124/validation.json)

- 새 고정 자세 검사: PC·모바일 각각 4종 수납 × 4복장, 열기·닫기·걸어 나오기 각 16회, 여닫기 1,280표본. 발 위치·점프 상태·닫힌 뚜껑·단계 사이 순간 이동·최종 통행 위치를 확인했다.
- 기존 여섯 의뢰의 수납 206개 출입을 PC·모바일에서 확인했다. 시체 수납·적과 들어가기·기절/사망 대상 회수와 목표 물품·옷 복구도 통과했다.
- 환풍구·하수구·간판 접속, 창문 496개·층 이동 72개, 낙하·매달림 처치와 누르기 입력 회귀 검사를 통과했다. 새 시트를 포함한 인물 18,056프레임의 투명 여백·잘림도 검사했다.
- 문 조작의 점진적 열림·닫힘, 늦은 상태 적용, 작업 중 반복 입력과 완료 1회를 검사했다.
- 전체 AI·CCTV·피해를 켠 VIP 경로를 PC 191초·모바일 192초에 완료했다. 두 경우 체력 3·발각 0회. 컨트롤러는 맵을 알고 있으며 사람의 첫 플레이 평가는 아니다.
- 영상은 실제 게임 행동·렌더러를 사용한 동일 장소 비교다. 자세 확인을 위해 시작 위치를 맞추고 NPC를 제외했다.

## 남은 범위

손가락과 모든 방향의 손잡이를 실시간으로 정밀하게 맞추는 방식은 아니다. 이번에는 발을 띄우던 보정·점프 자세 재사용·멀리서 닫기·즉시 바뀌는 문짝을 수정했다. 전체 행동을 새로운 모션 캡처로 교체한 버전은 아니다.
