# v237 — 도시 구성과 모바일 시야

플레이: https://yahaeng.kkhkkh-20.workers.dev/?study=agent-city&v=237

## 구성 변경

- 첫 블록의 깊이를 줄이고 건물마다 앞뒤 경계와 높이를 달리했다. 내부 층과 계단, 옥상 및 육교의 실제 좌표도 함께 변경했다.
- 건물마다 반복되던 두 정면 입구를 한 개의 실제 계단 입구로 정리했다. 없어지는 문은 물리 지도에서도 창문 또는 벽으로 바뀐다. 입구 차양은 기존 구매 에셋이다. 나무 외벽의 원본 장식 문이 추가 출입구처럼 보이지 않도록 해당 지상 층은 원본 셔터 패널로 구성했다.
- 첫 블록 앞 보도를 연결하고 원본의 직선·모서리 연석을 도로 경계에 사용했다. 실외등은 실제 지지대와 스위치를 유지하면서 Dotonbori의 픽셀 기둥/전구를 사용한다. 점등 상태는 기존 회로와 연결된다.
- 외부 암부는 도로·차량의 윤곽이 읽히도록 조정했다. 실내 암부는 기존 수준을 유지하며, 광원은 같은 벽 차폐 마스크를 사용한다. 현관 조명 한 개를 실제 광원으로 추가했으므로 해당 입구의 밝기는 적 시야에도 반영된다.
- 옥상의 촘촘한 체크무늬를 같은 팩의 큰 슬래브 패턴으로 바꿨다. 창문의 따뜻한 색을 줄이고 꺼진 창의 푸른 색을 정돈했다. 높은 곳에서 도로 전체가 사라지던 어둠도 줄였다.
- 모바일 세로 화면은 기본 가시 폭을 약 8칸에서 10칸으로 넓히고 주인공의 세로 위치를 약 60%에서 46%로 옮겼다. 작은 화면에서는 실제 조작부와 HUD 경계 안으로 보정한다. 시안 확대 설정을 본편과 별도 저장한다.
- 요원은 v236 모델을 유지하고, 외곽선의 밝기를 줄여 배경과의 조화를 조정했다. 새 캐릭터 모델이나 새로운 모션을 제작한 작업은 아니다.

## 화면

[거리 전후 비교](street-before-after.webp)는 동일한 1440×900 렌더러 위치·배율의 장면이다. 촬영용 위치 고정 장면이며 임무 플레이 증거는 아니다.

[모바일 전후 비교](mobile-before-after.webp)는 390×844의 정상 시간 화면이다. 새 카메라 때문에 구도가 달라진다. [옥상과 육교](roof.webp)는 렌더러 위치 고정 장면이다.

## 검증

- PC 키보드와 모바일 CDP 터치로 실제 시간·AI를 유지한 채 기절 → 변장 → 운반/숨기기 → 문 열기 → 2층 표적 처치 → 기록 회수 → 탈출을 완료했다. 각각 체력 3, 발각 0, 경보 0. 이미 경로를 아는 플레이이므로 신규 사용자 테스트를 대신하지 않는다. [PC](native-pc.json), [모바일](native-mobile.json).
- 시작 위치만 옥상으로 설정한 뒤 실제 입력으로 육교 왕복과 계단 하강을 두 플랫폼에서 확인했다.
- 320×568, 390×844, 844×390, 1280×800에서 시작·현관 앞·육교 위치를 고정해 카메라와 플레이 영역을 검사했다. 캐릭터가 조작부에 가려지지 않고 시안 확대 설정이 본편 설정을 덮어쓰지 않는다. [결과](composition-checks.json).
- 정면 창문 181개와 실제 판정 일치, 건물별 정면 문 1개, 문 앞 장애물 없음, 옥상 연결, 층계 42개 및 저장 분리 검사를 통과했다. [결과](study-checks.json).
- 기존 본편 카메라 경계 144개, 터치 버튼 배치 6개 해상도/PC 숨김, 조명 명암/DPR 검사, 빌드 검사 8개, 물리 상호작용 검사 20개 그룹을 통과했다.

## 범위와 출처

이번 외관·카메라·명암 조정은 `study=agent-city` 도시 시안에 적용된다. 본편 전체의 맵 교체는 아니다. 본편 진행과 저장은 유지한다.

건물·차양·보도·가로등은 구매한 GuttyKreum Dotonbori City v3에서 선별한 원본 픽셀이다. 선별한 좌표와 SHA는 `src/art/city-study/details.json`에 기록했다. 전체 원본 타일맵, ZIP, 참고용 데모맵은 포함하지 않았다. v236의 Kenney CC0 차량과 Quaternius CC0 요원을 유지한다.
