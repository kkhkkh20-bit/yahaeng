# v101 설명과 옵션 정리

2026-10-31. [PC·모바일 전후 비교](editorial-v101/index.html).

## 참고한 실제 화면

[HITMAN 기본 상호작용](https://github.com/charc0al/HitmanCleanUI/blob/ea31cc73c1af16ffa6481882433e29b163916b59/smf/vanilla.webp), [NPC 상호작용 비교](https://github.com/charc0al/HitmanCleanUI/blob/ea31cc73c1af16ffa6481882433e29b163916b59/smf/npc_interaction.webp)를 다시 열람했다. 키·행동·대상을 짧게 구분하고, 가능한 행동을 찾는 데 필요한 단어를 남기는 기준으로 사용했다. 이 자료는 상호작용 화면이며 설정 화면 전체를 검토한 자료로 주장하지 않는다. 외부 그림·코드는 가져오지 않았다.

## 적용

| 영역 | 변경 |
| --- | --- |
| 플레이 | 자동 도움말 패널을 제거한다. 조작 설명은 연습과 조작 화면에서 확인한다. 반복 무전 중 조작 조언·칭찬·경고의 재설명은 줄인다. 시체 발견·핏자국 추적·민간인 피해는 짧게 알린다. 비밀번호·획득한 단서·긴급 경고·층과 위험 단계는 남긴다. |
| 상호작용 | ‘키·행동·대상’과 누르는 시간의 구분을 유지한다. 심문 뒤 ‘심문 완료·추가 정보 없음’, 근처 숨을 곳이 없을 때 ‘은신처 찾기·이동하며 찾기’는 표시하지 않는다. 실제 가까운 은신처와 실행 가능한 기절/처치는 계속 표시한다. |
| 의뢰·대화 | 주요 두 의뢰의 도입을 각 한 문장으로 줄인다. 이전 의뢰의 반복 조작 안내도 정리한다. 배신 의뢰의 서사 대화와 현장에서 얻는 정보는 유지한다. 브리핑의 반복 이탈 문장은 빼고, 상세 현장 정보와 추가 목표는 펼쳐서 확인한다. |
| 의뢰 목록 | 짧은 임무 요약을 사용하고 빈 별점은 제거한다. 획득 별·최고 등급은 남긴다. 재도전 조건은 클리어 후, 장비는 획득 후에 접힌 목록으로 표시한다. 미획득 장비와 ‘0/4’ 기록은 기본 목록을 채우지 않는다. |
| 설정 | 음량·밝기·전체 화면이 기본 항목이다. 확대/축소·프레임·음소거·순찰 동선·단서 수준은 고급 설정에 둔다. 조작은 기기에 맞는 짧은 키표/버튼표와 핵심 규칙 6개로 정리한다. 음소거 중에는 음량 행에 현재 상태를 표시하고 슬라이더를 올리면 해제한다. 기존 값과 재도전 조건은 그대로 저장·적용된다. |
| 결과 | 접근 방식·수고비·시간·발각 횟수까지 최대 4개 지표를 먼저 보여 준다. 정산 설명·칭호·나머지 통계와 경로는 상세 기록에 둔다. 지급액·등급·추가 조건의 판정과 기록은 유지한다. |

브라우저의 동일 초기 상태에서 설정의 기본 조작 항목은 9개에서 3개로 줄었다. 전체 화면 기능을 지원하지 않는 환경에서는 해당 버튼을 숨긴다. 첫 화면의 표시 글자는 PC 931→40자, 모바일 423→40자로 측정했다. 이는 해당 설정 화면의 `innerText` 측정이며 게임 전체 문구의 감소율을 의미하지 않는다.

- `t_quiet_editorial.py`: 320×568, 390×844, 844×390, 1280×800의 기본/잉크 모드 8개 조합. 기본 항목 수, 접힌 고급 설정·조작, 설정 저장과 음소거 해제, 실제 재도전 조건 적용, 장비 해금, 일반 무전 억제와 중요 알림, 실제 붙잡기·심문·정보 획득, 기절/처치 구분, 상세 통계와 정산 접근을 확인한다.
- `t_play_clarity.py`: 자동 도움말 제거와 완료 문구 정리에 맞춰 표시 기대값을 갱신했다. 실제 시야·선택·제압·접촉 시점·체크포인트 복원 검사도 통과한다.
- `t_ink_study.py`: 기본/잉크 모드의 6개 의뢰 지도·문·가구·조명·목표와 조작 영역이 같다. 주요 제목·본문 대비와 인게임 모델 초상도 검사한다.
- `t_combat_policy`, `t_product_plan`, `t_comfort_polish`: 실제 키보드/터치의 기절·처치·붙잡기, VIP 행동·정보·저장, 코드 문·화면 전환·대상 선택·설정 회귀 검사.

사진은 동일 상태를 배치한 브라우저 화면이다. 붙잡기·심문은 실제 동작을 실행했다. 결과는 레이아웃을 확인하기 위한 상태이며 실제 의뢰 완주 기록이 아니다. 실제 휴대전화의 성능 측정은 포함하지 않는다.
