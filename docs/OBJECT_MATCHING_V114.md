# v114 · 사물과 행동의 위치 맞추기

2026-11-01 · [화면 확인](surfaces-v114/index.html)

첫 의뢰 VIP의 약국·포차·공중화장실과, VIP·배신 의뢰의 메모를 정리했다. 전체 맵을 새로 제작한 변경은 아니다.

## 화면과 사물

- 모바일에서 숨겨졌던 현재 의뢰명을 기존 목표 칸 위에 표시한다. 예: `의뢰 01 · VIP`.
- VIP의 비밀번호 메모와 배신의 출입 메모를 실제 책상 위에 둔다. 폐사무소에는 남아 있는 책상을 추가한다. 종이 그림·행동 표시·접근 가능한 칸·손이 닿는 판정을 같은 가구에 연결한다. 문서의 청색 사각 테두리는 제거한다.
- 약국 진열대에는 약품을 채우고 구토제와 설사약을 서로 다른 약병으로 놓는다. 약을 내려놓으면 그 위치의 바닥에 남고, 저장 후에도 진열대로 되돌아가지 않는다.
- 실장의 술병을 실제 바 위에 둔다. 바는 VIP룸 출입구를 막지 않는 위치에 있고, 실장은 기존 음용 위치에서 마신다. 술병을 조작한 순간 화장실로 이동하지 않는다.
- 기존 공중화장실에 변기·세면대·조명·WC 표지를 추가한다. 포차에는 식사 표지와 식탁 위 음식·수저를 놓는다. 포차·약국·화장실 입구도 공개 구역으로 맞춰 일반 손님에게 직원 복장을 요구하지 않는다. 음식과 술병은 주변과 같은 조명 처리를 받는다.

## 식사로 문지기 자리 비우기

1. 약국 진열대에서 설사약을 집는다.
2. 포차 식탁의 문지기 식사에 넣는다. 도구와 음식이 맞고 같은 층에서 손이 닿을 때만 가능하다. 손 조작의 접촉 시점에 한 번 소모한다. 직원 복장 없이 약을 넣는 모습은 수상한 행동이다.
3. 문지기가 식사 시간에 직접 포차로 걸어온다. 실제 음식 앞에서 멈춰 3초 동안 먹어야 약효가 적용된다. 먹은 식사는 빈 그릇으로 바뀐다.
4. 약을 먹었으면 공중화장실로 걸어가 32초 머문다. 화장실이 사용 중이면 밖에서 기다린다. 입구를 비우는 동안 잠입할 기회가 생긴다.
5. 원래 클럽 입구까지 걸어 돌아온 뒤 다음 식사 시간이 잡힌다. 약을 넣지 않았을 때도 정상적인 식사와 복귀를 한다. 경보나 싸움이 끼어들면 식사는 중단하고 적의 기존 목격 기억을 유지한다.

설사약은 문지기를 없애는 처치 수단이 아니다. 기존 실장의 구토제·간판·내선 전화 공략은 계속 사용할 수 있다. 손에 설사약을 들었을 때 최소 안내가 해당 식탁을 가리킨다. 직접 선택한 임무 목표와 단서 끄기 설정은 우선한다.

## 이동과 저장

전체 NPC를 실행하면 식당 직원 옆에서 우회 경로가 반복해서 쌓여 문지기가 맴도는 문제가 있었다. 중첩 우회를 막고, 진전이 없으면 서 있는 인물의 칸을 피해 경로를 다시 계산한다. 벽이나 사람을 순간이동으로 통과시키지 않는다.

이전 저장본에 새 약·책상 위치·화장실 시설과 조명을 보충한다. 새 가구와 겹쳐 저장된 인물은 같은 실내의 인접한 빈 칸으로 옮겨 갇힘을 방지한다. 읽은 메모·비밀번호·내려놓은 약·진행 중 식사 경로는 보존한다.

## 검증

- `t_surfaces_dining.py`: PC·모바일의 메모 받침 가구, 층간 접근 차단, 약과 음식의 일치, 접촉 후 한 번 소모, 실제 식사·화장실 체류·입구 복귀, 중단, 체크포인트와 구버전 저장 복원. 실제 키보드·터치로 약병을 집고 음식에 사용하는 입력 검사 포함.
- 같은 검사에서 전체 NPC 39명을 함께 실행해 식사·화장실·복귀를 확인했다. 고정된 조건에서 약 68초에 식사, 약 147초에 화장실 도착, 약 211초에 입구 복귀했다. 플레이 중 경계와 군중 상황에 따라 시간은 달라진다.
- `t_mission_flow.py`: 여섯 의뢰 × 세 배치 × PC·모바일의 기존 36개 완료 경로.
- `t_product_plan.py`, `t_contract_density.py`, `t_rendezvous.py`: 준비 저장·실제 음용·기존 의뢰 구조·내선 매복 유지. 술병 검사 위치는 새 바의 실제 접근 칸을 사용한다.
- `t_building_search.py`, `t_ai_feedback.py`: 실내 위치 13,372곳·실제 위층 수색·시야·휘파람·신원 판정·기존 성능 조건.
- `t_controls_readability.py`, `t_fixture_lighting.py`: PC·모바일 화면 비율, 행동 우선 표시, 주변 조명과 시설 색감 일치.

Chromium에서 검증했다. 화면 자료는 사물 배치를 확인하기 위해 인물 위치와 상황을 고정한 게임 캡처다. 이번과 관련된 검사 결과이며, 전체 테스트 묶음이 모두 통과했다는 의미는 아니다.
