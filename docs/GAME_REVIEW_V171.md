# v171 전체 게임 리뷰와 개선

현재 게임의 중심은 관찰, 제압, 변장, 은닉으로 다음 기회를 만드는 잠입이다. 첫 의뢰에서는 이 흐름이 이어진다. 대청소와 배신에서는 긴 준비 이동, 행동 대상의 혼동, 복장 권한과 피격 중 작업 제한 때문에 실패 원인을 읽기 어려웠다. 같은 상황을 다시 실험하는 비용도 컸다. 이번 개선은 각 의뢰의 판단을 더 빨리 시작하고, 누를 행동과 실패 이유를 분명하게 만드는 데 집중했다.

| 리뷰 영역 | 실제 관찰 | 반영 내용 |
|---|---|---|
| 대청소 진입 | 동쪽 끝에서 첫 표적까지 걷는 시간이 길다. 기존 재현에서는 약 16초에 첫 표적에게 행동했다. | 공개 보도의 시작점을 31열로 이동. 같은 난수의 새 재현에서는 PC 약 8.12초, 터치 약 8.14초에 첫 표적에게 행동했다. 두 실행 모두 체력 3이었다. 평균 플레이 시간 측정은 아니다. |
| 조준 의도 | 짧게 다트를 누르면 바라보는 방향의 다른 순찰을 고를 수 있다. 주시한 표적도 방향이 다르면 무시됐다. | 실제 화면에서 클릭·탭한 살아 있는 대상을 우선 지정한다. 사거리·시야·층 조건을 통과하지 못하면 다른 사람으로 바꾸지 않고 발사를 보류한다. 지정하지 않은 경우에는 기존 전방 조준을 유지한다. |
| 조준 피드백 | 누르기 전에 선택된 적을 알아보기 어렵다. | 기존 HUD를 유지하며 선택된 적에 고리를 표시하고, 지정 대상과 겨누는 대상의 이름을 보여 준다. 도구 접근성 설명에도 이름을 포함한다. 새 조작 버튼은 추가하지 않는다. |
| 기절과 암살 목표 | 다트로 표적을 기절시켜도 처치 목표가 남아, 다음 행동을 오해하기 쉽다. | 직접 제압했거나 실제로 관찰한 기절 표적에 마무리 안내를 표시한다. 숨긴 표적은 꺼내는 방법을 안내한다. 기절을 살상 완료로 인정하거나 보상을 주지 않는다. |
| 미션 물품 옆의 몸 | 배신 2층에서 전투 후 무전기 옆에 몸이 쌓이면, 이미 들통난 옷으로 갈아입기가 물품 회수보다 먼저 나왔다. | 쓸 수 없는 옷과 운반보다 미션 물품을 우선 제안한다. 쓸 수 있는 새 복장과 사용자가 직접 고른 행동은 우선권을 유지한다. |
| 작업 중단 | 피격에서 회복 중인 상태에서는 물품 회수가 바로 취소되는데, 안내는 단순히 그만뒀다는 말이었다. | 피격 회복 때문에 시작할 수 없는 경우, 피격과 이동으로 중단된 경우를 구분한다. 기존의 피해와 중단 규칙은 유지한다. |
| 감옥의 선택과 난이도 | 감방을 나온 뒤 압수품 경로를 목표창에서 직접 선택할 좌표가 없었다. 2층은 복장이 통하지 않는데 지상과의 차이가 약하게 전달됐다. | 탈출 후 압수품과 무전기 경로를 목표창에서 선택한다. 압수품은 선택 사항이며, 배우지 않은 다트를 사용 가능한 장비처럼 알리지 않는다. 2층 보안구역과 복장 통행 불가를 안내한다. |
| 감옥 2층 진입 | 층계참에서 방에 들어서며 두 경비의 시선을 함께 받기 쉽다. | 진입 안쪽에 실제 사물함을 배치해 관찰할 엄폐 공간을 만든다. 사물함의 그림, 이동 판정, 시야 차단과 은신 기능이 같은 가구를 사용한다. 경비의 인지나 계단 추격은 낮추지 않는다. |
| 재도전 | 목표를 진행해도 수색 단계가 지속되는 동안 저장되지 않았다. | 획득한 진행이 있을 때, 주변에 경비가 없는 곳에서 들키지 않고 3초 이상 숨어 있으면 수색 중에도 저장한다. 열린 장소, 추격 중, 가까운 경비, 목격된 은신처와 어려움 난이도에서는 새 저장을 만들지 않는다. |

첫 의뢰는 기술 구입이나 다트 없이 PC·모바일 입력으로 장부 회수, 내선 유인, 표적 처치와 탈출을 확인했다. PC는 체력 3·그림자, 모바일은 체력 3·암살자였다. 모바일 전체 완주를 무발각 성공으로 기록하지 않는다.

대청소는 수정 전 수금원 처치, 경호원 제압과 변장, 창고 현금과 파란 카드키, 정산 쪽지의 출입번호까지 진행했다. 당시 체력 2, 수색 2단계였고 체크포인트가 없었다. 수정 후 시작 구간은 PC의 살상 투척과 모바일의 비살상 투척을 별도로 확인했다. 후자는 기절한 표적의 마무리 안내와 미완료 목표를 검증했다. 이 의뢰의 전체 완주는 검증하지 않았다.

배신은 감방 문 해제, 간수 복장, 압수품 회수, 보안실 해제, 2층 경비 제압과 반격을 여러 차례 실행했다. 무전기 앞에서 피격과 잘못된 기본 행동 때문에 실패한 상황을 재현했다. 물품 우선순위를 수정한 뒤 실제 입력으로 무전기 회수까지 진행했다. 마지막 시도에서는 무전기 회수 후 탈출 이동 중에 사망했다. 이 의뢰의 전체 완주는 검증하지 못했다. 상층의 수색 압력과 처음 플레이하는 사람의 반격 난이도는 계속 살펴볼 필요가 있다.

캠페인 플레이는 Playwright 키보드와 CDP 터치 입력을 사용하고, 경비·CCTV·무전·증원을 작동시킨 채 시뮬레이션 시간을 나누어 진행했다. 상태를 읽어 경로와 입력 시점을 정했으며 플레이어와 경비의 위치, 체력, 인벤토리, 습득 기술, 목표 달성 상태를 덮어쓰지 않았다. 사람의 실시간 첫 경험, 실물 휴대폰의 성능 측정, 재미에 관한 사용자 조사로 해석하지 않는다.

입력·저장·시야의 경계 조건은 제어된 회귀 장면에서 별도로 확인했다. 지정 대상이 가려졌을 때의 탄약 보존, 기절한 표적의 실제 미완료 상태, 직접 선택한 갈아입기 유지, 작업 회복, 선택 경로, 2층 사물함의 실제 시야 차단, 수색 중 저장과 추격·어려움 난이도의 저장 제한이 포함된다. 핵심 회귀 스크립트 68개, 빌드 파이프라인 7개, 스프라이트 소유권과 도달 검사를 통과했다. 마지막 행동 우선순위 변경을 포함한 빌드로 다시 검사했다. 최종 검사와 플레이 자료는 [실행 기록](review-v171/checks.json)에 보관한다. [대청소 모바일](review-v171/m4-mobile-target.png)과 [무전기 회수 직후](review-v171/m6-radio-recovered.png) 화면도 함께 남겼다.

다음으로 검증할 부분은 대청소의 나머지 목표와 배신의 안정적인 전체 탈출, 실물 모바일에서의 가독성과 반격 타이밍이다. 새로운 기술이나 이펙트의 수를 늘리기 전에, 플레이어가 상황을 읽고 실험 결과를 이해할 수 있는지 계속 확인한다.
