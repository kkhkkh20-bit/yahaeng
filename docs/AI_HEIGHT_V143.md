# v143 층·옥상 시야와 추적

클럽 옥상 중앙에 있는 플레이어가 아래쪽 경비에게 보이고, 경비가 발견 후에도 옥상까지 제대로 접근하지 못한다는 피드백을 대상으로 수정했다.

## 원인과 수정

기존 `canSee`는 옥상과의 시선에서 `ign`을 사용해 지붕이 있는 칸의 벽을 전부 무시했다. 높이가 다른 시선은 통과하는 각 칸에서 시선 높이와 지붕·옥상 구조물 높이를 비교하도록 바꿨다. 아래층 벽·천장을 통과하지 않으며, 가장자리의 실제 노출은 여전히 볼 수 있다. 웅크린 자세는 낮은 실루엣으로 계산한다. 같은 층의 시야는 관찰자의 층 지도를 사용하며, 도시 경찰의 별도 재발견 경로도 대상 층과 은신 상태를 확인한다.

기존 층 연결 그래프는 1층의 실내와 거리를 하나의 단계로 묶었다. 갈아타는 횟수가 적은 배관이 실내에서 접근 불가능해도 선택될 수 있었다. 경비의 이동은 실제로 걸어서 이어지는 영역과 출입 가능한 문을 기준으로 연결한다. 계단에는 낮은 이동 비용을 주고, 접근 가능한 배관·사다리는 대안으로 남겼다. 연결이 없는 다른 층의 좌표를 같은 층 목적지로 사용하는 대체 동작은 제거했다. 연결 영역은 경비의 문 접근 권한별로 캐시하고, 문 상태·지도 수명·짧은 유효 시간을 확인한다. 이전 의뢰·저장 상태의 지도는 유지하지 않는다.

실제 목격·신고 위치는 다른 층이어도 먼저 확인한다. 이후 주변 방과 은신처를 분담 수색한다. 보지 못한 플레이어의 새 위치는 추적 목표에 넣지 않는다. 잠긴 문은 현장에 접근한 뒤 여는 동작을 하며, 길을 계산하는 것만으로 멀리 있는 문을 부수지 않는다. 수색 중 문 처리는 위층도 지원한다.

옥상 위 시야 원뿔과 공격도 높이 판정에 맞췄다. 아래층 실내 벽 때문에 같은 옥상의 근접 공격·사격이 막히는 경우를 고쳤고, 옥상의 쓰러진 사람을 보는 호출에도 실제 높이를 전달한다. 옥상 가장자리를 아래쪽 경비에게 실제로 들킨 경우 HUD도 발각으로 표시한다.

가로 모바일에서 중요한 말풍선이 HUD와 겹쳐 사라지는 선행 문제를 함께 고쳤다. 일반 배치가 불가능할 때 유용한 대사·경고는 가까운 옆 공간을 찾아 표시한다.

## 검증

- 실제 클럽 지도: 지붕 중앙은 차폐, 가까운 가장자리 노출은 발견, 낮춘 자세 차폐, 층·실내 벽 분리, 물탱크의 실제 판정과 시야 원뿔 일치.
- 같은 옥상에서 아래층 벽을 사이에 둔 근접 공격·사격 성공.
- 클럽 경비가 1층·2층에서 마지막으로 목격한 옥상 위치까지 계단을 통해 이동. 숨은 플레이어를 다른 위치에 두어도 기억한 위치가 바뀌지 않음.
- 여섯 의뢰의 옥상 계단마다 위층 입구·아래층 계단·각 의뢰 경비 출발점을 조합한 119개 경로 모두 도착.
- 실제 2층 문 통로에 잠금 상태를 둔 검사에서 경로 계산 중에는 문이 열리지 않고, 현장 접근·개방 동작 후 통과.
- 핵심 회귀 묶음 38개 실행. 37개 통과 후 카메라/말풍선 검사 실패를 이전 v142 배포 패키지에서도 재현. 말풍선 배치 보완 후 PC·세로/가로 터치 108개 카메라 경계 검사 통과. 최종 전투·HUD·층간 추적 검사 별도 재실행.

이는 실제 지도의 통제된 브라우저 시나리오다. 모든 의뢰의 자연 플레이 완주나 실물 휴대폰 성능 측정을 의미하지 않는다.
