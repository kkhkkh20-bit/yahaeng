자동 전체 경로는 시간을 전진시켜 규칙과 도달 가능성을 검증한다. 순간이동으로 목표를 얻거나 경비를 지우지 않았다. 화면 비교용 정지 장면은 별도로 배치해 캡처했다. 이 둘을 수동 플레이와 혼동하지 않는다.

별도 네이티브 브라우저 프레임 재생은 기본 구현 커밋 `0d04734`에서 실제 방향키 입력 및 전체 회수 경로를 녹화했다. 이후 커밋 `3746fe5`에서 처치한 몸과 운반 시작·종료 표시를 보완했고, `t_club_handling.py`로 추가 검증했다. 영상이 이 후속 표시 수정을 포함하는 것으로 해석하지 않는다.

클라우드에서 실제 GPU 대신 Chromium SwiftShader를 사용했다. 프레임 녹화는 DPR 0.65/그림자 맵 384로 낮춘 검사 환경이며, 실제 휴대폰이나 일반 설정의 성능 측정이 아니다. 자동 테스트의 `metrics` 값도 GPU 전체 프레임 시간으로 보지 않는다. 출시 성능·기기 호환성은 실제 기기 검증이 남는다.

재현: `python3 build.py --club --itch` 후 Playwright/Chromium이 설치된 환경에서 `tests/rev/t_club_study.py`, `t_club_study.py mobile`, `t_club_projection.py`, `t_club_handling.py`, `t_club_study_live.py`를 실행한다. 프레임 녹화에는 Playwright FFmpeg가 필요하다.

네이티브 프레임 경로는 게임 시간 73.83초, 체력 3으로 `임무 완료`에 도달했고 브라우저 실행 오류는 없었다. 손목 기준 기록은 문 2개 샘플 최대 9.8cm, 물건·수납함 작업의 유지 구간은 0.1cm 미만이었다. 이것은 모든 방향의 손가락·물체 접촉이 완성됐다는 의미가 아니다.

일반 재생 녹화는 약 794초다. 보기용 영상은 중복 프레임과 GPU 대기를 제거하고 남은 순서를 20fps로 재생했다. 약 20fps는 게임 업데이트의 0.05초 제한에 맞춘 재생 기준이며, 실제 기기의 성능 수치가 아니다. 원래 시간의 영상도 함께 제공한다.
