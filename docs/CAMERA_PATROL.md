# 맵 끝 시점·말풍선·NPC 이동 · v88

[같은 좌표의 전후 화면](camera-patrol/index.html).

- 모바일 카메라의 하단 상한이 맵 끝보다 화면 높이의 56%가량 아래까지 허용되어 있었다. 화면 아래 조작부의 얕은 여백(화면 높이 18%, 최대 140px)만 남기도록 바꿨다. 본부 맵 하단의 390×844 재현에서는 빈 공간이 473px에서 140px로 줄었다. 위쪽 지형이 더 보이고 주인공은 화면 아래쪽으로 이동한다.
- 따라갈 목표 위치를 먼저 경계 안으로 제한한 뒤 카메라를 부드럽게 이동한다. 지도보다 화면이 크면 지도 중앙에 둔다. PC·모바일 가로 화면·줌에서도 같은 원칙을 적용한다.
- 말풍선을 건물·옥상·층 덮개보다 먼저 그려 가려지던 순서를 고쳤다. 한 프레임에 한 번, 월드 그림 뒤에 표시한다. HUD와 화면 상하단 밖으로 잘리지 않게 위치를 조정하고, 다른 글자 표시는 말풍선을 피한다.
- 세력 구역은 길찾기를 막는 벽이 아니다. 평소 순찰은 본거지 주변을 돌지만 경계 밖의 길도 통행 가능하다. 길 없는 추적에서도 걷기 상태를 강제로 켜던 코드와, 세력 처리 도중 이전 프레임의 걷기 상태가 남던 코드를 제거했다. 실제 이동량으로 걷기 동작을 결정한다.
- 닿을 수 없는 상대·사건 때문에 2초간 이동하지 못하면 세력 추적을 취소하고 자기 동선으로 돌아간다. 같은 상대를 곧바로 다시 고르는 것도 8초간 막는다. 도달 가능한 싸움·추적은 유지한다.

`tests/rev/t_camera_presentation.py`: 6개 의뢰 × 줌 3종 × 상/하단 × 세로 모바일·가로 모바일·PC = 108개 경계 조건. 빈 공간 상한, 주인공 표시, 경계 접근의 카메라 튐, 건물 위 말풍선과 한 번만 그리기, 상단 말풍선의 잘림 방지를 확인한다.

`tests/rev/t_patrol_motion.py`: 건달파 구역 밖으로 실제 통행, 완료/빈 경로에서 서 있기, 잠긴 금고 안 상대를 쫓다가 멈추고 복귀하는 상황을 재현한다. 세력 싸움·도발·관계, 변장 AI, 사물 상호작용, 모바일 UI 회귀 검사도 함께 실행한다.

버튼·미니맵·중앙 상태 표시의 위치와 맵 이동 좌표는 유지했다.
