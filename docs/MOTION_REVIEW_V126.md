# v126 — 흰 말풍선과 동작 연결 검수

[전후 영상·실시간 의뢰 검수 녹화](motion-v126/index.html)

## 확인한 문제와 적용

| 확인한 장면 | 원인과 수정 |
| --- | --- |
| 어두운 말풍선이 배경에 섞임 | 흰색 `#f7f6f1` 배경·짙은 `#202521` 글자로 변경. 둥근 외곽·화자를 향한 꼬리·버튼과 인물을 피하는 배치는 유지 |
| 물건을 줍거나 조작할 때 갑자기 숙였다 일어남 | 두세 개 정지 자세를 번갈아 쓰던 부분을 17프레임 손 조작으로 연결. 바닥·침대 아래·낮은 서랍은 낮은 자세, 책상·탁자·금고·컴퓨터 작업은 서서 손을 뻗는 자세 사용. 긴 작업은 손을 놓지 않고 작은 움직임을 이어가다 마무리 |
| 사람을 들고 내릴 때 몸이 순간 이동함 | 주인공과 대상의 들기 자세를 25프레임으로 함께 다시 구움. 바닥의 대상 위치·방향에서 어깨 위치까지 연속 이동하며, 내릴 때 역순으로 연결. 실제 들기·내리기 시간은 늘리지 않음 |
| 창문 넘기가 세 자세로 끊김 | 기존 모델의 관절을 보간한 17프레임 통과 자세 추가. 창문 좌표·도착점·높이 판정은 유지 |
| 달려들기 시작에 서 있는 자세로 미끄러짐 | 붙잡으러 접근하거나 달려드는 중 `travelSpeed`가 이전 정지 값에 머물렀다. 실제 이동 거리로 걸음 시간을 갱신 |
| 직접 걷기와 자동 출입의 발동작이 튐 | 계단·접근·출입의 걷기에 같은 이동 거리 기반 시간을 사용. 사람을 메거나 붙잡은 두 사람도 같은 시간을 사용 |
| 수납함을 닫고 걸어 나올 때 방향이 급변함 | 닫기를 마친 뒤 손을 거두는 구간에서 나갈 방향으로 몸을 돌림. 별도의 대기 시간을 추가하지 않음 |
| 제압 후 잠깐 웅크렸다 바로 서기 | 정지 상태에서 일어서는 구간을 역순의 중간 자세로 연결. 이동 입력은 기존대로 바로 받을 수 있음 |

여성 주인공과 복장·주민의 외모를 바꾸지 않았다. CC0 원본 모델을 사용해 추가 2D 시트를 구웠으며 AI 이미지는 사용하지 않았다. 캐릭터가 발을 땅에 고정하는 작업에는 몸 전체를 끌어당기는 보정을 다시 넣지 않았다. 처치의 길게 누르기 규칙, 버튼 위치, 전투 판정·경비 시야는 유지했다.

## 실행 화면 검수

일반 프레임 루프를 켠 VIP 의뢰를 기존판과 수정판에서 탈출까지 진행했다. 최종 수정본도 별도로 다시 녹화했다. 전체 NPC·CCTV·피해 처리를 켰으며 순간이동, 체력 보충, 열쇠·복장·목표 지급을 사용하지 않았다. 경로는 약국·식당 준비·화장실에서 붙잡기와 기절·변장·사무동·2층 비밀번호·장부·전화 유인·사물함 매복·표적 제압·탈출이다.

이는 맵과 시스템을 아는 자동 입력 검수다. 사람의 첫 플레이나 블라인드 사용성 평가와 구분한다. 영상 프레임을 확인해 들기·내려놓기·손 조작·창문 통과의 전후 차이를 검수했다. 조작 연계와 짧은 동작을 크게 보기 위한 비교 영상에서는 NPC를 제외하고 시작 위치를 맞췄다.

## 검증

[검사 결과](motion-v126/validation.json)

- 신규 `t_motion_tracks.py`: 실제 들기·내리기, 25개 중간 자세·연속 위치, 17개 창문 통과 프레임, 9종 작업의 손 뻗기·마무리, 접근·자동 이동의 걸음 시간, 정지 시 발 멈춤, 말풍선의 흰 픽셀을 PC·모바일에서 검사했다. 새 시트를 처음부터 모두 디코딩하지 않는지도 확인했다.
- 기존 인물과 새 시트의 23,000프레임에서 잘림·빈 프레임·투명 여백을 검사했다. 큰 체형에서 발견한 잘림은 촬영 여백과 런타임 배율을 함께 조정해 수정했다.
- 창문 496개·층 72개·매달림 접점 128개, 수납 206개 출입과 회수, 문·맨홀·환풍구·간판, 실제 누르기·길게 누르기와 동반 제압 검사 통과.
- 현행 계단 검사: 실내 59·옥상 70·자동 진입 118·NPC 이동 258·저장 복원 통과.
- 전체 AI의 VIP 자동 경로는 PC 190초·모바일 191초, 체력 3·발각 0회로 완료했다. 실시간 녹화 경로의 결과는 검사 JSON에 별도로 기록했다.
- 구형 `t_stairs_all.py`는 없어진 수동 내려가기 버튼을 요구하는 47개 항목에서 실패했다. 통과로 처리하거나 검사를 끄지 않았으며 현행 자동 계단 검사를 함께 실행했다. 구판으로 돌린 추가 진단은 4분 뒤 중단했다.
- 무작위성이 있는 VIP 별도 경로 검사 한 장면은 처음에 화장실 도착 조건을 만족하지 못했다. 같은 검사의 재실행 12개 장면과 구판의 12개 장면은 통과했다. 최초 실패를 통과로 기록하지 않는다.

## 용량과 남은 범위

추가 시트는 총 약 0.8MB다. 필요한 주인공·가까운 대상의 시트만 읽고, 판이 바뀌면 쓰지 않는 모션 캐시를 정리한다. 게임 중 3D 렌더링을 추가하지 않았다. 압축 크기와 실제 휴대폰 메모리 사용량은 다르며 기기별 장시간 성능 검증은 별도다.

배관·매달림·기존 전투 등은 기존 동작을 유지하면서 접점·잘림·입력의 회귀 검사를 했다. 이번에 모든 행동을 새 모션 캡처로 교체하거나 모든 어색함이 없어졌다고 주장하지 않는다. 아직 방향 수와 원본 포즈의 제약은 남는다.
