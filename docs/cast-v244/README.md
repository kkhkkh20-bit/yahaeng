# v244 — 얼굴, 인게임 들개, 창가 전환

## 수정

- 올빼미는 작은 인게임 머리를 확대해 붙인 이전 얼굴 대신, 승인한 여성 요원 시안에 맞춘 전용 상반신을 사용한다. 대사·무전·HUD·브리핑·표적 정보가 같은 초상화 경로를 사용한다. 변장해도 주인공 얼굴은 유지된다.
- 까마귀·제비·의사·간부 9명·일반 경비/주민의 남녀 초상화를 구분했다. 새로운 초상화는 생성한 원본 그림이며 구매 에셋으로 표기하지 않는다. 느린 이미지 로딩 중에는 이전 얼굴이 잠깐 나타나지 않으며, 로딩이 끝나면 이미 열린 대사창도 갱신한다.
- **들개는 인게임 이미지**를 교체했다. 좌우 반전하던 두 프레임 대신 32px 셀의 8방향 정지·걷기·쓰러짐을 사용한다. 들개 초상화는 넣지 않았다. 소유한 도톤보리 원본 타일맵에는 교체할 동물 스프라이트가 없었으며 이번 대체 그림은 별도 생성 원본이다. 같은 작가의 유료 캐릭터 팩에는 시바견이 있지만 구매하지 않았다.
- 창가를 지나가기만 하면 방이 열리지 않는다. 창을 바라보고 약 0.12초 머물면, 입구 쪽부터 부드러운 경계와 투명도로 내부가 드러난다. 충분히 가까이 붙어 기다리면 기존처럼 연결된 방 전체를 볼 수 있다. 떨어질 때도 짧게 사라진다. 다른 층으로 이동·실내 진입·문 닫기에는 즉시 정리한다. 모션 감소 설정은 공간 확장 없이 투명도만 바꾼다.
- 기존 캡처 캔버스를 재사용한다. 창별 전체 화면 캔버스나 프레임마다 새 캔버스를 만들지 않는다. 벽·닫힌 문·층 구분, 조명/AI 판정과 물리 구조는 유지한다.

## 확인 범위

- PC 1280×800 / 모바일 390×844: 27맵에서 주인공 얼굴 유지, 핵심 간부 9명 얼굴 구분, 대사와 표적 정보 일치, 변장 시 얼굴 유지, 들개/문서에 얼굴 없음.
- 패키지의 초상화 요청을 의도적으로 지연: 이전 얼굴이 나타나지 않고, 다운로드 후 이미 열린 대사창의 얼굴이 갱신됨.
- 창가 전환: 바라보는 방향·짧은 머무름·연속 페이드·완전히 드러난 방·이탈 후 닫힘·층 이동 시 정리·반복 그리기에서 캔버스 추가 생성 없음. 명시적 위치/시계 설정 검사와 실제 렌더러 녹화를 사용했다. 초보자 블라인드 플레이 검증은 아니다.
- 기존 창가/계단/스위치 검사, 조명 가림 검사, 브리핑과 목표 정보 4개 화면 크기 검사, 물리 상호작용 20그룹, 빌드 파이프라인 8개 검사.
