# 도시 2배 시험 구역 (cityXL)

기존 도시(`src/stages/17_city.js`, 4×3 블록, 84×64칸)의 블록 설계 12종을 그대로 써서 8×6 블록(168×128칸)으로 넓힌 시험 구역이다. 가로·세로가 각각 2배라 넓이는 4배다.

- 파일: `src/stages/17b_city_xl.js`
- 여는 법: 빌드 후 `build/preview_city.html?study=city-xl` 을 열고, 콘솔에서 `__game.start(__game.STAGES.findIndex(s=>s.id==='cityXL'))` 를 실행한다.
- 캠페인과 분리: 주소에 `study=city-xl` 이 없으면 의뢰 목록에 들어가지 않는다. 기본 실행의 의뢰 목록은 27개 그대로다. 도시 복귀 버튼은 기존 `city` 를 쓴다.
- 의뢰 장소는 넣지 않았다. 주행 시간, 밀도, 성능을 확인하는 용도다.

## 구성

| 항목 | 기존 도시 | 2배 시험 구역 |
| --- | --- | --- |
| 맵 | 84×64칸 (4032×3072px) | 168×128칸 (8064×6144px) |
| 블록 | 12 | 48 |
| 건물 | 27 | 124 |
| 인물 (행인 / 경찰) | 48 (38 / 2) | 146 (126 / 4) |
| 차량 (AI 주행) | 28 (16) | 80 (48) |
| 조명 | 174 | 546 |
| 은신처 | 60 | 331 |

행인, 가로등, 조직원, 경찰 순찰은 기존 도시와 같은 규칙으로 블록마다 배치했다. 지구대 2곳, 병원 2곳, 조직 창고 2곳, 조직 본부 2곳이다.

## 측정 (헤드리스 Chromium, 1280×720, 소프트웨어 렌더)

절대값은 실제 기기와 다르다. 같은 조건에서 두 맵을 비교한 비율을 봐야 한다.

| 항목 | 기존 도시 | 2배 시험 구역 | 배율 |
| --- | --- | --- | --- |
| 판 생성 (`start`) | 772ms | 2622ms | 3.4 |
| 게임 갱신 1프레임 (`update`) | 3.5ms | 11.8ms | 3.4 |
| 화면 그리기 1프레임 (예열 후) | 11–12ms | 21–23ms | 약 1.9 |
| JS 힙 | 97MB | 116MB | 1.2 |
| 내장 도달 검사 (`validate`) | 문제 0 | 문제 0 | — |

주행 시간은 빼앗은 차로 최상단 도로를 따라 측정했다. 측정할 때는 같은 도로의 다른 차와 경찰을 치웠다. 차 최고 속도는 약 430px/초다.

| | 기존 도시 | 2배 시험 구역 |
| --- | --- | --- |
| 실측 | 3084px를 7.8초 | 6340px를 15.4초 |
| 끝에서 끝까지 환산 | 약 9.4초 | 약 18.8초 |

## 발견한 점

1. **지붕 그리기가 화면 밖 건물까지 전부 처리한다.** `src/js/render/roofs.js`의 `drawRoofs()`는 `BLD` 전체와 모든 창문, 문, 사다리를 돈다. 지붕 단계를 끄면 2배 구역의 그리기 시간이 약 21ms에서 9.8ms로 줄었다. 기존 도시는 12ms에서 8.4ms였다. → 화면 밖(여유 4칸) 건물과, 화면 밖(여유 2~8칸) 창문·문·배관·굴뚝·환풍구는 건너뛰도록 고쳤다. 지붕 열림 상태(`b.ra`)는 화면 밖에서도 계속 갱신한다. 고치기 전후로 의뢰 맵 8개, 연습 맵, 도시 두 개, 건물 안(지붕 열림), 옥상 위 등 20개 장면을 찍어 비교했고 모두 픽셀 단위로 같았다. 그리기 시간은 2배 구역에서 약 25ms에서 14ms로, 기존 도시에서 약 11.4ms에서 10.7ms로 줄었다.
2. **게임 갱신 비용이 전체 인물·차량 수에 비례한다.** 화면에서 먼 행인과 차도 매 프레임 계산한다. 넓은 맵에서는 멀리 있는 인물과 차를 쉬게 하거나 덜 자주 갱신하는 처리가 필요하다. → 도시 판에서 플레이어와 화면 양쪽에서 1100px 넘게 떨어지고 평상시 상태(순찰·복귀, 경계 0)인 행인·조직원·AI 차는 3번에 한 번만 갱신하도록 고쳤다(`src/js/47_city.js`의 `cityLodStep`). 건너뛴 시간은 모아 두었다가 한꺼번에 넘기고, 한 번에 0.15초를 넘기지 않는다. 경찰, 표적, 경계 중인 인물, 추격·사고 차량은 항상 매번 갱신한다. 의뢰 판은 바꾸지 않았다. 갱신 시간은 2배 구역 15.9ms → 9.5ms, 기존 도시 3.7ms → 3.2ms. 60초 동안 행인·차가 움직인 평균 거리는 전후 차이 2% 이내였고, 차 겹침은 전후 모두 0건이었다. `t_city`, `t_vehicle_contacts` 통과.
3. **교통 정체에서 차가 서 버린다.** 플레이어 차 앞의 AI 차가 멈추면 같은 차선에서는 지나갈 수 없다. 사람이 운전하면 차선을 바꾸면 되지만, 경찰 추격 중에는 막히기 쉽다.
4. **확대한 상태에서 빠르게 달리면 차가 화면 가장자리로 밀린다.** 카메라가 진행 방향을 앞서 보여 주기 때문이다. 확대 1.45에서 확인했다.
