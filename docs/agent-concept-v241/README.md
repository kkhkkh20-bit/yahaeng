# v241 — 승인한 여성 요원 시안 적용

일반 캠페인과 도시 실험판 모두 같은 여성 요원 외형을 사용한다. 기본 복장은 검은 단발·남색 정장·밝은 셔츠·짙은 바지다. 경비/직원/운반책/정장/작업복으로 갈아입어도 얼굴·머리색과 머리 모양이 유지된다. NPC 외형과 조직 의상색, 변장 통행 판정, 진행 데이터는 그대로다.

## 실제 적용 방식

사용자가 승인한 [외형 시안](../world-polish-v240/hero-turnaround.webp)을 바탕으로 얼굴과 단발머리를 8방향 도트로 정리했다. 원본 승인 이미지를 정지 그림으로 미끄러뜨리는 방식이 아니다. 기존 CC0 Quaternius 여성 정장 몸체와 동작 뼈대에 새 도트 머리를 붙여 **오프라인에서 2D WebP 동작 이미지로 재렌더링**했다. 기본 정장의 색과 명암도 시안에 맞췄다. 게임에 3D 엔진이나 새 런타임 의존성을 추가하지 않는다.

새 머리는 자세에 따라 위치와 기울기를 바꾸고, 기존 3D 깊이 판정을 이용해 팔·운반하는 몸과 가림 관계를 유지한다. 머리 이미지는 팔레트 채널로 인코딩해 복장을 바꿔도 조직 의상색이 머리에 묻지 않게 한다. 초상화도 새 외형에서 다시 출력했다. 모든 요소를 손으로 새로 그린 동작 팩이라고 주장하지 않는다.

## 적용 범위

- 기본/경비/직원 몸체 각각의 기본 동작, 연속 이동, 연속 작업, 연속 전투, 두 사람 작업 동작을 재생성했다.
- 쓰레기통 뚜껑 열기 전용 동작도 세 복장에 추가했다. 기본 복장뿐 아니라 변장 상태에서도 같은 머리를 사용한다.
- 정지, 8방향 걷기/달리기, 웅크림, 암살, 기절, 시신 운반, 붙잡기, 변장, 작업, 매달림, 등반, 쓰러짐에 적용된다.
- 일반 캠페인의 `ninja` 저장/표시 키는 유지하되 새 몸체로 연결한다. 기존 명시적 몸체 키도 계속 읽을 수 있다. 캠페인과 실험판의 저장 구분은 유지한다.
- 실제로 쓰는 복장만 불러오고 사용하지 않는 이미지 메모리는 계속 해제한다. 뚜껑 열기 이미지를 미리 준비해 첫 상호작용에서 이전 외형으로 바뀌지 않게 한다.

## 검증

- **16,632개 프레임**: 세 복장 × 기본/연속/상호작용/전투/뚜껑 동작의 8방향 전체가 비어 있지 않고 잘리지 않음을 검사했다. 북쪽 웅크림에서 잘리던 15개 기본 프레임은 카메라 여백과 배율 정보를 함께 조정해 수정했다. 월드 크기는 유지한다.
- 모든 복장에서 동일한 피부·머리 팔레트, 새 동작 소스, 남색 기본 정장, 뚜껑 동작을 검사했다. 이전 색상 인코딩이 초록색 픽셀로 남지 않음도 실제 렌더 결과에서 확인했다.
- 기존 연속 동작 검사: 이동 거리와 보행 박자, 정지/웅크림 전환, 한 주기 연결, 암살자/피해자 각 25프레임, 등반 손 접촉, 이미지가 아직 준비되지 않은 상태의 대체 표시, 한 인물 중복 그리기 방지 통과.
- 기존 여성 캐릭터/변장/NPC 및 저장 몸체 키 검사, 팔레트 변환 검사 통과. 사용하지 않는 이미지 메모리 해제와 지연 로딩 검사도 PC/모바일 양쪽 통과.
- 실제 PC/모바일 임무: 기절 → 변장 → 운반/숨기기 → 문 → 2층 → 표적 처치 → 기록 회수 → 탈출. 두 기기 모두 체력 3, 발각 0으로 완료했다. 사전 맵 지식을 사용한 플레이이며 초보자 블라인드 테스트는 아니다.
- 빌드 파이프라인 8개 및 물리적 상호작용 20개 그룹 통과.

## 소스와 재생성

머리 소스/유래는 `tools/prerender/agent_art/heads.png`와 `heads.json`에 기록했다. 생성된 원본 투명 여백의 alpha=1 잡음은 실제 머리 크기로 계산하지 않는다. 전체 배경을 머리 경계로 잘못 계산해 도트가 작아지는 문제를 방지한다.

```sh
python tools/import_agent_concept.py /path/to/original-head-sheet.png
python tools/prerender/bake_modular.py --only=heroAgent,heroAgentCrew,heroAgentWorker,heroAgentMotion,heroAgentCrewMotion,heroAgentWorkerMotion,heroAgentLid,heroAgentCrewLid,heroAgentWorkerLid
python tools/prerender/bake_modular.py --only=heroAgent,heroAgentCrew,heroAgentWorker --faces-only
python tools/prerender/bake_fluid_motion.py --only=heroAgent,heroAgentCrew,heroAgentWorker
python build.py
```

몸체·동작 뼈대는 기존 Quaternius CC0 라이선스를 유지한다. 새 머리는 승인 시안에서 생성한 원본 그림이며, 구매한 GuttyKreum 팩이나 Quaternius가 제작한 얼굴이라고 표기하지 않는다. 추가 구매는 없다.
