# v231 창문·벽등 마감

v230의 창문은 셔터가 붙은 정면 창 일부를 잘라 얇게 늘린 뒤 옆벽에서 회전시키고 있었다. 벽등도 실제 발광 기구가 아닌 옆 벽 패널을 포함한 모듈을 사용해 둘 다 밝은 막대처럼 보였다.

구매한 Office Interior v3 원본에서 독립된 완전한 창틀과 벽부 조명의 기구 부분을 다시 골랐다. 창틀은 원본 모서리·테두리 두께를 유지하는 nine-slice로 조립하고, 옆면에서는 수직 창짝과 들어간 유리면을 가진 벽면으로 투영한다. 회전한 정면 창 이미지를 옆벽에 붙이는 방식은 제거했다. 창턱과 어두운 홈이 벽 두께를 나타내며 창틀의 흰 강조는 낮췄다.

창문 상태는 기존 잠금 걸쇠·창살·열린 개구부로 표시한다. 실내외 표현 모두 같은 창문의 실제 상태와 해당 층의 실내 조명 회로를 읽는다. 가로등과 손전등은 실내 점등으로 취급하지 않는다. 별도 회로가 없는 경우에도 해당 층의 실내 광원과 벽 가림만 확인한다. 이전의 장식용 둥근 노란 빛 번짐과 창틀 이중 덧그리기는 구매 아트 경로에서 제거했다. 게임의 빛·시야 판정은 바꾸지 않았다.

벽등은 원본의 작은 기구 부분을 사용한다. 일반 조명과 따뜻한 조명은 같은 형태에 발광부 색만 달리한다. 실제 점등/소등/파손 상태에 맞게 발광부를 그리고, 기존 벽 장착 지점·스위치·광원·회로는 유지한다.

검증은 9개 공개 에피소드의 아트 활성/비활성 물리 상태 비교, 창문 상태별 이미지·창틀 캐시·회전 없는 옆면 표현·실내 회로/층 분리 검사, 창문 통과/위층 출입/등반 접점 검사, 공용 스위치와 NPC 재점등 검사로 구성했다. PC/모바일 실제 화면을 비교하고, 모바일 첫 에피소드와 PC 세 번째 에피소드의 기존 경로를 실제 입력으로 재플레이했다. 이는 경로 및 동작 회귀 검증이며 신규 사용자 사용성 조사와 구분한다.
