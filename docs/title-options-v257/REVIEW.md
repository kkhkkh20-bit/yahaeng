# v257 배경·글꼴·옵션 화면

메인 배경을 도로 교차로의 플레이 화면에서 옥상과 밤거리가 보이는 전용 키아트로 교체했다. PC는 도시와 요원을 오른쪽에 두고, 모바일은 요원과 골목이 상단에 남도록 CSS로 구도를 조정한다. 새 배경은 image_gen으로 제작한 메뉴용 그림이며 구매한 GuttyKreum 에셋의 일부가 아니다. 원본은 보존했고 WebP로 인코딩해 사용한다. 생성 출처와 원본 해시는 `src/art/title/PROVENANCE.json`에 남겼다. 플레이 중의 구매 배경·캐릭터는 이번에 교체하지 않았다.

로고를 제외한 메뉴·옵션·기술·브리핑·결과·장비 화면은 기존의 완전한 한국어 글꼴인 IBM Plex Sans KR를 사용한다. 섞여 있던 Black Han Sans 화면 제목과 East Sea Dokdo 붓글씨의 런타임 등록·배포를 제거했다. 로고는 기존 Black Han Sans를 유지한다. 글꼴 원본과 라이선스 자료는 보존했다.

옵션 화면은 기존의 잘린 모서리 프레임과 청회색 재질을 사용한다. 소리·화면 구획, 황동색 아이콘·레일·손잡이, 눌리는 버튼의 테두리와 활성 상태를 함께 맞췄다. 손잡이는 별도 SVG UI 에셋이다. 브라우저 기본 원형 슬라이더를 표시하지 않고 실제 range 입력은 유지해 키보드와 터치 조작을 지원한다. 슬라이더 채움은 각 설정의 실제 최소·최대값으로 계산한다.

음소거를 음량 옆으로 옮겨 현재 상태를 `aria-pressed`로 제공한다. 음량을 조절해 음소거가 풀리는 기존 동작을 유지한다. 고급 설정·조작·출처는 접힌 상태로 시작한다. 작은 화면에서는 옵션 패널 안을 스크롤하며, 돌아가기 헤더는 위에 남는다. 지원되지 않는 전체 화면·진동 버튼은 숨기는 동작을 유지한다.

## 확인

- 320×568, 390×844, 844×390, 1024×768, 1440×900에서 실제 range 키 입력, 음소거 전환, 85% 음량·105% 밝기·30fps·동선 표시의 재접속 유지, 조작 안내, 가로 넘침, 기술 창 왕복, 일시 정지 화면으로 복귀를 확인했다.
- 같은 크기에서 실제 렌더링 글꼴을 브라우저의 폰트 검사로 확인했다. 설정 제목·구획 제목·라벨·버튼·조작 설명 모두 IBM Plex Sans KR를 사용한다.
- 5개 메인 화면의 처음 시작·이어하기 메뉴, 기존 원형 스킬트리의 5개 화면에서 선택·습득·재배분·초점·복귀 검사를 통과했다.
- 패키지의 HTML·스크립트·폰트 12개 해시와 PC·브라우저 터치 이동·웅크리기·목표 열람 정지/재개를 확인했다. 빌드 파이프라인 8개 검사도 통과했다.

이 기록은 브라우저 검증이며 실제 iOS 기기 검사는 아니다. 설정 값 검사는 정상 UI 입력으로 했고, 스킬트리 검사에는 기존의 저장 상태 조건을 사용했다. 포인트나 임무 규칙은 바꾸지 않았다.
