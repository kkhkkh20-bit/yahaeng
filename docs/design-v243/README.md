# v243 디자인 점검과 수정

게임에 등록된 전체 **27개 맵, 105개 건물, 이동 가능한 182개 층**을 촬영해 검토했다. 현재 선형 진행 9개와 보관 중인 18개 맵을 포함한다. PC 시작 화면, 실제 터치 모드의 세로 화면, 전체 평면, 각 건물의 층별 화면을 비교했다. 메뉴·기술 트리·브리핑·일시정지·결과·장비·무전·상황별 행동 버튼도 별도로 점검했다.

카메라와 인물 위치를 지정한 디자인 검토 화면과 실제 플레이 검증을 구분했다. 화면 캡처만으로 모든 미션을 플레이했다고 주장하지 않는다.

## 통합과 유지

- 보조 아이템의 원본을 `src/art/field-items`로 통합했다. 장비 하단 아이콘과 비행 중 물체는 같은 그림을 사용한다.
- 옛 보조 아이템 SVG는 참고 자료로 보관하되 빌드에서 제외했다. 인라인으로 쓰는 필드 아이콘의 중복 CSS 변수도 제외했다.
- 사용 중인 버튼의 원형 배치·동일 간격·터치 영역은 유지했다.
- 구매한 외벽·경계석·옥상 재질을 재사용했다. 문·벽·가구의 충돌 칸을 장식 때문에 바꾸지 않았다.
- 밝기는 기존 실제 광원과 은신 판정을 사용한다. 도로의 재질을 바꾸면서 플레이어의 탐지 판정을 밝기 보정으로 덮어쓰지 않았다.

## 검증

- 27개 맵의 전체 외부 지면·식생·불투명 지붕·옥상 장애물 표현 검사 통과.
- 수정 전후 27개 맵의 바닥·층·가구·문·조명·경비 배치와 출발 위치 지문이 모두 동일했다. [비교 데이터](geometry.json)
- PC와 실제 터치 모드에서 27개 맵의 목표 문장이 두 줄 안에서 잘리지 않음을 확인했다. 제목 글자는 브라우저의 실제 렌더링 글꼴까지 검사했다.
- 원형 버튼과 보조 아이템은 세로·작은 화면·짧은 화면·가로·작은 가로 5가지 크기에서 조작, 취소, 개수 표시, 겹침을 검사했다.
- 무전의 조용한 상태/발각/숨어 기다리기/다시 듣기 및 목표 열람 화면의 겹침 검사 통과. 문구가 바뀌어 낡은 정확 문자열을 요구하던 검사는 지시의 의미를 확인하도록 갱신했다.
- 브리핑과 목표 신원 카드의 4가지 화면 크기 검사 통과.
- 첫 에피소드 tB를 PC 키보드와 모바일 터치로 실제 진행했다. 두 환경 모두 기절 2명, 변장, 몸 숨기기, 2층 진입, 서류 회수, 계단 하강과 탈출까지 완료했다. 체력 3, 발각 0, 살해 0이었다.
- 빌드 파이프라인 8개 검사와 물리 상호작용 20개 그룹 통과.
