# v105 · 내 캐릭터가 보이는 모바일 화면

2026-10-31 (한국 시간)

요청은 특정 아이콘의 의미보다 ‘내 캐릭터가 어디에 있으며 무엇을 하는지 찾기 어렵다’는 문제였다.

모바일 세로 화면의 카메라 기준을 높이 38%에서 60%로 옮겼다. 가로 화면은 56%로 맞춘다. 맵 하단의 빈 공간 제한과 부드러운 카메라 이동은 유지한다. 상단과 오른쪽 끝에서는 캐릭터가 HUD·미니맵 아래에 숨지 않도록 여유를 둔다. 기본 배율에서 세로 캐릭터는 약 20%, 가로는 약 12.5% 크게 보인다. PC 카메라와 기본 배율은 유지한다.

모바일 플레이어에만 실제 자세·프레임·위치와 같은 얇은 윤곽을 그린다. 숨음 상태에서도 몸을 지나치게 투명하게 그리지 않아 팔과 붙잡는 자세가 읽히게 했다. 작은 발밑 표식의 청록색 방향 표시는 미니맵의 내 표시와 색을 맞췄다. 위험에 따른 노랑·빨강 구분은 남긴다. 배관 동작의 표식은 실제 손 접점에서 계산한 발 위치를 사용한다. 숨어 있거나 운전 중이면 현재 조작하는 물체 위치를 표시한다.

목격 지점은 주인공 모델을 복제하지 않고 수색 원과 작은 지점 표식으로 남긴다. 현재 캐릭터의 시인성을 높이며 새로운 설명 박스나 옵션은 추가하지 않는다. 말풍선은 캐릭터와 방향 표시의 자리도 피한다.

[모바일 세로·가로·PC 전후 화면](framing-v105/index.html). 같은 위치와 배치를 사용했고 붙잡기는 실제 행동을 진행해 촬영했다. 캐릭터 모델이나 판정 좌표를 바꾸지는 않았다.

검증:

- `t_player_framing.py`: 360×740·390×844·844×390·1280×800, 확대율별 모바일 아래쪽 기준·PC 카메라 유지, 맵 상단 양끝에서 HUD·미니맵 가림 방지, 실제 몸 투명도·공개 구역 윤곽, 붙잡기 자세와 윤곽 프레임 일치, 목격 지점이 주인공을 복제하지 않는지 검사.
- `t_camera_presentation.py`: 6개 의뢰·3개 확대율·세로/가로/PC의 맵 위아래 경계 108건과 말풍선 위치 검사.
- `t_controls_readability.py`: 두 미술 모드의 행동·말풍선·HUD 가림과 실제 붙잡기 입력 검사.
- `t_pipe_contacts.py`: 실제 배관 32곳 왕복과 복장별 손 접점·그리기 위치 검사.

## v106 · 인물 크기와 내 표식

실제 휴대폰 비율에서 인물은 여전히 작고, 위험도에 따라 발밑 표식이 바뀌어 위치를 찾는 데 방해가 됐다. 세로 기본 시점을 가로 10칸에서 8칸, 가로 화면은 16칸에서 14칸으로 가까이 잡았다. 기본 배율에서 인물이 v105보다 각각 25%, 약 14% 크게 보인다. 화면 높이 60%·56%의 카메라 기준은 유지한다.

내 발밑 고리와 방향은 청록색으로 고정한다. 위험도는 기존 중앙 상태와 감지 방향 호로 전달하며, 모바일의 옛 발밑 색상 설명은 띄우지 않는다. 목표 화살표·근처 아이콘은 화면 확대에 따라 함께 커지지 않게 했다. 사용자 확대 설정은 유지하며 PC 기본 시점과 판정 좌표는 그대로다.

[같은 장면의 v105 / v106 비교](framing-v106/index.html). 실제 붙잡기·수색·거리 장면을 모바일 세로와 가로로 촬영했다.

검증: `t_player_framing.py` 4개 화면, `t_camera_presentation.py` 맵 경계 108건, `t_controls_readability.py` 두 미술 모드 8개 화면에서 통과. 브라우저 모바일 화면으로 확인했으며 실제 휴대폰 성능 측정은 포함하지 않는다.
