# 문구 검수 · v93

목표·행동 버튼·상태 표시·알림·도움말·브리핑·기회 경로·대사·결과 화면을 점검했다. 소스에서 한글 문구 후보 2,322개를 추출해 검토했다. 장소명·인물명·내부 검사 문구도 포함한 추출 수이며, 수정 건수와는 다르다. 도움말의 규칙 설명 46개와 PC·터치 조작 안내를 다시 정리했다.

## 적용 기준

- 행동은 무엇을 하는지, 상태는 무엇이 진행 중인지 바로 알 수 있게 쓴다.
- 기절·붙잡기·처치를 구분한다. 표적도 짧게 누르면 기절, 길게 누르면 처치한다.
- 버튼·대상 위 안내·키보드 안내·접근성 이름이 같은 입력을 설명한다.
- 실제로 목격·신고·녹화된 상황과 정상 변장 통과를 구분한다.
- 물건·장소 이름 뒤 조사는 받침에 맞춘다. `을(를)`, `(으)로` 같은 편집 표기를 표시하지 않는다.
- 카드키·비밀번호·층수·웅크리기 명칭을 맞춘다. 대사의 구어체는 인물 말투에 맞게 유지한다.
- 이미 표시하는 진행 숫자나 완료 안내를 반복하지 않는다.

옷 갈아입기 단계에는 조명 등 다른 행동이 선택됐을 때의 대상 전환 안내를 추가했다. 기절자를 시체로만 부르던 운반 상태·결과 통계도 구분했다. 제압만으로 받을 수 있는 보너스는 `몰살` 대신 `전원 제압`으로 표시한다.

## 저장과 확인

기존 저장의 `비번` 단서도 현재 `비밀번호` 기회 경로를 연다. 소품 표시 이름은 현재 의뢰 정의로 보정하며, 들고 있는 물건·체력·획득 여부는 보존한다.

관련 회귀 17개 통과: `t_copy_scenarios`, `t_combat_policy`, `t_hanging_controls`, `t_disguise_ai`, `t_building_search`, `t_mission_flow`, `t_mission_progress`, `t_m2`, `t_ui2`, `t_choice`, `t_interaction_flow`, `t_contract_density`, `t_tut`, `t_tutI`, `t_tut2`, `t_btn4`, `t_change`. 전체 지도 도달 검사도 통과했다.

새 문구 시나리오는 실제 표적 기절 후 처치 안내, PC·모바일 버튼 및 접근성 이름, 카드키 획득 조사, 물품별 회수 알림, 공터·2층 표시, 구버전 단서 및 소품 이름 복원을 확인한다. 기존 신분 연습 테스트는 현재 행동 선택 방식에 맞춰 대상 전환과 동작 완료 대기를 사용하도록 보완했다. PC·모바일 화면을 직접 캡처해 버튼 문구와 도움말 줄바꿈도 확인했다.
