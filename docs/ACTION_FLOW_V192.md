# 접근·제압·운반과 도주 v192

모션 수보다 입력과 다음 동작의 연결을 개선한다. 기존 주인공, 스프라이트, 공격 거리, 달리기·운반 속도, 발소리·시야·위장·처치 입력 규칙을 유지한다.

## 연결

- 접근하며 누른 공격은 0.32초 동안 처음 고른 적과 실제 입력에 묶인다. 실제 48px 접촉 범위에 들어와야 시작하며 자동 이동·돌진은 없다. 멈춤·후퇴·장애물·층 변경·피격·적의 돌아봄 또는 발견·대상 교체·일시정지는 취소한다. 놓은 입력은 기절로 유지되고 다른 공격 키를 빌려 처치로 바뀌지 않는다. 기존의 특정 대상 없는 공격 예약을 대체한다.
- 제압 마무리의 행동 예약 범위를 마지막 0.25초에서 0.45초로 넓힌다. 접근 때 유지하던 이동 방향은 계속 누를 수 있다. 새 방향으로 이탈하거나 피격되면 예약을 취소한다. 옷을 얻으려던 입력을 운반으로 바꾸지 않는다.
- 몸이 바닥에 닿은 뒤에만 운반으로 연결한다. 이어지는 운반은 이미 몸을 낮춘 자세에서 시작하고, 몸을 어깨에 올린 뒤 이동 입력을 받으면 첫걸음으로 넘어간다. 보관함에 넣기는 전체 들기 동작과 보관함 접촉을 기다린다. 운반 속도나 기술 효과를 무료로 높이지 않는다.

## 도주 동선

첫 의뢰 「담배 한 대」 서쪽 적치장에 실제로 시야를 막는 상자와 두 번째 모서리 뒤 풀숲을 둔다. 쫓기던 길에서 방향을 바꿔 마지막 목격 위치를 벗어나는 선택이다. 원래 잠입·암살·탈출 통로는 유지한다. 첫 반복에서는 나무 충돌로 풀숲 옆에 도착하는 문제가 보여, 자연스럽게 돌아 들어가는 위치까지 풀숲을 넓혔다. 적의 추적·수색·기억을 약하게 만들지 않았다.

## 실제 입력 검토

`tests/tutorial/action_flow_live.py`는 새 저장에서 UI로 연습·첫 의뢰를 선택하고 키보드 또는 CDP 다중 터치를 사용한다. 일반 RAF·비고정 난수·활성 AI 상태다. 배우 위치, 기술, 체력, 인벤토리, 경계 또는 임무 진행을 변경하지 않는다. 이미 지도를 아는 개발자 재생이며 실물 휴대전화나 초보자 사용성 연구는 아니다.

PC에서 같은 접근·이른 행동 입력을 재생한 한 쌍의 기록:

| 관찰 | v191 | v192 |
|---|---:|---:|
| 이른 운반 입력 | 무시되어 제압 종료 후 한 번 더 입력 | 첫 입력으로 연결 |
| 제압 시작 관찰→운반 첫걸음 | 약 1.805초 | 약 1.455초 |
| 몸 들기 시작 관찰→첫걸음 | 약 0.667초 | 약 0.433초 |

v192 모바일에서도 같은 연결을 약 1.488초에 완료했다. 모든 사람의 체감이나 평균 성능을 나타내는 수치는 아니다. PC·모바일 모두 제압·운반·숨기기에서 체력 3·발각 0·기절자 숨기기 1회를 기록했다.

PC·모바일 도주는 실제 발각을 확인한 뒤 달리기→모서리 우회→걷는 속도로 웅크려 다른 풀숲에 진입했다. 체력 3을 유지하고 10초 후에도 수색 중인 적에게 재발견되지 않았다. 위치를 바꾸는 플레이를 검증한 것이며 이 풀숲이 영구 안전하다는 뜻은 아니다. 순찰이 실제로 보지 못한 대기 시도는 도주 성공으로 세지 않았다. 대기 지점이 차량에 가려질 수 있어 재검증용 입력은 순찰 통로에서 발각을 확인한다. 해당 재검증도 양쪽에서 통과했다.

- [PC 연결 GIF](action-flow-v192/pc-handoff.gif) · [모바일 연결 GIF](action-flow-v192/mobile-handoff.gif) · [실제 도주 GIF](action-flow-v192/pc-escape.gif)
- GIF는 실제 입력 녹화의 일부다. PC 연결 장면은 동작이 보이도록 잘라 확대했고, 모바일과 도주는 화면을 축소했다.
- 같은 폴더의 JSON은 v191 비교, v192 네 장면, 추가 도주 반복과 제어된 입력 검사 기록이다. 기절은 처치와 다르며, 이 연결 재생은 기절→운반을 검증한다. 지속 입력 처치와 의뢰 완료는 별도 회귀·VIP 재생으로 확인한다.

제어된 `t_action_flow.py`는 PC·다중 터치 입력의 실제 접촉, 단일 대상·입력 유지, 취소 조건, 짧은 예약 만료, 지속 입력 처치, 착지 후 운반, 몸을 확보한 뒤 이동, 옷 갈아입기 우선순위와 새 동선의 충돌·시야·접근성을 검사한다. 기존 회복 입력·암살 리듬·물리 상호작용 검사와 빌드 파이프라인 8개, 물리 상태 전이 20개 그룹도 확인했다. 전체 핵심 회귀와 실제 입력 재생은 PR의 CI에서 반복한다.

```sh
python build.py
python tools/package_cloudflare_2d.py build/yahaeng_city.html
PYTHONPATH="$PWD/tests/support:$PWD/tests/tutorial" YH_TEST_HTTP=1 python tests/rev/t_action_flow.py
# 저장소를 8002 포트에서 제공한 뒤 실행
PYTHONPATH="$PWD/tests/support:$PWD/tests/tutorial" YH_TEST_HTTP=1 python tests/tutorial/action_flow_live.py
```
