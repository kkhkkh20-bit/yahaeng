# 의뢰 04 공간·목표 확장 (v186)

v185는 정문 표적과 북서쪽 명세서만 처리하면 끝났다. 동쪽 분류 구역과 배송 사무실 2층을 사용할 이유가 약했고, 익숙한 경로는 1~2분에 끝낼 수 있었다.

## 이번 변경

- **동쪽 검수대의 표적**: 오태식은 분류창고 동쪽 검수대에서 운송 번호를 확인한 뒤 상차장을 돈다. 정문 시작 지점에서 곧바로 끝내던 암살은 창고 내부 잠입으로 바뀐다. 동쪽 선반 뒤에는 실제 차폐와 사물함을 두어 관찰·접근·시체 정리의 공간을 만든다.
- **북서쪽 기록보관실**: 카드 문과 덕트 우회 선택을 유지한다. 분류창고 내부 덕트를 이용하면 동쪽 검수 구역과 서쪽 보관실을 연결할 수 있다.
- **남동쪽 사무실 2층의 배송 중단**: 명세서의 출고 번호를 알아야 특정 배송을 취소할 수 있다. 서류를 가져오는 것만으로는 출구가 열리지 않는다. 실제 컴퓨터에서 3.5초간 작업해야 하며, 이동·피격 시 중단된다. 특수 기술을 요구하지 않는다.
- **배차 담당자**: 2층에서 단말과 사무 구역 사이를 순찰한다. 작업복으로 정상 통행은 가능하지만 단말 조작은 목격되면 의심받는 행동이다. 자리를 비우는 때가 작업 기회다. 배송을 중단하면 담당자가 실제 단말로 걸어와 확인한다. 그 사실만으로 전역 경보나 복장 발각을 만들지 않는다.
- 작업 완료 후 동쪽 큰길 또는 서쪽 골목으로 이탈한다. 목표 안내와 브리핑은 암살 → 명세서 → 배송 중단 → 탈출의 의미를 밝힌다. 단말은 서류 회수가 아닌 현장 작업으로 표시한다.

맵 크기를 늘리는 대신 기존 동쪽 창고와 2층을 필수 플레이 공간으로 만들었다. 의미 없는 지점 방문이나 임의의 카운트다운은 추가하지 않았다. 숙련 경로 재생의 시간과 사전 정보 없는 이용자의 첫 플레이 시간은 구분한다.

## 저장과 검증

기존 완료 기록과 보상은 그대로 유지한다. v185 체크포인트로 이어 할 때는 체력·복장·카드·명세서 진행을 보존하고 배송 중단 목표만 추가한다. 이미 명세서를 확보한 저장도 출고 중단을 마쳐야 탈출한다.

구조 검사는 동쪽 표적, 실제 2층 컴퓨터와 계단 접근, 명세서 선행 조건, 작업 시간·중단, 담당자 확인 행동, 출구 조건과 구버전 체크포인트 이관을 검증한다. 기존 의뢰의 서류 회수 동작에는 기본값을 적용한다.

실시간 재생은 새 저장과 실제 키보드/터치 입력으로 시작한다. 플레이어·적 위치, 체력, 기술, 인벤토리, 목표, 경보를 강제로 바꾸지 않는다. 지도 좌표와 순찰 상태를 읽어 알려진 경로를 재생하며, 실제 이동 궤적과 층 정보를 남긴다. 사전 정보 없는 사용성 평가나 실물 휴대폰 검사가 아니다.

환풍구를 열면 가까운 경비가 소리를 조사해 출입구까지 올 수 있다. 경비가 조사 중인 출구로 그대로 돌아가면 발각될 수 있으므로 재생에서도 실제 사물함에 숨고 순찰 복귀를 확인한 뒤 나온다. 경비를 비활성화하거나 시야·청각을 낮추지 않는다.

동일한 카드 접근 재생의 관측 시간은 v185 PC 약 78초·모바일 약 93초에서 v186 PC 약 120초·모바일 약 177초였다. 이는 경로와 순찰을 읽는 숙련 재생 시간이며 처음 플레이하는 사람의 예상 소요 시간은 아니다. 시간은 프레임 부하와 순찰 도착 시점에 따라 달라진다. PC 이동 궤적은 지상과 2층, 동쪽 검수대·서쪽 보관실·남동쪽 배차실을 실제로 거쳤다.
