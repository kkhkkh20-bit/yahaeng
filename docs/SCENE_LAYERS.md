# 실내외 겹침과 옥탑방 입구 · v89

2층 실내를 연 뒤 그리는 전선·옥상 간판·깃발이 방 안을 가리던 문제를 수정했다. 열린 상층 건물의 범위를 제외하고 외부 패스를 그린다. 건물 밖의 전선과 옥상에서 보는 간판은 유지한다. 살피기 표시도 현재 층에 맞춘다.

옥탑방 옆면 문은 현재 시점에서 거의 보이지 않았다. 실제 문 좌표와 진입 방향에 열린 철문, 작은 디딤판, 계단 명판을 그린다. 둥근 문 아이콘을 대체하며, 새 이미지·캔버스 캐시는 만들지 않는다. 건물 배치, 계단 좌표, 충돌, 자동 하강 동작과 버튼 위치는 바꾸지 않는다.

## 검증

- `t_scene_layers`: 외부 전선을 실내 위에 가로질러 배치한 경우와 제거한 경우의 실내 픽셀 동일. 옥상 간판은 실내에 제출되지 않고 옥상에서는 유지. 살피기 층 분리 확인.
- 7개 맵의 옥탑문 45개: 표시 생성, 캔버스 추가 할당 0, 그래픽 상태 복원, 문·격자 좌표 불변, 기존 문 접근 판정 유지.
- 관련 회귀: 옥탑문 자동 하강, 계단 구조, 공간 매칭, 높이 단서, 옥상 시체, 카메라·말풍선, 모바일 UI.

[실제 플레이 화면 전후 비교](scene-layers/index.html). 같은 맵·좌표·화면 크기(620×920)로 촬영했다. 첫 장면은 본채 2층 실내, 둘째는 같은 건물의 옥상 계단 입구다.
