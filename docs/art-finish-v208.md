# 인물과 공통 소품 마감

연락책 정하린과 회계 중개인 문서윤을 여성 인물로 구성했다. 연락책은 구리빛 머리와 청색 작업복, 중개인은 버건디 단발과 옥색 정장이다. 중개인은 정장 체형, 운반·제압 반응, 평상시 소품 동작과 초상을 함께 굽는다. 클럽 실장은 애쉬브라운, 상권 보스는 회색, 까마귀는 백발, 의장은 연금색 머리로 구분한다. 일반 주민의 기존 팔레트 열 개도 자연스러운 갈색·구리색·회색 계열로 나눴다. 복장 접근 권한을 정하는 키는 유지한다.

새 이름은 브리핑, 대사, 회수 문서와 조직도에 함께 반영한다. 의뢰·단서·표적의 저장 ID와 성장 순서는 유지한다. 이전 체크포인트의 명명된 표적에게 남은 구형 시체·벗겨진 복장 체형은 현재 프로필에 맞춘다. 인물의 머리와 옷, 기절·운반·소품 동작의 체형이 따로 바뀌지 않도록 검사한다.

## 실제 화면에서 확인한 소품 문제

기존 가구에는 밝은 살구색 목재·분홍 천과 짙은 새 가구가 섞여 있었다. 길게 구워진 그림자가 인접 물건과 바닥을 덮었고, 일부 스피커는 조리대처럼 보였다. 좋은 벽등·스위치 에셋은 한 사무실에만 쓰였다. 동일한 캐릭터 투영과 타일 크기에서 소품을 다시 정리한다.

- 가구 39종을 4방향, 침구·소파·의자·깔개는 3색으로 출력한다. 총 220개 프레임을 단일 2D 아틀라스에 담는다.
- 목재는 월넛, 금속은 차콜과 무광 회색, 천은 남색·와인색·올리브색으로 맞춘다. PC에는 모니터·키보드·문서, 선반에는 실제 재고와 라벨, 바에는 병과 서랍, 스피커에는 원형 드라이버를 넣는다.
- 그림자는 물건 밑의 짧은 접지 그림자로 통일한다. 책상·침대·선반의 충돌 칸, 엄폐·숨기·통로·층 정보는 바꾸지 않는다.
- 벽등과 스위치는 기존 CC0 기반 사무실 에셋을 전 구역에서 재사용한다. 전기 회로·광원 위치·밝기 판정은 유지한다. 책상 위 문서·전화·약품은 새 표면 높이에 맞추며 접근할 바닥 위치는 유지한다. 창틀은 무광 금속색, 실제로 열리는 옷장·사물함은 문 패널·힌지·손잡이 마감으로 맞춘다.

모든 가구는 기존 Kenney CC0 모델 또는 프로젝트에서 작성한 기하를 오프라인에서 렌더링한다. 출처·모델 SHA-256·라이선스는 `src/art/prop-finish/`에 기록한다. 실행 중 3D 모델이나 엔진을 추가하지 않는다. 아틀라스는 폭 1024px, 높이 4096px 이하, 256색이다. 사용하지 않는 이전 가구 이미지의 로딩을 피하고, 늦게 도착한 아틀라스는 바닥·위층·미니맵 캐시를 한 번 갱신한다.

오프라인 검수에서 발견한 두 오류도 수정했다. 공유 메시의 정점을 직접 수정하면 다른 부품까지 변형되므로 각 메시와 월드 변환을 먼저 복사한다. Blender가 오브젝트 행렬의 전단을 분해하면서 생기는 옆면 기울기는 최종 투영을 정점에 직접 적용해 제거한다.

## 검증 방식

`t_art_finish.py`는 모든 프레임의 실제 알파 경계·바닥 접점·아틀라스 크기를 확인한다. 실제 선형 의뢰 15개에서 모든 배치 가구의 렌더러와 상태 보존을 검사한다. 지연된 이미지 요청을 의도적으로 보류해 출발 뒤에도 새 그림이 적용되고 세계 상태가 바뀌지 않는지 확인한다. 여성 표적의 기절·구형 체크포인트 외형 복원도 검사한다.

`build/art-v208/`의 전후 화면은 위치와 RAF를 통제한 미술 검수이며 무보정 완주 기록이 아니다. 실제 키보드·터치 검사는 기존 캠페인·상호작용·VIP 플레이 검사로 별도 실행한다.

기존 `t_hide_flow.py`의 시체와 플레이어가 수납 공간을 함께 쓰는 fixture는 변경 전 v207에서도 같은 지점에서 실패했다. 이 오래된 기대값을 맞추기 위해 수납 용량이나 게임 규칙을 바꾸지 않았다. 현재 상호작용 검사와 실제 캠페인 검사는 별도로 유지한다.
