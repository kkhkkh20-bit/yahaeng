# v152 기술 경로와 미션 업적

[실제 전후 비교](skills-v152/compare/index.html) · [최종 화면과 검증](skills-v152/index.html)

기술 27개를 세 계열 모두 펼쳐 놓고, 기술을 선택할 때 오른쪽 설명 창을 연다. 화면이 좁으면 같은 연결도를 가로로 이동한다. 계열 버튼은 그 계열로 이동하며 다른 계열을 숨기지 않는다. 설명 창은 닫을 수 있고 Escape는 설명을 먼저 닫은 뒤 기술 화면을 닫는다. 작은 화면에서는 오른쪽 창이 화면 높이를 사용한다.

배치의 행과 열은 실제 선행 조건에서 계산한다. 모든 자식은 부모 바로 다음 단계에 놓이고 화살표는 실제 24개 선행 관계만 표현한다. 선택하면 루트부터 이어지는 경로가 강조되고, 설명에 전체 습득 순서와 아직 필요한 포인트를 표시한다. 노드 선택은 구매가 아니다. 별도의 배우기 버튼이 조건과 포인트를 확인한다. 기존 27개 ID·비용·선행 조건은 유지한다.

각 기술에는 기본/습득 후 변화, 실제 활용 상황, 조작법을 넣었다. 예를 들어 접근 암살은 제압 숙련 → 접근 암살, 합계 3P다. 회로 분석은 현장 장비 → 무전기 역이용 → CCTV 해킹 → 회로 분석, 합계 7P다. 이미 배운 선행 기술은 남은 비용에서 빠진다. 안내 그림은 기존 게임 스프라이트를 사용하는 정지 그림이며 전투 영상으로 표시하지 않는다.

## 가까이 붙어야 하는 기본 제압

기본 후방 기절·살상·붙잡기 거리는 32px(게임 거리 1m)로 줄인다. 기존 무료 112px 돌진을 제거하고 같은 `reach` ID의 **접근 암살** 기술에 넣었다. 제압 숙련 1P를 배운 다음 접근 암살 2P를 배우면 112px(3.5m)에서 직접 이동해서 접촉 후 제압한다. 기존에 `reach`를 배운 저장 기록은 그대로 인정한다.

대상 선택, 직접 행동 요청, 붙잡기 진입, 타격, 저장된 미완료 돌진 복원에서 범위를 검사한다. 접근 중 벽이 생기거나 대상의 층·높이가 달라지면 취소한다. 기존 짧게 기절/같은 입력을 계속 누르면 살상 규칙은 유지한다. 연속 암살의 두 번째 이동은 해당 기술이 제공하는 동작이다. 소매치기는 별도 상호작용이므로 기존 거리 규칙을 유지한다.

암살 연습의 표시 위치도 더 가까운 접근에 맞췄다. 연습에서 실제로 이동해 쌍암살·연속 암살을 완료하는 검사를 유지한다.

## 미션 업적으로 얻는 포인트

처음 4P를 주며 본편의 완료·업적 기록에서 포인트를 계산한다. 단순히 시도하거나 실패하거나 같은 업적을 다시 완료하면 추가 지급하지 않는다. 첫 완료와 새 업적은 결과 화면에 각각 내역을 표시한다. 브리핑과 의뢰 목록에서도 보상을 확인할 수 있다. 기술 화면의 **미션 업적 · 포인트 얻기**는 각 의뢰의 미달성 목표와 이미 받은 보상을 보여 준다.

| 현재 본편 미션 | 첫 완료 | 주요 업적 | 나머지 업적 | 신규 기록 최대 |
|---|---:|---|---:|---:|
| 의뢰 01 · VIP (`m2`) | 2P | 표적을 모두 사고로 처리 · 2P | 각 1P | 6P |
| 의뢰 02 · 대청소 (`m4`) | 2P | 시체·기절자 발견 없이 완료 · 2P | 각 1P | 10P |
| 의뢰 03 · 배신 (`m6`) | 2P | 기절·살상 없이 완료 · 2P | 각 1P | 8P |

신규 본편 기록만으로 시작 4P + 미션 보상 24P = 28P다. 전체 기술 비용은 43P이므로 먼저 자신의 접근 방식에 맞는 기술을 고르게 된다. 이전 의뢰의 완료·업적은 각각 1P이며, 이미 달성한 폐지 업적도 이월한다. 별은 등급·진입로를 위한 기존 기록으로 유지하고 기술 포인트와 표시를 분리했다.

연습은 새로운 영구 포인트를 지급하지 않는다. v151까지 이미 받은 연습/도시 포인트는 첫 마이그레이션 때 별도로 이월하고, 재배분·재실행에서도 이월분을 보존한다. 기존 보유 기술이나 남은 포인트를 빼앗지 않는다. 포인트 재배분은 저장된 업적 보상을 유지하면서 배운 기술만 비운다.

## 레퍼런스 조사와 적용 범위

공식 Steam 소개문을 읽고 공통 원리를 적용했다. 작품별 세부 경험치 수치나 공개하지 않은 내부 구현을 가져왔다고 주장하지 않는다.

- [Mark of the Ninja](https://store.steampowered.com/app/214560/): 선택 목표를 완료하고 도구·기술로 다른 공략 방법을 여는 성장. 미션의 선택 업적과 기술 보상을 연결하는 데 참고했다.
- [HITMAN World of Assassination](https://store.steampowered.com/app/1659040/): 반복 가능한 미션에서 장비를 해금하고 다양한 방법을 시도하는 구조. 의뢰별 미달성 업적과 이미 받은 보상을 보이게 하고, 같은 목표 재달성은 중복 지급하지 않는다.
- [Dishonored 2](https://store.steampowered.com/app/403640/): 능력 강화 트리를 통해 플레이 방식을 달리하는 설계. 단순 수치 설명에 그치지 않고 ‘어떤 경로·상황에서 쓸 수 있는가’를 기술마다 명시했다.

## 모듈과 검증

`25_skill_rewards.js`는 업적별 보상, `25_skill_tree.js`는 소유권·예산·마이그레이션, `83_skill_paths.js`는 선행 관계 배치·활용 정보, `84_skill_menu.js`는 선택·오른쪽 설명·구매를 소유한다. 새 UI 라이브러리나 외부 패키지는 추가하지 않았다. 기존 Impeccable 스킬로 화면을 검수했으며 신규 이미지나 연속 애니메이션 루프를 추가하지 않는다.

검증 범위는 최종 갤러리의 원본 JSON과 로그에 기록한다. 실제 PC·터치 입력의 기술 구매, 미습득 먼 거리 공격 차단, 습득 후 물리적 접근·기절, 전기 조작, 장비 연습 완료를 확인한다. 전후 비교는 v151의 실제 커밋 패키지와 v152 패키지를 같은 4P·미습득 상태에서 1440×900 / 390×844로 실행한 원본 스크린샷이다. 비교 슬라이더는 이미지를 수정하지 않는다.

최종 검증: 빠른 회귀 47개, 빌드 소유권 6개와 전 의뢰 도달 검사를 통과했다. 회귀 묶음 안에서 36개 의뢰 경로를 실제 이동·문·카드·목표·탈출로 완료했다. 최종 분할 패키지에서도 PC·터치 기술 구매와 접근 암살, 전기 조작, 장비 연습 완료를 확인했다. 독립 화면 검수는 12개 캡처와 소스에 대해 `ship`을 반환했다. 실물 휴대폰 성능 측정 결과는 아니다.
