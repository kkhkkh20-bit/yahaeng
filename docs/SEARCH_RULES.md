# 층 안내·변장·건물 수색 수정 · v92

## 화면 안내

- 상단 목표: `의뢰: 제비의 무전기 챙기기 · 감금동 2층 · 25m`처럼 실제 건물과 층을 표시한다. `1층 위/아래`를 거리 옆에 반복하지 않는다.
- 지도 목표: `의뢰: 제비의 무전기 챙기기 · 2층`. 모바일에서는 건물명까지 반복하지 않는다.
- 건달파 경계: `건달파 구역 · 적대 조직 발견 시 공격`. 기존 규칙상 중립 행인은 통과하고 적대 조직 복장이 공격 대상이므로, 모든 비조직원을 공격한다고 쓰지 않는다.
- 정상 변장으로 통과할 때 일반 경비의 시선만으로 빨간 고리를 표시하지 않는다. 노란 신원 확인과 실제 발각·추격을 구분한다. 얼굴을 아는 반장·정예·표적은 가까이서 얼굴을 확인한 뒤 변장을 알아본다. 뒤통수만으로 얼굴을 판별하지 않는다.
- 기존에 목격·신고된 복장은 계속 알려진 복장이다. 다른 옷으로 갈아입는 것이 목격되지 않으면 새 복장을 자동으로 알아내지 않는다.

## 판정과 수색

실내 1층의 가구·내벽을 외벽 등반으로 취급하던 조건을 제거했다. 실행할 때도 등반 지점을 다시 확인하므로, 실외에서 고른 오래된 행동으로 실내에서 옥상으로 이동할 수 없다. 정상 외벽 등반과 옥탑문·계단 이동은 유지한다.

수색은 마지막 목격, 신고된 시체 위치, 실제 CCTV 화면의 범행을 출발점으로 삼는다. 사라진 플레이어의 현재 위치·층을 읽어 추적하지 않는다. 최대 6명이 현장·출입구·층별 방·옥상·은신처를 예약해 나눠 확인한다. 방이 길면 안쪽까지 걷는다. 실제 계단·배관으로 이동하고 같은 층의 목적지에 도착해야 확인 완료로 처리한다. 길이 없다는 이유만으로 도착한 것으로 판정하지 않는다.

첫 계단 입구까지 갈 수 없는 경비에게 일을 맡기지 않는다. 잠긴 문이 경로에 있으면 문 앞에서 여는 동작을 거친다. 한 경비가 갈 수 없는 지점은 다른 경비가 다시 시도할 수 있다. 동료가 여는 문 소리 때문에 다시 한 지점에 몰리지 않는다. 수색이 끝나거나 시간이 지나면 자기 일과로 돌아간다. 은신처는 실제로 접근해서 조사하며, 다른 층의 은신처를 원격으로 들추지 않는다.

실내 CCTV는 같은 방의 벽 모서리 후보 중 실제 벽에 가리지 않는 촬영 범위와 경비 작업점과의 거리를 평가해 설치한다. 외부 카메라와 서치라이트는 유지한다. 관리실 담당자는 공동 수색에서 제외한다. 담당자가 화면 옆에 있어야 CCTV 신고가 전달되며, 자리를 비웠거나 제압되면 녹화만 남는다. 시체만 찍힌 경우 범인의 얼굴·복장을 새로 만들지 않는다.

기존 저장의 CCTV 위치를 보정하되 고장·정전·녹화 상태와 임무 진행은 보존한다. 수색 예약도 체크포인트에서 이어진다.

## 검증

- 6개 임무 실내 13,388개 위치·방향에서 잘못된 외벽 등반 없음. 6개 임무의 정상 외벽 등반 및 오래된 행동의 실내 실행 차단 확인.
- 실내 CCTV 6대의 실제 모서리 설치·열린 바닥 위치·기존 저장 보정 확인.
- 주요 의뢰 3개에서 6명씩 분담, 실제 2층 방 확인, 미목격 이동을 추적하지 않음, 수색 종료와 체크포인트 복원 확인.
- CCTV 담당자를 남겨 두어도 지상 경비가 계단을 타고 2층 은신처까지 조사해 발견함.
- 실제 공격 목격 → 추격 → 시야 상실 → 건물 공동 수색, CCTV 범행 신고의 위치·층·목격 복장 전달 확인.
- 정상 변장 순찰 유지, 뒤통수로 신원 확인하지 않음, 노란 신원 확인 → 실제 발각, 은신 직후 오래된 빨간 표시 제거 확인.
- 관련 기존 회귀 18개와 새 수색 회귀, 전체 지도 도달 검사 통과. 실시간 세력 테스트는 병렬 실행 1회 실패 후 단독 재실행에서 통과했다. 자동화된 상황 재현 결과이며 난이도·완주 시간의 사용자 플레이 평가는 별도로 필요하다.
