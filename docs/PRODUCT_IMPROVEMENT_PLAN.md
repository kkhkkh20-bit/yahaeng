# 야행 개선 기획안 — VIP 한 판의 완성

작성일: 2026-10-31 · 기획 기준: v93 / 0526d6d · v94 개발 반영. [적용 결과와 미실시 검증](PRODUCT_IMPLEMENTATION.md).

## 1. 목표와 범위

플레이어가 “위치를 따라가서 처리했다”보다 “관찰해서 만든 계획이 통했다”고 느끼는 잠입 게임을 만든다. 현재 주요 의뢰 세 개 중 VIP를 먼저 완성하고, 검증된 조작·표현·저장 규칙을 대청소와 배신에 확장한다. 앞선 자체 리뷰 58점은 주관적 평가이며 개선 후 점수를 보장하는 수치는 아니다.

이번 작업의 성공 기준은 다음 세 가지다.

1. 실패했을 때 누가 무엇을 봤고 왜 실패했는지 설명할 수 있다.
2. 같은 VIP 의뢰를 다른 방법으로 다시 해보고 싶다.
3. 안내문을 읽지 않아도 문·계단·층·현재 조작 대상을 구별할 수 있다.

첫 범위는 VIP의 클럽·사무동·연결 골목이다. 기존 여성 주인공, 메인 포스터, 현재 카메라, 오른쪽 미니맵, 중앙 섞임 표시, 모바일 버튼 위치를 유지한다. 장부 회수와 실장 처치는 순서를 자유롭게 선택한다. 처치는 모든 수동 입력에서 길게 누르기 원칙을 따른다.

## 2. 플레이 흐름

브리핑은 “클럽 실장 처치 / 사무동 장부 회수 / 이탈” 세 목표와 알려진 활동 장소를 전달한다. 출발하면 포차·클럽·사무동이 공간에서 읽히고, 공개 장소에서 위험 없이 관찰할 수 있다.

| 구간 | 플레이어의 판단 | 게임의 반응 |
|---|---|---|
| 탐색 | 실장이 어디서 무엇을 하는가? 어떤 신분이 통하는가? | 표적 일과, 직원의 이동, 구역 입구, 대화로 정보를 준다. |
| 준비 | 어떤 경로의 위험을 감수할 것인가? | 선택한 단서와 준비물이 한 경로의 기회로 연결된다. |
| 침투 | 정문·직원 복도·옥상 중 어디로 들어갈 것인가? | 신분·시선·문·높이의 실제 조건을 일관되게 적용한다. |
| 실행 | 혼자 있는 틈을 만들 것인가, 사고를 기다릴 것인가? | 준비한 조건이 실제 인물 행동과 현장 변화로 이어진다. |
| 뒷수습 | 목격·시체·녹화 중 무엇이 남았는가? | 남은 문제를 구체적으로 알리고 대응 기회를 준다. |
| 이탈 | 익숙한 길로 돌아갈 것인가, 다른 길을 쓸 것인가? | 경비는 실제 신고와 경로에 따라 움직인다. |

각 구간은 고정 순서의 퀘스트가 아니다. 정찰을 생략한 돌파와 조기 장부 회수도 허용한다. 플레이 시간을 늘리기 위한 대기·반복 왕복·추가 열쇠는 넣지 않는다.

## 3. 세 공략법의 차이

세 경로 자체는 이미 있다. 아래 표의 ‘변경’이 이번에 새로 다듬을 부분이다.

| 경로 | 기존 재료 | 이번 변경 | 주된 판단 |
|---|---|---|---|
| A 직원 잠입 | 직원 복장, 구토제, 술병, 화장실, 문밖에서 기다리는 호위 | 실제 음용을 유인의 원인으로 연결. 준비·음용·이동·실행 상태를 구별 | 어떤 신분으로 접근하고 언제 표적을 분리할까? |
| B 옥상 사고 | 컨테이너·배관·전선, 담배 일과, 간판 함정 | 발동 전 실제 낙하 구역과 목격 가능한 인물의 위험을 확인. 준비와 실행을 구별 | 언제 떨어뜨려야 표적만 맞을까? |
| C 금고와 뒷문 | 금고 비밀번호, 장부·파란 카드키, 직원 복도 | 카드의 사용처를 현물과 문에서 연결. 회수 뒤 기존 침투로를 재사용 | 장부를 먼저 확보해 표적 접근까지 해결할까? |

### A. 직원 잠입

직원 대화/심문/구토제 발견 → 직원 복장 확보 → 술병에 사용 → 실장이 바에 와서 실제로 마심 → 몸이 불편해 화장실로 이동 → 호위는 문밖 대기 → 플레이어가 처리·은닉·이탈을 판단한다.

현재는 술병에 구토제를 사용하는 즉시 표적 우회 경로가 시작된다. 개선 후에는 술병 상태와 실장 음용을 분리한다. 경보로 실장이 바에 오지 못하면 기회는 대기하며, “사용 실패”로 준비물을 다시 요구하지 않는다. 공격·붙잡기·사망이 일과보다 우선하고, 취소된 동작이 나중에 표적을 강제로 이동시키면 안 된다.

음용 전에는 물건을 만질 수 있는 신분과 바텐더의 시선이 위험이다. 음용 뒤에는 화장실까지 미행하거나 먼저 자리를 잡을 수 있다. 화장실 창밖·문밖 시선은 벽과 출입 구조를 따른다. 기존 호위의 사생활 대기는 새 기능으로 중복 개발하지 않는다.

일과가 한 번 지나갔다고 경로가 영구 실패하지 않도록 한다. 음용 기회 간격은 첫 조정에서 최대 약 60초를 목표로 하고, 그동안 장부·신분·CCTV를 준비할 수 있게 한다. 이는 설계 가설이며 실제 테스트 후 조정한다.

### B. 옥상 사고

담배 일과와 간판 상태 파악 → 접근로 선택 → 옥상 도달 → 낙하 구역 확인 → 실장과 행인의 위치를 보고 길게 눌러 발동 → 현장 반응과 이탈을 판단한다.

간판의 흔들리는 브래킷·파손 부위가 조작부다. 보이는 범위에서만 낙하 예정 구역과 위험을 표시하며 벽 너머 행인을 새로 드러내지 않는다. 표적이 범위 밖이어도 함정은 물리적으로 작동할 수 있지만, ‘표적 없음’을 발동 전에 알린다. 행인이 지나가면 ‘다른 사람도 맞을 수 있음’을 구별한다.

한 번 놓쳤으면 다음 담배 일과를 노리거나 다른 경로를 선택한다. 사고만 발생한 경우 주변 경비는 사고 현장을 확인한다. 플레이어의 조작을 목격하지 않았다면 자동으로 범인이나 적대 조직으로 단정하지 않는다. 은폐된 시체와 열린 거리의 사고에 같은 반응을 적용하지 않는다.

### C. 금고와 뒷문

야시장 대화/심문/사무동 2층 메모 → 사무동 1층 금고 → 장부와 파란 카드키 → 클럽 직원 복도 → VIP룸 뒷문 → 실장과 호위의 틈을 판단한다.

비밀번호를 아는 것과 사무동을 자유롭게 출입하는 것은 별개다. 조직원 복장은 사무동 접근, 클럽 직원 복장은 VIP룸 접근에 각각 의미가 있다. 카드를 얻었다고 복장 권한까지 생기지는 않는다.

금고를 뒤진 뒤 파란 카드키에 ‘클럽 VIP룸 뒷문’을 표시하고, 해당 문에도 같은 카드 표시를 둔다. 경비가 문을 보거나 호위가 방에 있으면 뒷문도 안전하지 않다. 장부를 확보했어도 표적이 남았다면 탈출을 지시하지 않는다.

## 4. 목표와 정보의 규칙

| 상황 | 보여줄 정보 | 표시 방식 |
|---|---|---|
| 브리핑만 확인 | 실장이 주로 있는 클럽, 알려진 장부 금고 | 건물/활동 구역 표시. 표적 실시간 좌표는 제공하지 않음 |
| 표적 직접 목격 | 현재 위치·층 | 선명한 인물 표식 |
| 시야 상실 | 마지막으로 본 위치·층·목격 시점 | 속이 빈 표식. 표적이 이동해도 따라가지 않음 |
| 오래된 목격 정보 | 알려진 활동 구역 | 정확한 점을 희미하게 없애고 건물 안내 유지 |
| 담배/술 일과 단서 확보 | 다음 활동 장소와 공략 기회 | 획득한 정보만 목록과 지도에 추가 |
| 위치가 이미 알려진 장부 | 금고와 실제 층 | 기존 정확한 회수 위치 유지 |

마지막 목격점 유지 시간은 15초부터 시험한다. 시간 만료가 표적 위치를 재탐색하거나 자동 갱신하는 계기가 되어서는 안 된다. 체크포인트에서도 위치 정보의 출처와 시점을 복원한다.

현재 안내 강도 설정을 활용해 전체 안내를 선택할 수 있게 한다. 기본 안내 변경 전에는 초보자가 목적지를 찾는지 검증한다. 안내를 줄여 생긴 길 찾기 부담은 난이도 개선으로 계산하지 않는다.

선택 목표는 기존 의뢰 목록에서 고정한다. 인물은 ‘클럽 실장’, ‘수금원’처럼 구별한다. 이동 중 가까운 목표로 바꾸지 않는다. 완료 시 다음 미완료 목표를 추천하고, 기회 추적을 켜면 사용자가 선택한 동안만 우선한다. 추격 시 회피 안내를 잠깐 우선할 수 있지만 기존 선택을 잃지 않는다.

다른 층 목표는 최종 목적지와 실제 연결 계단/옥탑 입구를 함께 구별한다. 평면상 같은 좌표의 빈 바닥을 ‘도착점’처럼 보이게 하지 않는다. 도달할 수 없는 최단거리 화살표 대신 연결 가능한 입구를 사용한다.

## 5. 위험·변장·수색의 공통 기준

중앙 상태, 대상 표시, 경고음, AI 판단이 같은 원인을 참조하게 한다. 노랑은 확인/의심, 빨강은 실제 발각·공격의 의미로 쓴다.

| 사건 | NPC 반응 | 플레이어에게 전달할 이유 |
|---|---|---|
| 허가된 복장으로 일반 이동·달리기 | 일과 유지 | 섞임. 경고음과 수상함을 만들지 않음 |
| 얼굴을 아는 인물이 가까이서 신원 확인 | 확인 진행 후 식별 가능 | 신원 확인 중 + 확인하는 인물 강조 |
| 허가 없는 출입 금지 구역 진입 | 경고 가능한 상황이면 퇴거 요구 | 직원 외 출입 금지 / 나가라는 경고 |
| 범행을 직접 목격 | 추격·신고 | 범행 목격 / 해당 목격자 |
| 범행을 못 보고 시체만 발견 | 현장 확인·분담 수색 | 현장 수색. 플레이어 복장을 임의로 지목하지 않음 |
| CCTV가 불법 행동 녹화 | 기록 생성. 담당자가 있어야 신고 연결 | 신원 녹화됨 / 보안실에서 삭제 가능 |
| 시야 밖에서 미목격 변장 | 기존 복장에 대한 기억 유지 | 새 복장을 자동으로 노출 처리하지 않음 |

최근 구현된 층별 분담 수색을 유지한다. 건물·입구·방·은신처를 실제 이동으로 확인하고, 현장에 한꺼번에 몰리지 않는지 점검한다. 표적 경호·보안실 담당자의 역할을 유지하며 NPC 전체를 수색에 동원하지 않는다. 수색이 끝나면 본래 일과로 복귀한다.

‘상대 조직 소행’ 추론은 이번 범위에서 추가하지 않는다. 직접 목격이나 현장 단서 없이 특정 조직에 책임을 돌리면 같은 불신 문제가 생긴다.

## 6. 상호작용과 모바일

공격·행동·붙잡기의 현재 위치와 구분을 유지한다. 수동 처치는 반드시 길게 누르며 손을 떼거나 앱을 전환하면 취소된다. 처음 선택한 대상과 입력을 동작 끝까지 유지한다.

기존 [대상] 버튼은 후보가 여러 개일 때 이름 목록을 펼치는 진입점으로 쓴다. 목록은 터치 한 번으로 선택만 하고, 실제 실행은 기존 [행동]으로 한다. PC Tab 순환도 유지한다. 각 후보는 실제 거리·시선·층 조건을 통과해야 한다.

예: ‘클럽 직원 옷으로 갈아입기 / 운반 / 조명 끄기’. 고른 대상만 윤곽선으로 강조하고 대상이 사라지면 조용히 다른 물체를 실행하지 않는다. 목록을 여는 동안 새 이동·전투 입력을 시작하면 목록을 닫는다. 게임을 멈추는 별도 메뉴로 만들지 않는다.

대상 이름은 목록에 충분히 보여주고, 평소 화면에는 선택한 행동 한 개만 둔다. 사용 불가 이유는 버튼을 누르거나 대상을 살필 때 ‘너무 멂 / 벽에 가림 / 다른 층 / 착지 공간 없음’처럼 제공한다. 실패마다 긴 알림을 쌓지 않는다.

모바일에서는 대사·표식·후보 목록이 주인공 발과 선택 대상을 가리지 않도록 배치한다. 기존 버튼을 옮겨 해결하지 않는다. 360/390/430px 세로와 가로 화면에서 확인한다.

## 7. 공간과 미술

VIP 사무동 한 채에서 거리→1층→2층→옥상→거리 왕복이 자연스럽게 읽히는 것을 먼저 완성한다. 바닥 두께·벽 단면·계단 개구부·옥상 난간을 현재 좌표에 연결한다. 문턱·입구 조명·계단 방향은 실제 이동 입구와 일치해야 한다. 확인 후 클럽과 감금동에 적용한다.

| 장소 | 재료와 그래픽 | 플레이 기능 |
|---|---|---|
| 클럽 | 낡은 금속, 제한된 네온, 직원용 무표식 문과 구별되는 공개 출입문 | 손님 동선과 직원 동선을 구분 |
| 사무동 | 콘크리트, 업무 책상, 문 옆 출입 장치, 모니터와 배선 | 금고·보안실·계단을 장소 용도로 이해 |
| 골목 | 벽 파손, 적치물, 접촉 그림자, 열린 통로 | 은폐·등반·이탈 경로를 구별 |
| 옥상 | 낮은 난간, 설비 기초, 실제 문 방향의 옥탑 입구 | 실내와 옥상·추락 경계를 구별 |

네오펑크 느낌은 보안 장치·조명·개조된 건물과 간판의 재료에서 만든다. HUD 전체에 네온 테두리를 더하는 방식은 사용하지 않는다. 주인공의 서기·걷기·손 접촉·운반이 같은 발 기준점을 유지하는지 확인한다.

무료 에셋은 문턱, 카드 리더, 간판 브래킷, 모니터 같은 기능상 부족한 소품부터 목록화한다. 기존 Quaternius·Kenney 자산을 우선 재사용하고, 추가 자산은 원본 링크·라이선스·크레딧 조건을 기록한다. 이번 기획에서는 새 팩의 적합성이나 라이선스를 조사했다고 주장하지 않는다.

## 8. 안전 저장과 결과 평가

단서 획득, 새로운 유효 복장, 술병 준비, 중요 문 개방을 안전 저장 예약에 포함한다. 같은 진행 상태로는 반복 저장하지 않는다. 추격·적대 인물의 확인·예약 동작·길게 누르기 중에는 기다린다. 안전 확인 뒤 여러 변화를 한 번에 저장한다.

같은 복장을 벗었다 다시 입거나 문을 반복 여닫아 저장을 남발하지 않게 진행 사건을 구별한다. 저장이 실제로 성공했을 때만 짧은 저장 표시를 내고, 전체 안내 알림을 반복하지 않는다. 구버전 저장을 복원할 때 새 기획 진행도를 임의로 부여하지 않는다.

녹화와 증거 정리는 다음처럼 나눈다.

- CCTV 기록을 지우면 현재 남은 신원 기록이 사라지고 탈출 조건을 해제한다.
- 그림자 등급의 CCTV 항목은 ‘남은 신원 기록 없음’으로 판정한다. 다른 목격·신고·전체 경보는 기록 삭제로 취소되지 않는다.
- 한 번도 녹화되지 않기는 별도의 도전 항목으로 구별하고, 발생 사실을 지우지 않는다.
- 결과는 사용한 접근 방식, 수고비, 등급과 미달 이유를 먼저 보여준다. 세부 집계는 기존 상세 보기에 둔다.
- 사고 성공을 범죄 목격까지 지워 주는 면죄부로 처리하지 않는다.

## 11. 사람 테스트로 판단할 항목

개발자가 아닌 신규 플레이어 최소 5명으로 작은 검증을 한다. 이 숫자는 시장성의 통계적 입증이 아니라 큰 이해 문제를 발견하기 위한 초기 표본이다.

- 5명 중 4명 이상이 설명 없이 공개 출입문과 직원 전용 출입문을 구별한다.
- 5명 중 4명 이상이 실패 직후 ‘누가 어떤 행동을 봤는지’를 설명한다. 실패를 경험하지 않았다면 해당 항목은 별도 상황에서 확인한다.
- 5명 중 3명 이상이 첫 판 뒤 다른 공략법을 구체적으로 말하고 자발적으로 재도전을 선택한다.
- 첫 판 10~15분, 숙련 재도전 4~7분을 초기 가설로 측정한다. 짧아도 선택이 만족스럽다면 늘리지 않는다. 길어도 길 찾기·대기 시간이 대부분이면 실패다.
- 막힌 곳과 원인을 기록한다: 길 찾기 / 조작 대상 / 신분 규칙 / 표적 대기 / 실제 잠입 판단.
- 실제 iPhone Safari와 Android Chrome에서 한 판씩 조작과 중단·복원을 확인한다. 모바일 성능은 30fps 지속 플레이를 초기 목표로 실측한다.

새 기능 수나 자체 리뷰 점수보다 판정 혼란·중단·길 찾기 부담이 줄고 공략 재도전 의사가 생기는지로 다음 작업을 결정한다.
