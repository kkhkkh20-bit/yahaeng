# v248 — 벽 재료와 사물의 수광

기준 버전은 v247 (`14eae82c`)다. 구매한 픽셀 원본은 유지하고, 면을 조립하는 방식과 빛을 받는 대상을 수정했다.

[같은 위치의 전후 화면](comparison.png)

## 수정

- 첫 에피소드의 세로 벽: 가로 벽의 굵은 상·하단 몰딩을 매 칸 반복하던 방식 대신, 구매 패널의 평평한 부분만 세로로 이어 붙였다. 경첩이나 입체 가구를 회전한 것이 아니다.
- 두 번째 에피소드의 보도: 곡선 경계까지 포함한 모듈 전체가 담처럼 보였다. 구매 보도 바닥을 유지하고, 도로와 접한 가장자리에 원본 2px/월드 3px의 띠만 배치했다. 통행·충돌 격자는 바꾸지 않았다.
- 실내 전용·높은 가구 전용이던 수광 처리를 확대했다. 벽의 가까운 면과 책상·의자·소파·수납장·상자·구매 식생의 실제 스프라이트 알파에 밝기를 적용한다. 올라간 그림 픽셀의 수광 위치는 해당 사물의 물리 footprint 앞면으로 투영한다.
- 벽 앞면을 밝히는 것과 벽 뒤 바닥을 밝히는 것을 분리했다. 광선과 수광 검사 모두 기존 `castRay/los`로 첫 차단 지점까지만 도달한다. 다른 방의 바닥을 드러내기 위해 광선을 벽 뒤로 늘리지 않는다.
- 이미 탐지 밝기에 반영되던 손전등·서치라이트를 같은 가려진 빛 필드에 연결했다. 꺼지거나 방향이 바뀐 광원은 잔광을 남기지 않는다. 서치라이트의 중복 채움 효과는 없애고 얇은 경계만 유지했다.
- 문이 움직일 때 가까운 광원의 다각형과 해당 층 합성 캐시를 갱신한다. 이전에는 판정 경로만 열리고 화면에는 닫힌 문의 그림자가 남을 수 있었다.
- 지상과 위층의 조명 계산은 층을 명시하고 이전 층을 복구한다. 카메라 시야를 그린 뒤 활성 격자가 플레이어 층으로 바뀌던 부작용도 수정했다.
- 고정 광원은 작은 지역 캐시에 보관한다. 문 하나를 열 때 모든 등과 가구의 수광을 다시 계산하지 않는다. 움직이는 빛만 프레임마다 계산한다.

이는 기존 2D/2.5D 장면의 밝기·차단 계산이다. 재질별 물리 반사, 다중 반사광, 노멀맵을 새로 구현했다고 주장하지 않는다. 지상에서 비추는 손전등이 옥상 전체를 밝히도록 바꾸지도 않았다.

## 확인

- `t_surface_lighting.py`: PC/터치에서 실제 제작 맵·구매 스프라이트의 켜짐/꺼짐 픽셀 비교. 수납장·소파·책상·의자·실외 상자의 밝기 변화 확인. 낮은 소파의 footprint 위로 올라간 451개 불투명 표본도 밝아졌다.
- 같은 검사에서 벽 앞면 조명 알파 221/255, 뒤 바닥 0/255. 손전등은 앞면 223·뒤 0, 서치라이트는 앞면 227·뒤 0. 회전·비활성화 후 잔광 0.
- 실제 문의 뒤 바닥 조명은 닫힘 0 → 열림 203 → 다시 닫힘 0. 문 충돌과 빛 캐시가 함께 갱신된다.
- `room_finish_live.py`: 자연 RAF와 실제 키보드/터치로 기존 사무실 스위치를 조작했다. 감지 밝기 1 → 0.04 → 1. [켜짐](mobile-on.png) / [꺼짐](mobile-off.png). 이는 경비를 제외하고 스위치 앞에 배치한 독립 조작 검사다.
- `first_steps_live.py`: 실제 PC/터치로 첫 에피소드의 기절·변장·몸 숨기기·2층 서류·탈출을 각각 완료했다. 체력 3, 발각 0, 페이지 오류 0. 이후 마지막 보도 띠 변경은 표시만 바꾼다.
- `t_light_presentation.py`, `t_room_finish.py`, `t_disguise_lighting.py`, `t_window_peek_surface.py`, `t_scene_layers.py`, `t_purchased_fixtures.py` 관련 검사 통과. 27맵 구매 에셋 표시, 층 사이 가림, 빛·회로·기존 저장 상태, 4,380개 광선, 창 접근도 확인했다.
- `t_scene_layers.py`의 계단 표시는 현재 게임의 내려갈 층 표기와 맞췄다. 오래된 '계단' 문구를 기대하던 검사만 정정했으며 계단 동작은 변경하지 않았다.
- 빌드 검사 8개·물리 상호작용 20개 그룹·맵 도달 검사 통과.

측정값은 [PC](pc-surfaces.json), [터치](touch-surfaces.json), [실제 스위치 입력](summary.json), [첫 에피소드](first-episode.json)에 저장했다. [렌더 표본](bench.json)은 같은 Chromium에서 한 개의 보이는 손전등을 추가했을 때 PC 약 10.0ms, 모바일 크기 약 5.1ms/프레임이었다. 짧은 렌더 표본이며 실물 iPhone 성능이나 모든 에피소드 완주를 의미하지 않는다.
