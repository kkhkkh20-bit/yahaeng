# v165 · 오른손 원형 웅크리기

웅크리기를 왼쪽 이동 영역에서 오른쪽 도구 버튼 위로 옮겼다. 사각 프레임을 제거하고 직접 제작한 58px 원형 SVG 세 상태(기본·웅크림·눌림)로 교체했다. 짧은 가로 화면에서는 미니맵을 피하도록 장비 버튼 위에 배치한다. 기술 연습의 보조 버튼도 겹치지 않게 배치했다. 기존 A안 그라파이트 마감을 유지한다.

390×844·320×568·844×390·568×320에서 화면 경계, 원형 모양, 44px 이상 입력 영역, 다른 버튼과의 겹침을 확인했다. 실제 브라우저 멀티터치로 왼쪽 조이스틱 이동과 오른쪽 웅크리기를 동시에 누른 상태의 이동을 검증했다. 장비·마감·인터페이스·모바일 행동·입력 경계·HUD 시스템·갈아입기 회귀 검사와 빌드 검사 7개도 통과했다.

## PixelFX 적용 현황과 후보

[PixelFX](https://github.com/patch-gg/pixelfx) 효과는 이미 9종을 사용한다. 현재 `src/art/fx/pixelfx.json` 기준으로 잎, 먼지, 피격, 칼날, 접촉 불꽃, 총구, 획득, 전기, 연막이다. 연막은 기술 장비 렌더러에서 직접 아틀라스를 사용한다. 초기 v146 문서의 8종은 당시 기록이며 현재 현황과 다르다. 현재 WebP 아틀라스는 70,764바이트다.

[공식 갤러리](https://patch-gg.github.io/pixelfx/)와 최신 README의 동작 타이밍 지원을 참고하면 다음 순서가 적합하다. 이번 버전은 조사만 했으며 새 효과를 추가하지 않았다.

1. 암살의 접촉 타이밍에 맞춘 짧은 타격 효과. 기존 캐릭터 동작의 예비 동작·접촉·회복과 연결하며 기존 칼날·먼지 효과가 중복 재생되지 않게 한다.
2. 연속 암살 이동에만 짧은 잔상을 적용해 연쇄 동작을 읽기 쉽게 한다.
3. CCTV 해킹 완료 시 현재의 범용 접촉 불꽃 대신 작은 전자 간섭 효과를 사용한다.

야간 잠입 화면에 맞춰 색과 지속 시간을 절제하고, 실제 소리·노출·조명 판정은 기존 규칙에 따라야 한다. 기존 캐릭터를 유지하며 효과와 타이밍만 가져오는 것이 적합하다.
