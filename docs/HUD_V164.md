# v164 · 승인한 A안 그라파이트 마감

모바일 6버튼과 기존 장비 패널 흐름을 유지하면서, 무광 그라파이트·은회색 테두리의 승인된 A안을 실제 게임에 적용했다.

- 직접 제작한 SVG 9개: 기본·사용 가능·눌림·위험 상태의 일반/주 공격 프레임과 패널 프레임. `tools/art/build_hud_frames.py`로 재생성한다.
- 얇은 단색 테두리를 외곽 키라인·은회색 베벨·안쪽 어두운 홈·미세한 표면결로 교체했다. 패널은 9-slice로 모서리를 보존하고 주 공격은 팔각 실루엣을 사용한다.
- 목표·메뉴·미니맵·키 안내·장비 패널·상황별 버튼을 같은 중성색으로 맞췄다. 목표 방향 표시도 은백색으로 맞췄다. 실제 조명·세계의 탈출 표시·AI 위험 판정은 바꾸지 않는다.
- 공개 빌드의 연속 캔버스 렌더링에서 일부 CSS 마스크 아이콘이 빠지는 현상을 확인해, 아이콘은 색을 상속하는 실제 SVG 노드로 직접 표시한다. 프레임은 기존 SVG 이미지와 9-slice를 사용한다.
- 눌림은 별도 에셋과 1px 내용 이동으로 표시하며 버튼 입력 영역은 고정한다.
- 기절자 마무리 처치는 문구에 ‘기절’이 들어 있어 KO로 분류되던 시각 표시를 바로잡아, 처치 아이콘과 위험 프레임으로 표시한다. 실제 공격 판정과 길게 누르기 규칙은 유지한다.

검증: 기존 핵심 회귀 스크립트 58개, 새 마감 검사 1개, 빌드 검사 7개와 지도 도달 검사 통과. 390×844·320×568·844×390 터치와 1280×800 PC에서 이미지 디코딩, 입력 영역 44px 이상·겹침·화면 경계, 사용 가능/눌림/위험 프레임 구분을 검사했다. 마무리 표시 수정 후 전투 정책과 마감 검사를 다시 통과했다. 별도로 네 화면 크기의 실제 갈아입기·제압 검사를 통과했다. 전체 회귀와 fuzz, 실물 휴대폰 성능 검사는 실행하지 않았다.

참고한 출시 게임 화면과 포트폴리오: [Maria Capel · The Last of Us Part II](https://www.mariacapel.com/projects/3oKe0B), [MGSV 실제 HUD](https://interfaceingame.com/screenshots/metal-gear-solid-v-the-phantom-pain-hud/), [Julien Mario · Dishonored 2](https://www.behance.net/gallery/97231325/DISHONORED-2-UI-DESIGN). 실제 구현 프레임은 원작 그래픽을 복사하지 않고 직접 제작한 벡터다. 생성형 비교 시안은 방향 승인 자료이고, [전후 비교](hud-v164/index.html)는 실제 게임 캡처다.

아이콘 직접 표시 수정 후 빌드 검사 7개와 UI·프레임·장비·모바일 입력·HUD 시스템·갈아입기 검사를 다시 통과했고, 연속 실행 화면에서 아이콘 표시를 직접 확인했다.
