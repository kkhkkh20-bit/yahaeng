# v252 — 옥상 시야와 휘파람·벽 모서리 끌어오기

기존 행동이 실제로 작동하는 조건과 화면에서 알 수 있는 조건을 맞췄다. 새 미션·장비·스킬은 추가하지 않았다.

## 아래 경비가 보는 옥상 범위

v251은 아래 경비가 옥상 가장자리를 실제로 볼 수 있어도, 시야 선택은 같은 높이의 인물만 대상으로 삼았다. 시야 그림 역시 경비가 서 있는 높이를 기준으로 그렸다. 같은 장면에서 실제 발견 판정은 참인데 표시 대상은 없었다.

이제 가까운 아래 경비도 시야 표시 대상이 된다. 현재 서 있는 옥상에 도달하는 범위를 실제 `canSee`로 계산하고, 지붕을 그린 뒤 그 표면에 표시한다. 조명·자세·경비 방향·지붕 가장자리·옥탑 구조물에 의한 가림을 적용한다. 판정에 쓰는 시야 거리 식은 `guardSightRange`로 공유한다. 실내 2층의 바닥·천장 차폐는 유지하며, 창문을 통한 별도의 기존 위층→지상 규칙은 이번 변경 대상이 아니다.

- 기본은 기존 시야 선택 방식에 따라 한 명의 범위를 보여준다. '지상 경비 → 2층 옥상'처럼 감시하는 높이와 대상 높이를 짧게 적는다.
- 웅크리거나 경비가 돌아보면 범위를 다시 계산한다. 별도 지도 레벨의 허공을 가상의 서 있는 자리로 칠하지 않는다.
- 표시는 12월드픽셀 격자의 근사 경계다. 각 칸 중심은 실제 판정을 만족한다. 연속된 모든 픽셀의 정확한 경계를 뜻하지는 않는다. 점프·배관·매달리기 중의 별도 시야도 새로 설계하지 않았다.
- 측정 캐시는 0.14초 이내이며 방향·자세·높이·조명·문 상태가 바뀌면 갱신한다. `WeakMap`에 두어 체크포인트에 렌더 캐시를 저장하지 않는다.
- 옥상에서 지상의 적을 지나칠 때 늘 뜨던 '높이가 다르다' 공격 불가 문구는 실제 공격을 시도할 때만 나타나도록 줄였다.

## 휘파람과 벽 모서리

- 기본 휘파람 반경 230→360 월드픽셀, 약 4.8→7.5칸. 음악으로 줄어드는 기본 반경의 하한은 180→260이다. 벽을 통과하는 감쇠와 열린 통로를 돌아가는 소리 전파는 유지한다. VIP 구역의 기존 380 반경도 보존한다.
- 예전 소리만 조사 중인 경비는 새 휘파람의 고정 발생 지점으로 이동할 수 있다. 실제 목격·시체·현장 수색을 소리로 지우지는 않는다. 그런 경비만 들었으면 '들었지만 다른 현장 조사 중'이라고 알려준다.
- 벽에 붙어서 부르면 실제로 걸어갈 수 있고 끌어오기 범위 안에 드는 조사 위치를 고른다. 경비가 직접 열 수 있는 문도 실제 이동 규칙에 따라 경로에 포함한다. 당길 수 있는 정지 지점을 찾지 못하면 원래 소리 지점의 조사를 유지한다. 플레이어가 그 뒤 이동해도 소리 지점은 따라 움직이지 않는다. 반복된 유인에 조심하는 행동, 두 경비의 조사/망보기 역할은 유지한다.
- 벽 끌어오기는 직선만 허용하던 데서 **가까운 모서리 한 곳을 돌아올 수 있는 짧은 경로**도 허용한다. 경로 길이는 기존 100/접근 숙련 120 범위를 넘지 않으며 몸의 여유 폭을 검사한다. 당기는 동작도 같은 꺾인 경로를 따른다. 긴 벽을 관통하거나 다른 층·높이의 적을 끌어오지 않는다.
- 가능할 때 공격 버튼에 **끌어 기절**을 표시한다. 짧게 누르면 기절, 계속 누르면 처치라는 기존 입력을 유지한다. **은신 기습 습득 조건도 유지**한다. 미습득 상태라면 기술이 필요하다고 안내한다.

모서리의 일반 RAF 검사는 플레이어와 기존 경비 한 명을 실제 맵에 배치하고 다른 경비·카메라를 제거한 **통제된 단일 조우**다. 전체 미션 완주로 주장하지 않는다. 첫 에피소드 완주는 이와 별도로 원래 배우를 유지했다. Chromium 터치는 실제 iPhone/Safari 검사나 모바일 기기의 성능 측정이 아니다. 전 에피소드의 실시간 재완주는 이번 범위에 포함하지 않았다.

변장의 복장 분류 체계는 이번 버전에서 바꾸지 않았다. v251의 목격자 기억/완료 보고 분리는 유지하며, 같은 종류의 자경대원 제복을 각기 다른 개별 의상으로 구별하는 기능은 아직 없다.
