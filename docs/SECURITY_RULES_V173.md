# v173 — 복장, 목격, CCTV 판정의 가시성

복장은 특정 구역의 통행 권한이고, 목격된 작업과 근거리 신원 확인은 별도 판정이다. 이전 화면은 CCTV의 실제 게이지를 사람 감지 HUD에 반영하지 않았고, 현재 통행 가능한 상태와 훔치기를 시작했을 때의 위험을 연결하지 않았다. 공개 구역과 제한 구역 사이의 경계만 표시해, 같은 제한 구역 안에서 복장 권한이 달라지는 문턱도 놓쳤다.

## 화면과 실제 판정의 연결

- 현재 복장과 구역의 통행 권한을 기존 감지 HUD에 유지한다. 통행 허용은 작업 허용을 뜻하지 않는다. 실제 `zoneInfo`와 `permitted`를 사용한다.
- 카메라의 위치·시야·벽·층·조명·가동 상태·허용 복장·인상착의·수상한 행동을 `cameraAssessment`에서 함께 읽는다. 실제 카메라 감지와 작업 전 미리보기가 같은 함수를 쓴다.
- 물품 회수, 락픽, 운반, 갈아입기, 전선 분리, 창문 넘기 등 가까운 선택 행동에 위험을 미리 표시한다. 현재 카메라 시야 안의 훔치기는 `CCTV 녹화 위험`, 실제로 플레이어를 보고 있는 경비가 있으면 `경비 목격 위험`으로 표시한다. 감시자가 보이지 않는 경우에도 작업이 수상한 행동임을 알리며, 작업이 끝날 때까지 안전하다고 보증하지 않는다. 카메라의 회전과 경비 이동은 계속된다.
- CCTV를 보고 있는 동안의 실제 감지 게이지를 카메라 아이콘과 함께 표시한다. 카메라의 부채꼴은 감시 범위를 표시하고, 실제 감지 게이지가 차는 동안 경고색으로 바뀐다. 통행 중인 사람과 작업 중인 사람을 동일하게 위험 표시하지 않는다.
- 눈 표시 인물에게는 근거리 신원 확인 설명을 붙인다. 거리·시야를 끊으면 확인이 멈추는 기존 규칙을 그대로 읽는다.
- 공개/제한 구역 구분뿐 아니라, 복장별 허용 구역과 금고·보안구역의 경계도 표시한다. 실내 계단은 올라가기 전에 도착 층의 복장 통행 가능 여부를 보여 준다.
- 녹화 후에는 의뢰 제목에 `CCTV 기록 남음`을 유지한다. 펼친 목표에는 삭제할 보안실과, 전선 분리로 기존 녹화가 지워지지 않는다는 점을 표시한다. 실제 보안실 조작을 마치면 표시가 사라진다.
- 월드의 낮은 우선순위 이름표도 HUD 영역을 피해 배치해 판정 설명을 덮지 않게 한다. 게임 조작 버튼은 추가하지 않았다.

## 짧은 실습

추천 순서는 `시야와 소리 → 제압과 몸 숨기기 → 복장과 CCTV → 의뢰 01`이다. 의뢰 선택에서 본편을 바로 시작하는 경로도 제공한다. 기존 선택 연습의 ID와 저장 기록은 유지하고, 새 실습은 `tC`를 사용한다.

실습은 본편과 같은 규칙으로 다음을 경험하게 한다.

1. 평상복으로 공개 구역의 CCTV 앞을 걸어도 게이지가 차지 않는다.
2. 실제로 놓인 자경대원 옷으로 갈아입고 직원 구역을 통행한다.
3. 눈 표시 경비에게 가까이 다가가 신원 확인이 시작되는 것을 보고 물러난다.
4. 현재 옷이 허용되지 않는 기록 구역의 경계 표시를 확인한다.
5. 같은 허용 복장으로도 서류를 훔치려 하면 CCTV가 감지함을 미리 본다.
6. 카메라 뒤로 돌아가 기본 행동으로 전선을 분리하고 서류를 가져온다.

실습에서 실제로 녹화되거나 변장이 들통나면 획득한 단계의 체크포인트로 다시 진행한다. 감지 면제, 임시 기술, 보상 포인트를 지급하지 않는다.

## 검증 방법과 범위

PC 키보드와 모바일 CDP 터치 입력으로 새 실습을 완주했다. 두 실행 모두 허용 복장으로 일부러 훔치기를 시작해 실제 CCTV 게이지와 실패를 확인하고, 실제 복구 타이머로 안전한 단계에 돌아온 뒤 전선 분리·서류 회수·탈출을 마쳤다. 최종 체력 3, 기술 습득 0개, 시작 예산 4P 유지, 전선 분리 1회를 확인했다. 시간만 나누어 진행한 자동 브라우저 플레이이며, 사람의 실시간 초행 플레이나 실물 휴대폰 성능 측정이 아니다.

첫 의뢰도 기술·다트 없이 PC·터치로 전체 완주했다. PC는 무발각, 모바일은 발각·경보 각 1회였고 둘 다 체력 3이었다. 이 실행의 카메라 감지와 경비·추격·작업 규칙은 실제로 작동한다. 배우지 않은 기술을 지급하거나 플레이어·경비의 위치, 체력, 아이템, 목표 상태를 덮어쓰지 않았다.

별도의 제어 장면에서는 허용 복장/다른 복장/공개 구역/금고/보안층, 작업 전 위험과 실제 감지, CCTV 시야 이탈·정지·다른 층, 근거리 신원 확인·후퇴, 기록 유지와 실제 보안실 삭제를 검증했다. PC, 모바일 세로·가로, 320px 화면에서 표시가 잘리지 않는지도 확인했다. 단계 전환과 직접 의뢰 선택을 포함한 기존 연습 경로 검사도 갱신했다.
