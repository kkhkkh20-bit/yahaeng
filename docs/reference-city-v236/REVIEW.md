# v236 — 도시 시안과 차량 충돌 수정

플레이: https://yahaeng.kkhkkh-20.workers.dev/?study=agent-city&v=236

## 바뀐 부분

- Dotonbori 원본의 완성된 층 구성을 사용했다. 유리·벽돌·목재·금속 외벽과 상가, 큰 광고판을 조합하고 옥상 깊이를 줄였다. 실제 문과 창문 판정도 원본 패널 위치에 맞췄다. 178개 개구부를 검사했다.
- 여성 요원은 기존 CC0 Quaternius 팩의 다른 머리 모델과 정장을 조합했다. 각진 짧은 헤어 실루엣과 밝은 재킷으로 이전 모습과 구분한다. 조직원·직원으로 변장해도 같은 머리와 얼굴을 유지한다. 자체 제작한 전용 도트 캐릭터의 최종 품질을 뜻하지는 않는다.
- AI 차량이 충돌 함수를 거치지 않고 좌표를 바꾸던 오류를 수정했다. 차량 중앙의 충돌 빈틈도 메웠다. 고속 이동과 회전을 잘게 검사하고, 충돌하면 정지/반동·금속음·충격 이펙트·양쪽 차량 손상을 처리한다.
- 교차로 대기는 통과 순서를 예약한다. 오래 기다리면 다른 차를 뚫고 가던 예외를 삭제했다. 뒤차가 앞차보다 먼저 교차로를 점유하던 교착도 수정했다.
- 옥상 해치는 원본 사다리 입구를 사용한다. 양방향 육교 이동과 실제 해치 하강을 확인했다.

차량 수정은 공통 로직에 적용된다. 외관과 새 요원은 `study=agent-city` 시안에만 적용된다. 본편 전체를 이 도시로 바꾼 작업은 아니다. 본편 진행과 시안의 체크포인트는 분리한다.

## 검증과 한계

1. PC 키보드와 모바일 CDP 터치로 정상 시간·AI를 유지한 채 임무를 각각 완료했다. 기절 → 변장 → 운반/숨기기 → 문 열기 → 2층 표적 처치 → 기록 회수 → 탈출. 두 실행 모두 체력 3, 발각 0, 경보 0. 이미 경로를 아는 실행이므로 신규 사용자의 난이도 검증과는 다르다. [PC](native-pc.json), [모바일](native-mobile.json).
2. 시작 위치만 옥상에 설정한 뒤 실제 입력으로 육교 왕복과 해치 하강을 PC/모바일에서 확인했다.
3. 실제 키보드/터치 운전으로 충돌 후 두 차량 HP 감소, 비겹침, impact 효과 발생을 확인했다. [PC](collision-pc.json), [모바일](collision-mobile.json).
4. 명시적인 시뮬레이션 장면으로 정면/측면/고속 벽 충돌과 회전 간섭을 검사했다. 일반 교통 60초 동안 28,800회 접촉 검사에서 겹침과 자발적 사고가 없었고, 8대 모두 이동했다. 이것은 60초 구간의 증거이며 모든 도로 배치의 무교착 보장은 아니다. [결과](traffic-checks.json).
5. 요원 세 복장 16,224개 비어 있지 않은 프레임, 등반 접촉 408개 표본, 개구부 178개, 저장 분리 검사를 통과했다. [결과](study-checks.json).
6. 기존 주인공 모션 회귀 검사, 빌드 통합 검사 8개와 물리 상호작용 검사 20개 그룹을 통과했다.

## 출처

건물은 프로젝트 소유자가 구매한 GuttyKreum Dotonbori City v3의 선별된 게임용 아틀라스다. 원본 ZIP·전체 타일맵·데모맵은 커밋하지 않는다. 차량은 Kenney RPG Urban CC0, 캐릭터는 기존 Quaternius CC0 모듈 팩이다. 새 머리 GLB의 출처와 SHA는 `tools/prerender/characters/sources.json`에 기록했다. Rancic 캐릭터나 홍보 이미지의 스프라이트를 복사하지 않았다.
