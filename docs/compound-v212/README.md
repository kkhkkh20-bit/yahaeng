# v212 — 누적형 잠입 의뢰

첫 배차실 에피소드(tB) 이후의 다섯 의뢰를 실제 암살 임무로 재구성한다. 이전에 익힌 행동은 계속 사용할 수 있고, 임무마다 새 공간 문제를 하나씩 추가한다. 아래 번호는 배차실 이후의 의뢰 순서이며, 화면의 에피소드 번호에는 배차실이 포함된다.

| 의뢰 | 공간과 적 | 필수 목표 | 새로 활용하는 것 |
| --- | --- | --- | --- |
| 1 · 닫힌 철문 (p0) | 마당 경비, 1층 경비, 2층 운반책 | 운반책 처치 후 철문 밖으로 탈출 | 기절 → 실제 경비의 옷 → 운반·은폐 → 계단 → 의도적인 살해 |
| 2 · 불 꺼진 출고동 (p1) | 마당 포함 4명, 두 층 | 출고 감시담당과 작업반장 처치 | 벽 스위치로 어둠을 만들고 복구하러 오는 경비 분리 |
| 3 · 야간 기록실 (p2) | 5명, 두 층 | 감시반장·기록책 처치와 이송 명세서 회수 | 여러 적 처리와 은폐, 조명, 실제 책상에서 서류 작업 |
| 4 · 녹화된 얼굴 (e1) | 5명, 두 층, 서류를 비추는 CCTV | 감시팀장·정하린 처치와 인계서 회수 | 허용 복장 통행과 불법 작업 녹화의 차이, 전선 분리, 실내 관리 단말 |
| 5 · 지붕 위의 장부 (e2) | 6명, 3층 건물 두 동과 옥상 | 중개인·인계책 처치와 3층 원본 장부 회수 | 현장 철사로 창문 락픽, 3층·옥상 진입, 건물 사이 점프, 간판 사고 |

일반 스위치·계단·현장 창문 락픽·옥상 점프·간판 조작에 구매 기술을 요구하지 않는다. 간판은 치명적인 행동이므로 행동 버튼을 1초 길게 눌러야 한다. 5번은 창문·옥상 외에 정문과 계단으로도 공략할 수 있다. 변장과 은폐는 해법이며, 특정 체크리스트를 채워야만 승리하는 강제 조건은 아니다. 필수 표적이 살아 있는 기절 상태이면 임무 완료로 세지 않는다.

CCTV 뒤 전선은 이후 녹화를 막는다. 이미 남은 신원 기록은 지우지 않으며, 같은 층의 실내 관리 단말에서 감시망을 정지하고 기록을 지운다. 기록이 남은 실수는 즉시 실패로 처리하지 않는다.

기존 단일 규칙 의뢰 e3/e4/e5는 필수 선형 경로에서 제외한다. 기존 완료 기록과 이미 받은 기술 포인트는 보존한다. 지형이 바뀐 다섯 의뢰의 구버전 중간 체크포인트는 새 배치로 시작하고, 완료 기록은 유지한다. 새 배치의 체크포인트는 정상적으로 이어 간다.

## 검증

- `tests/rev/t_compound_progression.py`: 목표의 생사 판정, 실제 조명 감소와 경비 복구, CCTV 녹화·전선·관리 단말, 점프 대상의 지속성, 간판의 짧은 입력 취소와 길게 누르기, 기존 보상·체크포인트 호환성.
- `tests/tutorial/compound_live.py`: 일반 RAF와 AI를 유지한 키보드/CDP 터치 여정. 이동 경로 계산은 실제 지도만 읽고, 이동·기절·변장·운반·은닉·조명·계단·살해·서류·탈출은 실제 입력으로 수행한다. 적·체력·시각·장비·시계를 덮어쓰지 않는다. 임무 종료 후 실제 획득한 포인트를 소비한다.
- 기존 UI·전투·층 이동·감각·기술·고급 의뢰 회귀 검사도 실행한다.

자동 플레이는 알려진 지도에서 조작과 완주 가능성을 검증한다. 처음 접하는 사람의 이해도나 재미를 측정한 결과는 아니다. 작업 중 일반 RAF/AI로 완주한 PC·모바일 각 5개 경로의 실제 입력 결과는 `playback.json`에 기록했다. 최종 커밋의 CI는 패키지에서 같은 여정을 다시 검사한다. 상용 마감 검토는 `commercial-polish-review.md`에 별도로 정리했다.
