## 추천과 검수 단위

과거에는 저렴하게 실내외 소재를 넓게 확보하는 관점에서 LimeZu 두 팩 $8를 추천했다. 현재 사용자가 지적한 **가구·조명·스위치·창문 마감**과 이스트워드의 생활감 있는 공간이라는 목표에서는 Office Interior로 방 하나를 검수하는 선택이 더 직접적이다. 다른 캐릭터까지 들여오기보다 기존 주인공을 유지하고 가구와 건축 부품을 맞춘다. 어느 팩도 야행과 완벽하게 맞는다고 확정하지 않았다.

이스트워드를 참고할 부분은 일관된 픽셀 밀도, 두꺼운 창틀, 생활감 있는 소품 배치, 따뜻한 광원과 차가운 주변광의 구분이다. 이스트워드가 위 판매팩을 사용한다는 근거는 없다. 한국의 간판·물류실·배전함 같은 장소성은 따로 제작해야 한다.

비교할 최소 장면은 기존 주인공 + 책상 + 수납장 + 문 + 창문 + 벽 스위치 + 조명 한 회로다. 기존 무료 자산 장면과 같은 카메라·해상도에서 비교하고 다음을 통과해야 한다.

- 손·발 접촉 위치와 가구 비율이 맞고 8방향 캐릭터가 공간에 붙어 보인다.
- 창문과 벽이 실제 시야/빛 차단 경계와 맞는다.
- 스위치와 담당 방의 관계, 소등 후 경비가 복구하러 오는 동선이 읽힌다.
- 불을 꺼도 문·경비 자세·상호작용 실루엣을 알아볼 수 있다.
- 한국어 간판과 기존 캐릭터 색이 배경과 충돌하지 않는다.

정적인 타일팩은 조명 판정·스위치 상호작용·캐릭터 애니메이션을 제공하는 엔진이 아니다. 그림을 바꾼 뒤에도 기존 물리 판정과 접촉 위치를 직접 맞춰야 한다.

## 사용 조건

두 제작자 모두 상용 게임 사용과 편집을 허용하지만 원본 에셋/추출 가능한 소재 묶음의 재배포·재판매를 금지한다. LimeZu는 크레딧을 요구한다. GuttyKreum은 구매자 라이선스와 게임 밖으로 추출해 사용하는 형태를 제한한다. 구매 시점의 전문 약관을 기준으로 하며 유료 ZIP/개별 PNG를 공개 저장소에 올리지 않는다. 실제 구매 전에는 본편에서 불필요한 무료 자산부터 제거하거나 구매를 강제할 이유가 없다.
