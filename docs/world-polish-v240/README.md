# v240 — 차량·도로·간판·층수 안내·옥상 사다리

일반 캠페인에는 차량 이미지, 구매한 도로 표면, 후진, 임무 경계 안내, 목표 층수 안내가 적용된다. `?study=agent-city` 도시에는 한글 간판 8종과 옥상 해치의 자동 하강도 적용된다. 캠페인 진행과 도시 실험판 저장 공간은 그대로 분리된다.

## 적용한 에셋

- 차량: [MinZinn Pixel Vehicles](https://minzinn.itch.io/pixelvehicles), TopDown Vehicles v1.17, **CC BY 4.0**. 흰 세단, 빨간 Civic, 초록 해치백, 파란 왜건, 검은 Luxury, 경찰차. 차종별 원본 회전 이미지 48장, 총 288장. 기존 물리 크기와 접촉 중심을 유지하고 정면 이미지를 길게 늘리는 처리를 제거했다. 게임 내 제작자/라이선스/출처/변경 사항 표기와 `src/art/vehicles/LICENSE.txt` 포함. 별도 구매 없음.
- 도로: 구매한 **GuttyKreum Dotonbori City v3**의 원본 포장 타일. 보도·연석과 같은 도트 크기로 표시한다. 도로선과 충돌 판정은 기존 게임의 정보를 유지한다. 이 구매 팩에는 자동차 스프라이트가 없으므로 차량 팩을 별도로 선택했다.
- 간판: 원본 생성 이미지에서 검수·선정한 한글 이미지 8종. 백송상사, 밤샘식당, 청솔약국, 음악실, 선일전기, 동진인쇄, 종로서점, 백야다방. 청록/적갈/상아/보라/황토/청회/크림/갈색을 구분하고 작은 윗면·두께를 포함한다. 일본어 광고와 매 프레임 Canvas 글자로 조립하던 간판을 사용하지 않는다. 구매한 작가의 간판으로 표기하지 않는다.
- 이전 Kenney 자동차 3개의 확대 이미지는 도시 세부 아틀라스에서 제거했다. 이미지가 준비되지 않은 순간의 기존 차량 그리기 대체 경로는 유지한다.

## 동작

반대 방향 입력은 도로가 비어 있어도 **제동 → 후진**으로 이어진다. 진행 방향 입력으로 다시 전진한다. 지도 바깥은 차량 파손/충돌 효과 대신 “아직 할 일이 남았어. 임무부터 마무리하자.”를 6초 간격으로 안내한다. 실제 건물과 차량에 부딪히는 충돌은 유지된다. 도보로 임무 경계에 접근해도 같은 안내를 쓴다.

목표는 `↓ 2층 · 이도현 활동 구역 · 5m`처럼 목적 층과 이동 방향을 표시한다. 연결 입구로 안내할 때도 최종 목적 층을 보존한다. 수평 거리가 1m여도 다른 층의 목표를 숨기지 않는다. 옥상과 그 바로 아래 최상층도 구분한다. 기존 표적 관찰/목격/활동 구역 정보는 그대로 사용한다.

도시의 평평한 옥상 해치는 아래 화살표 발판을 그리지 않는다. 어느 방향에서든 해치로 다가가면 자동 하강한다. 연결교를 따라 옆으로 지나갈 때는 내려가지 않는다. 올라온 직후에는 해치에서 벗어났다가 다시 다가와야 내려가므로 입력을 놓거나 방향을 바꿔도 즉시 되돌아가지 않는다. 일반 캠페인의 계단실 문 진입은 유지한다.

## 주인공 — 외형 시안, 게임 교체 미완료

[8방향 여성 요원 시안](hero-turnaround.webp)은 **새로 생성한 외형 제안**이다. 완성된 애니메이션 팩이나 실제 플레이 화면이 아니다. 게임에서는 현재의 8방향 이동·암살·기절·운반·변장·벽/창문 접촉 애니메이션을 계속 사용한다. 시안의 정지 그림을 이동 중에 미끄러뜨리는 방식으로 대체하지 않았다.

단발, 남색 재킷, 상아색 셔츠, 작은 구리색 머리핀으로 정체성을 잡는다. 제작 사양은 32×48 프레임 안에 약 18×34의 인물, 14–20색, 재질당 3단계 명암, 배경과 같은 1.5배 픽셀 크기다. 시안 원본의 고해상도 텍스처는 최종 게임 도트로 다시 정리해야 한다. 변장해도 얼굴·머리는 유지하고 조직 의상색을 따른다.

확인한 기성 팩:

| 팩 | 확인한 범위 | 판단 |
|---|---|---|
| [BossNelNel 8-Direction Character Sprites](https://bossnelnel.itch.io/8-direction-top-down-character-sprites) | 32–34px, 8방향, 정지 1장·걷기 8장, 개인·상업 이용/수정 허용 | 체형이 너무 귀엽고 암살/운반 동작 없음. 현재 게임의 주인공 교체용으로 비추천 |
| [GL Studio Reiko](https://glstudio.itch.io/isometric-character-animations-reiko) | 여성 캐릭터, 달리기/공격/점프는 NE·NW, 정지는 SW | 전체 8방향이 아니며 변장/운반 동작 없음. 구매 후 바로 적용 가능한 세트가 아님 |
| [Rancic Yakuza Enemy](https://rancic.itch.io/yakuza-enemy) | 기존 사용자가 고른 조직원 미술 방향 참고 | 여성 요원 전체 동작을 제공하는 팩으로 간주하지 않음. 원본을 복사하지 않음 |

현재 추천은 외형 시안을 정리한 **여성 요원 전용 도트 동작 세트** 제작이다. 정지/걷기/달리기/웅크림/후방 기절/살해/운반/변장/작업/매달림/등반을 한 스타일로 제작해야 한다. 후보 팩을 샀다는 이유로 기존 동작을 잃는 교체는 하지 않는다. 이번 배포에는 새 주인공 동작 세트가 포함되지 않는다.

## 검증

- 실제 입력 + 활성 AI: 모바일에서 기절 → 변장 → 운반/숨기기 → 문 → 2층 → 표적 처치 → 기록 회수 → 탈출 완료. 체력 3, 발각 0. 사전 맵 지식을 사용한 경로이며 초보자 블라인드 리뷰는 아니다.
- 위치만 명시적으로 설정한 뒤 실제 입력: PC/모바일 모두 연결교 왕복 → 해치 접근 → 5층 내부 하강. 실제 키보드/CDP 터치 후진 → 전진 전환도 양쪽 통과.
- 명시적 시계/배치 회귀 검사: 해치 8방향 접근 판정, 동서남북 실제 이동 하강, 바로 재하강 방지, 연결교 옆 지나가기, 다른 층 작동 방지, 목표 층/옥상/1m 표기, 제동 후 후진, 임무 경계 무충격·무손상 안내.
- 실제 차량 솔버: 28,800회 접촉 검사, 정면/교차 충돌·회전·교차로 대기 검사. 건물/차량의 실제 충돌 효과는 유지.
- 도시/캠페인 분리, 42개 층 연결, 원본 동작 16,224개 프레임, 등반 접촉 408개, 물리적 문/창 일치, 차량 288개 이미지 비어 있지 않음 검사.
- 빌드 파이프라인 8개 및 물리적 상호작용 20개 그룹 통과.

스크린샷은 위치를 설정한 화면 검수 자료다. 실제 입력 증거와 구분한다. `checks.json`과 `reverse.json`에 회귀 검사 결과를 기록한다.
