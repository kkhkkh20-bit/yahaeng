# v154 모바일 잠입 액션

[같은 조건의 원본 전후 비교](mobile-v154/index.html)

목표는 **숨기 → 바짝 접근 → 기습 → 몸 정리 → 다음 그늘**을 적은 조작으로 이어 가는 것이다. 기존 v153의 어두운 게임 화면, IBM Plex Sans KR Regular 400, 직선 기술 트리와 주요 조작을 유지한다.

- **공격 버튼 통합:** 배워서 장착한 쌍암살·연속 암살이 실제로 가능한 경우에만 공격을 길게 눌러 사용한다. 짧게 떼면 처음 선택한 한 명만 기절한다. 다른 경우에는 기존의 즉시 제압·길게 처치가 작동한다. B와 연습용 기술 버튼도 지원한다. 본편 모바일의 별도 기술 버튼은 숨긴다.
- **몸 정리 한 번:** 가까운 쓰러진 몸과 자리가 남은 은닉처가 있으면 행동의 기본값을 ‘기절자/시체 숨기기’로 제안한다. 들어 올리는 0.55초, 실제 접근, 뚜껑/문 조작, 몸 넣기를 거친 뒤에만 결과를 적용한다. 수동 운반·옷 갈아입기는 대상 바꾸기로 고른다. 기존 첫 운반 연습은 개별 조작을 가르친다.
- **경계 검사:** 살아 있는 사람은 이 동작의 대상이 아니다. 벽·층·높이·거리·용량을 확인하고, 도중 피해·장애물·용량 변경 시 아직 숨기지 않은 몸을 운반 상태로 남긴다. 앱 전환·취소·저장 복원은 준비 중인 공격이나 자동 운반 예약을 이어 실행하지 않는다. 이미 풀숲에 숨겨진 몸은 다시 자동 은닉 대상으로 제안하지 않는다.
- **그늘과 자세:** 모바일에서도 실제 풀숲 은신/어두운 곳의 웅크림은 몸을 흐리게 하고 윤곽을 남긴다. 실제 어둠에 웅크린 상태는 ‘그늘 속’으로 안내한다. 빛·시야·수색·발소리 판정을 그대로 사용하며 그늘에서 공격해도 목격자는 반응한다.
- **작은 세로 화면:** 320×568처럼 폭·높이가 작은 화면에서는 캐릭터가 버튼 위에 보이도록 카메라와 맵 끝 여백을 조정하고, 기존 연습용 기술 버튼을 옆으로 옮긴다. 다른 화면 크기의 구도는 유지한다.
- **연습:** 암살 기술 연습은 공격 버튼 길게 누르기를 안내한다. 은신 기습 연습은 버튼 없이 풀숲 진입, 짧게 기절/길게 처치, 세 번째 경비에게 접촉 거리로 접근, 한 번 눌러 몸 숨기기, 출구까지 이동을 가르친다. 연습 능력은 본편에 저장되거나 포인트로 지급되지 않는다.

새 도구나 초기 무료 능력은 추가하지 않았다. 기본 뒤잡기는 32px 접촉 거리이며, 배운 접근 기술의 112px 이동과 암살 기술의 대상·방향·길·재사용 조건을 유지한다. 기존 AI의 기억과 수색을 초기화하는 안전 지대도 만들지 않았다. 임무 전체의 경비 배치와 난이도를 다시 조정하는 작업은 이번 범위에 포함하지 않는다.

## 검증

회귀 스크립트 49개와 빌드 검사 7개를 통과했다. 마지막 작은 화면 수정 후 새 흐름 24항목, 4개 화면 크기의 UI, 여섯 임무·세 배율·양쪽 맵 경계 144경우를 다시 확인했다.

검증 원본은 같은 폴더의 `mechanics.json`, `production-journey.json`, `captures.json`, `design-detection.json`에 있다. 실제 키보드/터치 입력과 활성 AI로 은신 기습 연습을 완료했다. 고정 시뮬레이션 시계로 동작을 검증하며 실제 휴대폰 FPS 측정으로 주장하지 않는다. 촬영은 실제 v153/v154 배포 패키지를 사용한다. 몸 장면은 같은 실제 의뢰 풀숲과 배치한 쓰러진 경비를 쓰는 비교용 장면이며 미션 완료 증거와 구분한다.

Impeccable 독립 검수의 첫 판정은 작은 화면의 플레이 영역 가림에 대한 `fix`였다. 수정 후 같은 16개 화면을 다시 검토해 해당 M1 항목을 `resolved`, 판정을 `ship`으로 기록했다. 이 재검수는 M1 해결 여부에 한정하며 실제 기기 플레이 검증으로 주장하지 않는다. 배포 기록은 같은 폴더에 별도로 추가한다. 기존 PRODUCT.md와 DESIGN.md는 없으며, 이번 변경은 기존 시각 체계 안의 조작·상태 확장이다. 새 시각 체계나 외부 의존성을 설치하지 않는다.
