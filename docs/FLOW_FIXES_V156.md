# v156 리뷰에서 발견한 문제 수정

[v155 → v156 원본 전후 비교](flow-v156/index.html)

v155 직접 조작 리뷰에서 발견한 다섯 문제를 수정했다. 모바일의 **웅크려 숨기 → 바짝 접근해 제압 → 몸 정리 → 다음 은신처** 흐름이 목적이다. 기존 어두운 게임 화면, IBM Plex Sans KR Regular 400, 조작부와 직선 기술 트리를 유지한다.

| 발견한 문제 | 적용한 수정 |
| --- | --- |
| 390×844 맵 끝에서 캐릭터가 하단 조작부에 가림 | 실제 버튼 영역을 기준으로 플레이 위치와 맵 끝 카메라 여백을 계산한다. 작은 세로·가로 화면에도 적용한다. DOM 측정은 화면 크기·임무·기술 버튼 표시가 바뀔 때만 한다. |
| 경계 상태에서 첫 제압 뒤 기본 행동이 옷 갈아입기 | 본편에서는 가까운 은닉처에 숨기기 또는 몸 운반이 먼저 나온다. 옷 갈아입기는 대상 바꾸기로 명시적으로 선택한다. 운반 중에는 내려놓기를 던지기보다 먼저 제안한다. 기존 운반·변장 연습은 유지한다. |
| 벽 접촉 시 의도치 않은 엄폐와 대상 없는 기술 잠금 안내 | 자동 엄폐는 웅크린 상태에서만 들어간다. 행동으로 나올 수 있다. 실제 가까운 대상이 없으면 ‘은신 기습 필요’를 표시하지 않는다. 실제 은신 공격의 학습 조건은 유지한다. |
| 첫 의뢰가 장부부터 가리키고 시작부터 배경 싸움 발생 | 서쪽 풀숲 → 순찰 등 뒤 접근 → 쓰러진 몸 숨기기를 선택 가능한 진입 안내로 추가했다. 이후 실제 표적을 먼저 가리킨다. 수동 목표 선택·다른 경로는 존중한다. 처음 45초의 자발적 세력 충돌을 억제하고, 평상시 제한 구역 민간인은 실제 경로로 내보낸다. |
| 기술을 배워도 본편에서 효용을 체감하기 어려움 | 야시장 경비 둘은 동시 암살, 뒷골목 순찰은 연속 암살의 실제 거리와 경로를 만족할 수 있게 배치했다. 소유·장착한 기술과 현재 경비 상태에 맞을 때만 현장 안내를 띄운다. 잠행·웅크린 이동 기술은 실제 적용 효과를 짧게 안내한다. |

첫 진입 안내는 강제 관문이 아니다. 영역 밖 다른 경로로 가면 건너뛰고, 기존 저장의 진행 중인 플레이에는 소급 적용하지 않는다. 몸 운반 중에는 같은 층·높이·용량·도달 경로를 확인한 가까운 은닉처를 안내한다. 숨길 곳이 안전하다고 보장하지 않는다. 안내 완료로 경험치나 무료 능력을 주지 않는다.

45초 배경 충돌 유예는 플레이어 범죄의 목격·경보·경찰 반응을 막지 않는다. 플레이어가 소문으로 유발한 싸움, 이미 시작한 전쟁도 그대로 작동한다. 민간인을 순간 이동시키지 않고 실제 이동 경로로 내보낸다. 암살 기본 접촉 거리 32px, 배운 접근 거리 112px, 은신 기습·다트·전기 기술의 학습 조건과 AI 수색 기억을 유지한다.

## 검증

- 빌드 파이프라인 검사 7개, 도달 검사, 핵심 회귀 스크립트 **50개**를 통과했다. [전체 결과](flow-v156/regression.txt).
- [수정 회귀 검사](flow-v156/mechanics.json): 평상·수색·추격의 몸 행동 우선순위, 명시적 변장 실행, 엄폐 해제·실제 대상 학습 조건, 진입 진행·수동 목표·저장·포인트 보존, 소유 기술의 현장 조건, 민간인의 실제 퇴장 경로를 확인했다. m4의 시드 1/42/777에서 각각 입력 없이 30초를 진행했을 때 쓰러진 NPC와 플레이어 처치는 모두 0이었다.
- [PC·터치 실제 첫 진입](flow-v156/entry-journey.json): 메뉴에서 의뢰를 시작해 실제 이동·웅크림·근접 기절·몸 운반과 숨기기를 완료했다. 경비와 카메라가 활성화된 상태에서 체력 3, 발각 0, 기절 1, 숨긴 몸 1, 스킬 예산 4를 유지했다. 배우·체력·인벤토리를 재배치하지 않았다.
- [PC·터치 본편 기술 사용](flow-v156/field-journey.json): 기술 트리에서 포인트를 써서 선행 기술과 동시 암살을 배우고, 실제 야시장까지 이동해 공격을 길게 눌러 두 경비를 처치했다. 동시 암살 기록 1회, 실제 몸 2개, 남은 포인트 1, 체력 3을 확인했다. 배우·체력·인벤토리 강제 변경은 없다.
- 기존 첫 두 연습의 PC·터치 조작 완료 검사도 통과했다. [PC](flow-v156/tutorial-pc.json) · [터치](flow-v156/tutorial-touch.json).
- 실제 v155/v156 생산 패키지를 PC 1440×900, 세로 390×844, 가로 844×390, 작은 세로 320×568에서 같은 조건으로 촬영했다. 전후 각 16장의 원본과 패키지·이미지 해시를 공개한다. 몸 장면은 명시적인 비교용 배치이며 실제 첫 진입·기술 사용 검증과 구분한다.

브라우저 자동 조작과 고정 시뮬레이션 시계로 기능을 검증했다. 실제 휴대폰 FPS나 모든 의뢰의 전체 클리어 검증으로 주장하지 않는다. 새 외부 패키지·아트·서체를 설치하지 않았고, 보관된 episode-one/club-study 판본은 변경하지 않았다.

Impeccable 검사 결과는 [빈 경고 목록](flow-v156/design-detection.json)이다. 독립 검수는 네 화면 크기의 16장과 동작 기록·변경 코드를 확인하고 **ship**으로 판정했다. [독립 검수 기록](flow-v156/finish-review.json). 이 판정은 해당 다섯 수정의 범위이며 실제 휴대폰 성능이나 의뢰 전체 완료 검증이 아니다. 공개 배포 상태는 같은 폴더에 기록한다. 이번 작업은 기존 시각 체계 안의 기능 확장으로 새 PRODUCT.md·DESIGN.md나 시각 체계를 만들지 않는다.
