실제 HTTPS 주소에서 PC 1000×740, 모바일 터치 390×844의 소개·출발·이동·메뉴·소개 복귀를 확인했다. 키보드와 브라우저 터치 입력으로 실제 프레임의 이동 방향을 검사했다. v132, 송대건, 책상 메모 1개와 번호판 문 2개가 로드되며 브라우저 오류는 없다. index와 제작 JS 13개의 SHA-256이 로컬 게시물과 일치한다(`live.json`).

AI 활성 완주는 번호판·계단(12개 상황), 맨홀·창문·기절 후 처치(10개), 환풍구 우회(8개)를 통과했다. 세 경로 모두 체력 3으로 이탈했고 재시작·실패 후 소개 복귀까지 확인했다. 통제 상황 6항목, 기존 사선 구역 완주, 기존 PC/터치 수납함·손 조작과 길게 누르기 회귀 검사도 통과했다.

완주 검사는 고정 시뮬레이션 시간을 빠르게 진행한 결과다. 실물 휴대폰 성능이나 신규 플레이 분량 측정은 아니다. 공개 실행 확인은 별도의 실제 브라우저 프레임 검사다.

Cloudflare의 기존 2D 주소는 v128-loading-fix를 유지한다. public/과 playtest-2d에는 이번 에피소드를 덮어쓰지 않았다.
