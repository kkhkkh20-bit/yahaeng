# v168 · 잠입 난이도와 행동 선택 리뷰

실제로 첫 추천 의뢰 **01 VIP(m2)**를 새 저장에서 플레이했다. 개선 전에는 시작 순찰을 기절시킨 뒤 갈아입기·운반을 고르는 사이 정문 경비에게 발각되어 사망했다. 개선 후에는 기술을 구매하지 않고 첫 의뢰의 장부 회수, 내선 유인, 표적 처치, 서쪽 탈출까지 완주했다.

## 플레이에서 드러난 문제와 반영한 변경

| 관찰 | 플레이에 미치는 영향 | v168 반영 |
|---|---|---|
| 캠페인의 쓰러진 인물 옆에서는 운반이 갈아입기보다 먼저 선택됨 | 옷을 입으려다 몸을 들고, 다시 내려놓고 선택해야 함 | 쓸 수 있는 옷은 갈아입기를 먼저 제안. PC Y 전용 입력, 모바일 전용 갈아입기 유지. 운반·은닉은 행동 선택에서 별도로 선택 |
| 주변 행동 후보가 바뀌면 갈아입기가 운반으로 돌아갈 수 있음 | 누르려던 행동과 실제 행동이 달라짐 | 선택한 대상과 행동을 유지. 명시적으로 선택한 대상이 사라져도 다른 행동으로 실행하지 않음 |
| 미습득 조명 기술이 금고 비밀번호보다 먼저 나옴 | 문 앞에서 행동을 눌러도 기술 구매 안내가 나옴 | 실제 실행 가능한 행동을 먼저 제안. 미습득 기술은 목록 끝에서 확인 가능 |
| 시작 제압 지점과 정문 경비 시야가 겹침 | 변장 3초와 은닉을 익히는 도중 바로 발각 | 5–6열/16행에 적재물, 5열/18행에 화단을 배치. 물리적인 시야 차단과 짧은 은닉 동선 확보 |
| 금고 앞 정지 경비가 문 통로를 막음 | 변장과 번호를 얻어도 지나가려면 다시 제압해야 함 | 금고 앞 ↔ 사무실을 순찰하도록 변경. 관찰 후 통과할 틈 제공 |
| 다트·해킹·전기 기술이 없으면 CCTV 대응이 잘 드러나지 않음 | 특수 기술이 사실상 필수처럼 느껴짐 | 모든 일반 CCTV에 기본 근접 전선 분리 추가. 같은 층, 40px 이내, 실제 손이 닿는 위치에서 2초 작업. 서치라이트 제외 |
| 첫 안내가 제압·은닉 후 표적부터 지시함 | 장부·금고 번호·내선 유인을 놓치기 쉬움 | 기본 추천을 변장 → 은닉 → 공개 구역 엿듣기 → 장부 → 내선 유인으로 연결. 수동 표적·단서 선택은 우선권 유지 |

CCTV를 만지는 것은 위법 행동이며 목격·녹화될 수 있다. 전선이 빠진 카메라는 경비가 발견하면 확인하러 온다. **이미 녹화된 기록은 전선 분리로 지워지지 않는다.** 관리실에서 삭제해야 한다. 기존 기술의 포인트·선행 조건과 계단 추격은 유지한다.

배치 변경은 새로 시작한 의뢰에 적용된다. 진행 중인 체크포인트의 인물·물건·신분·지도는 강제로 초기화하지 않는다. 기존 저장에서도 입력 개선과 CCTV 근접 행동은 사용할 수 있다.

## 전체 캠페인 레벨 설계

현재 주 캠페인은 01 VIP, 02 대청소, 03 배신의 세 의뢰다. 예전 m1/m3/m5 지도는 별도로 존재한다. 각 의뢰가 새 문제를 하나씩 더하도록 구성한다.

| 의뢰 | 익힐 판단 | 권장 동선과 긴장 변화 | 이번 반영 범위 |
|---|---|---|---|
| 01 VIP | 시선 관찰, 제압, 변장, 은닉, 기회 만들기 | 서쪽 안전한 관찰 지점 → 한 명 제압/변장/은닉 → 공개 야시장에서 정보 획득 → CCTV 회전 관찰/우회 또는 근접 분리 → 금고 → 내선 유인 → 가까운 서쪽 출구 | 실제 엄폐·화단·금고 순찰과 자동 안내 수정, 완주 플레이 |
| 02 대청소 | 두 표적과 열쇠의 의존 관계, 다층 경비 회피 | 공개 남쪽 골목에서 계획 → 수금원/빨간 카드 → 창고 현금/파란 카드 → VIP → 연락책 메모 → 사무동 2층 초록 카드 → 1층 계약서 → 출구. 중간에 공개 구역으로 나와 관찰을 다시 시작할 여유 확보 | 기존 단계별 안내와 맵 유지. 새 CCTV 근접 선택지는 공통 적용. 이 동선의 전체 완주는 이번에 검증하지 않음 |
| 03 배신 | 장비 없는 상태의 탈출, 배운 동선 판단 재사용 | 감방 머리핀 → 간수의 등을 기다려 문 탈출 → 압수품 회수는 선택 → 감금동 2층 무전기 → 정문 또는 남쪽 개구멍. 장비 회수를 강제하지 않는 경로 유지 | 기존 맨손 시작·머리핀·대체 출구 유지. CCTV를 장비 없이 다룰 수 있게 공통 개선. 전체 완주는 이번에 검증하지 않음 |

설계 기준은 안전한 곳에서 관찰하고, 실행한 뒤 결과를 읽고, 다음 위험 전에 정리할 수 있게 하는 것이다. 여러 경비의 시야·카메라·복장 확인을 첫 행동 한 번에 겹치지 않는다. 고급 기술은 더 빠르거나 다양한 해결을 제공하고 기본 경로의 필수 열쇠로 쓰지 않는다.

02/03의 표에 적은 동선은 기존 구조를 바탕으로 정리한 캠페인 설계 방향이다. 이번에 세 의뢰의 지형과 적을 전면 재배치했다는 뜻은 아니다. 후속 배치는 두 의뢰를 각각 완주한 기록을 바탕으로 결정해야 한다.

## 실제 플레이 방법과 결과

- Chromium에서 실제 의뢰 선택, 키보드 입력으로 이동·제압·갈아입기·비밀번호·장부·전화·처치·탈출을 실행했다.
- 모든 경비, CCTV, 순찰, 인식, 무전, 증원은 원래 게임 갱신으로 동작했다. 플레이어/경비 위치, 체력, 장비, 습득 기술, 목표 진행을 덮어쓰지 않았다.
- 자동화 브라우저에서 재현할 수 있도록 시뮬레이션 시간을 나눠 진행했다. 게임 상태를 읽어 동선과 시점을 정했다. 사람이 실시간으로 처음 보고 플레이한 소요 시간이나 실물 휴대폰 사용성 평가로 해석하지 않는다.
- 첫 완주: 게임 시간 약 1분 38초, 체력 3/3, 기술 구매 0, 다트 사용 0, CCTV 전선 분리 2, 주민 살상 0, 장부 회수와 서쪽 탈출 성공.
- 첫 수동 입력 완주에서는 표적 처치 때 발각/경보 1회, 이후 전체 경보와 증원이 발생했다. 이 시도를 무경보 성공으로 기록하지 않는다.
- 최종 재현 PC 완주: 게임 시간 약 1분 39초, 체력 3/3, 발각 0·경보 0·몸 발견 0, **그림자** 등급.
- 최종 재현 모바일 터치 완주: 게임 시간 약 1분 52초, 체력 3/3, 발각 0·몸 발견 1·경보 1, **암살자** 등급. 두 실행 모두 기술 구매·다트 사용 0, CCTV 차단 2회. 터치 이동에 걸리는 시간 차이로 순찰의 도착 시점도 달라졌다.
- 재현 스크립트: [contract_intro_walk.py](../tests/tutorial/contract_intro_walk.py). PC 키보드 및 모바일 CDP 터치로 같은 의뢰를 처음부터 재생하며 결과를 JSON으로 저장한다.

## 남은 리뷰

첫 의뢰는 기본 조작과 기회 선택을 익힐 공간이 생겼다. 다만 한 의뢰에 변장, 대화, 비밀번호, 카메라, 물건 회수, 표적 유인까지 등장하므로 처음 플레이하는 사람에게는 여전히 정보량이 많다. 카메라의 회전과 작업 시간을 관찰하면 기술 없이 진행할 수 있지만, 두 번째 CCTV가 창문과 붙어 있어 행동 선택 목록에서 골라야 한다.

다음 우선순위는 02/03의 실제 무기술 완주와 실물 모바일의 카메라·행동 선택 가독성 검사다. 정예와 일반 경비의 복장 확인 차이, 표적 처치 후 경보로 이어지는 원인을 더 잘 읽을 수 있는지도 확인해야 한다. 적의 시야나 계단 이동을 다시 약화시키는 방향으로 해결하지 않는다.

## 회귀 검증

핵심 묶음 65개 중 기존 은닉 기본값을 가정한 검사 하나를 새 갈아입기 우선 규칙에 맞춰 갱신했다. 명시적으로 은닉을 선택한 뒤의 취소·피해·가득 찬 수거함·바닥/벽/층 경계 검사는 유지했으며, 재실행에서 24개 모바일 행동 검사를 통과했다. 나머지 핵심 64개, 빌드 검사 7개, 스프라이트 관리와 지도 도달 검사는 통과했다.

새 CCTV 검사는 PC/모바일 실제 행동 입력, 2초 이전 작동 방지, 거리·층·높이·서치라이트·운반/은신 중 제한, 사라진 대상의 실행 중단, 녹화 보존과 저장 복원을 검사한다. 사무동의 미습득 조명이 비밀번호를 가리지 않는지도 실제 배치에서 확인한다. 제어된 위치를 사용하는 단위 상황 검사를 전체 의뢰 플레이와 구분한다.
