# 대사·안내 문구 검수

참고: [byungjunjang/slop-rewrite](https://github.com/byungjunjang/slop-rewrite), 특히 [원칙 요약](https://github.com/byungjunjang/slop-rewrite/blob/main/principles/prompt-core.md). 문학·업무 문체를 게임 대사에 일괄 적용하지 않고 문맥을 읽어 직접 고쳤다. 외부 검사기 통과를 문장 품질로 주장하지 않는다.

## 다음 수정에도 지킬 기준

- 까마귀는 현장을 보며 짧게 지시한다. 지금 할 행동과 필요한 주의만 말한다. 올빼미는 보고서처럼 혼잣말하지 않는다.
- 농담은 상황에서 나온 짧은 반응으로 제한한다. 모든 인물에게 푸념이나 마지막 재치 한 줄을 붙이지 않는다.
- 인물 이름·실제 층·목적물·행동의 조건을 보존한다. 짧게 눌러 기절, 1초 길게 눌러 살해, 직원 복장은 통행 허용이라는 차이를 흐리지 않는다.
- 화면 왼쪽 위에는 목표, 무전에는 당장 할 일과 위험을 둔다. 대사와 짧은 목표는 역할이 다르다.
- 기술·버튼 이름은 실제 표시와 맞춘다. 한 개념을 여러 용어로 꾸며 쓰지 않는다.
- 말이 자연스러우면 그대로 둔다. 글자 수나 금칙어 수를 맞추려고 대사를 자르지 않는다.

## 이번 수정

첫 에피소드의 지시, 이후 의뢰의 상황별 무전, 공개 에피소드 시작 대사, 표적의 현장 대사 51줄을 고쳤다. 같은 말을 반복하거나 설명을 예고하는 문장을 줄였다. 살해·기절의 입력 차이와 CCTV 기록이 남는 조건은 남겼다.

- “지금 가까워. 아래에서 했던 것처럼 짧게 누르고 떼.” → “등 뒤에 붙었네. 아까처럼 공격을 짧게 눌렀다 떼.”
- “벽 스위치를 꺼 봐. 경비가 켜러 오면 다른 사람들한테서 떨어질 거야.” → “벽 스위치를 꺼. 불을 켜러 오는 경비를 혼자 있을 때 노려.”
- “까마귀는 2층, 원본 장부는 1층 금고. 뒷문부터 한번 보자.” → “까마귀는 2층에 있고 원본 장부는 1층 금고에 있어. 뒷문부터 보자.”

모든 목적물을 장부라고 부르던 공통 무전은 현재 남은 목적물의 이름을 사용한다. 문서윤의 습관 설명은 실제 배치인 3층에 맞췄다. 미션 순서·승리 조건·대사 발생 조건·플레이 중 기술 학습 제한은 바꾸지 않았다.

진단·재작성: 본 컨텍스트에서 직접 검수. 원문과 수정 기록은 Git diff에 보존한다. 이 문서는 문체 참고 적용 기록이며 slop-rewrite 전체 문서 윤문 파이프라인을 실행했다는 의미는 아니다.
