# 옥상 통로와 옥탑문 진입 · v86

## 판자 연결

잔칫날(m3)의 동·서쪽 판자 두 곳은 건물 외곽까지만 연결되어 있었다. 정면 외벽 두 줄은 실제 옥상 바닥이 아니어서 북쪽 건물로 걸어갈 수 없었다.

`11_roof_links.js`에서 선언된 통로 옆의 같은 높이 외벽 구간만 확장한다. 통행 마스크와 그림이 같은 구간을 쓰고, 양 끝 그림은 옥상 안쪽까지 8px 겹친다. 판자 위에서는 외벽 가장자리 보정이 작동하지 않으며, 아래 골목의 지상 지도와 충돌은 바꾸지 않는다. 옥상 소품의 배치 예약도 이 연결 구간을 쓴다.

[기존/수정 화면](roof-routes/index.html).

## 옥탑방 문

- 실제 옥탑문이 있는 계단은 별도 내려가기 버튼을 표시하지 않는다.
- 문 정면으로 걸어 접근해 24px 안에 들어오면 기존 계단 이동 동작을 시작한다. 입구 폭은 좌우 18px다.
- 문 옆을 스치거나, 뒤에서 밀거나, 멈춰 있거나, 다른 높이에 있을 때는 시작하지 않는다.
- 걸어 들어가는 구간과 계단 이동을 이어서 재생하고, 층 전환은 한 번만 한다. 도착지는 기존 실내 계단의 열린 층계참이다.
- 계단에서 나온 뒤 같은 방향 입력을 계속 누르고 있어도 바로 되돌아가는 동작을 막는다.
- 배관·사다리·굴뚝의 수동 내려가기, 실내 계단 버튼, HUD·모바일 버튼 위치는 유지한다. 옥탑문이 가까워도 다른 배관의 행동 후보가 가려지지 않는다.

## 검증

`t_roof_routes`: 동일 높이 통로 4개 × 양방향 × PC/모바일 = 16회 실제 플레이어 이동. 잔칫날 판자 두 곳은 정면 외벽을 지나 양쪽 실제 옥상에 도달한다. 옥탑문 45개 × PC/모바일 = 90회 자동 진입, 옆/뒤 접근·정지·다른 높이·연속 입력과 층 전환 횟수를 확인한다. 대표 옥탑문은 실제 키보드 이벤트와 390px 모바일 터치 조이스틱 이벤트로도 내려간다.

기존 계단 구조 검사(실내 61개·옥상 72개·NPC 경로 266회), 세계 정합성, 사물 상호작용, 매달리기 조작, v85 높이 단서 검사를 함께 실행한다. 옥상 소품·경비 동선의 단절도 확인한다.
