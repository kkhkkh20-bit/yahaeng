# v193 · 인물과 시야를 읽는 인터페이스

같은 자경대원이 경비 등급에 따라 초록·남색·검정 옷을 입고, 주변 인물의 시야를 모두 그려 소속과 위험을 함께 읽기 어려웠다. 브리핑에서는 플레이어와 연락하는 인물이 소개되지 않았고, 대사에서 올빼미의 역할이 변장 옷 이름으로 바뀌었다.

## 바뀐 동작

- 자경대원은 회녹색 제복으로 통일한다. 기존 피부·머리·체형과 등급 표시는 유지한다. 건달파는 붉은 점퍼, 경찰은 파란 제복이다. 훔쳐 입은 옷, 쓰러진 인물과 초상에도 같은 팔레트가 적용된다.
- 실시간 플레이에서는 한 명의 전체 시야를 표시한다. 클릭·탭한 인물 또는 CCTV를 우선하고, 실제 감지가 시작되면 발견자를 강조한다. 발각한 인물은 부분적인 신원 확인보다 우선한다. 위험이 사라지면 선택한 인물로 돌아간다.
- 여러 명이 감지하면 경계 표시는 모두 유지한다. 전체 시야만 가장 위험한 한 명에 배정하며, 작은 차이로 초점이 계속 바뀌지 않게 한다. 선택하지 않은 경비에게는 작은 방향 표시를 남긴다.
- CCTV도 클릭·탭으로 시야를 고정하고 다시 눌러 해제할 수 있다. 다트의 인물 지정과는 분리한다. 선택하지 않았다면 가까운 경비 또는 CCTV의 시야를 표시한다. 일시정지 지도에서는 전체 시야를 볼 수 있다. 물리적인 서치라이트 빛은 유지한다. 표시하지 않는 인물도 기존 규칙대로 감지한다.
- 위층에서 선택 고리가 바닥에 가려지던 그리기 순서를 고쳤다. 다른 층과 가려진 건물의 인물 표시를 노출하지 않는다.
- 브리핑에서 **올빼미 · 당신 / 까마귀 · 의뢰인 / 제비 · 현장 지원**을 소개한다. 대사에도 화자의 역할과 무전 상대를 표시한다. 변장해도 올빼미의 이름과 초상은 유지한다. 까마귀의 초상을 VIP 표적과 구분했다.
- 브리핑을 기존 야간 도시와 금속 HUD에 맞는 짙은 회색 계열로 정리했다. 반복된 목표 상자를 구분선으로 바꾸고 장부는 장부 그림으로 표시한다. 출발 버튼은 스크롤 영역 밖에 유지한다. VIP의 설명에도 세 번째 목표인 거래 암호표를 포함한다.

## 참고와 적용 범위

Mimimi의 리드 디자이너 Moritz Wagner는 **Shadow Tactics에서 한 번에 한 명의 시야만 보여준 이유**로 가독성과 다른 경비의 시야를 기억하며 움직이는 긴장감을 설명했다. 플레이어의 감지가 시작되면 해당 발견자의 시야를 자동으로 표시한다고 밝혔다.

- [Game Design Deep Dive: Dynamic detection in Shadow Tactics](https://www.gamedeveloper.com/design/game-design-deep-dive-dynamic-detection-in-i-shadow-tactics-i-), 2017-02-13.
- [특정 지점의 관찰자를 확인하는 기능 안내](https://steamcommunity.com/app/418240/discussions/0/152391995405120490/). 이 지점 표시 기능은 이번 변경에 추가하지 않았다.

이번에는 시야 표시의 우선순위를 적용했다. Shadow Tactics의 녹색 구역·웅크림 구역·슬로모션은 옮기지 않았다. 야행의 실제 밝기·엄폐·복장·목격 판정을 유지한다.

## 검증

`tests/rev/t_cast_vision.py`는 PC·모바일 세로·가로·320px 화면에서 인물 소개, 실제 출발과 무전, 출발 버튼 노출, 캔버스의 단일 시야, 복수 관찰자와 CCTV의 위험 우선순위, 위험 종료 후 선택 복귀, 지도 전체 시야, 제복·변장·벗겨진 옷의 일관성을 검사한다. 기존 핵심 회귀 묶음과 키보드·터치 플레이 검증을 PR 필수 검사에 유지한다.

Impeccable의 수동 디자인 검사도 실행했다. 원본 template의 옛 기본 스타일에 대한 경고는 빌드에서 나중에 삽입되는 interface.css를 반영하지 못한 항목이다. 실제 화면에서는 지도 범례 11px, 출발 16px, 현장 정보의 테두리 제거, 설정 구분선 안쪽 18px 여백을 확인한다. 기존 게임 HUD의 조밀한 수치·보조 표시는 이번 메뉴 개선 범위 밖이다.
