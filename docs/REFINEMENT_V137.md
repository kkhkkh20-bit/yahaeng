# v137 — 창문·빛과 소리·경비 판단 개선

## 적용 범위

기존 2D 본편을 개선했다. 3D 실험판 `episode-one/`, `club-study/`에는 적용하지 않았다. 전투 수치나 이동 속도로 난이도를 바꾸지 않고, 원리를 먼저 배우는 연습과 소리에 대응하는 경비의 판단을 고쳤다.

- 측면 창문: 회전한 문처럼 길게 보이던 틀을 짧은 외벽 창틀·유리 두 칸·돌출 창턱으로 변경했다. 큰 금색 손잡이를 줄이고, 잠김·열림·방범창과 실내 조명 상태를 구분한다. 통과 규칙은 유지한다.
- 첫 연습: 이동 → 달리기 소리 → 조용한 걸음 → 시야 관찰 → 가로등 끄기 → 어두운 열린 길 통과 → 풀숲 은신 → 휘파람 → 이탈. 불을 꺼도 다른 조명·손전등·소리는 남는다고 안내한다. 추가한 가로등만 조작하며 기존 조명 세 개는 유지한다.
- 경비 판단: 같은 층에서 실제로 소리를 들은 경비만 반응한다. 서로 가까우며 시야가 통하는 일반 경비는 한 명이 확인하고 나머지는 잠시 주변을 지킨다. 이미 본 침입자·시체·다른 수색 단서가 소리 유인에 덮이지 않는다.
- 반복 유인: 60초 동안 같은 곳에서 들은 휘파람·돌소리를 함께 기억한다. 확인자는 소리 지점 앞에서 살피고 주변 은신처 하나를 직접 확인한다. 플레이어의 은신 위치를 참조해 목적지를 정하지 않는다. 초급 연습에는 이 고급 대응을 적용하지 않는다.
- 조명 복구: 경비가 스위치까지 접근한 뒤 1.8초 동안 작업해 불을 켠다. 한 명이 맡고, 접근 불가나 사망으로 방치된 예약은 해제한다.
- 모바일: 검수에서 발견한 이동 버튼의 작은 보조 글자를 9px에서 11px로 키웠다.

## 승인한 외부 도구 설치와 실제 사용

[설치 내역](EXTERNAL_TOOLS_V137.md). Impeccable은 기존 화면에 한정해 시각·문구·온보딩 검수와 실제 브라우저의 기계 검사를 수행했다. Ponytail REVIEW는 변경 함수의 호출부와 연결된 AI 상태 흐름을 추적하는 코드 리뷰에 사용했다. 별도 에이전트는 실행하지 않았다.

수정한 구체적 리뷰 지적:

1. 반복 소리 기억을 소리 종류별로 분리하면 휘파람과 돌을 번갈아 써서 초기화할 수 있었다. 같은 위치의 기억으로 합쳤다.
2. 소리 대응이 추적 중인 시각·혈흔 증거를 덮거나 벽 너머 동료와 역할을 나눌 수 있었다. 기존 증거 우선순위와 실제 상호 시야 조건을 넣었다.
3. 경계 역할에 일반 둘러보기 타이머까지 중첩되면 불필요하게 오래 멈췄다. 중복 타이머를 제거했다.
4. 꺼진 조명을 제자리에서 켜고 죽은 경비가 복구 예약을 잡을 수 있었다. 접근·시야·작업 단계 및 유효 예약 조건을 넣었다.
5. 경로가 비면 수색 목적지 도착으로 간주하던 분기를 제거했다.
6. 조명마다 모든 경비의 예약을 검사하기 전에 층·거리·시야로 후보를 줄였다.
7. Impeccable이 지적한 9px 이동 보조 글자를 수정했다. 같은 세로 연습 화면의 재검사 결과는 `[]`다.

가정한 부하는 현재 맵 크기의 단일 브라우저 게임이다. 소리 기억은 경비당 최대 네 지점이며 시간이 지나면 제거된다. 대규모 군중이나 실물 저사양 iPhone의 성능을 검증한 것은 아니다. 소리 묶음의 동료 비교 및 경로 탐색 비용은 기존 맵 범위를 전제로 한다.

## 검증과 한계

- `tests/tutorial/first_session.py`: 실제 키보드 / CDP 터치 입력으로 두 연습을 완료하고 첫 의뢰 `m2`에 진입했다. AI를 멈추거나 플레이어 위치·도구·진행을 지급하지 않는다. 일정한 게임 시간으로 재현한다. 같은 열린 지점은 불을 켰을 때 보이고 끈 뒤 보이지 않는지, 어두운 길에서는 은신 상태가 아닌지도 확인한다.
- `tests/rev/t_ai_decisions.py`: 통제된 배치에서 확인자 1명·주변 경계 2명, 반복 소리의 거리 유지와 주변 은신처 확인, 시각/시체 우선순위, 층별 청력, 실제 스위치 접근과 복구, 막힌 길, 죽은 작업자 예약을 검증했다. 첫 사용자 완주를 대신하는 검사는 아니다.
- `tests/rev/t_security_response_live.py`: PC/터치 각 3개 시드에서 기존 실종 확인·짝 수색·VIP 복귀·경계 해제를 실제 AI 시간으로 검증했다. 사건과 플레이어 위치를 통제한 회귀 검사다.
- `tests/rev/t_light_fixtures.py`: 11개 스테이지의 조명 스위치 95개 접근 가능, 기존 조명 상태 호환을 확인했다.
- `tests/rev/t_motion_windows.py`: PC/터치 각각 창문 통과 496회, 층 이동 72회, 매달림 접점 128개를 통과했다.
- `tests/tutorial/perception_visual.py`: 다섯 웅크림 전환 상태에서 시야 채움·윤곽 각 한 번, 지속 발소리 타원 없음, 체크포인트 복구를 확인했다.
- `tests/rev/t_side_windows.py`: 동일한 실제 서쪽 외벽의 변경 전/후·잠김/열림/방범창을 PC와 세로 터치 화면으로 촬영했다. 화면 비교를 위한 통제 배치다.
- `tests/tutorial/audit_ui.py`: 설치한 Impeccable 엔진으로 세로 연습 화면의 DOM을 검사했다. 게임 전체의 접근성·AI를 자동 보증하는 결과가 아니다.
