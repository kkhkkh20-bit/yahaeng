# 초보자 학습과 에피소드 연결 · v159

목표는 처음 하는 사람이 ‘시야를 피해 접근하고, 가까이서 제압하고, 몸을 숨긴 뒤 목적을 마치고 나온다’를 직접 해내는 것이다. 설명을 한꺼번에 읽거나 변장·도구 선택을 먼저 이해할 필요가 없도록 한다.

## 구성

| 순서 | 장소·목적 | 새로 익히는 행동 | 다음 구간 |
| --- | --- | --- | --- |
| 첫걸음 tB | 클럽 외곽 골목에서 경비 시야를 지나 빠져나오기 | 이동, 뛰는 소리와 웅크림, 부채꼴, 풀숲 은폐, 소리 유인 | 뒤에서 제압 t0 |
| 의뢰 01 준비 t0 | 물류 골목 경비를 제압하고 풀숲에 숨긴 뒤 출구로 | 바짝 접근, 짧게 기절, 직접 운반, 풀숲에 몸 숨기기 | 의뢰 01 VIP |
| 의뢰 02 준비 tL | 상가 후문 보안등을 끄고 어두워진 길로 통과 | 연습용 전기 조작, 실제 시야 감소, 안전한 길로 빠져나오기 | 의뢰 02 대청소 |
| 의뢰 03 준비 tR | 연락 거점 2층의 서류를 회수해 골목으로 복귀 | 실내 진입, 계단으로 층 이동, 물건 회수, 내려와 탈출 | 의뢰 03 배신 |

기본 연습의 전기 조작은 두 번째 의뢰 준비로 옮기고, 첫 제압 연습에서 강제 붙잡기·변장·대상 선택을 제거한다. 변장·붙잡기·암살 기술·도구는 기존 선택 연습에서 익힐 수 있다. 준비 임무는 새 포인트나 본편 기술을 무료로 주지 않는다. 전기 조작 임시 허용은 tL 안에서만 유효하다.

## 진행과 실패

기존 목표 영역에 현재 행동과 이유 한 줄을 표시한다. 대상에는 기존 목표 표식을 사용하고 필요한 조작 하나를 강조한다. 관찰은 안전한 자리에서, 실행은 바로 다음 짧은 구간에서 한다. 성공하면 다음 행동으로 넘어가며 한 프레임에 여러 설명을 건너뛰지 않는다. 알아야 할 마지막 행동을 마치기 전에는 출구가 열리지 않는다.

처음 시작·결과 화면·의뢰 이어 하기는 같은 학습 순서를 따른다. 이미 마친 준비 임무는 반복 강제하지 않으며, 장부에서 본편을 직접 고르는 길은 유지한다. 각 준비 임무는 자신이 연결된 의뢰로 간다. 선택 연습을 마쳤을 때 무조건 의뢰 01로 돌아가는 혼란도 줄인다.

기본 연습에서는 들켰을 때 가장 최근 안전한 학습 지점에서 다시 한다. 메뉴·재시작·단계 이동 때 입력과 강조 상태를 정리하고, 기절 대신 처치했거나 몸을 이미 숨긴 경우도 진행 불가능해지지 않게 한다. 튜토리얼 효과는 본편으로 새지 않는다.

## 검증 계획과 증거 범위

PC 키보드와 실제 터치 입력으로 처음 시작부터 두 기본 연습, 두 에피소드 준비 임무, 각각 본편 연결을 검증한다. 활성 NPC와 실제 충돌·작업 시간·계단을 사용한다. 별도 통제 검사에서 조기 출구 차단, 실패 복구, 완료 기록별 추천 순서, 직접 본편 선택, 임시 기술 해제, 네 화면 크기 안내 잘림을 확인한다. 기존 회귀 검사와 배포 패키지도 검증한다. 실제 신규 사용자 이해도 평가는 구현 검사와 구분하며 사용자 테스트 결과를 꾸며내지 않는다.

## Direction contract

기존 2D 야간 마을·Plex Sans KR Regular 400·현재 HUD와 버튼 위치를 상속하는 좁은 개선이다. 신규 브랜드나 메뉴 체계를 만들지 않는다. 기존 목표창 하나에 ‘지금 할 일 → 이유’만 남기고, 다음 의뢰 전에 필요한 작은 장소를 실제 맵과 NPC로 제공한다. 시그니처 행동은 풀숲에서 빠져나와 등 뒤에 바짝 붙어 제압하고 몸을 직접 치우는 첫 성공이다. 기존 원본 렌더와 전후 비교를 기준으로 작은 화면에서도 목표·플레이어·조작부가 겹치지 않는지 확인한다. 코드로 구현하며 승인된 별도 이미지 시안은 없다. unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance. 새 시각 체계·래스터 자산은 없으므로 새 DESIGN.md와 이미지 자산 제작은 해당하지 않는다.

## 구현 결과와 로컬 검증

네 연습의 실제 키보드·터치 완료와 각 본편 연결을 확인했다. 첫 제압 중 실수로 몸을 내려놓고 다시 운반하는 경로도 완료했다. 전기 연습의 같은 통과 지점은 밝기 약0.675→0.04, 실제 시각 감지0.219→0으로 바뀌었다. 새 실내 연습은 실제 문·계단으로2층에 올라가 서류를 행동으로 회수하고 내려와 탈출한다. 의뢰03 진입 후에는 실제 이동으로 머리핀을 줍고 감방 문 안내로 전환되는 것까지 검증했다.

전체54개 핵심 회귀 중 첫 실행53개가 통과했고, 풀숲 검사1개가 이전 단계 번호6/7을 사용해 실패했다. 새 단계4/5에 맞춘 뒤 동일 은폐·몸 숨기기·효과 상한 검사가 통과했다. 마지막 튜토리얼 조작/안내 변경은 관련 회귀와 실제 배포 패키지의 네 연습을 다시 검사했다. 최초 실패 로그와 수정 후 결과를 모두 남겼다. [검사 해소 기록](lessons-v159/regression-resolution.json). 전체54개를 마지막 변경 후 한 번 더 전부 실행했다는 의미가 아니다.

24개 안내 문구는 PC·세로·가로·320px 화면에서 잘림을 검사했고, 전후 비교는 네 상태·네 크기32장 원본이다. 시작 화면 촬영은 실제 진입 후48프레임을 진행해 진입 페이드가 끝난 상태를 사용했다. 실제 진행 기록과 비교용 상태 선택을 구분한다. 앞선 v158은 연결 오류로 미배포된 로컬 작업본이며, 이번 빌드는 외벽·몸 정리 입력·추적 수정도 누적 포함한다.

마감 중 2층 서류 단계에서 가까운 내려가기 버튼을 강조하던 불일치를 수정했다. 기본 연습의 행동 강조는 현재 목표와 같은 층·64px 이내이고 실제 행동이 있을 때만 나타난다. 서류에서 멀면 기존 이동 표식만 보이고, 서류 옆에서는 회수 행동을 강조한다. 실제 계단 도착과 회수 시점에서 각각 검사한다.
