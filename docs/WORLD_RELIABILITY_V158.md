# v158 — 보이는 외벽과 끊기지 않는 행동

맵 우측·하단의 검은 빈 공간, 제압 직후 무시되는 몸 정리 입력, 장애물 앞에서 멈추는 경비를 재현하고 수정했습니다.

- **맵 밖 검은 공간 → 마을 외곽:** 실제 이동 제한선 바로 밖에 콘크리트 외벽·기둥·출입문을 그리고, 그 너머에는 보도·골목·인접 건물 지붕을 이어 그립니다. 화면을 확대하거나 카메라를 잘라 문제를 숨기지 않습니다. 실제 플레이 그리드·시야·은신 판정은 유지합니다.
- **제압 직후 입력 유실 → 짧은 몸 정리 예약:** 제압 종료 직전 0.25초 동안 누른 행동 입력을 그 제압 대상에게만 적용합니다. 이동·피격·메뉴 진입·층 변경·대상 소실 때 취소합니다. 다른 적을 자동 공격하지 않습니다.
- **벽 안 조사 지점 반복 → 닿을 수 있는 조사 지점:** 막힌 셀 대신 실제 도착 가능한 인접 셀을 경로 끝점으로 삼습니다. 기억한 목격 위치는 보존합니다.
- **가로등 충돌로 추격 정지 → 물리적으로 돌아가기:** 야시장 가로등 앞에서 계속 밀려나던 경로를 재현했습니다. 기둥 양쪽 우회 후보를 벽 충돌까지 확인해 선택합니다. 충돌을 끄거나 경비를 이동시키지 않습니다. 기존 계단·옥상 추적도 회귀 검사했습니다.

## 검증

핵심 회귀 53개, 빌드 검사 7개, 스프라이트 소유권 검사, 도달 검사가 통과했습니다. 본편 세 의뢰·세 배율·네 모서리·네 화면 크기의 실제 렌더 144경우에서 맵 밖 검은 공간과 캐시 상한을 확인했습니다. 주변 건물은 6개 작은 캔버스와 바닥·외벽 캐시를 재사용하며 약 1.5MB입니다. 전체 맵 크기의 추가 캔버스를 만들지 않습니다.

PC·터치에서 제압 직후 몸 정리 입력과 5개 취소·무시 조건을 실제 키보드/터치로 검사했습니다. 이 입력 타이밍 검사는 단일 적을 배치한 통제 장면입니다. 별도의 실제 본편 진행에서는 활성 AI 아래에서 첫 순찰 제압 → 운반 → 풀숲에 숨기기 → 메뉴 → 저장한 이어 하기를 PC·터치로 완료했습니다. 강제 적 재배치·체력·인벤토리 수정은 없습니다.

막힌 조사 지점 3곳, 고정 목표·0.4초 간격 재계산을 포함한 가로등 추적 4경우를 검사했습니다. 원래 실패했던 야시장 경로는 10초 뒤 약 52px 떨어져 멈췄고, 수정 후 도착합니다. 기본 다층 이동 전체가 고장 났다고 주장하지 않습니다. 기존 다수 경비 옥상 이동 검사는 수정 전에도 통과했습니다.
