## 결정

2026-10-30 후속 적용: 사용자 승인 B안으로 메인을 교체했다. 아래의 송명체·3인
실루엣은 이전 적용 기록이며, 현재 메인은 `title-poster.webp`와 Black Han Sans를 쓴다.
인게임 UI의 위치는 바꾸지 않았다.

- 메인은 `야행`, 시작, 의뢰 선택, 조작 방법, 버전만 표시한다. 부제·영문 슬로건·가짜 작전 상태·좌표 장식은 제거한다.
- 메인 제목은 송명체를 쓰고, 메뉴는 읽기 쉬운 기본 한글 서체를 쓴다. 붉은 막대는 현재 선택에만 쓴다.
- 금색은 보상·등급처럼 의미 있는 정보에 남기고, 일반 메뉴와 지도 프레임에서는 걷어낸다.
- 방향키로 메인 메뉴 이동, Enter로 실행, Esc로 이전 화면 이동을 지원한다. 하위 화면에서 돌아오면 사용한 메뉴로 포커스를 되돌린다.
- 게임 위의 메뉴가 열려 있으면 Tab/Enter를 게임 조작이 가로채지 않게 한다.
- 의뢰/연습 탭 선택은 메뉴를 나갔다 돌아와도 유지한다. 데모의 잠긴 의뢰와 기존 진행도는 그대로 유지한다.

## 제목 글꼴

[Google Fonts의 Song Myung](https://github.com/google/fonts/tree/main/ofl/songmyung), SIL OFL 1.1.
`src/fonts/title-songmyung.ttf`는 `야행` 두 글자만 포함한 4.6 KB 서브셋이다.
원본 라이선스는 `src/fonts/OFL-SongMyung.txt`에 보관했다.
`build.py`가 글꼴을 HTML에 포함하므로 제목을 표시할 때 외부 글꼴 요청이 필요하지 않다.

## 메인 배경 일러스트

메인의 인게임 지도 배경을 `src/art/title-trio.webp`로 교체했다.
대사창의 올빼미(hero), 제비(aide), 까마귀(master) 실루엣을 참조해 새로 생성한 3인 일러스트다.
짧은 머리·단발·코트로 인물을 구분한다. 첫 시안의 사실적인 얼굴·근육·의상 묘사, 젖은 골목과 삼색 테두리 빛을 제거하고, 회색 벽과 검은 실루엣 위주의 평면 구도로 교체했다.
제목과 부제는 그림에 넣지 않았으며, HTML의 `야행` 제목과 메뉴만 표시한다.

1672×941 WebP. `build.py`가 `--menu-art`에 이미지 데이터를 포함한다.
PC는 왼쪽 메뉴·오른쪽 인물, 세로 화면은 위쪽 인물·아래쪽 메뉴로 배치한다.
브리핑·일시정지의 옅은 배경에도 같은 그림을 사용한다.
기존 `build/title_bg.json`과 `tools/titlebg.py`는 인게임 장면 기록용으로 남겨 두며 메인 일러스트를 덮어쓰지 않는다.

## 현재 메인 — 승인 B안

- `src/art/title-poster.webp`: 여성 주인공의 검은 단발·차콜 재킷을 잉크 초상으로
  표현했다. 따뜻한 종이색, 먹색, 붉은 대각선 인쇄 구도다. 승인된 B 시안과 실제
  주인공 모델을 참조해 생성했다. 외부 게임의 그림을 복사하지 않았다.
- `야행` 제목과 시작·의뢰 선택·조작 방법은 이미지에 구워 넣지 않은 실제 HTML이다.
  키보드 포커스·터치·진행도에 따른 시작 버튼 동작을 유지한다. 부제·장식 문구는 없다.
- PC는 왼쪽 큰 제목과 메뉴, 오른쪽 초상. 세로 모바일은 위 초상·아래 제목과 메뉴,
  가로 모바일은 PC와 같은 좌우 구도를 쓴다. 320×568부터 1440×900까지 확인한다.
- 제목은 [Black Han Sans](https://github.com/google/fonts/tree/main/ofl/blackhansans)
  두 글자 서브셋이다. SIL OFL 1.1은 `src/fonts/OFL-BlackHanSans.txt`에 보관한다.
  제목·배경은 빌드에 포함돼 외부 요청 없이 표시된다.

## 임무 안내 규칙

- 연습 단계 → 탈출 → 미완료 필수 첫 행동 → 추적 기회(전체 안내) → 가까운 의뢰 목표 순서다.
- 전체 안내에서 최상단 행동과 화면 방향 표식은 같은 단계를 가리킨다. 위치 없는
  단계에는 거리나 표식을 만들지 않는다. 추적 단계의 문장은 아래 목록에 반복하지 않는다.
- 기본인 최소 안내에서는 기회의 위치를 새로 공개하지 않는다. 최상단은 `의뢰:`,
  기회 목록은 `추적 중:`으로 구분한다. 기존 안내 강도 설정을 유지한다.
- T로 마지막 기회를 넘기면 추적 해제, 다시 T로 첫 기회를 선택한다. 완료 뒤에는
  다른 발견한 기회로 자동 전환하지 않는다. 완료한 기회 행과 완료한 첫 행동은 접는다.
- 중앙 섞임, 우측 미니맵, 모바일 행동 패드의 위치·규모·판정은 변경하지 않는다.
