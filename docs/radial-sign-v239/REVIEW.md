# v239 — 백송상사 간판과 세 개의 보조 버튼

플레이: https://yahaeng.kkhkkh-20.workers.dev/?study=agent-city&v=239

## 간판

백송 / 상사로 나누던 정사각 광고판을 걷어내고, 입구 위 6칸 폭의 가로형 간판으로 바꿨다. 상호는 한 줄, 업종은 작은 `수출입 · 물류`로 표시한다. 구매한 빈 철제 프레임의 모서리/마감을 사용하면서 테두리 두께를 줄이고 짙은 녹색 바탕과 아이보리 글자를 적용했다. 출입문과 차양은 가리지 않는다.

간판의 실제 불투명 영역과 창문 판정을 함께 변경했다. 도시 시안의 레이아웃 버전을 갱신해 이전 시안 체크포인트의 창문 목록을 잘못 복원하지 않는다. 본편 저장은 유지한다. 일본어 광고판은 다시 사용하지 않는다.

## 버튼

- 메인 버튼의 왼쪽·왼쪽 위·위에 같은 크기의 보조 버튼 세 개를 배치한다. 중심 기준 각도는 0°/45°/90°, 반경은 106px이다. 374px 이하에서는 보조 버튼 48px, 반경 94px로 조정한다. 계산식은 CSS 변수 한 곳에서 관리한다.
- 왼쪽은 행동, 대각선은 웅크림, 위쪽은 상황/도구 자리다. 붙잡기·옷 입기·심문·도구가 같은 자리에서 전환되며, 조준 중인 버튼은 손을 뗄 때까지 유지한다. 사용 가능한 탄약이 있으면 접근 안내만 하는 붙잡기 버튼보다 도구를 우선한다.
- 선택한 도구가 비어 있고 상황 동작도 없으면 기존 휘파람을 제공한다. 이 버튼을 눌러도 선택한 장비나 수량은 변경하지 않는다. 명시적으로 선택한 휘파람은 유지한다.
- 장비·빠른 아이템·대상 선택은 하단 줄에 둔다. 세로 화면은 메인 묶음 아래에 공간을 확보하고, 가로 화면은 좌우 여백을 사용해 같은 버튼 기하를 유지한다. 기존 메뉴/학습 단계의 표시 규칙과 PC 터치 조작부 숨김은 유지한다.

[모바일 전후 비교](mobile-before-after.webp), [백송상사 정면](baeksong-front.webp), [가로 화면](landscape.png). 정면 이미지는 촬영용 위치 고정 장면이며, 모바일 비교와 가로 화면은 정상 시간 화면이다.

## 검증

1. 여섯 화면 크기에서 소모품 전체·빈 도구·탄약 있는 도구·시체/옷·휘파람의 30개 조합을 검사했다. 정확히 세 개의 보조 버튼, 같은 반경과 45도 간격, 동일 크기, 최소 44px, 화면 경계와 사각 터치 영역의 비겹침을 확인했다. 작은 화면의 실제 반경 차이는 브라우저 반올림에 따른 0.03px 미만이다. [결과](layout-checks.json).
2. 같은 여섯 크기에서 실제 터치로 빈 도구의 휘파람을 사용했다. 휘파람 횟수가 증가하고 장비 선택과 수량이 보존된다. 장비 열기/선택/닫기와 기존 휘파람·옷 조작도 네 가지 화면 조건에서 통과했다.
3. 568×320, 844×390의 정상 시간 화면에서 메인/보조 버튼이 미니맵·메뉴 버튼과 겹치지 않는 것을 확인했다. 기존 도시 카메라 가시 영역 검사도 통과했다.
4. 최종 소스로 정상 시간·AI를 유지한 모바일 CDP 터치 임무를 완료했다. 기절 → 변장 → 시체 운반/숨기기 → 문 열기 → 2층 표적 처치 → 기록 회수 → 탈출. 체력 3, 발각 0, 경보 0이다. 이미 경로를 아는 플레이이며 초보자 테스트를 대신하지 않는다. [기록](native-mobile.json).
5. 변경 후 창문 179개와 실제 판정, 층계 42개, 육교 연결과 본편 저장 분리 검사가 통과했다. [결과](study-checks.json). 빌드 검사 8개와 배포용 PC/모바일 기본 실행·조작 검사도 통과했다.

버튼은 본편과 도시 시안 공통, 백송상사 간판은 도시 시안에 적용된다. 캐릭터/배경 에셋과 미션 내용은 이번 변경 범위에 추가하지 않는다.
