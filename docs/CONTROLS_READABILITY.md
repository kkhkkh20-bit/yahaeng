# v98 조작과 화면 가독성

2026-10-31. 살피기를 제거하고 메뉴를 상단 오른쪽으로 옮겼다. 기본 실행과 잉크 시안 모두 적용한다.

- 살피기 버튼·Alt/4 입력·범례·도움말을 제거했다. 기본 연습의 해당 단계는 문·벽에 접근해 행동 안내를 확인하는 단계로 교체했다. 전술 지도는 유지한다.
- 메뉴를 상단 오른쪽에 배치하고 터치 영역을 48×44px로 잡았다. 모바일 목표 줄은 메뉴 폭을 비워 둔다. 공격·행동·붙잡기·도구 버튼 위치는 유지한다.
- 행동 선택을 말풍선보다 먼저 배치한다. 주변 대화는 평소 최대 두 개, 행동 근처에서는 한 개만 표시한다. 인물·행동 안내·미니맵·메뉴·터치 버튼과 겹치면 표시를 생략한다. 단서 문장은 잘라내지 않고 줄을 바꾼다.
- 행동 중 일반 알림과 도움말을 숨기고 긴급 경고는 유지한다. 비필수 대화창은 표시와 타이머를 멈췄다가 행동이 끝나면 이어 보여준다. 첫 처치·연속 처치의 반복 무전은 제거했다. 중요한 단서·획득 정보·경고 기록은 유지한다.
- 잉크 시안의 생성 초상과 로더를 제거하고 이전 인게임 모델 초상으로 복원했다. 모달 대화 중에는 배경 말풍선을 표시하지 않는다.

## 검증

- `t_controls_readability.py`: PC·390×844·360×740·844×390 각각 기본/잉크 모드. 삭제된 입력, 메뉴 접근과 목표 줄 겹침, 실제 키보드/터치 붙잡기, 행동과 말풍선의 겹침, 비필수 대화의 대기·재개, 연습 단계 진행, 모델 초상 렌더링을 검사한다.
- `t_ink_study.py`: 기본/잉크의 여섯 의뢰 지도·충돌·조명·목표와 조작 영역 비교, 초상·제목·대비 검사.
- `t_camera_presentation.py`: PC/가로·세로 모바일의 108개 맵 경계 조건과 건물 위 말풍선 배치.
- `t_play_clarity`, `t_combat_policy`, `t_interaction_flow`, `t_presentation`: 행동·붙잡기·탭 기절/길게 처치·이동·대화 배치 회귀 검사. 실제 휴대전화에서 실행한 검사는 아니다.
