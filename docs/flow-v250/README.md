# v250 — 통로 정리와 기술 준비 화면

삼거리·담장 출입구·실내 서비스 통로를 검토했다. 공개 에피소드의 수거함 11개, 상자 4개, 분리된 울타리 2개를 벽 쪽으로 옮겼다. 출입구에는 접근과 회전에 필요한 바닥을 남겼다. 흡연 표적과 경비 옷을 확보하는 장소의 엄폐, 첫 에피소드의 상자 엄폐는 유지했다.

실내는 m2의 좁은 수납장 모듈을 3칸에서 2칸으로 줄이고, m6의 선반 두 줄을 왼쪽 벽에 붙여 두 칸짜리 통로를 확보했다. m4 식당의 의자는 식탁 앞자리로 옮겨 두 식탁 사이 통로를 비웠다. 기존 구매 에셋을 사용하며 추가 장식으로 바닥을 채우지 않았다.

옮긴 수거함은 그대로 몸 숨기기에 쓸 수 있다. 구 저장을 불러올 때 안에 숨은 플레이어와 보관한 기절자·시체도 같이 이동하고 체력·아이템 진행은 보존한다. 새 시설물 자리에 서 있던 인물은 바로 옆의 빈 바닥으로 옮긴다.

기술 화면은 한 분야씩 읽는 카드 목록으로 바꿨다. 각 카드에서 이름, 습득 후 효과, 비용, 습득 가능/선행 필요/배움 상태를 확인한다. 선택은 조회이며 실제 구매는 설명창의 버튼으로 한다. 설명창은 기본/습득 후 수치를 먼저 보여 주고, 긴 규칙은 접어 둔다. 필요한 기술은 실제 습득 순서대로 표시한다.

PC는 옆 설명창, 모바일은 하단 설명창을 사용한다. 모바일 설명 중 목록은 비활성화하고 키보드 초점도 창 안에 유지한다. 화면 크기가 바뀌면 다시 적용한다. 읽기 전용, 포인트 부족, 이미 배움 상태를 구분하며, 기술 비용과 지급량·게임 중 습득 제한은 바꾸지 않았다. 미해금 암살 장착 버튼은 감췄다. 기존 연결선 렌더러를 삭제해 카드와 겹치지 않게 했다.

## 확인한 범위

- 27맵의 사물함·옷장 115개 앞에서 접촉과 동작 공간 확인. 변경한 시설물 17개와 수거함 11개의 앞 공간, 담장 출입구 회전 공간, 실내 통로 확인. 전체 맵의 모든 가능한 동선을 인간 플레이로 전수 완주한 것은 아니다.
- 구버전 저장의 숨은 플레이어·보관 기절자·새 시설물 위치에 서 있던 플레이어를 별도 fixture로 복원해 진행 보존 확인.
- 실제 RAF와 키보드/터치로 예전 수거함 자리와 선반 옆 통로 통과. 인물을 제거하고 시작 위치를 지정한 이동 fixture이며 임무 난이도 검증은 아니다.
- 첫 에피소드 PC/터치 실제 RAF·AI 완주: 각각 체력 3, 발각 0, 기절 2. 완료 대사·새 기술 화면의 실제 구매·다음 의뢰 진입 확인.
- VIP 임무 PC 실제 RAF·AI 완주: 체력 3, 직접 발각 0, 경보 2. 표적 처치·위장·카메라 전선 분리·장부와 암호표 회수·탈출 후 새 기술 화면에서 추가 1P 사용 확인. 첫 완료 보상은 1P로 유지했다.
- 기술 화면은 320×568, 390×844, 844×390, 1024×768, 1440×900에서 분야 이동, 설명/비용/선행 기술, 잘못된 구매 차단, 실제 구매와 반환, 초점, 화면 회전, 첫 1P 준비 화면 확인.
- 기술을 임무 사이에서만 배운다는 규칙, UI/폰트와 27맵 목적지 문구, 표면 조명과 차폐, 층/계단/배경 정렬, 사물함/신체 상호작용, 425개 실외 조명 접근 검사 통과.
- 실제 모바일 기기 검사는 수행하지 않았다. 터치는 Chromium 에뮬레이션이다.
