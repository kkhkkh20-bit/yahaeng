## 의뢰 화면

처음에는 의뢰명·보수·필수 목표·위치와 지도만 보여 준다. 출발 화면에 섞여 있던 선택 도전은 `현장 정보 · 추가 목표` 안으로 옮겼다. 현장 정보는 기존 의뢰 데이터를 사용하며, 일시정지의 전체 목표와 CCTV 기록 삭제 조건은 유지한다. 이미 녹화된 신원 기록은 실제 목표 안내가 계속 추적한다.

목표의 위치는 작은 둘째 줄로 나누고 탈출 안내는 한 줄로 줄였다. 지도 이름은 굵은 색 글자·두꺼운 외곽선 대신 작은 명판을 쓴다. 이어 하기 버튼의 긴 문장을 줄이고 저장 시각은 버튼 안의 작은 줄에 표시한다. 모바일에서는 의뢰와 출발 버튼을 먼저 보고 아래에서 지도를 확인한다.

## 대화창

초상화와 본문을 하나의 패널 안에 넣었다. 초상화의 음수 여백·색 광택·흔들림, 다음 표시의 반복 운동을 없앴다. 짧은 대사와 긴 대사, 얼굴 없는 메모도 같은 구조를 사용한다. 대화 중 하단 키 안내도 숨겨 진행 입력과 게임 입력이 겹쳐 보이지 않게 했다.

첫 주요 의뢰(VIP)의 시작 대사를 7줄에서 3줄로 줄였다. 직원 복장의 출입 범위, 경호원·바텐더의 얼굴 확인 정보는 남겼다. 주변 인물의 말풍선도 어두운 패널·얇은 테두리로 맞췄으며 기존 화면 경계·건물 위 표시·충돌 회피는 유지했다.

## 붙잡기 발견성

붙잡기를 할 수 있을 때만 나오던 표시 외에 접근 중의 안내를 추가했다. 같은 층·높이에서 시선이 닿는 가까운 사람만 대상으로 한다.

- 실행 가능: `C / Q 붙잡기`, 터치는 기존 `붙잡기` 버튼 활성화. 플레이어 쪽에 대상 안내도 표시한다.
- 거리 부족: `붙잡기 · 더 가까이`.
- 방향 부적합: `붙잡기 · 등 뒤로`.
- 기존 예외: `붙잡기 · 정예 불가`, `붙잡기 · 교전 중`.

예고 상태는 실행 가능 표시와 구분한다. 예고는 최대 150px, 정예·민간인·교전 중 인물은 72px 안에서만 보인다. 실행 거리·정예 예외·기절과 길게 처치하는 규칙은 바꾸지 않았다. 기존 공격·행동·붙잡기 버튼 위치와 미니맵·중앙 은신 표시는 유지한다. 붙잡기 안내는 화면 경계와 HUD·말풍선을 피해 배치한다.

## 검증

- 신규 `t_presentation.py`: 주요 의뢰 3개의 기본/상세 화면, 긴/짧은 대화와 초상화 경계, 얼굴 없는 메모, 실제 이어 하기, 접근 예고와 방향·정예·교전 예외, 다른 층 표시 제거를 확인한다. C/Q 키와 실제 터치 버튼으로 붙잡기 동작을 시작해 적이 포로 상태가 되고 처치 수가 늘지 않는 것까지 확인한다.
