## 포인트와 이전 기록

처음 **4P**, 의뢰에서 이미 얻었거나 새로 얻는 **별 1개마다 1P**다. 별과 의뢰 완료 기록은 소비하지 않는다. 같은 기술은 한 번만 배우고 선행 조건·잔여 포인트를 확인한다. 24개를 모두 배우는 비용은 **40P**다. 여러 계열에 나눠 투자할 수 있다.

v147 이전 사용자는 별 3개/6개로 열렸던 쌍암살·연속 암살과 기존 별 보상 장비를 해당 기술과 선행 기술을 배운 상태로 한 번 이관한다. 그 기술의 비용을 사용 포인트로 표시한다. 의뢰 선택 화면의 **다시 배우기**로 환불받고 다른 계열로 바꿀 수 있다. 플레이 중에는 재배분할 수 없어 장비와 재사용 시간을 반복 초기화하지 못한다.

배움·선택은 기기에 저장된다. 중복·알 수 없는 ID·선행 조건 없는 노드·예산 초과 기록을 복원할 때 거른다. 체크포인트는 소비한 장비와 진행을 보존하며, 같은 기술을 다시 동기화한다고 장비가 생기지 않는다. 이전 체크포인트에 이미 지급된 장비도 중복 지급하지 않는다.

## 실제 동작과 제한

- 신체 기술은 실제 이동·발소리·AI 감지 게이지에 연결된다. 주변 살피기는 같은 시점의 카메라 범위를 10% 넓힌다. 풀숲은 웅크려 들어가면 자동 은폐되는 기존 조작을 사용한다. 은폐 거리와 웅크림 바깥 시야 감소가 이중 적용되던 계산을 정리해 풀숲의 기본 36px / 숙련 28px 한계와 24px 접촉 감지가 실제로 동작한다.
- 낙하 공격은 낮은 옥상 가장자리와 바깥의 유효한 착지 대상을 찾는다. 공격 버튼으로 실제 하강하며 짧게 기절·계속 누르면 처치한다. 쌍암살·연속 암살의 민간인·정예·벽·층 제한과 실제 이동·중단 처리는 유지한다. 연계 정비는 다음 사용의 대기시간을 줄인다.
- 기존 **다트**의 짧게 기절·길게 처치는 유지한다. 새 **쿠나이**는 살상 전용이며 1초 이상 눌렀다 떼야 투척된다. 명중 위치·벽·층·대상 이동을 재검사하고 실제 시체와 처치 기록을 만든다.
- 연막탄은 먼저 날아가 착지하고, 바닥으로 연결된 영역과 원형 범위 안에서 시선을 가린다. 경비 시야와 CCTV 원뿔도 같은 연막 경계에서 잘린다. 다른 층과 벽 안으로 번지지 않는다. 발소리·기척·개의 후각·접촉은 남고, 연막이 끝나도 경비의 기존 수색과 기억을 초기화하지 않는다.
- 무전기 역이용은 쓰러진 **무전 담당**에게서 장비를 실제로 확보해야 한다. 지시를 받을 무전 담당 한 명과 같은 층의 연결 경로를 찾는다. 실패하면 횟수를 소비하지 않고, 성공은 의뢰당 2회·재사용 30초다. 정기 무전 점검은 계속된다.
- CCTV 해킹은 실제 장비가 있어야 하며, 같은 층·가까운 거리·벽에 막히지 않은 대상 앞에서 1.5초 작업한다. 이동·피격·메뉴 전환으로 중단할 수 있다. 정지는 일시적이며 기존 녹화는 남는다. 전원 회로나 다른 CCTV를 함께 끄지 않는다.
- 맨손 시작에서는 배운 투척 도구나 해킹기가 생성되지 않는다. 압수품을 되찾으면 배운 장비를 한 번 받는다. 새 투척물은 기존 ‘던지는 도구 안 쓰기’ 평가에도 반영하며 결과 화면에 실제 사용 횟수를 표시한다.

## 조작·연습

**K / 메뉴 → 기술 트리**에서 포인트를 투자한다. PC에서는 세 계열을 함께 보여주고 작은 화면에서는 신체·암살·도구 탭으로 전환한다. 비용·선행·배운 상태·장착 상태를 구분하고 스크롤해도 포인트와 돌아가기 버튼을 유지한다.

**B 길게:** 장착한 쌍암살·연속 암살. **공격:** 상황에 맞는 낙하 공격. **F/V 또는 도구 버튼:** 선택한 도구. PC의 도구 이름 또는 터치의 **도구 바꾸기**로 배운 장비를 고른다. 1–3의 기존 도구 단축키와 R 이동 속도 전환은 유지한다.

기초 시야·소리 → 잠입 기초를 먼저 보여주고, 선택 연습을 뒤에 둔다. **연습 5 · 암살 기술**, 새 **연습 6 · 현장 도구**에서는 관련 기술을 무료로 시험하며 본편 포인트와 해금을 바꾸지 않는다. 현장 도구 연습은 기절 → 무전기 확보 → 허위 점검 → 연막 → 카메라 뒤로 이동 → 해킹 → 쿠나이 → 탈출 순서다.

## 구조와 비용

`25_skill_tree.js`가 정의·포인트·선행·저장·이관·한 번 지급을 소유한다. `84_skill_menu.js`는 세 계열 화면과 의존 선을 그린다. `interaction/skill_devices.js`가 실제 투척·연막·무전·해킹 작업을 처리한다. 신체 효과는 각 이동·소리·시야 모듈에 연결하고 새 파일을 모듈 manifest에 등록했다. 이전 자동 장비 보상 목록은 제거했다.

연막은 설치된 PixelFX의 고정 소스 `a84159688af3ca37a4be05a0d422b94451b2e24e`에서 smoke-bomb를 골라 회색·낮은 광량으로 구운다. 원본, 회색 조정, 실제 게임 화면을 검수했다. 기존 단일 WebP 아틀라스를 9종·206프레임·1024×775로 확장했고 파일 크기는 70,764바이트다. 일반 효과는 최대 24개, 연막은 최대 3개다. 게임은 파티클을 시뮬레이션하거나 프레임마다 캔버스를 만들지 않는다. [선택 효과](skills-v148/pixelfx-smoke.png).

배포 스크립트 **4개**, 게임 에셋 **175개**를 유지했다. 게임 에셋은 v147의 7,724,679바이트에서 **7,802,939바이트**로 78,260바이트(약 1.0%) 증가했다. 새 실행 패키지 설치는 없다. 실물 휴대폰 FPS를 측정한 값은 아니다.

## 검증

- 빠른 회귀 검사 **43개**, 빌드 소유권 검사 6개, 이미지 소유권과 전 의뢰 도달 검사 통과. 마지막 장비·효과·화면 조정 후 관련 판정과 패키지를 다시 검사했다.
- 새 검사는 실제 보행·달리기·운반 거리, 실제 경비의 청각·어둠 감지·풀숲 시야·후방 공격 각도를 비교한다. 실제 옥상에서 배운 낙하 공격으로 하강·처치되는 것도 확인한다.
- 포인트 중복·선행·예산·재배분·기존 기록·이전 체크포인트·장비 한 번 지급, 맨손 시작·압수품 복원, 새 투척물의 도전 평가를 확인한다.
- 연막의 경비/CCTV 시야 차단·접촉·개의 후각·청각·층·벽·만료, 실제 무전기 확보와 단일 수신자·경로·사용 횟수, CCTV 작업 중단·임시 정지·자동 복귀·녹화 유지·벽·층 제한을 확인한다.
