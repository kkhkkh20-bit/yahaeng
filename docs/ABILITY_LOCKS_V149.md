# v149 초기 능력과 기술 해금

다트를 기본 장비에서 빼고, 은폐한 채 하는 근접 기습을 기술로 분리했다. 처음에는 기본 행동으로 잠입하며 필요한 능력에 포인트를 투자한다.

| 기능 | 조건 | 비용 |
| --- | --- | --- |
| 다트 조준·발사 | 현장 장비 → 다트 운용 | 각각 1P |
| 풀숲·은신처·엄폐 기습, 환풍구 끌어들이기, 가장자리 끌어내리기 | 제압 숙련 → 은신 기습 | 각각 1P |
| 웅크리기·풀숲 자동 은폐·은신처 진입·일반 뒤잡기·운반·시체 숨기기 | 기본 행동 | 없음 |

신체 8개·암살 9개·도구 9개, 총 **26개**이며 전체 비용은 **42P**다. 시작 4P와 의뢰 별 보상, 기존 기술의 비용·선행 조건을 유지한다. 기존 사용자의 다트나 은신 기습을 자동으로 해금하지 않는다. [이전 기술과 레퍼런스 조사](SKILL_TREES_V148.md).

## 판정과 이전 저장

- 신규 의뢰의 다트 재고는 0이다. 다트 운용을 배우면 의뢰 설정과 난이도에 맞는 재고를 한 번 받는다. 일반 설정은 2발이다. 맨손 시작은 장비 회수 조건을 유지한다.
- 배우지 않은 다트는 도구 목록과 순환 선택에서 빠진다. 단축키 선택·조준·직접 발사·기존 비행 다트의 명중도 같은 기술을 확인한다. 이전 체크포인트에 남은 탄약은 보존하되 배우기 전에는 사용하지 못한다.
- 투척 숙련만 배워도 다트가 생기지 않는다. 다트 운용도 배웠을 때만 추가 1발을 지급한다. 동기화와 체크포인트 복원은 소비한 탄약을 다시 채우지 않는다.
- 풀숲에서 숨은 채 일반 공격이나 붙잡기를 눌러 기습 제한을 우회하지 못한다. 공격 후보·전투 의도·직접 붙잡기·엄폐에서 끌어당기기·끌어들이기·환풍구·매달림 판정에 동일 제한을 적용한다. 쌍암살·연속 암살도 은폐 상태에서는 은신 기습이 필요하다.
- 은폐 공격이 잠기면 버튼에 **은신 기습 필요**를 표시하고 기술 트리에서 배우도록 안내한다. 숨기와 탈출은 막지 않는다. 다트와 쿠나이는 각각의 도구 기술로 사용한다.
- 이전 체크포인트에서 은폐 상태로 진행 중이던 미완료 접근·붙잡기 예약은 해금 여부에 맞춰 취소한다. 이미 기절·사망한 결과는 유지한다.

## 연습

기초 시야·소리와 잠입 기초에는 다트를 지급하지 않는다. 고급 연습의 기존 동작에는 필요한 다트·은신 기습만 명시적으로 임시 허용한다. 현장 도구 연습의 첫 단계는 실제 다트로 기절시킨 뒤 무전기를 확보하는 순서로 변경했다.

**연습 7 · 은신 기습**에서는 적의 뒤에서 웅크려 풀숲에 들어가기 → 짧게 눌러 기절 기습 → 다음 풀숲에 접근 → 계속 눌러 처치 기습 → 탈출을 연습한다. 이 연습은 은신 기습만 기본으로 임시 지급하며, 연습 중 기술 트리에서 따로 고른 기술도 연습 안에서만 적용된다. 완료해도 기술이나 별을 영구 지급하지 않는다. 본편에서는 직접 포인트를 투자한다.

## 검증 자료

빠른 회귀 44개와 빌드 소유권 6개, 전 의뢰 도달 검사를 통과했다. 마지막 엄폐 기습 제한 후 전투·암살 기술·해금 검사와 실제 패키지를 추가 확인했다.

[실제 화면과 검사 결과](skills-v149/index.html). 검사는 초기 재고·강제 보유·직접 호출·이전 체크포인트·한 번 지급·투척 숙련과의 조합·임시 기술의 본편 유출을 포함한다. PC 키보드와 CDP 터치로 장비 연습과 은신 기습 연습을 실제 이동과 공격 입력으로 끝까지 진행한다. 고정 시간으로 입력과 게임 판정을 검사하며 실물 휴대폰 FPS 측정은 아니다.

새 실행 패키지와 게임 이미지·효과를 추가하지 않았다. 기존 3D 실험 경로는 이번 변경에 포함하지 않는다.
