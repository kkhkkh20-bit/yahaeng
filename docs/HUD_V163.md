# v163 · 야행 HUD와 현장 장비

상시 버튼의 위계를 다시 잡고 기존 선 아이콘을 게임용 실루엣 에셋으로 교체했다. 모바일 평상시 버튼은 메뉴·웅크리기·장비·선택 도구·행동·공격 여섯 개다. 이전 같은 장면은 여덟 개였다. 붙잡기·옷 갈아입기·겹친 대상 선택은 해당 상황에서만 나타나므로 실제 총수는 상황에 따라 달라진다. 미니맵과 펼칠 수 있는 목표도 별도의 터치 표면이다.

## 레퍼런스와 시각 체계

- HITMAN World of Assassination: 목표·지도·선택 장비를 서로 다른 정보 묶음으로 읽는 위계와 상황별 조작 안내를 참고했다. 모바일에서는 아래쪽을 손가락 조작에 쓰므로 지도는 오른쪽 위에 남겼다.
- Dead Cells: 선택한 장비의 그림·수량을 한 슬롯에 모으고 주요 플레이 영역을 비워 두는 구성을 참고했다.

실제로 확인한 정지 화면의 링크는 [references.json](hud-v163/references.json)에 기록했다. 레퍼런스 게임을 실행해 검증했다고 주장하지 않으며, 원작 스크린샷이나 그래픽을 게임에 복사하지 않는다.

어두운 청록 바탕, 따뜻한 금속색 테두리, 흰색 본문과 위험색의 역할을 통일했다. 주 행동은 오른쪽 아래, 웅크리기는 이동 손 쪽으로 옮겼다. 목표에는 작은 야행 표식을 더하고, 체력·구역·은신 정보의 반복 배경을 줄였다. 기존 IBM Plex Sans KR Regular와 기술 트리 레이아웃은 유지한다.

Game-icons.net의 Lorc·Delapouite SVG 13개(CC BY 3.0)를 실제 에셋으로 포함하고 단색 마스크로 표시한다. 빈 캔은 별도로 제작한 SVG다. [파일별 출처·라이선스](../src/art/hud/ATTRIBUTION.json)를 남겼고 게임 설정의 크레딧에도 저자를 표시한다. 외부 요청 없이 빌드에 내장한다.

## 조작

- 장비 패널에서 배운 도구를 이름과 수량으로 직접 고른다. 같은 것을 다시 골라도 다음 장비로 넘어가지 않는다. 선택은 투척·발사를 실행하지 않는다.
- 휘파람도 패널에서 장착한 뒤 기존 도구 버튼으로 사용한다. 걷기/달리기 고정도 패널 안에서 전환한다. PC의 기존 숫자 키·G·R·공격과 행동 단축키는 유지한다.
- 장비 선택 중 실제 게임 시간이 멈춘다. Tab을 패널 안에 가두고 Escape/닫기/바깥 터치로 돌아온다. 앱 전환·메뉴·재시작은 선택창과 준비 입력을 정리한다.
- 붙잡기와 옷 갈아입기는 같은 상황 슬롯을 사용하고, 사용 가능한 대상이 없으면 비워 둔다. 잠긴 PC 암살 기술은 상시 버튼으로 광고하지 않는다. 기술 트리는 K와 메뉴에서 열 수 있다.
- 기존 짧게 기절·길게 처치, 길게 준비하는 연계 암살, 도구 조준 취소, 운반·은닉의 실제 판정은 그대로 사용한다.

## 검증

390×844, 320×568, 844×390 터치와 1280×800 PC에서 실제 브라우저 입력으로 장비 선택·정지/재개·키보드 포커스·휘파람 장착/사용·이동 속도·갈아입기 상황 표시와 7개 도구 접근을 확인했다. 기존 핵심 회귀 56개와 새 HUD/기존 HUD 시스템 검사를 합쳐 58개를 검증했다. 빌드 검사 7개와 지도 도달 검사도 통과했다. 별도로 네 크기의 기존 갈아입기·제압 검사를 통과했다.

이전 전봇대 경로가 제거되어 성립하지 않던 HUD 시스템 fixture는 실제 기절자의 운반·갈아입기 후보로 바꿨다. 버튼 검사도 항상 보이던 옛 7개 조작 대신 새 상시 6개 조작과 패널 속 이동 전환을 확인한다. 모바일 취소 검사는 병렬 실행에서 한 번 실패하고 재시도·독립 실행에서 통과했으며 판정 조건은 바꾸지 않았다. 전체 회귀와 fuzz, 실물 휴대폰 성능 검사는 이번 검증 범위가 아니다.
