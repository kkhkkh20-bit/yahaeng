# 의뢰 진행 점검 · v87

6개 의뢰를 PC 방향키·모바일 조이스틱 입력, 배치 변형 3종으로 각각 진행했다. 총 36회 모두 목표 달성 뒤 실제 탈출 지점에서 ‘임무 완료’ 화면을 확인했다.

| 의뢰 | 확인한 주요 진행 |
| --- | --- |
| 장부 털기 | 상회 장부 → 증거물실 문 따기 → 사본 → 탈출 |
| VIP | 비밀번호 입력 → 파랑 카드·장부 → VIP 처리 → 뒷문·탈출 |
| 잔칫날 | 초록 카드 훔치기 → 본채 문 → 2층 서류 → 회장 처리 → 탈출 |
| 대청소 | 수금원·빨강 카드 → 창고·파랑 카드 → 변형 위치의 초록 카드 → 계약서·VIP 처리 → 탈출 |
| 본부 | 금고 비밀번호 → 장부 → 2층 보스 처리 → 탈출 |
| 배신 | 감방 머리핀 → 문 따기 → 압수품 → 2층 무전기 → 탈출 |

`tests/rev/mission_flow.js`는 실제 이동·충돌·계단·행동 후보·문 조작·금고 입력·훔치기·길게 처치·탈출 판정을 쓴다. 주인공 좌표를 순간이동시키거나 열쇠·목표 완료를 지급하지 않는다. 진행을 분리해 확인하려고 이 검사에서는 NPC 시뮬레이션을 멈춘다. 적의 시야와 순찰을 전부 켠 상태로 36회 잠입에 성공했다는 의미는 아니다.

별도로 실제 AI를 켠 `t_m2`, `t_m3`, `t_disguise_ai`, `tm1`에서 배탈약·화장실 왕복, 정전·발전기 이동, 감전·간판/실외기 사고, 조끼로 마당 통과, 택배·직원 경로, 변장 인식과 수색을 검사했다. 연습 1의 경고·엿듣기·기절·변장·숨기기·출입·탈출, 사망 후 이어 하기도 확인했다.

## 고친 문제

1. **기절을 표적 처리 완료로 안내하던 문제.** 의뢰 2~5의 목표 관련 기회 9개, 체크포인트 진도, 남은 표적 수를 실제 사망 판정과 통일했다. 옛 저장에 남은 잘못된 완료 표시는 되돌리며 위치·카드·획득한 물건은 유지한다.
2. **옥상에서 쓰러진 사람의 높이가 사라지던 문제.** 기절·사망 시 높이를 유지하고 옥상 위에서 한 번만 그린다. 같은 지도 위치라도 지상의 조직원이 옥상 사람을 깨우지 못한다. 옥상에서 기절시킨 표적도 길게 눌러 처치할 수 있다.
3. **옮긴 기절 표적을 예전 위치로 안내하던 문제.** 목표와 미니맵 표시는 현재 몸의 위치를 따른다. 운반해 수거함에 넣어도 표적과 수거함의 연결을 유지해 안에서 의도적으로 처치할 수 있다.
4. **금고 확인 연타의 중복 처리.** 올바른 비밀번호를 받았으면 문이 열리는 동안 후속 입력을 무시한다. 확인을 여러 번 눌러도 문·효과음·통계는 한 번만 처리한다.
5. **대청소의 잘못된 옥상 경로.** 1층 창고와 2층 사무동을 잇는 것처럼 보이던 공중 판자를 제거했다. 사무동 계단·배관을 이용하도록 안내를 맞췄다. 같은 높이인 사무동–클럽 통로는 유지한다.

## 회귀 검사

- `t_mission_flow`: 위 36개 진행과 완료 화면. 목표가 남아 있는 동안 탈출이 열리지 않는지도 확인.
- `t_mission_progress`: 표적 5건·기회 9개에서 기절/실제 처치를 구별. 금고 2개 확인 연타, 옛 저장 복구, 남은 표적 수.
- `t_target_body`: 옥상 몸의 높이·옥상 뒤 그리기·중복 없음·지상 조직원 분리, 옮긴 표적 좌표와 수거함에 넣은 표적의 처치 가능 여부.
- `t_trav`: 6개 의뢰에서 이동 동작 264건 통과. 배관·사다리·계단·벽·2층 창문·매달려 내리기의 완료 위치와 화면/좌표 튐 확인. 후보 269개 중 해당 지점에서 동작이 제공되지 않는 벽 오르기 5개는 건너뜀.
- 기존 핵심 회귀 묶음과 계단 구조·세계 정합성·제압 정책·붙잡기·변장·UI·체크포인트 검사를 함께 실행.

UI·미니맵·모바일 버튼의 위치, 기존 시점과 에셋은 유지했다.
