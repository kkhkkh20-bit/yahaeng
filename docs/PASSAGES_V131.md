# 사선 구역 우회 경로와 출입 동작 · v131

기존 게임의 지하·환풍구 판정을 새 화면과 연결한다. 경로는 선택 사항이며 장부 목표나 기존 정면·창문 진입 방법을 바꾸지 않는다. 신규 다운로드 에셋 대신 기존 CC0 캐릭터와 현재 구역의 금속·석재 재질을 재사용한다.

| 경로 | 공간과 역할 | 구현 기준 |
|---|---|---|
| 맨홀 2개 | 골목 남쪽 (6,18) ↔ 북쪽 (6,3). 출입문 앞 순찰을 우회해 뒤편으로 이동 | 기존 `ugAt` 셀을 그대로 3D 수로로 생성. 열린 뚜껑·손잡이·사다리·작업 발판. 은신과 지하 이동을 구분하고 기존 시체 은닉·회수도 유지. |
| 외벽 환기구 | (7,5), 서쪽에서 접근 ↔ 1층 (9,5) | 외벽에 세운 환기함과 수직 덮개를 표현. 접근·퇴장 방향을 서쪽으로 고정하여 벽 반대편에서 손을 뻗지 않음. |
| 실내 환풍구 | (9,5) ↔ 순찰 통로 (18,10) | 기존 `ventAt` 연결망을 3D 통로·미니맵에 사용. 낮은 자세로 이동. 순찰을 기다릴지 바로 나갈지는 플레이어가 선택. |
| 환풍구 기습 | 창살 가까운 같은 층의 적 | 즉시 사라지던 결과 대신 붙잡기·끌어내리기·은닉 순서. 짧게 기절, 같은 입력을 1초 이상 계속 누를 때만 처치. 다른 층의 적을 잡지 않음. |
| 조명 스위치 | 벽부등·가로등·실내 조명 | 렌더링, 행동 판정, 손 접촉이 `lampControl()` 좌표를 공유. 가로등에 기둥을 세우고 벽부등은 실제 벽에 부착. 실내 스위치는 접근 가능한 벽 옆에 배치. 1층은 환풍구와 떨어진 (12.25,5.125)로 옮겨 행동 버튼을 가로채지 않게 함. |

통로에서는 지상의 NPC·물품 표식을 가리고 해당 통로와 출구만 미니맵에 표시한다. 가까운 시점으로 부드럽게 전환하며 주인공이 화면 아래쪽에 놓이는 구도와 기존 모바일 버튼 위치는 유지한다. 지하·덕트에 있을 때 지상의 '금지 구역' 문구를 붙이지 않는다.

손으로 덮개를 조작하는 동안 발은 접근 지점에 고정한다. 출입 중 임의의 2D 화면 Y 보정을 3D 이동으로 사용하지 않는다. 공유 포즈 생성기에서 '캐릭터를 200만큼 아래로 찍기' 보정이 살아 있어, 오르기에서 서기 포즈로 보간할 때 몸이 튀는 문제도 제거했다. 판정상 노출되는 시점은 사선 화면에서 몸이 통로 밖으로 나오는 시점과 맞춘다.

검증과 실제 화면은 `docs/passages-v131/`에 보관한다. 실제 AI가 움직이는 PC·터치 조작 경로와, 출입 뼈대 연속성·작업 중 발 고정·맨홀 시체 회수·길게 처치의 경계 조건을 분리해 확인한다. 가속 시뮬레이션은 경로/판정 검증이며 실물 휴대폰의 FPS 측정은 아니다.

Cloudflare 기존 2D 동결본(public/ 및 playtest-2d 브랜치)은 변경하지 않는다. 새 사선 구역은 club-study에 배포한다.
