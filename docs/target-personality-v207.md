# 간부의 복장과 현장 연기

9명의 표적을 복장·체형·말투·평상시 동작으로 구분한다. 실장은 붉은 정장, 수금반장은 큰 체격의 황금색 정장, 상권 지부장은 보라색 정장, 운송 지부장은 밝은 안전모와 주황 작업복을 입는다. 까마귀는 백발과 진홍색, 의장은 은발과 아이보리 재킷·자주색 바지로 구분한다. 입문 표적도 주황 후드·청색 작업복·옥색 정장으로 이어진다. 브리핑의 외형 설명과 조직도, 초상, 시체·변장 팔레트를 같은 프로필에서 가져온다.

## 동작과 대사

기존 CC0 캐릭터로 통화, 장부 확인, 손짓, 술잔, 흡연을 각각 14프레임·8방향의 스프라이트로 사전 렌더링한다. 소품은 모델의 실제 손에 붙여 함께 굽고 몸과의 가림도 함께 처리한다. 지팡이를 사용하는 체형은 빈손으로 연기한다. 수금반장은 평상복을 재색칠하는 대신 큰 정장 체형과 그에 맞는 처치·운반·반응 스프라이트를 추가한다. 게임 실행 시에는 2D 이미지와 프레임 데이터만 사용한다.

새 동작은 기존 일과의 실제 정지 구간에서 실행한다. 실장의 흡연·술자리, 운송책의 검수·통화, 의장의 건배·연못·연회 동선에 맞춰 연기를 선택한다. 예약 호출과 구토제 반응 등 기존 이벤트를 우선한다. 대사는 사람마다 다르게 작성하고 가까운 경호원은 거리가 맞을 때 짧게 대답한다. 표적이 화면 안에서 말할 때는 안내 무전창이 잠시 비켜주고 종료 후 같은 목표로 돌아온다. 일반 대사처럼 벽·층·관찰 조건을 따르고, 여러 간부의 말이 동시에 쌓이지 않도록 간격을 둔다.

경보, 추격, 제압, 운반, 벗겨진 복장에서는 평상시 연기를 중단한다. 실제 경계 상태로 전환하면 인물별 반응을 사용하며 기존 위험 안내 대사를 덮어쓰지 않는다. 시야·청각·이동·경로·판정·보상은 바꾸지 않는다. 전용 아틀라스는 해당 의뢰의 표적만 보관하고 이전 의뢰의 소스는 해제한다. 체크포인트는 연기의 진행과 쿨다운을 보존한다.

## 검증 범위

- `t_target_personality.py`: 9개 복장, 모든 방향의 프레임 경계, 일과와 대사, 경계·기절 시 중단, 기존 AI/보상 유지, 체크포인트와 리소스 해제를 통제된 fixture로 검사한다.
- `officer_hunt_live.py`: 정상 AI와 키보드·터치로 입문 표적의 실제 연기를 관찰하고 암살·단서·탈출·다음 의뢰까지 진행한다.
- `vip_choices_walk.py`: 실제 순찰이 바라보는 서쪽의 반대편으로 책상을 돌아 후방 접근한다. 과거의 임의적인 북쪽 시선 대기 조건을 제거하고, 실시간 입력은 프레임 사이에서 사라지지 않도록 최소 80ms 유지한다. NPC·체력·경계·진행을 강제로 변경하지 않는다.
