# v95 · 실외 조명의 설치 구조

2026-10-31. [전후 화면](lighting/index.html).

실외 조명이 길 가운데 발광 점으로만 표시되던 부분을 실제 조명 기구와 설치 위치로 연결했다. 실외 91개를 벽부등 49개, 독립 가로등 32개, 기존 전신주 보안등 10개로 구분했다. 대상은 주요·이전 의뢰와 연습·도시를 포함한 지도 10개다.

- 가까운 외벽에 적합한 자리가 있으면 벽부등을 설치한다. 실제 외벽 타일과 바깥쪽 빈 공간을 확인하며, 원래 위치에서 벽을 관통해 다른 골목으로 옮기지 않는다.
- 열린 공간은 보도·길 가장자리를 우선해 가로등을 둔다. 기존 전신주 자리도 미리 예약해 바로 옆에 새 기둥이 중복되지 않게 한다.
- 기둥은 보도의 모서리 쪽에 두고 작은 원형 충돌을 사용한다. 한 칸 전체를 장애물로 만들지 않는다. 플레이어와 NPC의 일반 이동에 같은 기둥 위치를 사용하며 벽 안으로 밀어내지 않는다.
- 등갓·브래킷·기둥·밑판·스위치와 연결 배관을 표시한다. 기존 전신주의 기둥·전선·등반은 재사용한다. 실외의 단독 발광 점과 꺼짐 원·파손 X 표시는 조명 기구 표현으로 대체한다.
- 빛의 지면 투영 위치와 손으로 누르는 스위치를 구분한다. 행동 이름은 벽부등·가로등·전신주 보안등으로 표시하고 살피기 표시도 스위치를 가리킨다.
- 옮긴 위치에서 조명 다각형과 밝기 조회용 격자·빛 캐시를 다시 만든다. 범위·색·깜빡임·켜짐·파손 상태는 보존하되, 위치 변경에 따라 밝은 구간과 그림자 위치는 달라진다.
- 상층 실내에 외부 조명 기구가 겹치지 않도록 기존 실내 클리핑을 사용한다. 실내 자동 조명은 이동하지 않는다.
- 구버전 체크포인트는 기존 조명 객체를 유지하며 설치 구조를 보정한다. 끄기·파손·전체 정전과 물품·카드·체력 등 임무 진행을 보존한다. 새 저장을 다시 불러와도 위치를 중복 보정하지 않는다.

## 검증

- 신규 `t_light_fixtures.py`: 지도 10개 실외 조명 91개 모두 지지대·외벽·길 가장자리 조건, 스위치 접근과 행동 후보, 기둥 충돌, 구버전 저장의 상태·진척·실내 조명 보존, 재저장 위치 안정성을 확인했다.
- `t_environment_targets.py`: 전신주·조명·문 중첩, 구버전 스위치 좌표, 실제 PC·터치 조작을 확인했다.
- 관련 회귀 14종. 초기 새 기둥이 임무 경로를 막는 사례를 찾아 모서리 배치로 고친 후 전체 경로를 재검사했다.
- `t_mission_flow.py`: PC/모바일·배치 3종으로 6개 의뢰의 전체 이동·목표·탈출 경로 36개 통과. 이 진행 검사는 NPC를 정지시킨다.
- `t_vip_routes.py`: NPC를 켠 세 VIP 경로의 PC·터치 장면 12개 통과. 시작 위치·장비는 재현 조건이며 사람의 완주 시간 검사가 아니다.
- 전체 지도 도달 검사 문제·페이지 오류 0건. 실제 기기 성능 평가는 이번 범위에서 수행하지 않았다.

`36_light_fixtures.js`가 설치 위치·표현·작은 기둥 충돌을 관리한다. `lampControl()`은 광원 대신 스위치 좌표를 반환하며, 새 판과 체크포인트 복구에서 같은 설치 규칙을 사용한다. 외부 모델이나 이미지 생성 자산은 추가하지 않았다.
