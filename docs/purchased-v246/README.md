# v246 — 구매 에셋으로 기능 오브젝트 통일

도톤보리 City v3와 Office Interior v3 원본을 대조했다. 새 캐릭터(v245), 미션, AI, 조명 회로와 48px 충돌 그리드를 유지하며 대체 가능한 환경 그림을 구매 에셋으로 바꿨다. 신규 구매나 다른 팩 다운로드는 없다.

## 교체 범위

| 대상 | 적용 | 기존 기능 |
|---|---|---|
| 층간 계단·야외 돌계단 | 도톤보리의 실제 발판과 금속 난간 재료 | 같은 층계참, 오르내리는 방향, 위층 구멍 |
| 사다리 | 도톤보리 사다리 원본 | 기존 타일과 등반 접근점 |
| 옥상 연결 다리 | 도톤보리 바닥·난간, 가로와 세로 모두 지원 | 기존 널판 경계와 아래 통로 |
| 여닫는 문 | 구매 문짝을 기존 탑다운 경첩 평면에 투영 | 열림 진행·잠금·통행 판정 |
| 숨는 수납장 | 구매 수납장 외곽·문짝·앞턱 | 여닫기, 몸 가림, 손 접촉·수납 용량 |
| 환기구 | 구매 환기 장치와 벽에서 분리한 금속 그릴 | 지붕/벽/바닥 입구와 회전 덮개 |
| 맨홀 | 도톤보리 덮개 | 열린 구멍, 이동 덮개, 앞턱 가림 |
| 배관 | 도톤보리의 금속 기둥 재료 | 기존 수직 관과 등반 손 좌표 |
| 물류 선반 | Office Interior 수납 선반 | 원래 가구 점유 칸과 엄폐 |
| 포장 상자 | Office Interior 포장 상자를 적층 | 원래 상자 점유 칸 유지 |
| 서류·메모 | 원본의 낱장 서류 픽셀 | 기존 책상 위치·읽기·회수 조건 |
| 조명 조작판·분전함 | 도톤보리 제어함 패널, 상태 표시만 동적으로 추가 | 기존 스위치 접근점과 회로 |
| 가로등 | 도톤보리 가로등을 모든 캠페인에 공유 | 실제 기둥·광원·회로 위치 |
| 옥탑 계단실 | 구매 벽 패널·바닥 테두리·문 | 기존 옥상 출입 위치 |
| 측면 창틀 | 구매 창틀의 테두리 픽셀 | 좁은 탑뷰 형태, 열림·잠금, 실내 미리보기 |
| 나머지 실내 | 책상·의자·수납장·벽·바닥의 기존 구매 에셋 경로를 27개 맵 전부에 확장 | 명시적 스타일이 있는 본편은 유지, 나머지는 건물 용도에 따라 재료 선택 |

사무실 팩에서 짧은 계단으로 보았던 부품은 확대 검수 결과 단상 프레임이었다. 계단으로 사용하지 않는다. 실제 발판은 도톤보리 원본에서 가져온다. 금속 배관은 원본의 금속 기둥을 반복 조립한 것이며, 완성된 배관이 팩에 들어 있다고 표기하지 않는다.

침대·욕실·냉장고·실제 소파·금고·스피커·CCTV·큰 수거함 등은 구매한 두 팩에 용도가 맞는 대응 그림을 확인하지 못해 기존 올바른 물체를 유지한다. 의자를 늘여 소파로, 원형 탁자를 냄비로 표시하던 구매 가구 매핑은 제거했다. 캐릭터·무전기·담배·도구와 전용 한글 간판, 게임의 상태/탐지/UI 표시는 유지한다. 이 작업을 모든 그림의 100% 교체라고 주장하지 않는다.

## 통합과 정리

- 새 `graphics/purchased_details.js` 한 경로에서 실제 판정 좌표를 읽고 그린다. 문·수납·환기구·맨홀의 기존 열림 진행과 손 접촉을 재사용한다. 정지 이미지로 상호작용을 덮지 않는다.
- 원본의 주변 벽과 다른 물체 조각이 들어가지 않도록 자른다. 환기 그릴은 흰 벽에서 분리하고 바닥 투영용으로 90도 돌린다. 문/뚜껑의 기울기와 폭 변화는 기존 동작을 따른다.
- 새 atlas가 늦게 도착하면 바닥·층별 그림·옥상 시설·닫힌 맨홀 캐시를 함께 갱신한다. 이미지를 불러오기 전에는 기존 그림으로 동작한다.
- 가로등/실내등과 중복으로 바닥에 남던 작은 네모 그림, 실행될 수 없는 예전 조명 코드, 틀린 가구 대체를 정리했다.
- 별도 원본 ZIP·통합 타일 시트·Unity 패키지는 공개 저장소에 넣지 않는다. 선택한 20개 조각과 원본 해시/좌표만 기록했다. 런타임 atlas는 약 2.2KB이며 전체 배포 자산 증가는 약 15KB다.

## 검증과 화면

- `t_purchased_fixtures.py`: PC/터치 각각 27개 맵의 모든 층을 렌더링했다. 구매 그림 적용 전후의 그리드·가구 점유·NPC 위치·회로·계단·아이템·은닉처·출구 좌표가 같음을 확인했다. 양쪽 각 2,621회 구매 atlas 그리기, 문짝/환기 덮개의 상태 변화 검사 통과. [PC](pc-coverage.json), [터치](touch-coverage.json).
- `t_stair_geometry.py`: 59개 층간 계단, 70개 옥상 계단, 118개 자동 이동과 258개 NPC 이동 검사 통과.
- `t_hide_flow.py`: PC/터치 각각 203개 출입, 실제 키보드/터치 출입과 수납 과정 검사 통과.
- `t_access_fixtures.py`: PC/터치 각각 환기구 15개·맨홀 21개·간판 3개, 손 접촉 128개 검사 통과.
- `t_light_fixtures.py`: 27개 맵의 벽등 358개·가로등 54개·기둥등 13개, 조작점 425개와 기존 저장 복구 검사 통과.
- `t_office_campaign.py`: 공개 에피소드 9개의 물리 세계·조명 조작·수납장 열림 검사 통과. 물리 상호작용 20개 그룹과 빌드 파이프라인 8개 검사 통과.
- 일반 RAF/활성 AI에서 키보드와 CDP 터치로 첫 에피소드의 기절 2회 → 변장 → 몸 숨기기 → 2층 → 서류 → 탈출을 완료했다. 양쪽 체력 3·발각 0. [PC 기록](pc-native.json), [터치 기록](mobile-native.json), [모바일 계단 이동](mobile-native.png). 원본 지도를 아는 개발자 플레이이며 실물 모바일/초보자 테스트나 전 맵 완주를 의미하지 않는다.
- 오래된 `t_stairs_all.py`의 전체 실시간 순회는 중단했다. 이를 통과했다고 계산하지 않는다. 현재 계단 구조/자동 이동 검사는 위 `t_stair_geometry.py` 결과를 사용한다.

[오브젝트 확대 비교](fixtures.png)는 실제 게임 렌더러를 명시적 좌표에 배치한 검수 이미지다. 실제 게임 스크린샷과 구분한다.

[사무실 교체 전](before-office.png) / [교체 후](after-office.png), [계단 교체 전](before-stairs.png) / [교체 후](after-stairs.png)는 v245/v246를 같은 좌표에 배치한 비교다. 사무실 비교는 기존 연습 맵 e5의 구매 가구 확장도 보여준다. 인물·시계·카메라를 설정한 시각 검수이며 일반 플레이 녹화는 아니다.

## 재생성

```sh
python tools/import_purchased_details.py /private/dotonbori/Tilemap/MainTileMap.png /private/office/Tilemap/MainTileMap.png
python build.py
python tools/package_cloudflare_2d.py build/yahaeng_city.html
```

원본 SHA-256과 각 조각의 팩/좌표/조립 방식은 `src/art/purchased-details/fixtures.json`에 있다. 전체 원본이 필요하며 공개 atlas에서 팩을 복원하거나 추출하도록 안내하지 않는다.
