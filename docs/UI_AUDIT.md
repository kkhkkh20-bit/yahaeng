# 게임 UI·그래픽 점검

2026-10-29 점검 기록.

2026-10-30 사용자 피드백: 기존 인게임 UI의 직관성과 익숙한 배치를 우선한다. 아래 표의 시각 변경은 철회했고, HUD·버튼 위치와 크기·색상·대화 초상·이름표·전술 지도 표시를 점검 전 상태로 복원했다. 승인된 메인 화면과 모바일 메인 구성은 유지한다. 미니맵의 키보드 접근 기능은 유지한다. 아래 검증 결과는 디자인 변경 당시의 기록이며, 현재 버전에 대한 보증이 아니다.

## 확인 범위

- 메인·의뢰 선택·브리핑·일시정지·결과·숫자 자물쇠
- 게임 HUD, 목표, 체력·경계, 은신 표시, 미니맵·전술 지도, 도움말·무전, 터치 조작, 대화 초상
- 의뢰 6개와 연습 3개의 시작 화면 캡처, 전체 도달 검사
- 화면 크기: 320×568, 360×640, 390×844, 844×390, 1440×900

## 당시 검토와 변경 — 현재 철회됨

| 문제 | 개선 |
| --- | --- |
| 초상의 강한 삼색 발광, 입체 배경, 흔들림이 메인과 어울리지 않음 | 초상은 체형·머리 윤곽만 남긴 검은 실루엣으로 변경. 회색 면과 얇은 테두리, 정적인 대화판으로 통일 |
| 은신 표시가 크고 둥글어 좁은 화면에서 시야를 많이 차지함 | 사각형의 작은 상태판으로 축소. 모바일은 왼쪽 배치. 위험·발각의 색과 발견 게이지는 유지 |
| 사용할 수 없는 터치 버튼이 지나치게 흐려 버튼 종류도 읽기 어려움 | 기본 버튼의 대비를 높이고, 가능한 행동은 밝은 면과 테두리로 구분. 기절·처치 구분 유지 |
| 지도 위에도 패드·미니맵·키 안내가 남아 전체 지도를 가림 | 전술 지도에서는 중복 조작 UI를 숨기고 계속하기 버튼만 명확하게 유지 |
| 미니맵을 키보드로 실행하기 어려움 | 버튼 의미와 Tab 포커스, Enter·Space로 지도 열기 및 키보드로 닫기 지원 |
| 확대할수록 물체 이름표도 커져 장면이 복잡해짐 | 그리기·충돌 회피 계산 모두 화면상 13px 기준으로 통일 |
| HUD·도구 선택·대화·설정·결과·자물쇠의 재질이 서로 다름 | 무광 먹색/회색 면, 얇은 선, 작은 모서리로 통일. 보상·위험·조작 상태 색은 의미에 따라 보존 |
| 일부 터치 메뉴 버튼의 높이가 44px 미만 | 이동·메뉴·살피기와 대상 전환 버튼의 터치 높이 보완 |

부제나 장식용 영문 문구는 추가하지 않았다. 지도 배치, 밝기에 따른 적 시야, 경계 단계, 행동 판정 등 게임 규칙은 바꾸지 않았다.

## 남은 그래픽 문제

### 의뢰 6 `배신`: 사전 렌더링 자료 누락

**2026-10-30 해결:** 같은 Quaternius CC0 원본 모델을 복구해 의뢰 6의 건물 4개를
다시 구웠다. 계단실 4곳의 그림과 막힘·문 앞 좌표를 함께 연결했고, 네 곳 모두
옥상 → 실내 → 옥상 왕복 검사를 통과했다. 아래는 수정 전 진단 기록이다.
창고 단지는 `kitStyle: 'industrial'`로 지정해 상점용 네온 간판·쇼윈도·차양을
제외하고 기존 벽·창문 모델로 구웠다. 의뢰 1~5의 구운 자료는 보존한다.

의뢰 1~5는 건물 35개가 모두 사전 렌더링 자료와 연결되지만, 의뢰 6은 건물 4개 모두 연결되지 않는다. 옥상 계단실 `(18,4)`, `(36,4)`, `(33,17)`, `(13,21)`도 소품/막힘 자료에 없다. 현재 기본 렌더링으로 표시된다.

이 문제는 이번에 수정하지 않은 `kitAttach()`와 `kit.json` 자료의 연결 문제다. `t_sh.py`도 해당 네 좌표를 `bad`로 출력한다. 이 테스트는 오류를 출력해도 종료 코드가 0이므로 정상 통과로 집계하지 않았다.

현재 `t_sh.py`는 모든 의뢰의 건물 연결·계단실 누락·문 앞 통로와 왕복 결과를
assertion으로 확인하며, 누락이나 페이지 오류가 있으면 실패한다.

`tools/prerender/mk`는 저장소에 없는 `/root/game/dl/megakit/Exports/glTF (Godot)`을 가리킨다. 원본 MegaKit 자료를 복구하고 의뢰 6을 구운 뒤 옥상 도달·충돌·왕복 검사를 함께 해야 한다. 그림 없이 막힘만 추가하거나 다른 의뢰의 그림으로 대체하지 않았다.
