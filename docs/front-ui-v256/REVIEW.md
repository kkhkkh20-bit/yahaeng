# v256 메인 화면과 기술 습득 UI

기존 픽셀 골목과 신체·암살·도구의 원형 스킬트리는 유지했다. 새 배경이나 캐릭터를 추가하지 않고, 메뉴의 우선순위와 기술 상태를 정리했다.

- 메인 화면: 큰 출발 버튼에 행동과 이어갈 에피소드를 두 줄로 표시한다. 조직도·기술 습득·설정은 같은 크기의 보조 버튼으로 묶고, 처음부터 시작은 아래에 별도로 둔다. 실제 버튼 글자에 접근성 이름을 제공하며 기존 키보드 이동과 저장·재시작 흐름을 유지한다.
- 기술 창: 3개 계열의 영역·헤더·전환 탭을 구분하고, 원래 27개 기술과 24개 선행 관계를 유지한다. 배울 수 있는 기술은 황동색, 배운 기술은 밝은 바탕과 체크, 잠긴 기술은 자물쇠와 점선으로 구분한다. 비용과 습득 경로는 그대로 표시한다.
- 상세창: 베이지색 전체 배경을 없애고 게임의 어두운 청회색으로 통일한다. 기본 / 습득 후 효과, 사용법, 미리보기, 선행 기술, 배우기 버튼 순서로 읽는다. 모바일은 화면 안에 들어오는 상세창을 사용하며 배경 입력 차단·초점 제한·Escape 복귀를 유지한다.
- 스타일 정리: 이전 먹색 테마 파일의 중복 기술 창 규칙을 제거하고 `skill-tree-finish.css`가 기술 화면의 외형을 담당하도록 했다. 이전 규칙이 돌아가기 버튼의 색을 덮어쓰던 문제도 함께 없앴다.
- 안내: 첫 방문에는 첫 에피소드를 마치면 1P를 얻는다고 설명한다. 기존의 첫 완료당 1P, 출발 전 습득, 임무 중 습득 금지, 재배분 규칙은 변경하지 않는다.

## 확인

| 검사 | 결과 |
|---|---|
| 메인·설정·이어하기 / 1440×900, 390×844, 320×568, 844×390, 390×640 | 모든 메뉴 버튼이 화면 안에 있고 실제 클릭 가능한지 확인. 이어할 에피소드 표시와 설정 왕복 통과 |
| 스킬트리 / 320×568, 390×844, 844×390, 1024×768, 1440×900 | 계열 전환, 27개 기술, 24개 실제 연결, 비용·잠금·선택·습득 상태, 실제 습득·재배분, 작은 화면의 모달 초점과 복귀 통과 |
| 습득 시점 / PC·세로·가로 | 첫 완료 후 1P, 모아 두고 다음 에피소드 진행, 출발 전 실제 습득, 플레이 중 습득 차단 통과 |
| 새 게임 / PC·세로·가로·320px | 취소·Escape·초점 복귀, 저장 실패 시 복구, 실제 새 게임 시작·이동·재접속 통과 |
| 배포 패키지 | 14개 HTML·스크립트·폰트 해시 일치, PC·브라우저 터치 이동·웅크리기·목표 열람 시 일시 정지와 복귀 통과 |
| 빌드 파이프라인 | 8개 검사 통과 |

스크린샷의 4P 및 습득 상태는 확인용 저장 조건이다. 포인트 추가 지급을 구현한 것이 아니다. 브라우저의 모바일 입력 검사이며 실제 iOS 기기 검사는 아니다. 배포 폰트 검사는 두 줄 버튼의 실제 글자 요소를 검사하도록 갱신했고, 완전한 한국어 커스텀 폰트 확인은 유지했다.
