# v147 암살 기술

기존의 일반 공격에서 조건 없이 두 명을 함께 처리하던 동작을 걷어내고, 해금·선택·준비·실제 타격을 갖춘 기술 두 개를 넣었다. 원래의 공격은 짧게 눌러 기절시키고 길게 눌러 처치하는 한 명 대상 행동이다.

연속 암살의 거리·재사용 시간·이동 속도는 야행용 설계다. Mirage의 Assassin's Focus를 그대로 복제한 기술은 아니며, 순간이동 없이 실제 좌표를 따라 두 번째 대상에게 접근한다. AC의 스킬 트리 전체·장비 요구·레벨별 암살 피해량은 이번 범위에 넣지 않았다. 외부 실행 라이브러리·브랜드 이미지·새 3D 모델은 추가하지 않았다.

## 사용법과 조건

- **쌍암살:** 의뢰 별 3개로 해금. 두 적 모두 62px 안, 서로 54px 안에서 등 뒤에 있어야 한다. 재사용 12초.
- **연속 암살:** 의뢰 별 6개로 해금. 첫 적은 62px 안, 다음 적은 첫 적으로부터 55–132px·플레이어로부터 195px 안이어야 한다. 빈 경로로 이동한 뒤 다음 타격을 실행한다. 재사용 16초.
- **PC:** K로 사용 기술 선택, B를 1초간 눌러 준비. **터치:** 메뉴 → 암살 기술에서 선택하고 기술 버튼을 길게 누른다. R의 기존 이동 속도 전환은 유지한다.
- 준비 중 머리 위 1·2가 실제 선택 대상을 보여 준다. 입력을 놓거나 창을 전환하면 준비가 취소된다. 시작 후 대상이 바뀌어도 다른 사람으로 자동 교체하지 않는다.
- 두 기술은 **살상 기술**이다. 주민·어린이·개·정예·포로·죽은 사람·발각한 적은 제외한다. 빈손, 같은 실내 층과 높이, 시선이 통하는 등 뒤 접근이 필요하다. 컨테이너·환풍구·차량·전선·매달림·옥상 높이에서는 사용하지 않는다.
- 도중에 피해를 받거나 두 번째 적이 돌아보고 발각하거나 벽·닫힌 문·층 변경으로 접근이 막히면 후속 공격을 중단한다. 첫 타격이 실제로 끝난 경우 시체와 재사용 시간은 남는다. 가까운 살상 소리·핏자국·시체·다른 경비의 실제 목격은 기존 AI 규칙을 사용한다.
- 의뢰 별을 소비하지 않으며 별도 스킬 포인트를 만들지 않는다. 기존 임무·도전 기록을 그대로 센다. 선택은 기기에 저장하고, 체크포인트는 남은 재사용 시간과 실제 결과를 보존한다.

## 연습

의뢰 선택 → 연습 → **연습 5 · 암살 기술**. 웅크려 등 뒤 접근 → 쌍암살 → 기술 목록에서 연속 암살 선택 → 통로 이동 → 연속 암살 → 출구 순서다. 연습에서는 두 기술을 바로 쓸 수 있지만 본편 해금과 별 기록은 바꾸지 않는다. 일반 공격으로 대상을 쓰러뜨려 진행할 수 없게 된 경우 이유를 알려주고 재시작할 수 있다. 기술 연습 경비는 임의의 잡담을 시작해 안내 도중 뒤돌아보지 않는다. 본편 경비의 잡담·고개 돌리기는 유지한다. 첫 시야·소리 연습과 풀숲의 웅크림 자동 은폐 흐름은 유지한다.

## 구조·성능

- `26_assassin_skills.js`: 별 해금, 대상·각도·거리·층·빈 경로 검사.
- `interaction/assassin_skills.js`: 준비 → 첫 타격 → 이동 → 다음 타격 → 종료/중단. 입력과 대상 ID를 고정한다.
- `84_skill_menu.js`: 선택 화면, HUD 상태, 준비 대상 표시와 연습 실패 안내.
- `92_assassin_training.js`: 선택 연습 데이터. 다른 의뢰에 동일 규칙을 적용한다.

기존 인물 스프라이트·PixelFX 아틀라스를 공유한다. 피해자는 자기 위치에서 쓰러지고, 연속 암살 중 플레이어는 프레임별로 실제 이동한다. 동작에 속한 인물과 시체를 중복 그리지 않으며 시체의 시각 처리 때문에 AI가 시체를 볼 수 없게 만들지 않는다. 공격 중에는 완료 전의 시체 위험 문구를 겹쳐 띄우지 않는다.

배포 스크립트 4개·에셋 175개를 유지했다. 에셋 총량은 v146의 7,706,882바이트에서 7,724,679바이트로 **17,797바이트** 늘었다. 새 효과 이미지·실행 의존성은 없다. HUD의 준비 가능 표시는 0.1초 간격으로 갱신하고 실제 입력·타격 때는 매번 재검사한다. 실물 휴대폰 FPS는 별도로 측정하지 않았다.

## 검증

42개 빠른 회귀 검사, 빌드 소유권 검사 6개, 이미지 소유권 검사와 전 의뢰 도달 검사를 통과했다. 새 기술 검사는 일반 공격 한 명 제한, 주민·정예·시야·방향·층 제한, 짧게 누르기·해제·touchCancel·앱 전환, 실제 PC B/K·CDP 터치의 두 기술, 이동 도중 벽·층·발각·피해에 따른 중단, 첫 사망·재사용 보존, 동작 중 체크포인트 복원, 연습 해금의 본편 비전파, 제삼자의 목격을 확인한다.
