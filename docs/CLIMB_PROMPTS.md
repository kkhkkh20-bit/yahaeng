# v102 · 행동 안내와 배관 오르기

2026-10-31 (한국 시간)

큰 공통 배경판·구분선·설명 줄·빈 공간을 제거했다. 모바일은 현재 가능한 공격·붙잡기·행동만 작은 글씨로 표시한다. PC는 키와 동작을 표시한다. 표시할 행동이 없으면 아무것도 그리지 않는다. 심문을 마친 뒤 재입력해도 ‘추가 정보 없음’은 띄우지 않는다. 짧게 기절·길게 처치 구분은 실제 터치 버튼과 PC 조작 안내에 남긴다.

배관 오르기는 원본 아틀라스에서 머리와 손이 이미지 경계에 잘려 있었다. 오르기 동작만 촬영 범위를 넓혀 다시 굽고, 동작별 배율과 기준점을 저장해 게임 안의 크기와 위치를 보정한다. 기본 인물과 주인공의 네 복장, 8방향 4프레임(160개)을 수정했다. 다른 동작의 이미지 픽셀은 이전 커밋과 동일함을 비교했다.

[모바일·PC 전후 화면](climb-v102/index.html). 동일한 배치를 사용했으며 오르기·붙잡기·심문은 실제 행동을 진행해 촬영했다. 휴대전화 실기기 검사는 아니다.

검증: `t_climb_prompt_visuals.py`는 160개 프레임의 투명 여백, 실제 배관 왕복 이동, 확대율에 관계없는 작은 안내, 불가능한 행동 숨김, 모바일의 배경판 제거를 검사한다. 기존 행동 가독성·플레이 판정·캐릭터·공격 탭/홀드 검사도 실행했다.
