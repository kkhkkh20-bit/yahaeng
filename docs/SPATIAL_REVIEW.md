# 사물 선택과 층 표현 검토 · v83

## 실행본에 반영한 상호작용 수정

| 확인한 원인 | 변경 |
| --- | --- |
| 전신주에 붙은 보안등은 조작 대상에서 제외됨 | 기존 보안등 8개를 끄기·켜기 대상으로 연결. 기둥 아래 스위치 상자를 그리고, 안내·손 닿음·캐릭터 방향이 같은 위치를 참조 |
| 전신주를 후보에서 제외할 때는 전깃줄, 다시 찾을 때는 전신주를 검사함 | 실제 전신주를 선택 대상으로 유지. 뒤에 있는 조명·문 후보도 수집 |
| 창문·옥상 전깃줄 후보가 제외 목록을 무시함 | 같은 줄을 반복해서 반환하지 않도록 수정 |
| 전체 전원·CCTV 행동에 고정 대상이 없어 다음 시설 후보가 잘림 | 시설별 대상을 연결하고 후보 제외 규칙 적용 |
| 깜빡이는 조명이 꺼지는 프레임에 조작 후보가 사라짐 | 전구의 순간 밝기와 스위치의 사용 가능 여부를 분리 |

스위치에 더 가까우면 조명을 먼저 제안하고, 직접 선택한 전신주는 유지한다. 기둥 뒤 벽을 통과해 오르는 판정도 막는다. 기존 HUD·키·모바일 버튼 위치는 유지했다.

## 공간 표현 시안

[비교 화면](spatial/index.html) · [세 공간 이미지](spatial/compare.png)

대청소 맵 빌라의 실제 평면, 가구 위치, 계단 위치를 바탕으로 기존 CC0 모델을 재사용했다. 동일한 52도 정사영 카메라와 동일한 거리 배치를 사용한다. 12도 측면 회전은 벽과 바닥 두께를 함께 검토하기 위한 시안 값이다. 층 높이를 타일 간격의 1.65배로 표현하고, 주인공의 발을 해당 층의 바닥에 둔다.

| 공간 | 구분하는 시각 단서 |
| --- | --- |
| 거리 | 세 층의 닫힌 외벽, 출입문, 지면의 주인공과 접촉 그림자 |
| 2층 실내 | 지붕과 위층 제거, 벽 단면, 계단 구멍과 아래로 이어지는 디딤판, 아래층 외벽·바닥 두께 유지 |
| 옥상 | 실내 바닥 대신 난간·옥탑·채광창, 원래 서쪽을 향한 옥탑문 앞에 주인공 배치, 외벽을 지면까지 연결 |

이 시안은 렌더링 비교용이며 **게임 전체의 카메라와 판정에는 적용하지 않았다.** 기존 모델·주인공 외모를 유지하면서 필요한 시점으로 다시 구울 수 있는지 확인한 결과다. 생성기는 제품용 아틀라스·지도·충돌 데이터를 덮어쓰지 않는다.

## 전체 적용 전에 연결할 구조

1. 거리·실내층·옥상을 공통 바닥 좌표와 실제 높이로 정의하고, 그 좌표에서 화면 위치를 계산한다. 현재의 실내 `fl`과 옥상 `z`를 화면에서 서로 다른 방식으로 보정하는 부분을 통합한다.
2. 그림뿐 아니라 터치 대상·손 닿는 위치·적 시야·창문·계단·전깃줄을 같은 변환으로 연결한다. 특히 옥상 앞의 정면 벽 줄을 지도 타일로 소비하던 표현을 새 좌표로 이관해야 한다. 그림만 새 각도로 바꾸면 다시 어긋난다.
3. 앞벽과 지붕은 주인공이 들어간 방을 가릴 때만 걷어낸다. 적이나 물건을 다른 층에서 조작할 수 있게 만들지 않는다.
4. 같은 문·계단·창문을 왕복할 때 발 위치, 도착 층, 터치 표시가 일치하는지 확인한 뒤 다른 건물로 확장한다.

## 확인

- 기존 핵심 회귀 21개와 새 `t_environment_targets.py` 통과. 새 검사에는 보안등 8개, 전신주·조명·문 중첩, 전체 전원 뒤의 후보, 구버전 스위치 위치, 벽 모서리 차단, 실제 키보드·모바일 조작을 포함한다.
- 비교 화면의 세 이미지 로드, 키보드 탭 이동, 모바일 390px에서 가로 넘침 없음 확인.
- `tools/prerender/spatial_preview.py`가 실제 게임에서 평면·가구·계단·주인공을 읽고 세 장을 생성한다. 기존 게임 서버 `127.0.0.1:8001`과 프리렌더 서버 `127.0.0.1:8766`이 실행 중이어야 한다.
- 사용 모델: Quaternius Downtown City MegaKit, Kenney Furniture Kit, Quaternius Ultimate Modular Women. 모두 CC0.
