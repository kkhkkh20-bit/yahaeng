갈아입기 버튼과 기본 제압 거리

옷 갈아입기가 대상 목록 안에 묻혀 있었습니다. 이제 사용 가능한 옷 옆에서는 별도 갈아입기 버튼이 나옵니다. 모바일은 즉시 붙잡을 적이 없을 때 기존 붙잡기 자리를 쓰고, PC는 대상 선택 옆에 표시합니다.

기본 제압 거리를 약 1m에서 1.5m로 늘렸습니다. 뒤쪽 접근·같은 층·시선 차단 조건을 유지하고, 세 걸음 거리에서 직접 이동하는 접근 암살은 배운 기술로 남깁니다.

갈아입기는 기존 3초 작업과 복장별 출입·목격 판정을 그대로 사용합니다. 운반과 대상 목록도 계속 쓸 수 있습니다.

비교 사진은 같은 시드·좌표·인물을 배치한 실제 실행 원본입니다. 별도로 PC 키와 실제 터치로 제압, 갈아입기, 작업 중 잠금, 완료 후 버튼 해제와 운반을 확인합니다. 본편 전체 완주·사람 대상 이해도 조사·실물 휴대폰 성능 검사는 아닙니다.
