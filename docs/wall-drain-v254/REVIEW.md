# v254 벽 기습과 맨홀 탈출

## 벽에 기대서 지나는 적 잡기

벽 기습은 이미 있었지만, 완전히 발각되기 전의 경계 상태에서도 대상에서 제외됐고, 옥상이나 화단에서는 일반 공격·화단 기습이 먼저 선택될 수 있었다. 끌어오는 시간이 살해 입력 시간에 포함되지 않아, 공격을 1초 눌러도 기절로 끝나는 경우가 있었다.

- 벽에 기대고 손이 닿으면 벽 끌어오기를 먼저 선택한다. 아직 발각을 확정하지 않은 경비도 잡을 수 있다. 완전히 발각된 ALERT 경비는 일반 전투로 대응한다.
- 짧게 누르면 끌어와 기절, 같은 입력을 1초 계속 유지하면 살해. 끌어오는 동안 누른 시간도 포함한다. 입력을 떼고 다시 누르면 이전 입력의 살해 의도를 잇지 않는다.
- 다른 암살 기술의 길게 누르기가 벽 끌어오기를 가로채지 않는다.
- 은신 기습 습득 조건, 층·높이 분리, 아동·들개 제외, 벽을 통과하지 않는 이동 경로는 유지한다. 몸을 들거나 누군가 붙잡은 상태에서는 추가 끌어오기를 제안하지 않는다.

## 공터 맨홀 탈출

m4 돈줄의 보조 출구는 맨홀 위에 서기만 해도 승리하던 지점이었다. 이제 공터 맨홀에서 행동으로 덮개를 열고 내려간 뒤, 도로 아래 점검 통로를 따라 남쪽 맨홀로 이동해 올라와야 탈출한다. 올라오는 동작을 마쳐야 결과 화면으로 넘어간다. 목표를 완료하기 전에는 같은 맨홀로 올라와도 임무는 계속된다. 서쪽 지상 출구도 유지한다.

이 맵의 지하 통로는 임의의 ㄱ자 연결 대신 도로·건물 사이 골목 아래를 지나는 경로로 지정했다. 5개 맨홀이 모두 연결되고, 사람이 있는 건물의 기초 아래를 지나지 않는지 검사했다. 다른 맵의 지하 배치는 이번에 전부 다시 만들지 않았다.

지하의 사다리는 구매한 Dotonbori 에셋을 사용한다. 지하 미니맵은 실제 통로·맨홀·현재 위치·해당 탈출구를 표시한다. 지상 경비의 위치를 천장 너머 점으로 보여주던 효과와 지상 건물이 비치는 배경은 제거했다. HUD·목표·무전은 남쪽 출구 안내로 일치시켰다.

옛 지하 체크포인트의 위치가 새 통로 밖에 있으면, 해당 실행에 한해 기존 연결망을 보존한다. 위치·체력·진행도를 임의로 옮기지 않는다.

## 확인

- 일반 프레임과 실제 키보드 / 브라우저 터치 입력: 휘파람 없이 순찰 중인 적의 벽 끌어오기 → 짧게 기절 / 1.12초 유지 살해, PC·터치 총 4회 통과.
- 같은 입력 방식으로 공터 맨홀 내려가기 → 직접 통로 이동 → 사다리로 나오기 → 승리, PC·터치 2회 통과.
- 기존 휘파람 → 벽 모서리 끌어오기 PC·터치 기절 / 살해 4회 통과. 4방향·2개 층의 경로 회귀 검사 통과.
- 수색·탈출 경로, 물리 상호작용, 습득 조건, 맵 경계, 임무 진행, 현장 HUD와 층 표현 회귀 검사 통과. 빌드 검사 8개 및 물리 상호작용 20개 묶음 통과.

새 조작 검증은 기존 맵에서 다른 적·카메라를 제거하고 위치와 목표 진행을 지정한 통제 상황이다. 임무 전체 완주 증거가 아니며, 브라우저 터치는 실제 iOS 기기 검증이 아니다. `native.json`과 `wall-drain.json`에 결과를 남겼다.
