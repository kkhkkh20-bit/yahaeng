# v265 · 제압 박자와 옥상 계단실

옥상 계단실에 실내 걸레받이 그림을 벽 전체로 반복하고, 목재 다리 바닥을 지붕 장식으로 잘라 쓰던 문제를 수정했다. 구매한 Dotonbori 외벽과 지붕 내부 면을 조합한다. 지붕 원본 테두리까지 반복하지 않으며, 옆문은 원본 전체를 좁은 벽면에 투영한다. 충돌 칸, 문 접근점, 층간 이동 경로는 유지한다.

기존 캐릭터의 8방향 조합과 25개 중간 프레임을 활용해 제압 시간을 다시 배치했다. 반복해서 같은 조르기 자세를 앞뒤로 되감던 흔들림을 제거했다. 접촉·힘 풀림·무릎 꺾임·내려놓기가 같은 시간표를 사용한다.

| 보통 제압 | 이전 | 변경 |
| --- | ---: | ---: |
| 손 접촉 | 0.14초 | 0.10초 |
| 실제 기절 판정 | 0.54초 | 0.42초 |
| 내려놓기 | 약 0.94초 | 0.79초 |
| 이동 재개 가능 | 약 1.01초 | 0.84초 |
| 전체 동작 | 1.15초 | 1.08초 |

마지막 구간의 행동 입력은 운반과 옷 갈아입기 모두 내려놓기 후 이어받는다. 다음 상대 공격도 내려놓은 뒤 새로 누른 입력만 받는다. 처음 누른 버튼을 1초 유지해야 살해되며, 다른 키나 놓았다 다시 누른 입력이 이전 살해 의도를 물려받지 않는다. 붙잡은 상대의 짧은 동작이 1초보다 먼저 끝나는 경우에는 마지막 자세를 유지하며 몸을 중복 표시하지 않는다.

접촉에는 작은 기존 픽셀 먼지를 사용하고, 일어나는 동작을 짧게 이어 붙였다. 캐릭터와 가까운 상대의 고밀도 제압 프레임을 미리 읽어 첫 동작 중 시트 교체를 줄인다. 효과는 게임의 광원·소음·공격 범위를 추가하지 않는다.

## 검증 범위

- `t_takedown_beats`: PC 키보드와 CDP 터치. 기절 이전 결과 없음, 0.9초 이전 이동, 옷 갈아입기 예약, 1초 살해 구분, 붙잡기 후 몸 중복 방지, 단조롭게 이어지는 4개 동작 시간표. 8개 의뢰의 실제 계단실 문 35개를 전체 원본으로 표시하고 이동 구조를 변경하지 않음.
- 기존 제압 리듬, 전투 입력 정책, 운반·변장 예약, 접근 동작, 암살 기술, 이벤트 피드백 검사 통과.
- 42,464개 고밀도 프레임의 빈 그림·잘림 검사와 두 사람 각각 25개 프레임, 단일 인물 그리기, 17개 사다리 손 접촉 검사 통과.
- 기존 옥상 이동 검사: 다리 횡단 16회, 계단실 문 접근 140회 통과.
- 정상 RAF와 실제 AI를 사용하는 PC·터치 접근→제압→운반→풀숲 숨기기 플레이. 플레이어·진행·체력·물품 부여 없음. 개별 연습 스테이지 선택만 사용하는 재현 절차이며 캠페인 전체 완주를 뜻하지 않음.
- 전체 첫 튜토리얼의 PC·터치 플레이, 빌드 8개 검사와 배포 파일 13개 해시·PC/터치 시작 검사.

`before/after-roofs.png`는 실제 지붕 소품 캐시를 모은 고정 장면 비교이며 주변 소품도 포함한다. `roof-scene-*.png`는 지붕에 플레이어를 배치한 렌더 검수 장면이다. `before/after-motion.png`는 실제 2D 캐릭터 렌더러의 자세 비교이며 플레이 녹화가 아니다. 네이티브 입력 기록은 별도 JSON에 보관한다.
