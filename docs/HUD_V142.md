# v142 HUD 정리

이번 범위는 기존 2D 플레이 HUD다. 게임의 어두운 거리·벽돌·산업 시설과 맞는 절제된 안내를 목표로 했다. 목표는 먼저 읽히게 하고, 경계색은 실제 위험에 쓰며, 손가락이 누를 영역과 화면을 가리는 장식을 구분했다.

- 목표를 첫 줄, 의뢰명·진행을 보조 줄로 배치했다. 반복된 장식 기호와 개별 상태 상자를 줄였다.
- 정상 체력은 밝은 막대, 낮은 체력과 발각은 경고색으로 표시한다. 은신 안내는 화면 왼쪽에 모았다.
- 큰 원형 터치 버튼을 직사각형 조작부로 바꿨다. 보조 버튼은 밑줄만 남기고, 주요 행동을 구분했다. 누르고 있기 진행은 버튼 아래 선으로 표시한다.
- 행동 선택창을 하나의 어두운 목록으로 정리했다. 목표 확인과 행동 선택 중 시간 정지, 키보드 탐색, 선택 후 별도 실행을 보존했다.
- 플레이 HUD 스타일은 `src/hud.css`가 맡는다. 템플릿·테마의 중복 HUD 규칙을 제거하고 빌드에 명시적 삽입 위치를 추가했다. AI·판정·입력 매핑은 바꾸지 않았다.

## 검증

1280×800 PC, 390×844·375×620 세로 터치, 844×390 가로 터치에서 실제 게임 화면을 캡처했다. 터치 조작의 44px 최소 크기·화면 경계·서로 겹침·미니맵 겹침을 검사했다. 목표 펼치기, 실제 발각, 수색 안내, 도구 소진, 실제 행동 선택창도 확인했다.

HUD 시스템, PC/실제 CDP 터치 튜토리얼, 제압·운반, 문·환풍구·상호작용, 매달리기 입력과 UI 오류 검사를 통과했다. 브라우저 에뮬레이션 결과이며 실물 iPhone 성능 측정은 아니다.

설치된 Impeccable의 기존 제품 범위 개선 절차를 적용했다. 수동 감지는 한 번 실행했으며 남은 경고 6개는 범위 밖인 일시정지 설정 여백·브리핑 라디오 여백·브리핑 지도 범례에 있다. HUD 최종 상태는 화면과 조작으로 검수했다.
