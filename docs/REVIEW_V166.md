# v166 · 암살 효과와 모바일 전용 조작

암살의 준비·접촉·회복 프레임을 실제 타격 시각에 맞췄다. 접촉 직후 55ms의 짧은 히트스톱에서 인물과 효과가 함께 느려지고, 칼날 효과는 비어 있는 선행 프레임을 건너뛴다. 암살 기술에서 기존 범용 먼지와 칼날이 함께 나오던 중복을 제거했다. 실제 살상 조건·두 번째 대상의 인지와 벽 검사·재사용 시간은 유지한다.

연속 암살의 실제 이동 구간에 현재 복장과 방향의 캐릭터 잔상을 최대 3개, 140ms 동안만 표시한다. 새로운 캔버스나 이미지를 프레임마다 만들지 않는다. 모션 줄이기 설정에서는 잔상을 생성하거나 그리지 않는다. 취소·회복 후에는 남지 않는다.

CCTV 해킹은 작업이 실제 완료됐을 때만 450ms의 작은 스캔선·간섭 효과를 한 번 재생한다. PixelFX의 `scifi/emp-blast`, `scifi/glitch`를 참고하고 세 차례 렌더링해 크기·입자 수·밝기를 줄였다. `tools/pixelfx/hack.mjs`와 기존 베이커로 재생성한다. 기존 9종을 포함한 아틀라스는 10종, 216프레임이며 70,764 → 71,196바이트로 432바이트 늘었다. 런타임 라이브러리는 추가하지 않았다.

## 조작

- 모바일은 상황에 따라 나타나는 붙잡기·갈아입기를 장비 위 별도 자리로 옮겼다. 대상 선택도 별도 자리를 쓰고 짧은 가로 화면에서는 미니맵을 메뉴 옆으로 옮긴다. 웅크리기의 원형 마감은 유지한다.
- 암살 연습의 별도 기술 버튼은 숨기고 공격 길게 누르기로 통일했다. 안내와 강조 표시도 공격 버튼을 가리킨다.
- PC는 오른쪽 행동·장비·상황·웅크리기 버튼을 표시하지 않는다. 주 입력 장치가 마우스이면 터치 API가 있어도 PC 조작을 사용한다. 메뉴와 미니맵은 계속 사용할 수 있다.
- PC 장비 선택은 `I`, 선택한 도구는 `F / V`, 대상 순환은 `Tab`, 행동 목록은 `Shift+Tab`이다. 갈아입기도 목록에서 선택한 뒤 `X / E`로 실행한다. 장비 선택을 닫으면 게임 캔버스로 키보드 포커스를 돌려준다. 기존 `G` 휘파람도 유지한다.

## 검증

빌드 검사 7개, 스프라이트 관리 검사, 지도 도달 검사와 핵심 회귀 스크립트 62개를 통과했다. 별도로 실제 입력을 사용하는 갈아입기 검사를 PC·모바일·작은 세로·가로 화면에서 통과했다. 마지막 도구 키 처리 변경 후 장비와 입력 경계 검사도 다시 통과했다.

새 조작 검사는 320×480, 320×568, 390×844, 430×932, 568×320, 667×375, 740×360, 844×390, 1024×600 모바일과 1280×800·390×844 PC에서 빈 공간·붙잡기·갈아입기 상태를 검사한다. 보이는 버튼과 미니맵은 서로 6px 이상 떨어지고 44px 이상의 입력 영역을 가지며 화면 안에 있다. 터치 API만 있는 마우스 PC도 포함한다.

새 효과 검사는 취소 시 효과가 없는지, 실제 접촉에 하나만 나오는지, 히트스톱이 효과와 세계에 같은 시계로 적용되는지, 잔상의 수와 모션 줄이기 설정, 해킹 취소·완료·효과 만료를 검사한다. 전체 회귀·fuzz와 실물 기기 성능 검사는 실행하지 않았다.

생성 중간 캡처·검사 JSON은 `build/review-v166/`, 효과 후보와 세 차례 스캔선 캡처는 `build/pixelfx-preview/`에 남긴다. [PixelFX 스킬](../.agents/skills/pixelfx/SKILL.md)과 [원본 라이브러리](https://github.com/patch-gg/pixelfx)의 MIT 크레딧을 유지한다.
