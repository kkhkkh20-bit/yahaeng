# v127 — 유인 템포·시민 서기·공터 정리

[실행 화면 비교](polish-v127/index.html) · [그래픽 진단과 재제작 범위](ART_DIRECTION_REVIEW_V127.md)

- 식당의 준비에 먼 클럽 문지기가 오기까지 기다리던 구조를 바꿨다. 기존 문지기는 클럽에 남고, 식당에서 쉬는 경비 한 명이 가까운 식사·화장실 동선을 이용한다. 준비하면 식사 주기 대기 없이 걸어온다. 첫 자연 식사는 60초 이후로 두어 첫 준비와 식사가 겹쳐 바로 목격되는 상황을 줄였다.
- 식사 동작은 3초에서 1.25초로, 목적이 있는 식사·화장실 이동은 평소보다 빠른 걸음으로 조정했다. 32초의 화장실 제압 기회는 유지했다. 직접 기절시키기에도 추가 제약을 넣지 않았다.
- '경비 식사 지켜보기'로 의뢰 목표를 덮어쓰던 안내를 없앴다. 화장실 유인은 목격자를 피하며 경비복을 확보하는 선택지다. 기다리지 않고 다른 목표를 진행할 수 있다.
- 실장 술병 준비 후에는 실장이 바에 한 번 들른다. 멀리서 즉시 배탈 상태로 바꾸지 않으며 실제로 이동해 마신 뒤 화장실로 간다. 이동 중 복귀 상태에서도 사람 사이에 막히면 경로를 다시 잡도록 수정했다. 시야·범행 목격·경보 처리는 켜져 있다.
- 시민·평소 경비·주인공의 정지·대화 자세는 원본 모델의 전투용 Idle 대신 Idle_Neutral에서 구웠다. 상체만 세우고 무릎과 발은 전투 자세로 남던 기울어짐을 수정했다. 외모·복장을 교체하지 않았다.
- 대청소의 공터 적치장 (18~20, 21)에 있던 컨테이너와 사다리를 그림·충돌·오르내리기에서 함께 제거했다. 다른 구역의 컨테이너 경로는 별개다. 예전 저장에서 그 위에 있던 플레이어는 바닥으로 복원되며 진행과 소지품은 보존된다.

## 검사

자세는 11종 외형 × 8방향, 총 88개를 실제 베이크 리그로 검사했다. 머리와 두 발 중점의 수평 오차는 키 대비 최대 3.1%였다. 양발 높이와 무릎의 위치도 확인했다. 수정한 서기·대화 외 걷기·전투·이동 16,600프레임은 기존 이미지와 픽셀이 같았다. 전체 23,000프레임의 잘림·빈 그림 검사도 통과했다.

음식 준비를 0·30·150초에 시작하는 PC·모바일 장면에서, NPC 40명·카메라 3대를 켠 채 물리적으로 화장실에 도착하는 것을 확인했다. 최종본은 약 13.6초였다. 순간이동 없이 이동하고, 입구 경비가 자리를 지키며, 혼자 제압할 수 있는 시간을 확보했다. 이는 시작 위치를 배치한 타이밍 검사이며 사람이 처음 플레이한 결과로 표현하지 않는다.

기존의 약 집기·실제 손 접촉 후 사용·화장실 점유·전투 중단·저장 복원, PC 키보드와 모바일 터치 입력 검사도 실행했다. 간판·약·뒷문 12개 AI 장면, 계단 59·옥상 70·자동 진입 118·NPC 계단 이동 258개, 창문 496·층 72·접점 128개, 짧게 눌러 기절/길게 눌러 처치 규칙을 검사했다.

전체 AI 의뢰 경로는 맵을 아는 자동 입력으로 약국·식사 준비·화장실 제압·변장·장부·전화 유인·매복·표적 처치·탈출을 진행했다. 게임 루프를 그대로 켠 녹화도 비교 페이지에 둔다. 순간이동·체력·열쇠·복장 지급을 사용하지 않았다. 녹화는 캔버스이며 HTML HUD는 포함하지 않는다.

검수 중 첫 약 유인 장면 하나에서 실장이 사람 사이에 막혔다. 복귀 경로 회복을 수정하고 재현 가능한 시드의 12개 장면을 통과했다. 실시간 검수 첫 배치에서는 가까이 둔 경비가 준비를 목격해 플레이어가 사망했다. 경비의 대기 방향과 첫 자연 식사 시간을 조정한 뒤 같은 전체 경로를 다시 검사했다. 이 실패를 성공으로 세지 않는다.

최종 결과·오류·영상 정보는 [validation.json](polish-v127/validation.json)에 기록한다. 모바일 검수는 Chromium 터치 화면 모사이며 실제 iPhone 검사와 구분한다.

최종 전체 AI 자동 경로는 PC 143초·체력 3, 모바일 139초·체력 1로 완료했다. 최종 실시간 녹화 경로는 155.3초·체력 3으로 완료했고 페이지 JavaScript 오류는 없었다. 모바일 경로는 발각 3회가 있어 무발각 성공으로 표현하지 않는다.

고정 자동 경로는 순찰 시간 변화 후 카메라 녹화·경보 때문에 전화 행동을 사용할 수 없는 장면에서 한 번 실패했다. 게임의 경보를 없애지 않고 자동 경로에서 금고 진입 전에 사무동 카메라를 먼저 끄도록 조정해 PC·모바일 경로를 다시 완료했다.
