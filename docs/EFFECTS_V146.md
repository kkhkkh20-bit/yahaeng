# v146 PixelFX 효과와 풀숲 조작

풀숲은 플레이어용 ‘들어가 숨기’ 행동에서 제외했다. 웅크린 채 걸어 들어가면 자동 은폐되고, 일어서거나 걸어 나오면 풀린다. 수거함·맨홀·옷장에 들어가는 행동과 기절한 사람을 풀숲에 숨기는 행동은 유지한다.

[PC·터치 전후 화면](effects-v146/index.html) · [풀숲·효과 검사](effects-v146/mechanics.json)

## 튜토리얼

시야·소리 연습의 풀숲 단계는 서 있으면 ‘웅크리기’를, 이미 웅크렸으면 이동을 안내한다. 완료 조건은 실제 풀숲 타일에서 `P.hidden`이 된 것이며 컨테이너 진입 상태로 대신 통과할 수 없다. 다음 휘파람 단계는 풀숲에 은폐된 채 낸 소리를 경비가 실제로 들었을 때만 완료된다.

이전 체크포인트가 풀숲을 컨테이너처럼 저장한 경우, 체력·진행은 유지하고 그 자리의 웅크림 은폐로 이관한다. 새 체크포인트에서는 이미 끝난 효과를 재생하지 않는다.

## 적용한 효과

PixelFX `a84159688af3ca37a4be05a0d422b94451b2e24e`의 여섯 효과와 같은 도구로 만든 두 효과를 골랐다. 잎·먼지는 세 차례 렌더링하며 수와 퍼지는 거리를 줄였다. 반짝임·칼날·타격은 회색과 낮은 광량으로 조정했다.

| 효과 | 실제 발생 지점 |
| --- | --- |
| 잎 흔들림 | 풀숲 은폐에 들어가거나 나올 때 |
| 작은 먼지·옷 접촉 | 달리는 발, 착지, 붙잡기·제압의 접촉과 몸이 내려오는 순간 |
| 둔기 타격 | 플레이어가 실제 피해를 받을 때 |
| 칼날 잔상 | 직접적인 살상 타격. 조용한 목 조르기는 잔상 대신 작은 접촉 효과 |
| 작은 접촉 불꽃 | 다트가 실제 명중한 위치, 금속 문·스위치 작업의 접촉 순간 |
| 총구 불꽃·연기 | 경비가 실제 발사하는 순간, 총구 방향과 층에 맞춤 |
| 획득 반짝임 | 열쇠·카드·물품을 실제로 얻었을 때. 옷을 바꿀 때는 재생하지 않음 |
| 전기 접촉 | 실제 감전 함정의 물웅덩이 |

상시 달리기 속도선 세 줄과 모든 상호작용에 붙던 동일한 원형 파동은 덜었다. 기존 소리 범위·시야·발각 판정은 시각 효과와 분리한다. 보안구역에서 신원 확인 게이지가 실제 확인 시간보다 먼저 차 보이던 계산도 맞췄다.

문과 스위치의 후보를 열거한 뒤 마지막 후보가 다음 프레임의 우선 대상이 되던 문제도 수정했다. 테스트는 문뿐 아니라 실제로 선택한 조명의 상태 변화까지 확인한다.

## 용량과 실행 비용

- 게임에는 PixelFX 라이브러리 전체를 넣지 않고 155프레임의 WebP 아틀라스 한 장을 넣었다. 이미지 파일은 20,878바이트, 크기는 1024×408이다.
- 배포 스크립트는 4개로 유지하고 에셋은 174개에서 175개가 됐다. 현재 배포 에셋 총량은 v145의 7,677,032바이트에서 7,706,882바이트로 29,850바이트 증가했다.
- 동시에 살아 있는 효과는 최대 24개다. 한 이미지를 공유하며, 프레임마다 파티클을 계산하거나 캔버스를 만들지 않는다. 실제 광량이나 AI가 듣는 소리는 추가하지 않는다.
- 층·옥상 높이·열려 있는 실내·화면 범위를 확인해서 다른 층이나 닫힌 건물 속의 효과가 겹쳐 보이지 않게 한다.
- `python3 tools/bake_pixelfx.py`로 다시 만들 수 있다. 원본 MIT 라이선스와 출처를 아트 폴더, 빌드 데이터와 크레딧에 포함했다.

## 검증

PC 키보드와 실제 CDP 터치 입력으로 시야·소리 연습 → 뒤에서 제압 연습 → 의뢰 진입을 통과했다. 풀숲 안으로 걸어 들어가 자동 은폐, 휘파람 유인과 조용한 이탈, 붙잡기·기절·갈아입기·운반·은닉을 확인했다.

새 통제 검사는 서 있을 때 비은폐, 플레이어용 풀숲 숨기 선택지 제거, 강제 진입 거부, 기절자 은닉 유지, 이전 저장 이관, 효과 24개 제한·만료, 층·높이 분리와 효과 그리기 중 캔버스 할당 0회를 확인한다. 효과를 그리면서 체력이나 소리 기록이 바뀌지 않는 것도 확인했다.

기존 빠른 묶음 41개 중 40개가 첫 실행에 통과했고, 대상 순서 검사가 실패했다. 위의 순서 문제를 수정하고 조명 상태를 포함해 재검사하여 통과했다. 원본 여섯 효과의 PixelFX 검사도 6 pass, 0 fail, 0 warnings였다. 커스텀 효과와 아틀라스 생성은 같은 시드의 출력 일치와 마지막 프레임의 빈 상태를 검사했다.
