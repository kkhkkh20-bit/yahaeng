# v258 버튼과 화면별 UI

메인·옵션에서 정한 청회색과 황동색을 출발 준비, 일시 정지, 결과, 장비, 조직도, 비밀번호 입력과 인게임 조작에 맞췄다. 메뉴 구성·기술 트리·인게임 버튼의 위치와 조작 규칙은 유지한다.

## 버튼의 역할

| 역할 | 표현 | 적용 |
|---|---|---|
| 주요 행동 | 황동색 면과 어두운 글자 | 출발, 계속하기, 다음 의뢰, 기술 습득, 코드 확인 |
| 보조 행동 | 청회색 면과 밝은 글자 | 돌아가기, 닫기, 조직도, 장비·메뉴 |
| 주의 행동 | 낮은 채도의 붉은색 | 처음부터 재시작, 저장 초기화 확인 |
| 선택 | 황동색 테두리와 채움 | 장비, 조직도 대상, 추적 목표 |
| 사용 불가 | 채도·명도를 낮춘 청회색 | 잠긴 습득 버튼, 비활성 주요 버튼 |
| 누르는 중 | 면이 어두워지고 안쪽 음영이 생김 | 메뉴·키패드·주요 버튼 |
| 키보드 초점 | 별도의 황동색 외곽선 | 메뉴·대화상자·키패드 |

사각 버튼은 별도 SVG 프레임 3종을 9분할로 사용한다. 긴 글자에도 모서리를 늘이지 않는다. 이전 스타일이 색을 다시 덮어쓰던 브리핑·일시 정지·스킬 버튼의 중복 규칙을 정리했다. 새 버튼 스타일은 `src/ui-controls.css`에서 관리한다.

모바일 원형 버튼은 기존 크기와 배치를 유지하며 프레임 4종의 색과 재질을 맞췄다. 평소는 회청색, 사용 가능은 황동색, 길게 눌러 처치는 붉은색이다. 선택과 누르는 상태도 별도로 표현한다. 아이템 하단 슬롯도 같은 강조색을 사용한다. 화면 흔들림·자동 클릭·공격 판정을 추가하지 않았다.

## 확인

- 인게임 HUD 5개 크기: 무전·목표·버튼 간 겹침, 조용한 상태와 위험 상태의 우선순위 통과.
- 장비 4개 크기: 장비를 선택해도 발사하지 않음, 시간 정지·복귀, 키보드 초점 유지, 짧은 화면에서 7개 장비 접근 통과.
- UI 4개 크기: 버튼이 화면 안에 있고 44px 이상인지, 일시 정지·복귀, 한국어 폰트 실사용, 폰트 다운로드 실패 시 시작 가능 여부 통과. 이전 폰트 검사 대상을 두 줄 출발 버튼의 실제 글자 요소로 수정했다.
- 기술 트리·옵션 각각 5개 크기: 실제 습득·재배분, 잠금 상태, 모달 초점과 복귀, 옵션 값 저장·재접속 통과.
- 조직도: 실제 모달 조작과 발견 정보·기절/사살·체크포인트·옛 저장 구분 통과.
- 빌드 파이프라인 8개 검사 통과. 최종 패키지의 파일 일치와 PC·브라우저 터치 기본 조작도 검사했다.

이 검증은 브라우저 기반이며 실제 iOS 기기 검사가 아니다. 게임 규칙·난이도·구매 배경 에셋은 변경하지 않았다.
