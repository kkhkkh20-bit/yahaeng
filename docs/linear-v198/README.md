# v198: 선형 성장과 첫 암살

튜토리얼 이후 바로 여러 경비의 시야와 순찰 타이밍을 동시에 읽어야 했고, 기술 포인트를 쓰지 않고 임무 선택 화면으로 돌아갈 수 있었다. 이제 첫 실전에는 표적 한 명만 배치하고, 임무 완료 직후 기술을 직접 배운 뒤 다음 에피소드로 진행한다. 조직 건물의 깃발·표시 문구도 제거했다.

## 레퍼런스 조사

실제 개발자의 설계 자료와 공식 FAQ를 읽었다. 아래 게임을 이번 작업에서 직접 플레이하거나 영상을 전부 시청했다는 뜻은 아니다.

**강제 선형 진행과 에피소드 종료 후 포인트 사용은 사용자의 요청이다. 레퍼런스 게임 모두가 이 규칙을 사용한다는 주장이 아니다.** 추천 기술이나 자동 구매는 도입하지 않는다.

## 진행과 예외

`tB → p0 → p1 → p2 → e1 → e2 → e3 → m2 → m4 → m6 → m7`

- 첫 화면, 브리핑 돌아가기, 중단 후 돌아가기는 모두 선형 이어하기로 연결된다. 공개 에피소드 선택 화면은 열리지 않는다.
- 매 편 성공 시 실제 기술 트리가 열린다. 원하는 기술을 선택하고 직접 배우며, 배울 수 있는 기술이 남아 있으면 다음 편으로 넘어갈 수 없다.
- 남은 포인트로 배울 수 있는 기술이 없으면 포인트를 이월한다. 모든 기술을 배운 경우와 마지막 에피소드도 막히지 않는다.
- 실패 시 현재 편 재시도는 유지하고, 기존 저장의 완료 기록·기술은 지우지 않는다.
- 첫 표적도 정상 시야·소리·접촉 감지를 사용한다. 정면 접근은 여전히 발각될 수 있다.

## 검증 방법

- `t_linear_campaign.py`: PC, 390px, 가로 모바일, 320px에서 완료·진행·포인트·선행 조건·이월·실패·완주 기록을 통제한 상태로 UI 구매와 게이트를 검증한다.
- `first_steps_live.py`: 새 저장과 실제 입력으로 튜토리얼 → 포인트 사용 → 첫 암살 → 포인트 사용 → 변장 에피소드까지 진행한다. 배우·체력·시간·진행도 덮어쓰기는 없다. PC와 CDP 터치 모두 첫 암살 체력3, 발각0이었다.
- `first_night_live.py`: p0의 독립 실행을 초기 조건으로 사용하고, 실제 입력으로 p0/p1/p2와 매번 포인트 사용을 검증한다. 두 환경 모두 완료했고 CCTV 작업 실수와 실제 체크포인트 복구도 확인한다.
- 다른 특정 임무·선택 기술·선택 연습 검증은 `standalone_stage`로 초기 임무만 설정한 뒤 실제 입력을 사용한다. 이는 공개 미션 선택 기능이나 처음부터 끝까지 선형 진행을 했다는 증거가 아니다.
- 기존 선택 화면을 클릭하던 검증은 이 초기 조건과 새로운 이어하기로 이관했다. 휘파람·선택 연습·본편의 상호작용 검증은 별도 시나리오에 남아 있다.

이 재플레이는 맵을 아는 개발용 자동 조작이다. 첫 사용자 이해도나 실제 iOS 기기에서의 재미를 입증하는 사용자 조사는 아니다. 핵심 회귀, 실제 입력 시나리오와 배포 검증 결과는 연결된 PR의 CI와 아티팩트를 함께 본다.
