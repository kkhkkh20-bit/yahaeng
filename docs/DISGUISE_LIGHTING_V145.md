# v145 변장과 실내 조명

허용 복장이 달리기·웅크린 이동까지 의심에서 제외하고 일반 경비의 근거리 신원 확인을 건너뛰던 규칙을 수정했다. 방 조명은 확률적으로 생기는 반경 115px짜리 등 하나에 의존해, 사무실이나 벽으로 나뉜 공간이 통째로 어두울 수 있었다.

[PC·모바일 전후 화면과 소등 비교](balance-v145/index.html)

## 변경한 규칙

- 복장은 일반 출입에만 통한다. 금고 구획과 의뢰에 지정한 주요 상층 사무실은 복장으로 통과할 수 없고 HUD에 ‘보안구역’으로 표시한다. 열쇠·카드의 문 개방 기능은 유지한다.
- 같은 복장의 일반 경비와 고정 경비도 제한구역에서 105px 이내에 오래 머무는 사람의 신원을 확인한다. 정상 정면 확인은 5.5초, 수색 경보 중에는 3.5초다. 기존 반장·정예의 확인은 3초다. 뒤돌아 서면 느려지지만 영구 면제되지 않는다. 실제 시야·층·벽 조건을 사용하며, 거리나 시야를 벗어나면 확인이 줄어든다.
- 정상 보행은 유지하되 제한구역의 달리기·웅크린 이동은 복장만으로 의심이 사라지지 않는다. 확인 중에는 눈 표시와 HUD 안내를 사용한다.
- 바닥에 놓인 옷과 쓰러진 인물의 옷 모두 갈아입는 데 3초가 걸린다. 완료 전에는 새 복장이 적용되지 않으며 목격되는 동안 불법 행동으로 판정한다. 반복 입력으로 시간을 줄이거나 중복 적용할 수 없다.
- 보안구역과 범행을 촬영하는 CCTV에 복장만으로 0.12배 속도 보정이 붙던 규칙을 제거했다. 허용 구역의 정상 직원과 공개 구역의 행인은 기존대로 지나갈 수 있다.
- 본편 6개 의뢰와 도시의 업무 공간에 차폐를 고려한 천장 조명을 보충했다. 점등된 보행 가능 업무 타일 2,519곳의 게임 밝기는 최소 0.662다. 실제 경비 발견 거리도 함께 증가한다. 클럽 홀의 색 조명, 취침 주택과 야외의 어둠은 유지한다.
- 스위치·분전반으로 불을 끄면 실제 밝기도 내려가며 복구 행동은 유지한다. 기존 저장에서 이미 꺼뜨리거나 부순 등은 켜지지 않는다. 새로 보충되는 등도 해당 건물의 차단된 회로 상태를 따른다.
- 조명 변경 시 쓰러진 사람의 밝기를 각자의 층에서 갱신한다. 고해상도 모바일에서 움직이는 은닉 시설이 잘못된 위치의 어둠 마스크를 읽어 밝아지던 좌표 계산도 수정했다.

## 검증

새 통제 검사는 업무 공간 밝기, 정상 복장 통과·보안구역 거부, 일반 경비의 실제 신원 확인, 거리·층 분리, 점등에 따른 실제 시야 증가, 보안구역 CCTV, 쓰러진 인물의 층별 밝기, 이전 저장의 체력·차단 회로 보존을 확인한다.

기존 빠른 묶음은 40개 중 39개가 첫 실행에 통과했다. 한 검사가 예전의 ‘뒤돌아 서면 영원히 확인되지 않는다’는 규칙을 기대해 실패했으며 새 규칙과 탈출 여유 시간을 검사하도록 수정했다. 도달 검사의 별도 실패는 이미 폐기한 장식용 배관과 비진입 지붕을 여전히 필수 등반로로 요구한 것이어서, 본편의 실제 계획된 접근로를 검사하도록 고쳤다. 변경한 검사와 도달 검사는 최종 재실행에 통과했다. 변장·CCTV·층별 조명·저장 호환 통제 검사, 실제 PC·터치 갈아입기, 조명 시설 상태 보존, PC·DPR 2 모바일의 두 테마 은닉 시설 조명 검사도 통과했다.
