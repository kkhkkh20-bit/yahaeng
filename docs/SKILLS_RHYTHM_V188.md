# 기술 준비와 제압 후 흐름 (v188)

기술 포인트는 시작부터 4P가 있지만 기존 화면에서는 메뉴 안의 기술 트리를 찾아야 했다. 의뢰 보상도 상세 기록에 있어 다음 기술을 배울 시점을 놓치기 쉬웠다. 공격 동작을 마칠 때 다시 누른 공격은 버려지고, 몸이 이미 내려간 뒤에도 이동을 기다려야 했다.

## 배울 시점과 순서

본편 의뢰의 브리핑에 사용 가능한 포인트와 추천 경로를 작게 표시한다. 출발 버튼은 기존 고정 푸터에 둔다. 기술 화면을 열고 닫으면 같은 브리핑으로 돌아오고 출발 전 시간을 진행하지 않는다. 완료 화면에서는 새로 사용할 포인트를 보여 주며 기술을 골라도 완료 결과를 유지한다.

추천은 실제 선행 조건으로 계산한다. 처음에는 제압 숙련 → 은신 기습(2P), 다음으로 접근 암살(남은 2P)을 선택해 시작 4P로 기습·접근 공략을 준비할 수 있다. 빠른 잠행은 가벼운 발 → 조용한 잠행 → 빠른 잠행(총 4P) 경로다. 다트와 동시·연속 암살도 현재 보유 기술에 맞춰 안내한다. 추천 경로를 누르면 아직 배우지 않은 첫 기술을 보여 주고, 배운 뒤에는 설명 창 안에서 다음 단계를 확인한다. 포인트를 자동으로 쓰지 않는다.

의뢰 중에는 기존 메뉴에 남은 포인트만 표시한다. 전투를 멈추거나 팝업을 자동으로 띄우지 않는다. 재배분은 의뢰 선택·출발 전·완료 화면에서 가능하고, 진행 중인 의뢰에서는 계속 금지한다. 장비 지급, 맨손 시작, 기존 저장의 포인트 예산과 일회성 보상 규칙을 유지한다.

## 접근 → 접촉 → 내려놓기 → 다음 행동

일반 제압의 마지막 0.22초에 새로 누른 공격 하나를 받아 둔다. 누른 순간의 가까운 적 하나에 묶으며, 실제 접촉 범위와 배운 접근 암살의 사거리만 사용한다. 처리 시점에도 거리·후방·벽·층·발각 여부를 다시 확인한다. 짧게 눌렀다 뗀 입력은 기절이고, 다른 키의 긴 누름을 빌려 처치로 바뀌지 않는다. 이동·피격·대상 이탈·메뉴·입력 취소로 예약을 지운다. 다음 대상으로 자동 전환하거나 추가 적을 자동 처리하지 않는다.

몸이 내려간 뒤 이동을 입력했으면 마지막 정리 동작을 짧게 마치고 이탈한다. 실제 몸이 생기기 전에는 끊지 않고, 계속 눌러 처치하는 의도가 남아 있으면 먼저 그 의도를 마친다. 기존 옷 갈아입기·몸 정리 예약은 우선한다. 입력을 하지 않으면 기존 전체 동작을 재생한다.

지상 발소리의 시계를 실제 이동 거리와 보행 애니메이션에 맞췄다. 모서리에서 거의 움직이지 않는데 일정한 발소리를 내는 현상을 줄인다. 이동 속도·공격 피해·경비 시야·일반 복장 통행 판정에 보너스를 주지 않는다. 타이밍 점수나 강제 리듬 입력은 추가하지 않는다.

## 검증

기술 준비 검사는 PC·휴대폰 세로·가로 화면에서 실제 포인트 구매, 다음 선행 기술 안내, 출발 버튼 가시성, 브리핑·완료 화면 복귀와 의뢰 중 재배분 금지를 확인한다. 입력 검사는 실제 키보드/CDP 터치를 사용하고 장면을 제어해 짧은 후속 제압·취소·다른 키의 살상 의도 차단·실제 접근 이동·미습득 사거리 제한·몸 내려놓기와 이동 해제·걸음/발소리 시계 동기화를 확인한다. 제어된 입력 검사는 전체 의뢰의 실시간 완주를 뜻하지 않는다.

알려진 VIP 경로 재생에서는 출발 전에 추천 경로로 2P를 직접 쓰고, 완료 후 빠른 잠행 경로에 4P를 직접 쓴다. 모든 경비와 카메라를 활성화하고 실제 이동·상호작용·공격 입력을 사용한다. 스킬·체력·장비·목표를 강제로 바꾸지 않는다. 사전 정보 없는 이용자의 첫 플레이나 실물 휴대폰 실험은 아니다.

검사 결과: 핵심 회귀 84개가 통과했다. 기술 준비 화면은 Chromium과 WebKit에서 각각 PC 1280×800·휴대폰 390×600·가로 844×390을 통과했다. 모바일의 알려진 경로 재생은 모든 NPC를 켠 고정 시계로 163초·체력 3으로 완주했으며, 출발 전 2P와 완료 후 4P를 실제 기술 화면에서 사용했다.
PC 일반 RAF·비고정 난수 재생도 202초·체력 3·직접 발각 0회로 완주했고 같은 2P/4P 구매 흐름을 통과했다. 경로와 순찰을 아는 재생의 시간이며 초보 이용자의 소요 시간이나 개선 전후 속도 비교 수치가 아니다.
