# 의뢰 01–03 지도 활용 확장 (v187)

표적과 물건이 북쪽에 몰려 남쪽 건물은 방문할 이유가 약했다. 기존 지도와 에셋을 사용하면서 목표의 이유와 지리적 연결을 보강한다. 건물 전체를 의무적으로 순회시키지 않고, 각 의뢰에 성격이 다른 잠입 구간을 하나씩 넣는다.

## VIP · 장부를 해독할 거래 암호표

사무동 1층 장부에 적힌 가명을 남동쪽 회계 숙소 2층의 암호표와 대조한다. 실장과 장부만 처리하면 끝나던 의뢰가 북서쪽 사무동에서 남동쪽 숙소까지 이어진다. 보관함 앞에서는 실제 경비의 왕복 순찰과 휴식 방향을 관찰한다. 경비 재킷은 숙소의 정상 통행을 허용하며, 서류를 훔치는 행동은 목격되면 수상하다.

흡연 매복·구토제 유인·간판 사고·장부 선회수 후 내선 호출은 유지한다. 내선 호출은 장부만 확보해도 가능하며, 암호표 때문에 실장을 불러내지 못하는 순환 조건을 만들지 않는다. 거래 암호표는 다른 목표와 같은 회수 물품으로 브리핑과 HUD에 표시한다.

## 대청소 · 북쪽 카드키와 남서쪽 금고

현금은 기존 창고 금고에 둔다. 계약서는 사무동의 다른 금고에서 남서쪽 조직 숙소 2층 금고로 옮긴다. 사무동 2층 보안실의 초록 카드가 그 금고를 열며, 빨간 카드나 사무동 문을 열었다는 사실로 대체할 수 없다. 숙소의 실제 왕복 순찰이 금고 앞을 살피므로 도착 후에도 관찰과 접근이 필요하다.

북서쪽 폐사무소 입구에는 연락책이 남긴 예비 조직원 재킷을 둬, 사람을 제압하지 않고도 잠입을 준비할 수 있다. 수금원과 경호원의 동선은 포차 남쪽 정산 골목까지 이어진다. 큰길의 빠른 공격과 간판 사고 외에 사람이 적은 남쪽에서 기다릴 선택이 생긴다. 창고 쪽지와 북서쪽 연락책 메모는 모두 실제 사무동 비밀번호를 알려 준다. 초록 카드 설명과 대화, 기회 단계, 목표 안내가 남서쪽 금고를 가리킨다.

## 배신 · 감금동에서 남동쪽 자재 창고로

감방에서 맨손으로 시작하고, 제비의 무전기는 감금동 2층에 둔다. 추가 목표인 까마귀 인계서는 남동쪽 자재 창고 보관함에 둔다. 무전기에 남은 연락과 서명된 인계 기록이 배신의 증거와 다음 의뢰의 집하장 단서가 된다. 무전기만 얻고 바로 남쪽 개구멍으로 나가던 경로는 창고 잠입을 거쳐야 한다.

창고에는 왕복 순찰을 둔다. 조직원 복장으로 마당과 창고를 걷는 것은 허용되지만 보관함을 뒤지는 모습은 감시를 피해야 한다. 감금동 2층 보안구역의 복장 제한은 그대로다. 압수품 회수는 선택이며 새 목표가 기술이나 장비를 자동 지급하지 않는다. 빠른 완료 도전 시간은 확장된 동선에 맞춰 420초로 조정한다.

## 저장 호환과 표시

이전 체크포인트는 체력·복장·키·제압한 적·확보한 물건을 보존한다. VIP와 배신에는 아직 확보하지 않은 새 물건과 감시자를 추가한다. 대청소는 아직 회수하지 않은 계약서만 새 금고로 옮기며 이미 얻은 계약서는 다시 요구하지 않는다. 기존 숙소 경비와 수금원의 순찰은 기존 배우를 유지해 갱신한다. 반복 이어 하기에서 감시자를 중복 생성하지 않는다.

새 목표의 브리핑·의뢰 카드·지도 미리보기·HUD·층 안내를 연결한다. 금고 회수는 단말 작업과 구분하고 기존 새벽 배송의 작업 완료 문구도 유지한다.

## 검증의 범위

핵심 회귀 묶음 82개와 전체 지도 도달 검사를 실행한다. 변경 후에는 교차 구역 카드 조건, 새 회수 목표, 계단과 가구 접근, 이전 체크포인트의 물품·경비 이관을 별도로 재검사한다. 기존 새벽 배송의 단말 작업도 확인한다.

실제 키보드와 CDP 터치로 알려진 경로를 재생하며 모든 NPC와 CCTV를 활성화한다. 플레이어·적 위치, 체력, 인벤토리, 기술, 경보와 목표를 강제로 바꾸지 않는다. 필요한 기술은 실제 기술 화면에서 시작 포인트로 배우고, 도구는 실제 보급품에서 얻는다. 지도 좌표와 순찰 상태를 읽는 숙련 재생이므로 사전 정보 없는 이용자 연구나 실물 휴대폰 검사는 아니다. VIP의 PC 재생은 일반 RAF, 모바일 재생은 재현 가능한 고정 시계로 검증한다. 구체적인 완주 기록과 검증 명령은 변경 PR에 남긴다.


최종 확인: VIP는 PC 일반 RAF와 모바일 고정 시계, 배신은 PC·모바일 일반 RAF 입력으로 완주했다. 대청소는 실시간 PC에서 재킷 준비·남쪽 표적 처치까지 확인했다. 실제 저장으로 이후 구간을 재개하던 중 실행 환경이 오프라인이 되어 최종 완주 결과는 확인하지 못했다. 대청소의 전체 목표·키·층 이동·탈출 경로는 NPC를 정지한 진행 검사와 별도 카드·금고·체크포인트 검사로 확인했다. 모든 의뢰를 미발각으로 완주했다는 의미는 아니다.
