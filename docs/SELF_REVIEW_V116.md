# v116 자체 리뷰와 개선

## 리뷰 결과

식사 유인이 문지기를 길 건너 먼 공중화장실로 보내는 데 그쳤다. 접근에 시간이 걸렸고, 경비복을 얻어 조직 건물에 들어가는 보상이 잘 이어지지 않았다. 식탁과 행동 지점도 화장실을 추가하면서 다시 맞출 필요가 있었다.

## 반영 내용

- VIP 의뢰의 포차에 작은 화장실을 배치했다. 기존 식당의 25칸 영역 안에서 식탁·의자·벽·문을 조정하고, 오른쪽 계단 통로와 왼쪽 이동 통로를 유지했다.
- 양념통과 식사·약 투입 지점이 같은 식탁을 사용한다. 문지기는 식사 후 식당 화장실로 직접 걸어가며, 문에서 뒤로 접근해 붙잡을 수 있다.
- 약 준비 뒤에는 한 줄로 `경비복 확보`를 안내한다. 기절 → 옷 갈아입기 → 사무동 출입으로 연결되며, 옷을 얻으면 안내가 끝난다. 이미 발각된 경비복은 다시 권하지 않는다.
- 실장의 구토제 경로는 골목 공중화장실을 계속 사용한다. 두 화장실이 서로 점유를 막지 않는다.
- 화장실 조명은 벽 스위치로 조작한다. 문지기 뒤로 접근하는 입구에서 광원 조작 버튼이 겹치지 않도록 했다.
- 이전 저장의 식사 목적지·이동 불가 위치·광원 범위를 새 배치에 맞춘다. 이미 옛 공중화장실에 도착한 방문은 기존 위치와 남은 대기 시간을 유지한다. 새 화장실 잠금 상태도 복원한다.

## 검증

Chromium과 Playwright로 검사했다. 모바일 입력은 터치 버튼과 가상 조이스틱을 사용했다. 실제 iPhone Safari 기기 검증은 포함하지 않는다.

- `t_uniform_walkthrough.py`: PC 키보드 / 모바일 조이스틱 × 배치 3종. 약국 → 양념통 → 화장실 → 붙잡기 → 짧은 공격으로 기절 → 경비복 → 사무동 진입. 6회 모두 사망자 0명, 약 122초. 이 6회는 문지기만 실시간 AI를 사용하고 다른 NPC는 고정한다. 추가 2회는 고정 시드 116에서 전체 NPC·CCTV를 작동시킨 PC / 모바일 검사다.
- `t_restaurant_route.py`: 식당·주방·계단의 이동 가능 21칸 연결, 수정 영역 밖 1,991칸 보존, 화장실 시야 차단·잠금·해제·저장, 두 화장실 점유 독립, 수동 목표와 안내 끄기 우선, 이전 저장 복원, 벽 스위치 접근.
- `t_surfaces_dining.py`: 전체 39명 장면의 식사·화장실·복귀와 실제 키보드 / 터치 약 투입. 전체 장면에서 식사 약 74초, 식당 화장실 도착 약 98초. 경로 고립 검사도 별도 통과.
- `t_mission_flow.py`: 기존 의뢰 6개 × 배치 3종 × PC / 모바일, 36개 완료 경로.
- `t_product_plan.py`, `t_rendezvous.py`, `t_building_search.py`, `t_controls_readability.py`, `t_review_v115.py`: 기존 조건·호출·실내 이동과 수색·화면 크기별 가독성 회귀 검사.

전체 과거 테스트 모음이 모두 통과한다는 뜻은 아니다. 이번 변경과 관련된 위 검사를 실행했다. 스크린샷은 입력 경로의 체크포인트를 복원해 촬영했으며, 다른 NPC를 고정한 촬영 조건은 갤러리에도 표시했다.

## 남은 개선점

식사 유인 한 경로를 더 자연스럽게 연결한 단계다. 모든 의뢰에 동일한 구성을 복제하기보다, 이후에는 다른 공간에서도 준비가 접근 권한·정보·표적의 동선 변화로 이어지는지 따로 검토해야 한다. 첫 시도에서 이 경로를 스스로 발견하는 비율과 약 2분의 대기·이동 비중은 실제 플레이 피드백이 더 필요하다.
