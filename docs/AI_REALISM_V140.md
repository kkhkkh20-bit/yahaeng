## 실제 변경

- **목격과 전달:** `rememberSuspect(g)`는 해당 경비에게만 기록한다. 전역 인상착의는 무전이 실제로 끝났을 때 기록한다. 주민이 직접 경비에게 전달한 신고도 우선 그 경비에게 남는다.
- **들리는 보고:** 같은 층·높이와 거리, 기존 벽 감쇠를 확인한다. 들은 경비는 전달받은 마지막 위치를 수색하며, 보지 못한 플레이어를 즉시 공격하지 않는다. 관계없는 멀리 있는 무전 경비를 자동으로 보고자로 선택하던 경로를 제거했다.
- **무전 차단:** 직접 목격자 또는 실제로 들은 무전 경비만 보고한다. 붙잡거나 제압하면 전역 인상착의 전달을 중단한다. 숨은 뒤 바꾼 옷·현재 위치는 보고에 섞이지 않는다.
- **현장 확인:** 몸에 접근해 시야를 확보한 뒤 기절자는 1.2초, 사망자는 0.9초 동안 상태를 확인한다. 경비가 몸을 낮추고 짧게 말한다. 상태 확인 전에는 깨우거나 발견 집계를 올리지 않는다.
- **역할 분담:** 현장마다 한 명만 확인한다. 실제로 몸을 본 동료 한 명은 주변을 경계한다. 담당자가 제압되면 다른 목격자가 맡을 수 있다. 몸을 옮기거나 숨기면 진행하던 확인을 취소한다. 한 사람을 여러 번 깨우거나 중복 집계하지 않는다.
- **기절자의 증언:** 정면에서 실제로 본 옷은 피해자와 깨운 동료가 기억한다. 뒤에서 당했다면 범인의 인상착의를 모른다고 말한다. 시체 발견만 보고한 무전은 수색 범위를 넓히지만 범인의 얼굴을 생성하지 않는다.
- **기존 체계 연결:** 목격을 놓친 뒤 건물 수색을 모집하는 경로에도 들리는 보고 범위를 적용했다. 다른 층 비명을 무조건 듣던 예외를 제거했다. HUD는 ‘목격자가 기억함’과 ‘인상착의 무전됨’을 구별한다.

## 검증 범위와 한계

`tests/rev/t_ai_evidence.py`는 실제 m2 지형에서 인물 배치만 통제하고 실제 AI 함수를 실행한다. 벽·층·높이·거리, 다른 무전 경비의 부당한 선택, 보고 차단, 옛 인상착의 유지, 동료 확인 시간, 역할 소유·해제, 중복 방지, 정면/후면 기절자의 기억, 신원 미확인 시체 신고를 PC와 터치 브라우저에서 검사한다.

기존 변장·유인 소리·물리적인 조명 복구·건물/은신처 수색·보안 대응·공격/운반·의뢰 진행 테스트도 실행한다. 첫 두 튜토리얼은 AI를 켠 채 키보드와 실제 브라우저 터치 입력으로 완주한다. 의뢰 36개 경로 검사는 NPC를 통제하는 진행 회귀 검사이며, 자연 플레이 난이도 검증으로 해석하지 않는다.

말소리는 기존 직선 벽 감쇠 모델을 사용하며 실제 실내 음향 계산은 아니다. 전략적 경계 단계·정기 무전 점호·보안 대응에는 기존 게임의 추상화가 남아 있다. 실물 휴대폰의 발열·FPS 측정은 이번 브라우저 검사에 포함되지 않는다.
