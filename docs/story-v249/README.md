# v249: 에피소드 연결·대화 비율·실내 조명

공개 9편에 진입 이유, 현장 단서 무전, 완료 뒤 대사를 연결했다. 기존 목표·보상·맵 구조는 유지했다.

배차실 서류 → 박인호 → 문서윤의 장부 → 클럽 암호표 → 정산 증거 → 철수 차량의 함정 → 구금동 인계서 → 새벽배송 명세서 → 까마귀 본부 → 윤서경의 사저.

m4 완료와 보상을 저장한 뒤 까마귀의 철수 지시, 주인공의 이상 징후 발견, 차량 문 잠김과 무전 단절을 순서대로 보여 준다. 완료 지도 위의 짧은 대사/현장 기록이며, 차량 승차 애니메이션은 아니다. m6의 시작 대사에서 구금 경위를 이어받는다. 배신 이후 무전 화자는 주인공이며, 마지막 제비의 음성은 ‘녹음’으로 표시한다.

완료 대사는 첫 클리어에만 표시한다. Space/탭으로 읽거나 Esc로 건너뛰면 기존 결과와 기술 화면으로 이어진다. 재도전은 빠른 결과 흐름을 유지한다. 도중에 닫아도 이미 저장한 클리어·보상을 잃지 않는다. 현장 이야기 무전은 추격 안내에 양보한다.

초상화 프레임과 캔버스를 정사각형으로 맞췄다. PC 80px, 모바일 60px, 짧은 가로 화면 48px. 무전 초상은 40/34/30px. 모달 대화 중 행동 패드는 숨기고 긴 글은 스크롤한다.

깨어 있는 사람이 사용하는 방과 순찰 지점에 벽 조명을 보충한다. 공개 9편의 어두운 실내 시작 위치 11곳을 해소했고 등기구 20개를 기존 스위치 회로에 연결했다. 잠든 사람이나 빈 방 때문에 조명을 추가하지 않는다. 꺼짐·파손·차단기를 복구하지 않으며 구버전 체크포인트의 정전을 새 등으로 우회하지 않는다.

## 검증

- `t_episode_continuity`: 완료를 주입한 장면에서 보상 저장 → 철수 함정 → 기술 화면, 건너뛰기, 재도전, 녹음 화자, 추격 우선순위를 PC·터치로 확인. 전체 9편 실제 완주 검사는 아니다.
- `t_occupied_lights`: 9편 실내 인물의 시작 조도, 20개 추가 등의 벽 부착, 중복 생성 방지, 새/구 체크포인트 정전·체력·아이템 유지.
- `t_dialogue_proportions`: 320×568, 360×740, 390×844, 568×320, 844×390, 1280×800의 기본/ink 화면. 타이핑 중 크기 고정, 잘림/겹침, 긴 글 스크롤, 터치/Space, 초상 없는 기록창 확인.
- 실제 RAF/AI를 유지한 첫 에피소드 PC·터치 입력 완주: 각각 체력 3, 발각 0, 기절 2. 변장·몸 숨기기·서류 회수·층 이동·완료 대사·기술 습득·다음 의뢰 진입까지 확인.
- 별도 인물 없는 사무실 fixture에서 실제 스위치 입력: PC·터치 조도 1 → 0.04 → 1. 임무 난이도 검사는 아니다.
- 표면 조명/문 차폐, 변장과 조명, 에피소드 경로, 기존 무전, 27맵의 외부 조명 425개 접근, 빌드 파이프라인 8개와 물리 상호작용 20개 묶음 통과.
- 보스 회귀 검사의 옛 사물함 좌표는 v247에서 이미 바뀐 실제 위치(13,8)로 수정했다. 구 위치에서의 저장 복원·신체/의상 정체성 유지 검증은 유지한다.
- 모바일은 Chromium 터치 에뮬레이션이며 실제 iPhone/Safari 기기 검사는 아니다.
