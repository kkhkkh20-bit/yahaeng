# v245 — 여성 닌자와 복장 구분

기존 맵의 캐릭터 크기와 8방향 동작에 맞춰 주인공을 다시 제작했다. 짙은 남색 랩 잠입복, 허리선, 짧은 붉은 허리띠, 묶은 검은 머리, 작은 칼집으로 구분한다. 허리띠는 기존 다리 움직임에 맞춰 조금만 흔들리고 정지하면 멈춘다. 얼굴과 머리 팔레트는 변장 의상과 분리되어 있다.

잠입복·경비 제복·작업복·정장 네 몸체의 기본/이동/작업/전투/쓰레기통 뚜껑 동작을 모두 재생성했다. 정장 변장이 기본 잠입복으로 표시되던 연결도 전용 정장으로 고쳤다. 무전·대화의 주인공 초상화도 같은 머리와 잠입복으로 교체했다.

주민은 긴 코트, 작업 조끼, 짧은 재킷을 추가하거나 실루엣을 변경했다. 일반 경비는 가벼운 제복, 정예 경비는 기존 장비 복장을 사용한다. 조직의 올리브색 제복은 유지한다. 명시적으로 제작한 간부 9명의 복장과 어린이는 보존한다. 새로운 자동 배정 복장은 스테이지 생성 때 적용하며, 기존 저장 데이터에 기록된 주민의 몸체는 강제로 교체하지 않는다.

## 실제 화면

- [8방향·주요 동작·복장 비교](wardrobe-gallery.png): 실제 게임 렌더러와 출하 스프라이트를 사용한 검수 배치. 방향과 동작 시간을 설정한 비교 자료다.
- [PC 기절 직전](pc-native.png), [모바일 변장 직후](mobile-native.png): 일반 RAF와 활성 AI에서 키보드/CDP 터치를 사용해 진행한 첫 에피소드. 캐릭터 위치·체력·시계의 강제 변경 없이 촬영했다.
- [PC 진행 기록](pc-native.json), [모바일 진행 기록](mobile-native.json): 기절 2회 → 경비복 변장 → 운반/숨기기 → 계단 → 서류 회수 → 탈출. 양쪽 모두 체력 3, 발각 0. 맵을 알고 수행한 개발자 플레이이며 초보자 테스트나 실물 iPhone 테스트는 아니다.

## 검증

- 네 주인공 복장의 **22,176 프레임**이 비어 있지 않고 잘리지 않음.
- 38,176개 연속 동작 프레임 검사, 암살자/피해자 각 25프레임과 등반 손 접촉, 이동 거리 기반 보행, 차가운 이미지 캐시의 대체 표시 검사 통과.
- 네 복장 × 등반 손 접촉 17개 = 68개, 네 복장의 걷기/달리기/웅크림/암살/기절/운반/등반/변장 소스와 얼굴 유지 검사 통과.
- 코트/조끼/재킷/일반 경비 기본 동작 2,472 프레임 경계 검사 통과. 27개 스테이지에서 새 복장 사용, 명시적 간부/어린이/조직색 유지 검사 통과.
- PC/모바일 이미지 지연 로딩과 사용하지 않는 몸체 해제, 기존 인물 초상화·들개·창문 미리보기 회귀 검사 통과.
- 빌드 파이프라인 8개, 물리 상호작용 20개 그룹 통과.
- 기존 `t_motion_tracks.py`는 작업/변장 동작을 `openHigh/openLow`만 허용해 실패한다. 변경 전 v244에서도 동일하게 실패하는 오래된 단언이다. 이미 도입된 `workHigh/workLow/dress`를 다루는 연속 동작/이번 복장 검사는 통과했다. 이 외형 작업에서 동작 로직을 옛 방식으로 되돌리지 않았다.

## 제작과 범위

런타임은 기존 2D 스프라이트다. 기존 Quaternius CC0 몸체·관절을 오프라인에서 조합하고 `tools/prerender/wardrobe.js`의 복장 디테일을 붙여 다시 출력했다. 원본 머리와 초상화는 별도 생성한 그림이며 구매한 GuttyKreum 또는 Quaternius의 작품으로 표시하지 않는다. 원본 해시는 `agent_art/heads.json`과 `src/art/cast/portraits.json`에 기록했다. Quiet City 및 다른 유료 캐릭터 팩은 사용하지 않았다.

몸체 atlas는 기존 64px 셀·기존 월드 크기를 유지한다. 지도와의 밀도를 바꾸거나 캐릭터만 고해상도로 확대하지 않았다. 기존 그림자·조명과 팔레트 경로를 공유한다. 색상 채널은 기존 다섯 개에 밝은 노란색으로 인코딩한 허리띠 채널을 추가했다. 실제 표시 색은 붉은색이고 기존 의상에는 중립색 기본값을 적용한다.

미션·AI·조명·조작 규칙은 변경하지 않았다. 패키지 이미지 수는 313→331개, 전송 자산 크기는 약 16.96→18.70MB이며 필요한 복장만 지연 로딩한다.
