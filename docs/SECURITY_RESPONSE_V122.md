# v122 — 경비를 줄인 뒤의 위험

기다렸다가 직접 암살하는 방법은 계속 허용한다. 대신 경비를 여러 명 제거해도 남은 사람이 똑같이 움직이던 문제를 고쳤다. 처치 횟수나 플레이어 위치를 AI에 넘겨 난도를 올리지 않는다.

| 상황 | 실제 대응 |
| --- | --- |
| 아무도 보지 못한 처치·기절 | 즉시 정체가 드러나지 않는다. 실제 시체 발견이나 정기 무전 점검까지 조직은 모른다. |
| 무전에서 응답이 없거나 경비가 쓰러진 동료를 확인 | 해당 경비 한 명의 사건으로 기록한다. 무전과 시체 확인을 별개 피해자로 세지 않는다. 기존 현장 수색과 연결한다. |
| 최근 확인된 피해·응답 두절이 두 명 이상 | 기존 경비 중 최대 두 조가 2인 순찰한다. 같은 층의 순찰 가능 인원만 편성한다. 새 적을 생성하지 않는다. |
| 순찰 중 동료가 사라짐 | 마지막으로 실제 보았던 위치를 확인한다. 숨겨진 시체나 플레이어의 현재 위치를 따라가지 않는다. 유인·소리·수색 반응도 유지한다. |
| VIP 의뢰에서 위 상황 발생 | 실장이 VIP룸으로 걸어가 약 20초 머무른 뒤 기존 일과로 돌아온다. 이미 진행 중인 전화 호출·배탈 동선은 먼저 마친다. |
| VIP의 평상시 흡연 | 단독 대기 최대 10초. 확인된 이상이 있으면 7초로 줄고, 2인 순찰 단계에서는 호위가 곁을 지킨다. 놓쳐도 다음 흡연 방문을 기다릴 수 있다. |
| 준비한 전화 매복·화장실 유인 | 경계 중에도 별도 대기 동선을 유지한다. 준비를 하면 일상 동선을 기다리는 것보다 안전하게 고립시킬 수 있다. |
| 사고로 확인된 사망 | 응답 두절 기록에서 제외하며 다음 무전에서도 새 실종으로 처리하지 않는다. CCTV 관리자가 자리를 비웠다면 복귀 후 실제 확인해야 한다. |
| 새 확인 없이 시간이 지남 | 각 사건은 마지막 새 확인 후 100초 동안 대응에 반영된다. 같은 시체를 거듭 보거나 같은 무전에 계속 답이 없다는 이유로 무한 연장하지 않는다. |

목격하지 않은 범행으로 변장·얼굴을 공유하지 않는다. 현장을 보는 경비와 실제 범행을 본 경비의 지식을 구분한다. 시체를 내려놓는 동작이 끝나기 전에는 시체만 먼저 보여 발견되는 일도 막았다.

대응은 구역이 있는 일반 의뢰의 조직 경비에 적용한다. 연습·도시 모드는 제외하며, VIP 이동·흡연·호위 조정은 대표 의뢰 「VIP」에 적용한다. 목표·버튼·필수 준비 단계는 추가하지 않았다.

## 검증

- `t_security_response.py`: PC·모바일에서 무전 발생 전 무반응, 실제 무전 확인, 경비·CCTV의 시체 확인, 범인 신원 미공유, 피해자 중복 집계 방지, 사고 확인·관리자 복귀, 회복한 경비의 응답, 유인 반응, 동료의 마지막 목격 위치, 기존 저장·불러오기, 연습 제외를 검사했다. 관찰 조건을 분리하려고 인물·시체 위치를 설정한 검사다.
- `t_security_response_live.py`: 두 경비의 사망·시체 은폐와 플레이어의 하수도 대기를 시작 조건으로 두고 나머지 AI를 모두 실행했다. 3개 시드 × PC·모바일 6장면 모두 약 55.1초의 실제 무전 뒤에 강화가 시작됐다. 최대 두 조의 실제 이동, 약 81초 무렵 VIP룸 도착, 일과 복귀, 약 155~165초에 대응 해제, 발각 0회를 확인했다. 처음부터 끝까지 플레이한 검사는 아니다.
- `t_vip_showcase.py`: 전체 NPC·CCTV·탐지·피해를 켜고 약국→식당 유인→비살상 제압·변장→2층 단서→금고 장부→CCTV 무력화→내선 호출→사물함 매복→VIP 처치→서쪽 탈출을 실제 이동·일반 행동으로 완료했다. PC 3분 10초·체력 3·발각 0회, 모바일 3분 11초·체력 1·발각 3회. 좌표 이동이나 체력·열쇠·목표 달성 지급은 하지 않았다. 맵을 아는 자동화 검사이며 처음 접하는 사람의 재미 평가와는 구분한다.
- 흡연 일과의 반복 6장면, 구토제·간판·뒷문 12장면, 식당 변장과 전화 매복 경로, 제압 길게 누르기·후속 입력·안내·첫 의뢰 연결 검사도 통과했다.
- 기존 6개 의뢰 × 3개 배치 × PC·모바일의 36개 진행 경로가 통과했다. 이 검사는 NPC를 정지하고 이동·문·열쇠·목표·탈출의 연결을 확인한다.
