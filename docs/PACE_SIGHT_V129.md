# v129 — 걷기 속도와 시야 표시

2026-11-01 (한국 시간). 그래픽·카메라 각도·버튼 위치를 유지하고 새 클럽 구역의 이동감과 시야를 수정했다. 기존 2D 게임은 Cloudflare에 v128 고정본으로 별도 배포한다.

## 느리게 느껴진 원인과 수정

기존 본편의 이동 배율은 1.3인데 사선 시점 시제품은 1.0이었다. 이동량 자체가 본편보다 약 23% 적었다. 같은 월드 거리를 이동해도 사선 투영에서 화면 위아래 성분은 수평의 약 58%로 압축됐다. 두 효과가 겹쳐 특히 위아래 걷기가 느리게 보였다.

새 구역을 본편과 같은 1.3 배율로 복원하고, 사선 투영에 따른 방향별 이동량 차이를 보정했다. 경비의 경로 이동에도 같은 방향 보정을 적용해 주인공만 유리해지지 않도록 했다. 걷기·달리기·웅크리기·운반의 속도 비율과 충돌 판정은 유지한다. 걷는 거리에 맞춰 애니메이션 위상이 진행되며, 운반·붙잡기 중 걷기를 정수 시점 사이에서만 보간하던 부분도 실제 연속 위상으로 수정했다.

같은 입력으로 가속 구간 뒤 0.3초간 화면 이동량을 측정했다. 카메라 추적은 측정 중 고정했고, 수치는 **게임 시간 기준 px/s**다. 실제 기기의 FPS를 뜻하지 않는다.

시야와 지형의 축척이 다른 두 렌더러를 비교하는 수치이므로 같은 물체가 똑같은 시간에 지나간다는 뜻은 아니다. 새 사선 시점 안에서는 여덟 방향의 화면 속도가 일정해졌다. 동일한 활성 AI 경로의 회수·탈출은 v128 약 65초에서 v129 약 48초로 줄었고, 체력 3·기절 2·처치 0으로 완료했다.

## 프레임 저하가 게임 시간을 늦추던 부분

기존 루프는 프레임 간격에서 0.05초까지만 사용했다. 새 3D 장면이 10fps로 표시되면 실제 0.1초마다 게임은 0.05초만 진행돼 이동과 AI가 함께 느려질 수 있었다.

사선 구역에서는 경과 시간을 1/60초 이하의 작은 충돌 단계로 나누어 진행한다. 표시 주기를 60·30·10·5fps로 주입한 검사에서 1초 뒤의 게임 시간과 이동 좌표가 일치했다. 긴 멈춤은 최대 0.25초까지만 반영하고, 창 비활성화·전술 지도에서는 진행하지 않는다. 기존 2D 캠페인의 프레임 정책은 유지한다. 이것은 화면을 더 많은 FPS로 그리게 하는 최적화와는 구별된다.

## 시야 표시

- 의심 단계에 진입하거나 선택해야만 보이던 경비 시야를, 보이는 같은 층의 경비에 평상시부터 표시한다.
- Canvas에서 건물 위에 덧칠하던 부채꼴을 깊이 판정이 있는 지면 메시로 옮겼다. 벽·지붕·소품이 표시를 가린다.
- 기존 AI의 시야각·벽 광선·조도 샘플을 공유한다. 각 영역의 중심점은 실제 `canSee` 판정을 통과해야 표시한다. 웅크리기와 낮은 엄폐도 반영한다.
- 평상시와 의심·발각 색을 구별한다. 공격 가능한 대상이라는 이유만으로 선택 링을 빨갛게 표시하지 않는다.

닫힌 문 앞 중심 광선은 72게임 단위에서 멈췄고, 같은 문을 정상 행동으로 열면 204까지 보였다. PC/모바일에서 평상시 시야 표시·층 구분·깊이 판정·웅크린 영역 208개 중심점의 실제 감지 판정 일치를 확인했다.

## 검증

`tests/rev/t_club_pace.py`, `t_club_clock.py`, `t_club_sight.py`, `t_club_study.py mobile`, `t_club_handling.py`와 기존 전투 정책·계단 검사를 실행했다. 소프트웨어 Chromium 및 터치 화면 환경이다. 실물 휴대폰 성능 검증을 완료한 것으로 표현하지 않는다.
