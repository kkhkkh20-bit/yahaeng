# Godot VIP 비교판 · 2026-11-04

기존 리소스를 Godot에서도 사용할 수 있는지 실제 프로젝트로 검증했다.
원작 웹 캠페인의 v176 소스·플레이 화면·진행 저장은 유지했다.
별도 `godot/` 프로젝트와 `/godot-vip/` 웹 비교판을 추가했다.

## 범위와 판단

클럽 한 구역, 연결된 2개 층에서 실장 제거 → 장부 회수 → 탈출을 플레이한다.
캐릭터·8방향 모션·짝 모션·가구·타일·효과음·PixelFX·한국어 서체는 기존 자산이다.
캐릭터를 다시 생성하지 않았고, 원본에서 애니메이션별 스트립만 추출했다.
활성 스트립은 최대 640×512여서 원작의 15,872px 시트를 직접 GPU에 올리지 않는다.
변환·복사한 36개 원본 기록은 `godot/assets/SOURCES.json`에 SHA-256과 함께 보관한다.
GDScript·셰이더·충돌·시야·경비·HUD는 Godot용으로 다시 작성했다.

엔진 이식의 이점은 물리 충돌, 독립된 층 레이어, 애니메이션 자원과 실제 raycast를
일관된 엔진 기능으로 다룰 수 있다는 점이다. 시각적인 완성도나 게임의 재미가
엔진만 바꾸면 완성된다는 뜻은 아니다. 현재 맵과 연출은 비교용 프로토타입이다.
전 캠페인·CCTV·기록 삭제·운반·상점·기술 트리·세이브는 이식 범위에 포함하지 않았다.

## 직접 플레이 후 수정한 문제

- 경비의 경로 재계산이 출발 셀의 중심으로 되돌리는 버그를 수정했다.
- 시야 경계에서 한 번의 추격을 여러 번 발각으로 집계하는 문제를 수정했다.
- 문과 실제 시야에 층별 물리 레이어를 사용하고, 다른 층의 사람이 문을 막지 않도록 했다.
- 경비가 계단 진입을 보았을 때만 목적 층을 기억하고, 계단으로 걸어가 추적하게 했다.
- 추격이 끝나면 자기 순찰 층으로 복귀한다.
- 가까이 스치자마자 피해를 받는 대신, 0.55초의 공격 준비와 원형 표시를 넣었다.
- 모바일은 별도 달리기 버튼 없이 스틱을 끝까지 밀면 달린다.
- 실제 터치 조작에서 작은 스틱 입력으로 좁은 출입구를 통과할 수 있는지 확인했다.
- 복장 허용 범위와 실제 행동 대상 이름을 계속 표시한다. 옷을 갈아입는 행동과 다른 행동이 섞이지 않는다.

## 검증 결과

- Godot 4.6.3 headless 회귀 검사 **32개 통과**: 두 층 충돌, 닫힌 문의 실제 시야 차단,
  다른 층·같은 층의 문 방해, 복장 허용/금지, 실제 순찰 전 구간, 계단 상행/하행 추격,
  기절과 사망 구분, 장부·탈출 조건 등.
- Chromium PC 키보드로 전체 목표 완료. 실제 스냅샷 기준 약 30.25초, 체력 3/3,
  신원 발각 1회. 경비는 아래층까지 추적했다. AI·체력·속도·판정을 변경하는 테스트 훅은 사용하지 않았다.
- 터치 모바일 브라우저 에뮬레이션에서 키보드 없이 전체 목표 완료. 약 34.57초,
  체력 3/3, 신원 발각 1회. 스틱과 공격 버튼을 동시에 누르는 멀티터치도 사용했다.
- DecompressionStream을 사용할 수 없는 경로에서도 fflate 대체 로더로 PC 전체 목표 완료.
- 각 완주 기록에서 브라우저 런타임 오류 0건. 소프트웨어 WebGL 환경이므로 실제 기기의 프레임 속도를 보장하는 측정은 아니다.
- 공식 Godot 4.6.3 비스레드 웹 템플릿의 WASM과 배포 gzip을 풀어 얻은 바이트가 일치한다.
  SHA-256: `26b61ce95247012ab3dca3ff51e96d1cdbff44ee91a8c20a83e150afca83f1b6`.

검사 실행법과 코드 위치는 `godot/README.md`, 재현용 브라우저 입력 스크립트는
`tools/godot/play_web.py`, 네이티브 검사는 `godot/tests/regression.gd`에 있다.

## 배포

`public/godot-vip/`는 공식 단일 스레드 WebGL 2 엔진을 사용한다. 공유 메모리/COOP/COEP
설정 없이 동작하며, 엔진의 WASM만 gzip 약 9.4MB로 묶었다. 게임 실행 시 다운로드는
약 12MB다. 모든 개별 정적 파일은 Cloudflare의 25MiB 제한 아래다.
프로젝트 ZIP은 편집 가능한 씬·스크립트·자산·라이선스를 포함하며 캐시·비밀 파일을 제외한다.
기존 두 도메인의 `/godot-vip/` 경로에 배포하며, Pages의 다른 프로젝트 디렉터리를 보존한다.
