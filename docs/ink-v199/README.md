# v199 · 수묵풍 인터페이스 마감

기존 수묵풍 타이틀을 실제 플레이 화면까지 이어가는 UI 보강이다. Mark of the Ninja 공식 스크린샷에서 모서리에 배치한 HUD, 선명한 인물·장비 실루엣, 읽기 쉬운 밝은 글자와 거친 재질의 조합을 참고했다. 맵·캐릭터 모델·AI 판정과 선형 성장 규칙은 유지한다.

- 직접 생성한 먹선 패널을 목표창·무전·장비 제목에 사용하고, 기존 금속 베벨 프레임은 단순한 원형/먹색 프레임으로 교체했다.
- 올빼미의 실제 캐릭터 초상과 이름을 HUD에 표시한다. 체력은 기존 세 칸을 세 개의 밝은 마름모로 표현한다.
- 접힌 목표창에는 현재 추적하는 목표 하나만 표시한다. 눌러 펼치면 기존 전체 목표와 완료 상태를 볼 수 있고, 수동으로 추적한 물품도 반영한다.
- 화면 제목에는 East Sea Dokdo를 사용하며, 본문과 조작 버튼에는 기존의 완전한 한국어 UI 글꼴을 유지한다. 기술 연결도에서 노란 강조를 흰색 계열로 정리했다.
- 모바일 버튼은 기존 오른쪽 배치·조작 영역과 PC 숨김 정책을 유지한다. 누르기·사용 가능·치명적 행동의 상태 차이도 유지한다.

## 원본과 라이선스

- 먹선 원본: OpenAI image generation. 정확한 프롬프트와 처리 내역은 `src/art/hud/ink-material.json`, 배포용 파일은 `ink-wash.webp`이다. 알파 가장자리 트리밍·크기 변환 후 27,960바이트이며 생성 원본은 별도로 보존했다.
- 프레임: 프로젝트용 직접 제작 SVG 기하 도형. 기존 Game-icons.net 아이콘과 CC BY 3.0 표기는 유지한다.
- 제목 글꼴: [East Sea Dokdo / YoonDesign](https://github.com/google/fonts/tree/main/ofl/eastseadokdo), SIL OFL 1.1. 출처·사용 범위와 전체 라이선스는 `src/fonts/ink-headings-source.json`, `OFL-EastSeaDokdo.txt`에 포함한다. 배포 글꼴은 작성된 의뢰명·화면 제목의 글리프를 포함한 102,868바이트 WOFF2이다.
- 참고 이미지는 [공식 Steam 소개](https://store.steampowered.com/app/860950/Mark_of_the_Ninja_Remastered/)의 스크린샷을 열어 확인했다. 해당 게임의 그림·로고·폰트 파일을 배포 에셋으로 가져오지 않았다.

## 검증과 재현

`python tools/capture_ink_interface.py after --url http://127.0.0.1:8001/public/`

1440×900, 390×844, 844×390, 320×568에서 타이틀·브리핑·대화·HUD·메뉴·기술·기술 상세·장비·완료 후 기술 선택을 촬영한다. 시각 비교용으로 고정 시계·시드·실제 맵 위치를 사용하고, CSS나 렌더링 결과를 주입하지 않는다. 각 화면에서 실제 먹선 이미지 디코딩, 제목에 사용된 실제 글꼴, 페이지 오류도 기록한다.

`first_steps_live.py`는 별도로 새 저장과 일반 RAF, 실제 키보드/CDP 터치를 사용해 튜토리얼 → 기술 선택 → 첫 암살 → 다음 편까지 진행한다. PC·터치 모두 첫 임무 체력3, 발각0이었다. 이는 맵을 아는 개발용 재플레이이며 신규 사용자 이해도 조사나 실제 iOS 기기 검증은 아니다.

기존 회귀 검사는 새 HUD의 접힘/펼침과 수동 목표 추적을 검증하도록 보강했다. 모든 프레임의 디코딩, 활성/눌림/치명적 행동의 시각 상태, 조작 영역과 겹침 검증도 유지한다. 최종 브랜치의 전체 회귀와 PC·모바일 재플레이는 PR CI 아티팩트에 남긴다.

정적 디자인 검사에는 기존 템플릿의 여백·지도 범례에 관한 6개 경고가 남는다. 신규 CSS의 실제 계산값과 캡처를 함께 확인하며, 이를 화면 전체에 문제가 없다는 인증으로 사용하지 않는다.
