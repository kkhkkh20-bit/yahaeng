# v161 · 갈아입기 접근성과 기본 제압 거리

옷 갈아입기는 삭제되지 않았지만, 기절자 옆에서 운반을 먼저 제안하면서 대상 목록 안에 묻혀 있었다. 사용 가능한 옷이 있으면 기존 붙잡기 자리에서 바로 갈아입기를 누를 수 있도록 한다. 당장 붙잡을 수 있는 적이 있을 때는 붙잡기가 우선이고, 갈아입기는 기존 대상 목록에서도 선택할 수 있다. PC에는 대상 버튼 옆에 표시한다.

기본 제압 거리가 32px(약 1m)라 터치로 순찰 뒤를 따라갈 때 접근을 과도하게 요구했다. 48px(약 1.5m)로 늘린다. 가까이서 제압하는 기본 액션과 112px(약 3.5m)에서 실제 이동하는 접근 암살 기술을 구분하며, 스킬 설명과 전후 효과 문구도 맞춘다.

변장은 공통 상호작용을 통해 3초를 채워야 완료한다. 기존 허용 복장·보안 구역·목격 판정은 유지한다. 기본 거리 변경은 뒤쪽 각도·시선 차단·같은 층 제한을 유지하며, 세 걸음 원거리 제압은 여전히 배운 기술이 필요하다. 새 자산·서체·외부 설치는 없다.

전후 화면은 같은 시드·좌표·인물을 사용한 열린 지상 통제 장면이다. 비교 촬영과 별도로 실제 버튼/키 입력으로 제압과 갈아입기를 검사한다. 본편 전체 완주나 실물 휴대폰 성능 측정으로 해석하지 않는다.

기초 두 연습의 실제 PC·터치 입력과 본편 진입, 준비 연습의 층 이동을 확인했다. 핵심 회귀 55개 중 기존 버튼을 누르던 검사와 잘못 배치한 경계 fixture를 수정해 다시 통과했다. 최종 패키지에서 관련 회귀 6개와 네 화면 크기의 전용 동작 검사를 통과했다. PC 버튼은 대상 선택 옆으로 옮겨 기술 버튼과 겹치지 않게 하고, 44px 이상 입력 영역과 모바일 조작 겹침을 검사했다. [회귀 기록](clothing-v161/regression.json).
