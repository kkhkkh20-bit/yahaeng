# v144 배치·대사·잠입 규칙

본편 6개 의뢰, 도시, 연습 4개 지도의 시설·소품 목록을 추출하고 배치와 사용 규칙을 점검했다. 목록은 1,958개에서 1,860개로 줄었다. 이는 오브젝트 목록과 배치 규칙 검사이며 모든 소품을 물리 시뮬레이션으로 바꾼 것은 아니다.

난이도는 경비 수나 투시 능력 대신 출입 통제, 도구 재고, 작업 시간과 경비 역할로 조정했다. 입문 시야·소리 연습은 유지한다.

## 대사

132곳의 개별 대사를 교체하고 도입부·경비 잡담·상태 반응도 다시 썼다. 과장된 농담과 처치 구호, 획득 사실을 혼잣말로 반복하는 표현을 덜었다. 인물은 자신이 알 만한 상황을 말하고, 행동 설명은 안내에 둔다. 의뢰에 필요한 방·카드·암호 단서는 유지했다. 감방 도입부에서 압수된 무전기로 조력자가 말하던 상황도 제거했다.

[개별 교체 기록](world-v144/dialogue-edits.json). 길어진 대사에서 초상화와 본문 높이가 어긋나는 모바일 레이아웃도 수정했다.

## 검증과 범위

- 11개 지도 1,860개 목록의 검사 규칙 위반 0건. 범위 밖 좌표, 무제한 은닉, 화물 사다리, 가스관 등반, 접근 공간을 검사했다.
- 기존 빠른 회귀 묶음 38개 중 최초 6개가 변경 규칙·대사창 문제로 실패했다. 실제 대사창 문제를 수정하고 변경 규칙에 맞춘 검사를 포함해 6개 모두 최종 재실행 통과했다.
- 새 규칙 검사: 조명 회로, 실제 다트 명중·빗나감·층 변경, 담배 대상, VIP 정전 반응, 이전 저장 이관, 기존 은닉 인원 보존 통과.
- 기존 119개 접근 경로와 층·지붕 차폐, 실제 계단을 통한 옥상 추적 재검사 통과.
- 대사창은 PC·세로·가로 6개 크기와 두 테마, 총 12개 조합에서 터치·키보드·긴 문장 스크롤 확인. PC·모바일 전후 화면 16장 기록.
