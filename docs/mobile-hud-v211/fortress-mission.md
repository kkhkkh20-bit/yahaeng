# 다음 레벨 방향: 적 기지 잠입

상태: 사용자 제안에 대한 설계 초안. 이번 HUD 배포에 요새·저격수·정문 봉쇄가 구현되었다는 뜻은 아니다.

## 한 판의 목적

기지 밖에서 표적을 확인한다 → 침입 경로를 선택한다 → 간부 한 명을 처치한다 → 출입문 밖으로 탈출한다. 서류 수집과 다른 간부 정보는 선택 보상으로 둔다. 첫 기지에서는 필수 목표를 늘리지 않는다.

## 공간과 경로

| 구역 | 역할 | 플레이 선택 |
| --- | --- | --- |
| 외곽 골목 | 정문과 감시탑을 안전하게 관찰 | 경비 교대와 간부의 이동을 확인 |
| 정문 검문소 | 가장 짧은 진입 경로 | 경비를 따로 유인해 기절시키고 복장 확보 |
| 측면 정비 통로 | 가장 안전한 우회 경로 | 벽과 적재물을 이용해 순찰 뒤로 이동 |
| 막사·중정 | 단지의 연결 공간 | 통행 가능한 복장과 지휘동 출입 제한을 분명히 구분 |
| 감시탑 | 긴 통로에 대한 압박 | 탐조등이 지나간 뒤 횡단하거나 전원을 차단 |
| 지휘동 2층 | 눈에 띄는 간부와 전용 행동 | 보고를 받는 방과 흡연 발코니 사이에서 기회 선택 |
| 경비실·출입문 | 처치 이후의 탈출 동선 | 경보 시 정문을 다시 열거나 이미 발견한 비상 출구 이용 |

정문→막사→지휘동과 측면 통로→정비 계단→발코니의 두 경로가 내부에서 연결되어야 한다. 들어온 길로만 되돌아가는 긴 왕복은 피한다. 지도와 실제 장면 모두 담장, 출입문, 지휘동이 즉시 구분되어야 한다.

## 적과 정보

일반 경비는 한 조직색, 지휘동 경비는 같은 색의 뚜렷한 장비 차이, 표적 간부는 붉은 외투와 고유 얼굴로 식별한다. 저격수는 감시탑에 실제로 배치하며 벽·옥상·폐쇄된 문을 관통해 보거나 쏘지 않는다. 먼 적도 최소한 탐조등이나 관찰 가능한 실루엣으로 위협을 사전에 알려야 한다.

시야는 모든 적의 원뿔을 계속 겹쳐 그리지 않는다. 선택한 적, 현재 접근 경로를 위협하는 적, 발각 진행 중인 적을 우선 표시한다. 복장이 통하는 구역과 신원을 확인하는 경비의 차이를 경고 없이 뒤집지 않는다.

발각의 첫 반응은 수색·호출이다. 저격 즉사로 처음부터 실패시키지 않는다. 정문이 봉쇄되더라도 경비실 조작과 비상 출구 중 적어도 하나는 항상 남겨 두며, 열쇠 소유자의 사망·시체 운반으로 탈출 불능이 되어서는 안 된다.

## 선형 성장

1. 작은 초소: 순찰 한 명, 기본 제압, 문밖 탈출.
2. 외곽 전초: 두 명을 유인으로 분리, 복장 확보와 출입 구역.
3. 폐쇄 기지: 2층 간부, CCTV와 경비실, 처치 후 경보를 끊고 탈출.
4. 지휘부 요새: 탐조등·저격수·증원, 이미 익힌 수단을 조합.

한 에피소드에서 새 판단은 하나씩 추가한다. 기술 포인트는 기존 원칙대로 완료 후 소량 지급하고 다음 진입 전에만 사용한다. 초기 기지의 필수 경로는 특정 구매 기술을 전제로 막지 않는다.

## 첫 프로토타입의 합격 조건

표적과 출구를 설명문 없이 식별할 수 있고, 기본 기술만으로 두 경로 모두 완료 가능해야 한다. 정문 봉쇄와 전원 차단, 시체 발견, 간부의 동선 변경을 각각 발생시켜도 목표와 탈출 안내가 유지되어야 한다. 모바일에서 큰 행동 버튼과 하단 보조 아이템만으로 유인→제압→변장→처치→탈출을 완주하고, 이후 AI를 정상 가동한 실제 입력 재플레이로 검증한다.
