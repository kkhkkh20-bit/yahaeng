# v115 · 자체 리뷰와 조작 신뢰성 개선

2026-11-01 · [PC·모바일 전후 화면](review-v115/index.html)

화면을 다시 확인하고, 약국 → 포차 → 사무동 2층 책상을 실제 이동 입력으로 연결했다. 이번 리뷰의 핵심은 **준비가 중간에 막히고, 눈에 보이는 사물과 조작 결과가 어긋나는 문제**였다.

## 발견과 수정

| 발견 | 수정 |
| --- | --- |
| 문지기가 식사를 끝내면 설사약 사용과 공략 안내가 막힘 | 식탁에 실제 양념통을 놓고 사용 대상으로 연결. 그릇이 비어 있어도 다음 식사를 준비할 수 있음 |
| 약을 넣은 상태를 알아보기 어렵고, 빈 그릇도 ‘문지기 식사’로 표시 | 가까이에서 `약을 넣은 양념통`·`빈 그릇`으로 구분. 새 안내 패널 없이 기존 한 줄 표시 사용 |
| 식탁 가까이의 특정 각도에서 음식이 사라짐 | 받침 가구에 시야가 닿으면 그 위 물건을 표시. 중간 벽·다른 층·다른 높이는 계속 차단 |
| 약병이 머리보다 높은 최상단 선반에 있음 | 기존 가구의 아래 선반으로 내려놓고, 그 자리에 일반 약품이 겹쳐 그려지지 않게 처리 |
| 물건을 집거나 사용하는 접촉 효과가 주인공 발밑에 뜸 | 실제 약병·양념통·메모의 그림 위치에 작게 표시 |
| 메모가 즉시 열려 읽는 동작이 생략됨 | 0.45초 손 동작 후 메모와 비밀번호를 한 번 적용. 멀어지거나 다른 층으로 이동해 취소하면 정보를 얻지 않음 |
| 첫 화면이나 시간이 멈춘 상태에서 은신 표시가 체력 줄과 겹치고 미니맵이 비어 있음 | 상단 내용 갱신 후 높이를 측정. 지도 그리기 주기와 배치 측정을 분리하고 새 의뢰는 즉시 그림 |
| 식사를 마친 인물이 밀려나면 다시 식탁으로 가는 상태에 머물 수 있음 | 완료한 식사는 유지하고 복귀 상태로 전환 |

양념통에 넣은 약은 문지기가 실제로 식탁 앞에서 식사를 마쳐야 효과가 난다. 그릇이 비어 있는 동안 준비했다고 즉시 인물을 이동시키거나 약효를 적용하지 않는다. 기존 저장본의 약 사용·식사 진행은 유지하며 사용 위치만 새 양념통으로 맞춘다.

## 검증

- `t_review_v115.py`: PC·모바일에서 빈 그릇 상태의 준비, 실제 표면의 접촉 위치, 접근 가능한 식탁 주변 여섯 위치의 표시, 벽·층·높이 차단, 상태 문구, 메모 읽기 지연·연타·취소, 이전 사용 위치 복원, 첫 화면 HUD 겹침·미니맵 초기화 검사.
- `t_review_walkthrough.py`: PC 키 이동·모바일 조이스틱 이동 × 세 배치로 약국에서 약 집기 → 포차에서 준비 → 실제 계단을 거쳐 2층 메모 읽기를 여섯 번 완료. 플레이어 위치 이동·열쇠 지급 없이 진행. 이 경로 검사는 NPC 시뮬레이션을 고정한다.
- `t_surfaces_dining.py`: 전체 NPC 39명을 함께 실행한 식사·화장실·복귀, 실제 키보드·터치 입력, 준비의 한 번 소모, 저장 복원과 구버전 저장 유지 검사.
- `t_mission_flow.py`: 기존 여섯 의뢰 × 세 배치 × PC·모바일의 36개 완료 경로.
- `t_product_plan.py`, `t_rendezvous.py`: 기존 술병 유인과 내선 매복, 준비 저장·중단·재시도 유지.
- `t_controls_readability.py`, `t_camera_presentation.py`, `t_play_clarity.py`: 조작 우선, 중요 대화, 화면 경계 108개 조건, 과도한 부가 설명 방지.
- `t_ai_feedback.py`, `t_fixture_lighting.py`: 기존 시야·휘파람·은폐·성능 조건과 시설 조명 처리 유지.
- 같은 Chromium 환경에서 HUD 갱신 300회 비교의 중앙값은 PC·모바일 크기 모두 v114·v115 약 0.3ms, 95백분위는 약 0.5→0.6ms였다. 실기기 전체 프레임율 측정은 아니다.

검증은 Chromium에서 수행했다. 전후 화면은 같은 배치 확인 상황을 고정한 게임 캡처이며, 전체 임무를 사람이 플레이한 재미 평가나 모바일 실기기 성능 측정과는 범위가 다르다. 전체 테스트 묶음이 모두 통과했다는 의미는 아니다.

## 리뷰 판단

이번 수정으로 준비·실행·결과를 더 일관되게 읽을 수 있게 했다. 임무 전체의 긴장감과 난이도가 완성됐다고 보지는 않는다. 문지기의 평상시 식사만으로도 입구가 오래 비는 점, 공략별 위험과 보상의 차이는 계속 조정할 핵심 항목이다. 이번에는 검증된 조작·표시 오류를 먼저 수정했다.
