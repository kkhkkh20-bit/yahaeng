# v170: 첫 경비를 제압하고 갈아입은 뒤 숨기기

첫 의뢰의 약 20초를 기준 장면으로 잡고, 행동의 연결과 입력 신뢰도를 개선했다. 기존 Graphite HUD와 모바일 전용 버튼 배치를 유지한다. PixelFX 효과의 종류를 추가하지 않았으며, 캐릭터의 기존 자세 프레임과 실제 접촉 효과를 연결하는 작업이다.

## 재현한 문제와 변경

v169에서 제압이 끝나기 약 0.16초 전에 행동 버튼을 누르면, 옷을 입지 않은 상태에서도 운반·은닉이 예약됐다. 같은 장면에서 제압이 끝난 뒤 누르면 갈아입기가 선택되므로, 입력 시점에 따라 다른 행동이 나왔다. 실제 PC·터치 입력으로 두 경우를 재현했다.

v170은 마지막 0.25초의 후속 입력에서도 같은 경비의 유효한 옷을 먼저 선택한다. PC Y와 모바일 갈아입기 버튼도 이 구간에서 입력을 받는다. 기존 복장과 같은 옷이면 운반·은닉을 선택하며, 옷이 사라지거나 다른 사람이 먼저 가져가면 예약을 취소한다. 취소된 갈아입기를 운반으로 바꾸지 않는다. 이동·피격·메뉴 열기는 예약을 취소하고, 처치는 예약하지 않는다.

갈아입는 동작은 낮은 곳에서 옷 집기 → 몸 일으키기 → 상체에서 정리하기 → 원래 자세로 복귀하기로 나눴다. 복장·권한은 기존처럼 3초 동작을 마친 뒤에만 바뀐다. 제압 시작 때 대상의 기존 위치에서 접촉 자세로 이어지는 시각적 보정을 추가하고, 몸 떨림을 줄였다. 효과 감소 설정에서는 떨림을 생략한다. 제압 사거리·시야·적의 계단 추격은 바꾸지 않는다.

## 다트의 의도와 이동 예측

자동 조준은 경비와 표적을 고른다. 일반 시민은 플레이어가 직접 표시했을 때만 후보에 들어간다. 아이는 계속 제외한다. 직접 표시한 대상도 사거리·시야·층 조건을 통과해야 한다. 기존처럼 시야가 확보된 옥상에서 거리로 던질 수 있으며, 예약한 대상의 높이가 바뀌면 발사를 취소한다.

출발 직전 예약 대상의 상태·거리·층을 다시 검사하고, 유효하지 않으면 탄약을 쓰지 않는다. 최근 실제 이동량을 이용해 투척 지점을 앞에 잡는다. 던진 뒤의 지점은 고정되어 추적하지 않는다. 급회전, 벽 뒤 이동, 층 변경으로 빗나갈 수 있다. 다트·쿠나이의 기술 해금 조건과 탄약 제한은 유지한다.

## 확인 결과와 범위

작업 중 핵심 회귀 스크립트 67개, 빌드 파이프라인 7개 검사, 스프라이트 소유권과 도달 검사를 통과했다. 배포 패키지는 PC·터치 입력과 HTML·스크립트·폰트 8개 파일 해시를 확인했다. 최종 높이 검증 보완 뒤 다트 의도·옥상 경로·월드 물리·기술 제한 검사를 다시 통과했다.

- 첫 구간은 두 난수 시드(42, 113), PC 키보드·모바일 CDP 터치, 일반 행동·갈아입기 전용 입력으로 실행했다. 네 실행 모두 약 14.56초에 제압·변장·은닉을 마쳤다. 체력 3, 발각 0, 경보 0, 살상 0, 제압 1, 변장 1, 은닉 1이었다.
- 첫 의뢰 전체도 PC와 모바일에서 장부 회수·실장 처치·탈출까지 통과했다. 기술을 배우거나 다트를 쓰지 않았다. PC는 체력 3·그림자, 모바일은 체력 3·암살자였다. 전체 의뢰의 무발각 완주를 두 기기 모두 달성했다고 보지 않는다.
- 제어된 회귀 장면에서 늦은 입력, 잘못된 대상 전환 방지, 이동·피격·일시정지 취소를 검사했다. 이동 다트 명중, 급회전 회피, 벽·층 차단, 시민 직접 선택과 기술 제한은 별도 회귀 장면에서 검사했다.

재현 스크립트: `tests/tutorial/opening_loop.py`, `tests/tutorial/contract_intro_walk.py`, `tests/rev/t_recovery_buffer.py`, `tests/rev/t_dart_intent.py`. 실행 결과는 `docs/feel-v170/`에 보관한다.

캠페인 검증은 실제 키보드·터치 입력을 쓰되 시뮬레이션 시간을 나누어 진행한다. 위치·체력·인벤토리·해금·미션 상태를 덮어쓰지 않으며, 경비와 보안은 작동한다. 사람의 실시간 재미 평가나 모든 의뢰·모든 모션의 완성 검증은 아니다. 이번 개선의 확인 기준은 첫 장면에서 같은 입력이 같은 의도로 이어지고, 그 결과가 동작과 상태에 맞게 나타나는 것이다.
