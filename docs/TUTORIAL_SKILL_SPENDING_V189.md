# 튜토리얼의 기술 포인트 사용 안내 (v189)

추천 기술·추천 경로 대신 포인트를 직접 쓰는 방법과 시점을 가르친다. 기존 v188의 제압 연결 입력과 이동·발소리 변경은 유지한다.

첫 연습(tB)의 첫 이동 직후, 안전한 시작 구간에서 기술 화면을 열고 원하는 기술 하나를 배우도록 안내한다. PC는 K, 모바일은 메뉴 → 기술 트리 경로를 안내하고 해당 메뉴 버튼에 기존 연습 테두리를 표시한다. 일시정지 화면에도 보유 포인트와 기술 버튼 테두리를 표시한다. 실제 구매 후 연습으로 돌아오면 달리기와 발소리 연습이 이어진다. 세 계열 중 어느 기술을 먼저 배워도 되며, 화면을 열기만 해서는 구매 연습이 완료되지 않는다.

이미 배운 기술이 있는 저장 기록은 추가 포인트를 쓰지 않고 이 단계를 통과한다. 시작 예산은 기존 4P다. 구매는 실제 저장 기록에 남으며, 구매 이전 체크포인트로 돌아가도 다시 구매할 필요가 없다. 별도의 임시 기술·보너스 포인트는 지급하지 않는다. 기본 연습의 기술 효과 제한과 고급 연습의 임시 적용 규칙은 유지한다.

첫 의뢰(p0)와 본편의 출발 전·완료 화면에서는 보유 포인트와 「원하는 기술을 배우세요」 문구만 표시한다. 기술 화면을 열면 전체 트리를 보여 주며 특정 노드를 미리 선택하지 않는다. 추천 경로 목록과 추천 경로의 다음 기술 버튼은 제거한다. 사용자가 선택한 기술의 효과·비용·필수 선행 조건은 계속 표시한다.

검증은 실제 구매·복귀 버튼, 구매 없는 복귀, 세 계열의 첫 기술 구매, 구매 전 체크포인트 복원, 포인트를 이미 모두 쓴 저장 기록의 재연습을 포함한다. 화면 검사는 PC·휴대폰 세로·가로 크기에서 출발 버튼 가시성을 함께 확인한다. 튜토리얼 단계와 완료 화면을 제어하는 회귀 검사와, 단계·좌표·시간을 바꾸지 않고 실제 입력으로 처음 두 연습을 완주하는 일반 RAF 재생을 구분해 기록한다. 브라우저의 터치 입력 재생은 실물 휴대폰 사용자 실험을 뜻하지 않는다.

Chromium과 WebKit에서 각각 PC 1280×800·휴대폰 390×600·가로 844×390의 준비/복귀 검사와 세 계열의 첫 구매·체크포인트·0P 재연습 검사를 통과했다. 일반 RAF·비고정 난수에서 PC 키보드와 모바일 터치로 기술을 구매하고 첫 두 연습을 완주했다. 시야/소리 연습은 양쪽 모두 직접 발각 0회·체력 3, 두 번째 제압 연습은 모바일에서 반격 1회·경보 1회가 있었고 체력 3으로 완료했다. 무경보 완주나 초보 이용자 실험으로 주장하지 않는다.
