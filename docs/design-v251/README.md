# v251 — 기존 기술 연결도 복원, 타이틀 디자인, 변장 보고 판정

기술 화면의 틀을 바꾸지 말라는 요청에 따라 v250의 카드 목록을 제거하고, 기존 27개 원형 노드·24개 실제 선행 연결·PC 3계열·우측 설명창을 복원했다. 기술·비용·해금 순서·첫 완료 1P 지급은 그대로다.

## 디자인

- 차콜 바탕, 황동 연결선, 습득한 노드의 밝은 채움, 선택한 노드의 적갈색 테두리로 상태를 구분했다. 이름과 비용 아래에서 연결선이 시작한다.
- 원래 설명창 안에 기본/습득 후 비교와 기존 동작 안내를 유지했다. 긴 규칙은 펼쳐서 읽는다. PC는 우측 영역, 모바일은 기존 우측 오버레이이며 닫기·Escape·포커스 제한을 지원한다.
- 메인은 기존 구매 에셋과 현재 여성 요원으로 구성한 도시 화면을 촬영하고, 큰 제목과 간결한 텍스트 메뉴로 정리했다. 메뉴 동작과 저장 데이터는 그대로다.
- 타이틀 배경은 **기존 선택형 도시 아트 스터디를 메뉴용으로 연출한 장면**이다. 기본 에피소드 맵을 새로 만들었다는 증거가 아니다. 촬영 시 경비·CCTV·HUD를 제거했다. 생성형 일러스트나 레퍼런스 게임의 그림을 제품에 넣지 않았다. 재현: `tools/capture_title_v251.py`.

2. [세키로 공식 메뉴 설명](https://www.fromsoftware.jp/manual/sekiroshadowsdietwice/win/pausemenu2.html): 선택 테두리와 정보 강약.

## 변장 보고 판정

원인은 `goAlert`와 `blowDisguise`가 한 목격자의 기억을 즉시 `P.blown`/`disguiseBlown`에 영구 기록하던 부분이다. 경비별 판정은 별도 기억을 쓰는데 HUD·통행 안내·재착용은 전역 플래그를 사용해 서로 달랐다.

- **직접 목격 / 근처 외침 수신**: 해당 인물의 `suspectMemory`에만 기록한다. 듣지 못한 경비는 모른다. 기존 벽·거리·층·높이별 청취 제한은 유지한다.
- **무전 중**: 완료 전 제압하면 전체 보고를 중단한다. 다른 목격자가 남아 있는지에 따라 완료 문구를 구분한다.
- **보고 완료 / 실제 CCTV 관제 보고**: 관측 당시의 복장만 `knownLooks`에 공유한다. 이후 보고자를 제압해도 이미 전달된 정보는 남는다.
- **복장 교체**: 보지 못한 새 옷은 모른다. 실제 보고된 옷을 재착용하면 알아본다. 갈아입는 장면을 본 목격자는 새 옷도 기억한다.
- **기절**: 의식이 없는 목격자는 현재 위험 표시에서 빠진다. 깨어나면 기존 기억을 유지한다. 기절이 영구 기억 삭제는 아니다.
- **예전 저장**: 전역 플래그를 완료 보고로부터 다시 계산해 잘못 남은 복장 발각을 제거한다. 실제 보고·경비별 기억·체력은 보존한다. 기존 수색 종료 시에도 공유 플래그를 함께 정리한다.

HUD는 목격자만 알아봄 / 인상착의 보고 중 / 인상착의 전체 공유 / 미전달을 구분한다. 동료 인사 역시 해당 경비의 실제 통행 판정을 사용한다. 현장이나 쓰러진 사람 때문에 수색은 계속될 수 있으며, 이것이 곧 현재 복장 공유라는 뜻은 아니다.

## 검증과 한계

- `t_skill_tree_finish`: 320×568, 390×844, 844×390, 1024×768, 1440×900. 실제 27개 노드·24개 선행 연결, 모바일 1계열/PC 3계열, 비용·잠금·습득·재분배, 설명창 위치·포커스·리사이즈, 첫 완료 1P를 확인했다.
- `t_skill_diagram`, `t_interface`, `t_menu`, `t_new_campaign`: 실제 클릭·키보드·터치 흐름, 선행 노드 탐색, 복귀, 폰트 및 폰트 다운로드 실패 시 시작까지 확인했다.
- `t_disguise_reports`: PC/모바일 크기의 **통제된 실제 게임 함수 검사** 8종. KO/살해 중단, 청취한 목격자/원격 경비 분리, 보고 후 사망, 옛 복장 지연 보고, CCTV 독립 보고, 구버전 저장 복구, 수색 종료를 확인했다. 전체 미션 플레이를 대신하는 검사는 아니다. [결과](disguise-reports.json).
- `t_disguise_ai`, `t_disguise_passers`, `t_disguise_lighting`, `t_ai_evidence`, `t_security_readout`, `t_multilevel_pursuit`: 기존 권한·통과·신원 확인·목격·청취·카메라·층간 추격 회귀 검사를 통과했다. 신원 확인 회귀 검사는 새 규칙에 맞게 ‘목격자 기억 있음 / 전체 보고 전’으로 명시했다.
- `node tests/integration/physical_interactions.cjs`: 실제 소스 함수 기반 20개 묶음을 통과했다. `t_walkway_clearance`의 27개 맵·115개 수납장·기존 17개 이동과 예전 저장 복구도 유지된다.
- `first_steps_live`: 일반 RAF·실제 키보드/CDP 터치·전체 작성된 AI를 유지한 첫 에피소드 완주. PC/터치 모두 체력 3, 발견 0, 기절 2, 운반 숨기기 1. 결과 후 실제 1P 습득과 다음 에피소드 준비 진입도 확인했다. [PC](native-first-pc.json) · [터치](native-first-mobile.json). 알려진 경로의 개발자 재생이며 초보자 사용성 연구나 실제 iPhone Safari 검사는 아니다.
- 로컬 패키지: 원본과 공개 HTML·스크립트·폰트 14개 해시 일치, 기본 URL 시작·키보드/터치 이동·목표 확인 시 정지/복귀·메뉴 복귀를 확인했다. [결과](local-release.json).
