# 막힌 골목·공격 동작·범인 인지 · v90

대청소 남쪽 빌라와 포차 사이 골목은 북쪽이 두꺼비집, 남쪽이 반대편에서만 푸는 빗장으로 막혀 있었다. 옆 골목의 수거함도 같은 구조였다. 두 시설물을 옆으로 옮겨 북쪽 큰길로 걸어서 나갈 수 있게 했다. 시설물 그림·상호작용·NPC 수리 목적지는 새 좌표를 사용한다. 쪽문은 기존 방향에서만 빗장을 푸는 지름길이다.

`fixtureMoves`를 새 지도와 구버전 체크포인트 모두에 적용한다. 이동한 수거함의 객체·보관 수량을 유지하며, 숨은 플레이어도 같은 수거함에 남긴다. 새 시설물 위치에 저장된 플레이어는 비워진 원래 칸으로 복구한다. 체력·임무 진행을 초기화하지 않는다.

공격 동작 타이머는 매 NPC 갱신 때 줄인다. 싸움의 마지막 일격이나 입막음 후 일상으로 돌아갈 때도 주먹질이 끝난다. 접촉 공격은 같은 층·높이이며 벽이 없는 실제 사거리에서만 유효하다. 닿지 않는 상대를 향해 계속 공격하지 않고 기존 경로 복귀 규칙을 따른다.

## 인지 기준

| 상황 | 반응 |
| --- | --- |
| 보이지 않은 처치 뒤 평범하게 나타난 플레이어 | 지난 범행 시각만으로 범인으로 특정하지 않는다. 침입·운반 등 현재 보이는 행동은 별도 판정한다. |
| 시체만 발견 | 현장 수색. 얼굴·복장 기억과 플레이어 추격을 새로 만들지 않는다. |
| 실제 공격 목격 또는 신원 신고 | 목격된 얼굴·복장에 기존 추격 규칙을 적용한다. |
| 상대 조직 복장으로 공격하는 모습 목격 | 기존 조직 누명·전쟁 기획 유지. 숨은 플레이어의 복장을 자동으로 읽지 않는다. |
| 동료 시체를 상대 조직 구역에 옮겨 둠 | 기존 시체 이동을 통한 조직 누명 유지. 사고사는 이 증거에서 제외한다. |
| 다트 누명 | 같은 층·높이에서 벽 없이 보이는 상대 조직이 있어야 한다. |
| 목격 없는 NPC끼리의 처치 | 게임 내부의 가해자 기록만으로 전쟁을 만들지 않는다. 동료가 현장을 조사하며 플레이어의 경보·시체 감점에 더하지 않는다. |

## 검증

- 관련 회귀 14개 통과: `t_access_evidence`, `t_fac`, `t_instig`, `t_disguise_ai`, `t_patrol_motion`, `t_combat_policy`, `t_mission_flow`, `t_world_alignment`, `t_environment_targets`, `t_interaction_flow`, `t_roof_routes`, `t_stair_geometry`, `t_camera_presentation`, `t_scene_layers`.
- 두 골목의 PC·모바일 이동과 실제 키보드·터치 조이스틱 입력, 구버전 체크포인트 및 보관 시체 유지 확인.
- 실제 싸움 마지막 일격 → 일상 복귀, 벽·높이 분리, 목격 여부에 따른 신원 인지, 양쪽 조직의 시체 수색, NPC 범행 목격/비목격 비교.
- 6개 임무 × PC/모바일 × 3개 물건 배치 = 36개 목표 달성·탈출 경로 통과. 검증 도중 목표·열쇠를 부여하거나 플레이어를 순간 이동시키지 않는다.
- 기존 다트 누명 테스트는 상대를 고정된 도로에 배치하도록 보완했다. 옛 테스트의 무작위 건달파 주변 배치는 벽 너머 상대를 누명 대상으로 요구할 수 있었다.
