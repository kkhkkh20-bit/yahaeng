불편한 조작을 구분하기

첫 의뢰를 직접 플레이하고, 갈아입기와 운반이 충돌하는 선택 구조·겹치는 시작 시야·장비 없는 CCTV 대응을 수정했습니다. 새 저장에서 기술을 배우거나 다트를 사용하지 않고 PC와 모바일 입력으로 각각 완주했습니다.

게임 플레이 →레벨 설계·검증 상세플레이 결과 원본 JSON

플레이에서 확인한 문제

옷을 입으려는 상황에서도 ‘운반’이 먼저 선택됐습니다. 다시 내려놓고 갈아입기를 고르는 동안 정문 경비에게 들켜 작업이 중단됐습니다. 사무동에서는 미습득 조명이 비밀번호 입력을 가리고, 금고 경비가 출입구를 계속 막고 있었습니다.

이번에 바꾼 첫 의뢰의 흐름

서쪽 풀숲에서 관찰 → 제압 → 갈아입기 → 가까운 화단에 은닉
→ 공개 야시장에서 금고 번호 엿듣기 → 카메라 회전 관찰·우회 또는 근접 전선 분리
→ 장부 회수 → 사무동 내선으로 실장 유인 → 처치 → 서쪽 탈출
  • 쓸 수 있는 옷은 갈아입기를 먼저 제안하고 선택을 유지합니다. PC는 Y, 모바일은 전용 갈아입기 버튼을 사용합니다. 운반과 은닉도 별도로 선택할 수 있습니다.
  • 첫 변장 구간에 실제 적재물 엄폐와 화단을 추가했습니다. 금고 경비는 사무실과 출입구를 오가므로 관찰 후 지나갈 틈이 있습니다.
  • 일반 CCTV는 같은 층에서 40px 이내로 접근하면 기술 없이 2초 동안 전선을 분리할 수 있습니다. 목격될 수 있고 경비는 빠진 전선을 확인합니다. 기존 녹화는 관리실에서 지워야 합니다.
  • 미습득 기술 안내가 실제로 쓸 수 있는 비밀번호·문 행동을 가리지 않게 했습니다. 직접 고른 단서와 목표는 계속 우선합니다.

두 실행 모두 기술 구매 0, 다트 사용 0, CCTV 전선 분리 2회입니다. 모바일은 표적의 몸이 발견되면서 경보가 발생했습니다. 첫 수동 입력 시도에서도 표적 처치 때 경보가 났으므로 모든 시도를 무경보 성공으로 기록하지 않습니다.

캠페인 난이도 설계

의뢰주요 판단설계 방향과 반영 범위
01 VIP관찰 · 제압 · 변장 · 은닉한 명을 상대하고 정리한 뒤 정보·카메라·금고로 확장합니다. 이번에 배치와 자동 안내를 실제 수정하고 완주했습니다.
02 대청소두 표적 · 열쇠의 순서 · 층간 이동수금원 → 창고 → VIP → 사무동의 단계별 계획. 공개 골목을 다시 관찰할 수 있는 완충 공간으로 씁니다. 기존 맵과 안내를 유지하고 공통 CCTV 선택지를 적용했습니다.
03 배신맨손 탈출 · 장비 회수의 선택머리핀 → 간수 회피 → 2층 무전기 → 대체 출구. 장비 회수를 강제하지 않습니다. 기존 맵을 유지하고 장비 없이 CCTV를 다룰 수 있게 했습니다.

아직 남은 문제

첫 의뢰는 여전히 배울 규칙이 많습니다. 두 번째 카메라와 창문은 가까워 행동 목록에서 고를 필요가 있고, 모바일은 이동 시간이 길어져 순찰과 만나는 시점도 달라집니다. 다음 검토 대상은 02·03의 전체 무기술 완주, 실물 휴대폰에서의 선택 가독성, 정예의 복장 확인과 경보 전달 원인이 얼마나 명확히 보이는지입니다.

검증 범위: Chromium의 실제 키보드 및 CDP 터치 입력, 전체 캠페인 AI·CCTV·무전·증원 동작. 재현을 위해 게임 시간을 나눠 진행하고 상태를 읽어 동선과 시점을 정했습니다. 위치·체력·장비·기술·목표 진행은 덮어쓰지 않았습니다. 사람의 실시간 초회 플레이나 실물 휴대폰 실험은 아닙니다. 02·03의 전체 완주를 검증했다는 뜻도 아닙니다. 새 지형 배치는 새 의뢰에서 적용됩니다.
