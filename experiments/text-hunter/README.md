# 문자 사냥 (Text Hunter) — v0.25

메모장 속 열린 입 하나로 시작해 적의 뒤를 잡고, 문자를 흡수해 미로를 지우고 다시 쓰는 실시간 사냥 게임.

## 실행
[게임 파일 열기](./index.html) 또는 `index.html`을 내려받아 Chrome / Edge / Safari로 실행합니다. HTML 단일 파일이며 추가 설치는 필요 없습니다.

## 조작
- 방향키 / WASD: 이동
- Space / 모바일 `+ 쓰기`: 먹물 1개로 전방에 임시 벽 작성 (8초 지속)
- Tab: 지도 / P: 일시정지 / R: 다시 시작

## 규칙
- 입이 벌어진 쪽이 공격 방향. 상대의 뒤에서 접근해야 먹을 수 있고, 정면·측면 충돌은 위험합니다.
- `@` 흡수 → 중앙에서 북·동·남·서 4개 문 중 원하는 곳 개척
- `&` 흡수 → 기존 사냥터 사이 순환로 연결
- `%` 흡수 → 외곽의 위·아래 지름길 연결
- 임시 `+` 벽으로 적을 우회시키고, 자신이 만든 지름길로 상대의 뒤를 노릴 수 있습니다.

## 적 AI
- `@` 순찰형 — 직진을 선호하고 발견 후 짧게 추적
- `&` 추격형 — 마지막으로 본 위치를 끈질기게 조사
- `%` 매복형 — 예상 진로의 교차로에서 기다리는 성향
