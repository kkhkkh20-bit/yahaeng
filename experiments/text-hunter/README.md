# 문자 사냥 (Text Hunter) — v0.24

메모장 속에서 문자로 이루어진 적의 뒤를 잡고, 먹은 문자로 같은 문자의 벽을 지우며 미로를 확장하는 실험 게임입니다.

## 실행하기
- [게임 파일(index.html)](./index.html)을 다운로드하여 Chrome 또는 Edge에서 열어주세요.
- 별도 설치 및 서버가 필요 없는 단일 HTML 파일입니다.
- GitHub Pages를 사용하려면 이 폴더의 `index.html`이 공개되도록 배포 설정이 필요합니다.

## 조작
- 방향키 또는 WASD: 이동
- Space: 먹물 자원을 사용해 전방에 임시 벽 쓰기 (먹물 보유 시)
- P: 일시정지
- R: 다시 시작
- 모바일: 화면의 방향키와 + 쓰기 버튼

## 게임 규칙
1. 입이 벌어진 방향이 정면입니다.
2. 적의 뒤에서 접근하면 적의 문자를 흡수합니다. 정면/측면 접촉은 위험합니다.
3. `@` 적을 잡으면 `@` 벽, `&` 적을 잡으면 `&` 벽을 먹으며 다음 구역을 개척합니다.
4. 먹물로 임시 `+` 벽을 써서 적의 이동 경로를 바꿀 수 있습니다.
5. 새 지역이 열려도 중앙의 기존 미로가 유지되며, 개척한 경로는 적도 이용합니다.
