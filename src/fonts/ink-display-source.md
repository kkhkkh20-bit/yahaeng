# Ink Display

Black Han Sans Regular, Google Fonts, SIL OFL 1.1.
Source: https://raw.githubusercontent.com/google/fonts/main/ofl/blackhansans/BlackHanSans-Regular.ttf
Retrieved: 2026-10-31.
License: OFL-BlackHanSans.txt in this directory.

`ink-display.woff` is a 254-glyph subset for the optional ink art study. It contains ASCII, current stage names and the principal menu/result headings. FontTools was used for subsetting and WOFF export. The original full font remains outside the repository; the existing two-glyph title font is unchanged.
