# Quick item pictograms

Four authored 40×40 SVG UI pictograms: a discarded can (stone), cigarette packet (coin), smoke canister (smoke), and handheld radio (radio). Shapes and colors name existing gameplay inventory; no health-potion mechanic or extra stock is implied. These are deterministic geometric interface assets, with no generated raster or external source. The general action silhouettes in the adjacent HUD directory retain their existing game-icons.net license and credits.
